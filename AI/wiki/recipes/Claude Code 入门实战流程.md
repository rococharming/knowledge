# Claude Code 入门实战流程

这页提炼自 [[Claude Code入门]] 中的 todo 应用实战部分，目标是保留“先规划、再确认、再执行、最后验收”的入门操作路径。它和 [[Claude Code 权限模式]] 的关系是：不确定需求时先用 `plan` 模式生成方案，确认后再进入可编辑执行。

## 基本流程

1. 进入项目目录后启动 `claude`。
2. 先切到 `plan` 模式，让 Claude Code 根据自然语言需求规划功能和技术方案。
3. 阅读方案，补充或修正需求；如果方案不符合预期，继续让它调整。
4. 方案确认后，让 Claude Code 按计划创建文件、修改代码并运行必要检查。
5. 执行完成后查看实际效果，并根据结果继续迭代。

## 使用建议

- 入门练习优先选择边界清楚的小应用，例如静态 todo、计数器、表单校验或单页工具。
- 第一次生成方案时，不要急着执行；先检查功能范围、文件结构、技术选择和验证方式。
- 如果任务涉及真实项目，先让 Claude Code 阅读仓库并输出计划，再决定是否进入可编辑模式。
- 执行后要看实际结果或运行测试，不要只根据 Claude Code 的完成描述判断任务已经结束。
