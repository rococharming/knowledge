
# 一、会话管理

会话管理用于统一查看和管理各 AI Agent 产生的历史会话。Coding Agent 在工作过程中通常会将会话记录保存在本地，其中包含用户输入、Agent 回复、工具调用以及项目路径等信息。CC Switch 会读取这些 Agent 已有的本地会话数据，并提供统一的浏览、搜索和恢复入口。

# 二、查看会话

在 CC Switch 首页点击 「会话管理」：

![[assets/Pasted image 20260809164323.png|600]]

进入到会话管理界面：





CC Switch 会话管理可以查看多种 AI 工具的会话记录并提供了切换AI工具的入口：


选择「全部」时会话列表会展示所有AI工具的会话记录，也可以选择只查看某个AI工具的会话。

此外，对于会话展示，可以选择「列表」和「分类」选项：




「分类」选项下，可以查看每个项目下的会话，更加清晰：



如果会话内容过多，也可以通过搜索会话：



点击会话可以查看当前会话的对话记录，这里可以看到会话完整的提示词内容，包括用户提示词、工具调用流程、工具输出内容 等：



# 三、恢复会话

会话详情提供了 恢复会话 和 删除会话 功能，点击「恢复会话」会打开终端工具并恢复当前会话，点击「删除会话」可以清除当前会话记录：



恢复会话使用的终端与设置中配置的打开终端对应。对于 macOS，CC Switch默认选择的是 Terminal.app。

如果想要配置其他终端，在设置 -> 通用 -> 首选终端进行选择：

![[assets/Pasted image 20260809170622.png|600]]
