# 一、供应商

供应商（Provider）是一套完整的模型接入配置。它通常包含名称、API 端点、认证信息和模型配置；切换供应商，就是让 CC Switch 将目标配置写入对应 AI 工具的配置文件。

## 1、配置组成

| 配置项 | 作用 |
|---|---|
| 名称 | 在 CC Switch 中识别和区分供应商 |
| API 端点 | 指定请求发送到哪个服务地址 |
| API Key 或登录信息 | 完成身份认证 |
| 模型配置 | 指定默认模型或模型角色映射 |

API 协议和配置字段会因受管工具而异，因此不能把一个工具的配置文件直接套用到另一个工具。

## 2、两种范围

添加供应商时，通常可以选择：

- **应用专属供应商**：只服务于当前选中的工具，适合需要分别配置不同端点或模型的情况。
- **统一供应商**：在支持的应用之间共享配置，适合多个工具使用同一个 API 服务的情况。

统一供应商并不代表所有工具都使用完全相同的配置格式；CC Switch 会根据目标应用生成对应配置。

# 二、添加供应商

## 1、选择预设

以下以给 Claude Code 添加 DeepSeek 供应商为例，其他预设的操作流程基本一致。

1. 点击主界面右上角的「+」按钮。

   ![[assets/Pasted image 20260809113050.png|600]]

2. 在预设列表中选择目标供应商；如果列表较长，可以使用搜索功能。

   ![[assets/Pasted image 20260809113253.png|600]]

预设通常会自动填充名称和 API 端点，具体字段以当前版本界面为准：

![[assets/Pasted image 20260809113440.png|600]]

## 2、填写认证信息

在「API Key」输入框中填写对应服务平台生成的密钥。API Key 只应保存在本地配置中，不要提交到 Git、截图公开区域或发送给他人。

![[assets/Pasted image 20260809113728.png|600]]

> 如果密钥已经泄漏，应立即在服务平台撤销旧密钥并重新生成。

## 3、配置模型

如果供应商端点支持模型列表接口，可以点击模型输入框旁的「获取模型」按钮，让 CC Switch 自动读取可用模型；如果端点不支持该接口，则需要根据供应商文档手动填写模型 ID。

模型映射用于把 AI 工具中的模型角色映射到供应商实际提供的模型。不要仅凭模型名称勾选上下文能力，只有在供应商明确提供相应上下文窗口时才应声明该能力。

![[assets/Pasted image 20260809115111.png|600]]

## 4、保存并确认

保存前可以检查生成的配置内容。以 Claude Code 为例，相关配置通常会写入 `~/.claude/settings.json`：

# 三、切换供应商

## 1、主界面切换

在当前应用的供应商列表中找到目标供应商，点击右侧「启用」按钮。CC Switch 会更新对应配置文件，并将该供应商标记为当前启用。

![[assets/Pasted image 20260809115738.png|600]]

## 2、系统托盘切换

需要频繁切换时，可以右键点击系统托盘中的 CC Switch 图标，在对应应用的子菜单中选择供应商，无需先打开主界面。

![[assets/Pasted image 20260809115918.png|300]]

## 3、生效方式

切换后应启动对应工具并发送一个简单请求验证。当前官方文档明确说明的常见行为如下：

| 工具 | 生效方式 |
|---|---|
| Claude Code | 支持热重载，通常无需重启 |
| Gemini CLI | 每次请求重新读取配置，通常无需重启 |
| Codex | 通常需要关闭并重新打开终端 |
| 其他受管工具 | 通常需要重启对应的 CLI 或应用，以当前版本实际行为为准 |

如果启用了本地代理，供应商切换还会受到代理是否运行、目标供应商协议是否匹配等条件影响。

## 4、独立配置

CC Switch 顶部按应用提供独立标签页。切换到对应标签页后，可以分别为 Claude Code、Claude Desktop、Codex、Gemini 等工具添加和管理供应商，避免误改其他工具的配置。

# 四、常见问题

## 1、切换没有生效

- 确认是否切换到了正确的应用标签页；
- 按照上表重启对应 CLI 或应用；
- 检查配置文件是否被其他程序占用；
- 检查 API Key、端点和模型 ID 是否正确；
- 如果使用本地代理，确认代理服务正在运行且供应商支持对应协议。

## 2、首次使用如何迁移

首次启动时，CC Switch 通常会读取受管工具已有的配置，并将其作为默认供应商保留。若仍需调整，可以先导入现有配置，再在此基础上复制或编辑供应商。
