# 一、提示词管理

提示词（Prompt）是提供给 AI 工具的行为规则，例如沟通方式、编码规范、工作流程和 Git 操作约束等。

CC Switch 的 Prompts 功能可以集中保存多套全局提示词，并在不同预设之间切换。启用预设后，CC Switch 会将它同步到对应 AI Agent 实际读取的全局指令文件中，避免频繁手动修改 `CLAUDE.md`、`AGENTS.md` 等文件。


# 二、提示词内容

## 1、适合存放的内容

提示词管理适合存放跨项目长期使用的通用规则，例如：

```markdown
# 全局协作规则

## 沟通偏好

- 默认使用中文
- 先讲结论，再讲关键原因
- 不确定时明确说明假设和风险

## 工作方式

- 修改代码前先阅读相关文件
- 优先沿用项目已有实现
- 保持最小修改范围

## Git

- 不自动执行 git push
- 提交前检查 status 和 diff
```

这类规则描述的是：

> Agent 在不同任务中都应该遵循的通用工作方式。

## 2、全局规则与项目规则

全局提示词适合放置稳定、通用的个人偏好和协作约束。项目专属的架构说明、构建命令、目录约定和测试流程，则应继续放在项目自己的 `CLAUDE.md`、`AGENTS.md` 等指令文件中。

这样可以避免把某个项目的特殊要求带入所有项目，也便于在不同项目之间复用全局规则。

而 CC Switch 管理的是全局规则，例如 Claude Code 的 `~/.claude/CLAUDE.md`，`~/.codex/AGENTS.md`。

# 三、创建提示词预设

## 1、打开提示词管理

在 CC Switch 中选择对应的 AI Agent，点击「提示词」进入 Prompts 管理界面。

![[assets/Pasted image 20260809152953.png|600]]

![[assets/Pasted image 20260809154814.png|600]]

## 2、填写预设内容

在提示词管理界面点击「添加提示词」，填写预设的名称、描述和提示词内容。

![[assets/Pasted image 20260809162341.png|600]]

提示词内容使用 Markdown 编写，可以按沟通偏好、工作方式、编码规范等主题组织规则，便于后续阅读和维护。

点击「保存」后，新的预设会出现在提示词列表中。

# 四、启用与同步

## 1、启用提示词

在提示词列表中点击预设左侧的开关，即可启用该提示词。

同一个 AI Agent 同时只能有一个生效的提示词预设。启用新的预设时，之前生效的预设会自动停用。

## 2、同步到 Agent 配置文件

预设启用后，CC Switch 会将提示词内容写入当前应用对应的全局指令文件：

| 应用 | 写入位置 |
| --- | --- |
| Claude Code | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |
| Gemini CLI | `~/.gemini/GEMINI.md` |
| OpenCode | `~/.config/opencode/AGENTS.md` |

以 Claude Code 为例，如果启用的预设包含以下内容：

```markdown
## 沟通偏好

每次回复使用中文
```

那么 `~/.claude/CLAUDE.md` 中就会同步出现这段提示词内容。
