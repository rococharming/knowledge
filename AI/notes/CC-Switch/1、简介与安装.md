# 一、CC Switch

CC Switch 是一款跨平台开源桌面工具，用于集中管理多个 AI 编程工具的供应商和模型接入配置，减少手动编辑各工具 JSON、TOML 或 `.env` 配置的需要。

## 1、工具定位

不同 AI 编程工具通常各自维护 API 端点、密钥和模型配置。CC Switch 将这些配置集中到一个界面中，提供预设、导入、自定义和切换能力；它还整合了代理、扩展管理、会话浏览和用量追踪等功能。

## 2、支持范围

当前官方仓库列出的受管工具包括：

| 工具 | 类型 |
|---|---|
| Claude Code | AI 编程 CLI |
| Claude Desktop | 桌面端 AI 应用 |
| Codex | AI 编程 CLI |
| Gemini CLI | AI 编程 CLI |
| Grok Build | AI 编程工具 |
| OpenCode | 开源 AI 编程工具 |
| OpenClaw | AI 助手与多供应商网关 |
| Hermes Agent | AI Agent 工具 |

具体功能会因工具和版本而异。例如，供应商管理、MCP、Prompts 和 Skills 不一定对所有工具提供完全相同的同步能力。

# 二、安装

## 1、官方渠道

请从 [CC Switch 官方网站](https://ccswitch.io/)、[GitHub Releases](https://github.com/farion1231/cc-switch/releases) 或官方源码仓库获取安装包。
## 2、平台选择

| 平台 | 常见安装包或方式 | 说明 |
|---|---|---|
| Windows | `.msi`、Portable `.zip` | 选择与系统架构匹配的安装包 |
| macOS | `.dmg`、`.zip`、Homebrew | Intel 与 Apple Silicon 选择对应版本；官方版本已签名并公证 |
| Linux | `.deb`、`.rpm`、`.AppImage`、AUR | 根据发行版和 CPU 架构选择 |

## 3、安装步骤

以从 [GitHub Releases](https://github.com/farion1231/cc-switch/releases)直接获取为例，进入最新版本的 **Assets** 区域，按照操作系统选择安装包：

![[assets/Pasted image 20260809112106.png|600]]

Windows 用户运行 `.msi` 安装包即可；使用 Portable 版本时，解压后运行 `CC-Switch.exe`。macOS 用户打开 `.dmg` 后，将应用拖入「应用程序」目录；Linux 用户按发行版安装 `.deb`、`.rpm` 或直接运行 `.AppImage`。

安装成功后，启动 CC Switch。正常情况下可以看到主界面，并能在系统托盘看到 CC Switch 图标：
