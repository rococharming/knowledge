
# 一、Token与文本表示

## 1、Token 的含义

`token`是大模型处理文本时使用的基本单位。模型不会直接按“字符”或“自然语言里的词”处理文本，而是先通过分词器把文本切分成一串`token`，再把这些`token`转换成模型可以计算的数字表示。

![[Pasted image 20260611170245.png|600]]

例如一行文本：

```text
今天天气不错，我们一起去公园散步吧！
```

可能被切分成类似下面的 token 序列：

```text
今 / 天 / 天气 / 不错 / ， / 我们 / 一起 / 去 / 公园 / 散步 / 吧 / ！
```

这只是示意，不同模型的`tokenizer`不同，实际切分结果也可能不同。

`token`可以直观理解为“文本片段”，但它不严格等于一个汉字、一个英文单词或一个标点符号。英文单词可能被拆成多个 token，中文词语也可能被拆成一个或多个`token`。空格、标点、数字、特殊符号都会影响 token 数。
