# 一、内容块

目前，Claude 的视觉模型可以同时接收文本和图像输入，用于图像描述、视觉问答、图片对比、图文抽取、截图理解、文档转录等任务。

在普通文本对话中，`messages` 的`content`写成字符串形式：

```python
messages=[  
	{  
		"role": "user",  
		"content": "给我讲一个笑话"  
	}  
]   
```

在多模态提示中，`content`通常写成内容块列表：

```python
messages=[  
	{  
		"role": "user",  
		"content": [  
			{  
				"type": "text",  
				"text": "给我讲一个笑话"  
			}  
		]  
	}  
]  
```

这两种写法在纯文本场景下是等价的。

多模态场景必须使用内容块列表，因为同一个用户消息中可能同时包含多个文本块和图像块。

# 二、图像内容块

图像需要以 `image` 内容块的形式放入 `content` 列表中：

示例：

```python
{
    "type": "image",
    "source": {
        "type": "base64",
        "media_type": "image/jpeg",
        "data": "/9j/4AAQSkZJRg...",
    },
}
```

其中：

| 字段                  | 含义                                                          |
| ------------------- | ----------------------------------------------------------- |
| `type`              | 内容块类型。图像块固定为 `image`                                        |
| `source.type`       | 图像数据来源类型，通常为 `base64`                                       |
| `source.media_type` | 图像媒体类型，例如 `image/jpeg`、`image/png`、`image/gif`、`image/webp` |
| `source.data`       | Base64 编码后的图像数据字符串                                          |
图像文件本身不能直接作为 Python 对象传给 API，需要先读取为二进制数据，再转换为 Base64 字符串。

# 三、发送本地图像

## 1、读取图像并转为 Base64

普通 Python 脚本中可以使用 `open(..., "rb")` 读取图片二进制数据：

```python
import base64

image_path = "./test.png"

with open(image_path, "rb") as image_file:
    binary_data = image_file.read()

base64_string = base64.b64encode(binary_data).decode("utf-8")
```

处理过程如下：

1. 以二进制模式读取图片文件
2. 得到`bytes`类型的图像数据
3. 使用`base64.b64encode(...)`编码
4. 使用 `.decode("utf-8")` 转换为字符串

## 2、仅图像提示

如果用户消息中只提供图像，不提供额外文本，模型通常会默认描述图像内容。

```python
with open("./test.jpeg", "rb") as image_file:  
    image_data = image_file.read()  
  
base64_string = base64.b64encode(image_data).decode("utf-8")  
  
  
response = client.messages.create(  
    model=model,  
    max_tokens=800,  
    messages=[  
        {  
            "role": "user",  
            "content": [  
                {  
                    "type": "image",  
                    "source": {  
                        "type": "base64",  
                        "media_type": "image/jpeg",  
                        "data": base64_string,  
  
                    }  
                }  
            ]  
        }  
    ]  
)  
  
print(response.content[0].text)
```

## 3、图像加文本提示

更常见的做法是同时提供图像和文本指令：

```python
with open("./test.jpeg", "rb") as image_file:  
    image_data = image_file.read()  
  
base64_string = base64.b64encode(image_data).decode("utf-8")  
  
  
response = client.messages.create(  
    model=model,  
    max_tokens=800,  
    messages=[  
        {  
            "role": "user",  
            "content": [  
                {  
                    "type": "image",  
                    "source": {  
                        "type": "base64",  
                        "media_type": "image/jpeg",  
                        "data": base64_string,  
  
                    }  
                },  
                {  
                    "type": "text",  
                    "text": "请使用中文简洁描述该图片"  
                }  
            ]  
        }  
    ]  
)
```

内容块按顺序排列。图像块提供视觉输入，文本块提供任务指令。

## 4、封装图像内容块

手动构造图像块较为繁琐，可以封装成辅助函数。

```python
import base64
import mimetypes
from pathlib import Path


def create_image_message(image_path: str) -> dict:
    path = Path(image_path)

    with path.open("rb") as image_file:
        binary_data = image_file.read()

    base64_string = base64.b64encode(binary_data).decode("utf-8")
    mime_type, _ = mimetypes.guess_type(path)

    if mime_type is None:
        raise ValueError(f"Cannot determine MIME type for image: {image_path}")

    return {
        "type": "image",
        "source": {
            "type": "base64",
            "media_type": mime_type,
            "data": base64_string,
        },
    }
```

`mimetypes.guess_type(...)` 会根据文件扩展名推断 MIME 类型，例如：

|文件扩展名|MIME 类型|
|---|---|
|`.jpg` / `.jpeg`|`image/jpeg`|
|`.png`|`image/png`|
|`.gif`|`image/gif`|
|`.webp`|`image/webp`|

## 5、多张图片提示

可以在同一个用户消息中放入多个图像块：

```python
response = client.messages.create(  
    model=model,  
    max_tokens=800,  
    messages=[  
        {  
            "role": "user",  
            "content": [  
                create_image_message("pokemon1.jpeg"),  
                create_image_message("pokemon2.jpeg"),  
                create_image_message("pokemon3.jpeg"),  
                {  
                    "type": "text",  
                    "text": "请识别每张图片的宝可梦是什么"  
                }  
            ]  
        }  
    ]  
)
```

对于多图任务，建议给每张图添加文本标签，尤其是在使用能力较弱的视觉模型时：

```python
response = client.messages.create(  
    model=model,  
    max_tokens=800,  
    messages=[  
        {  
            "role": "user",  
            "content": [  
                { "type": "text", "text": "图像1：" },  
                create_image_message("pokemon1.jpeg"),  
                { "type": "text", "text": "图像2：" },  
                create_image_message("pokemon2.jpeg"),  
                { "type": "text", "text": "图像3：" },  
                create_image_message("pokemon3.jpeg"),  
                {  
                    "type": "text",  
                    "text": "请识别每张图片的宝可梦是什么"  
                }  
            ]  
        }  
    ]  
)
```

给图片编号可以让模型更稳定地建立图像与回答之间的对应关系，避免只回答最后一张或遗漏部分图像。

# 四、处理URL图像

## 1、从URL获取图像数据

如果图片不在本地，可以先用`httpx`请请求图片数据，再转为Base64：

```python
import base64
import httpx

image_url = "https://example.com/image.jpg"

response = httpx.get(image_url)
response.raise_for_status()

image_data = base64.b64encode(response.content).decode("utf-8")
```

然后构造图像块：

```python
image_block = {
    "type": "image",
    "source": {
        "type": "base64",
        "media_type": "image/jpeg",
        "data": image_data,
    },
}
```

## 2、封装 URL 图像函数

可以封装一个根据 URL 生成图像块的函数：

```python
import base64
import httpx
import mimetypes
from urllib.parse import urlparse


def get_image_dict_from_url(image_url: str) -> dict:
    response = httpx.get(image_url)
    response.raise_for_status()

    mime_type = response.headers.get("content-type")

    if mime_type:
        mime_type = mime_type.split(";")[0].strip()
    else:
        path = urlparse(image_url).path
        mime_type, _ = mimetypes.guess_type(path)

    if mime_type not in {"image/jpeg", "image/png", "image/gif", "image/webp"}:
        raise ValueError(f"Unsupported or unknown image MIME type: {mime_type}")

    image_data = base64.b64encode(response.content).decode("utf-8")

    return {
        "type": "image",
        "source": {
            "type": "base64",
            "media_type": mime_type,
            "data": image_data,
        },
    }
```
