# 一、max_tokens

每次向模型发出请求时，除了必须的`model`和`messages`参数，还有`max_tokens`也是必须的。

`max_tokens`参数允许设置模型生成的最大`token`数量上限。

假设要求模型讲一个笑话，但设置`max_tokens=10`，那么模型在生成达到10个 token 时立即停止，这通常导致输出被截断或不完整。

示例：

```python
from dotenv import load_dotenv  
from anthropic import Anthropic  
import os  
  
  
load_dotenv()  
  
api_key = os.getenv("ANTHROPIC_API_KEY") or os.getenv("ANTHROPIC_AUTH_TOKEN")  
if not api_key:  
    raise RuntimeError("请设置 ANTHROPIC_AUTH_TOKEN 或 ANTHROPIC_API_KEY 环境变量")  
  
client = Anthropic(  
    base_url=os.getenv("ANTHROPIC_BASE_URL"),  
    api_key=api_key,  
)  
  
model = os.getenv("MODEL_ID")  
  
  
truncate_response = client.messages.create(  
    max_tokens=10,  
    model=model,  
    messages=[  
        {"role": "user", "content": "讲一个笑话"}  
    ]  
)  
  
print(truncate_response.content[0].text)  
print(truncate_response.stop_reason)
```

结果：

![[assets/Pasted image 20260611172602.png|200]]

`stop_reason`的值也是`max_tokens`，表示因为达到最大输出`token`上限停止。

如果产生使用更大的`max_tokens`值（500），那么就会得到完整的笑话：

![[assets/Pasted image 20260611172722.png|300]]

`stop_reason`也是`end_turn`，表示自然结束。

需要`max_tokens`参数的原因如下：

- 控制成本：输出 token 越多，费用越高，`max_tokens`可以限制最大花费
- 防止输出过长：避免模型一直生成很长内容，影响响应速度和可读性。
- 保护程序稳定性：在API调用中，限制输出长度可以避免超时、响应体过大、占用过多上下文或内存



# 二、stop_sequences

`stop_sequences` 用于指定一组停止字符串。模型生成响应时，一旦生成内容中出现这些字符串，生成过程就会立即停止。

它的作用可以理解为：

> 当 Claude 生成到某个指定序列时，停止继续输出，并移除该指定序列。

首先看不使用`stop_sequences`的情况：

```python
response = client.messages.create(  
    max_tokens=500,  
    model=model,  
    messages=[  
        {  
            "role": "user",  
            "content": "生成一个 JSON 对象，表示一个用户，包含姓名、邮箱和电话号码。"  
        }  
    ],  
)  
  
print(response.content[0].text)
```

结果：

![[assets/Pasted image 20260611182031.png|200]]


此时增加`stop_sequences=["}"]`：

```rust
response = client.messages.create(  
    max_tokens=500,  
    model=model,  
    messages=[  
        {  
            "role": "user",  
            "content": "生成一个 JSON 对象，表示一个用户，包含姓名、性别和电话"  
        }  
    ],  
    stop_sequences=["}"]  
)  
  
print(response.content[0].text)  
print(response.stop_reason)  
print(response.stop_sequence)
```

结果：

![[assets/Pasted image 20260611182158.png|200]]

这里需要注意，尽管停止序列生效了，没有输出`}`，但模型返回的`stop_reason`却还是`end_turn`，`stop_sequence`也是None。

这是因为现在用的不是 Anthropic 官方 Claude API，而是 Kimi 的 Anthropic-compatible 接口；它执行了 `stop_sequences` 的停止逻辑，但返回的元数据没有按 Anthropic 官方协议填充。


# 三、temperature

`temperature`参数用于控制生成响应的“随机性”和”创造性“。它的取值范围为0到1。较高的值会导致更多样化和不可预测的响应，措辞上会有更多变化。较低的值可能导致更确定的输出，这些输出会坚持最可能的措辞和答案。

`temperature`的默认值为1。

对于分析性任务，`temperature`应设置为接近于`0.0`；对于创造性和生成性任务，`temperature`应设置为接近于`1.0`。


# 四、system

`system` 是向模型发送请求时可以包含的可选参数，用于设置系统提示词。系统提示词通常用来提供高层级指令，例如定义模型角色、设定回答语气、补充对话背景等，从而影响模型在整个对话中的回应方式。

- 系统提示词是可选的，但对于统一对话风格、角色设定和上下文边界很有用。
- 系统提示词作用于整个对话，会影响该对话中模型的后续回应。
- 使用系统提示词可以避免在每条用户消息中重复写入相同的角色、语气或背景要求。

需要注意的是，系统提示词更适合放置稳定的高层级约束，例如语气、角色、任务背景和总体行为规范。具体任务指令、外部输入内容，例如文档、数据、长文本，以及示例输出，通常更适合放在第一个 `user` 消息中，以便模型围绕当前任务进行处理。

Anthropic 的 Messages API 也将 `system` 作为独立参数使用，而不是放入 `messages` 数组中。

对之前的持续对话示例改造：

```python
from dotenv import load_dotenv  
from anthropic import Anthropic  
import os  
  
load_dotenv()  
  
api_key = os.getenv("ANTHROPIC_API_KEY") or os.getenv("ANTHROPIC_AUTH_TOKEN")  
if not api_key:  
    raise RuntimeError("请设置 ANTHROPIC_AUTH_TOKEN 或 ANTHROPIC_API_KEY 环境变量")  
  
client = Anthropic(  
    base_url=os.getenv("ANTHROPIC_BASE_URL"),  
    api_key=api_key,  
)  
  
MODEL = os.getenv("MODEL_ID")  
  
conversation_history = []  
  
while True:  
    user_input = input("用户：")  
  
    if user_input.lower() == "quit":  
        print("对话结束")  
        break  
  
    conversation_history.append({  
        "role": "user", "content": user_input  
    })  
  
    response = client.messages.create(  
        system="每次回复我都以 Kamen Rider 开头",  
        model=MODEL,  
        max_tokens=1000,  
        messages=conversation_history,  
    )  
  
    assistant_response = response.content[0].text  
    print(f"助手：{assistant_response}")  
  
    conversation_history.append({  
        "role": "assistant", "content": assistant_response  
    })
```

关键：

```python
response = client.messages.create(  
	system="每次回复我都以 Kamen Rider 开头",  
	model=MODEL,  
	max_tokens=1000,  
	messages=conversation_history,  
)  
```
