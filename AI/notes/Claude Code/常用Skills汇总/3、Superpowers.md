
# 一、简介

Claude Code 在进行一个复杂项目时，默认直接写代码、跳过测试和流程，导致结果脆弱。

`Superpowers`的价值不是提升模型智力，而是通过技能框架和开发方法论，把规格说明、任务拆分、测试、代码审查、分支隔离等工程纪律嵌入 Agent 工作流，让 AI 编程更接近成熟的软件工程流程。

# 二、工作原理

## 1、概述

`Superpowers`不是简单的提示词增强，也不是零散的指令集合。它更像是一套完整的软件开发工作流：通过可组合的 `skills` 组织开发过程，并配合一组初始指令，强制 Agent 在合适的阶段调用这些技能。

这里的关键词是“强制”。在 `Superpowers` 中，`skills` 不是给 Agent 参考的建议，也不是可用可不用的辅助说明，而是工作流中的必经步骤。Agent 不能随意跳过这些流程，而必须按照预设的工程纪律完成任务。

## 2、核心工作流

在`Superpowers`中，一个完整的开发周期通常会经过七个步骤。

### 1、头脑风暴（苏格拉底式设计）

当 Agent 判断你正在构建某个功能时，它不会立刻开始写代码，而是先停下来确认你的真实目标。

它会通过类似苏格拉底式问答的方式，不断追问需求、澄清意图、发现边界情况，并逐步整理出一份设计文档。这个设计文档不会一次性塞给你，而是拆成较短的小节，让你可以逐步确认，避免被大量信息压垮。


## 2、创建 Git worktree

设计确认后，`Superpowers`会在新分支上自动创建一个隔离的`Git worktree`。

这种隔离非常重要，它允许同一个项目并行推进多个任务，而不同任务之间的代码改动不会相互覆盖。正式开始开发前，Agent 还会检查当前测试基线是否干净，确保不是在一个失败的状态上继续开发。
