

# 一、简介

Teach 是 Matt Pocock 技能仓库中的一个教学 Skill，用于让 AI 围绕一个学习目标，持续开展多次教学，并在工作目录中保存课程、参考资料和学习进度。

可以把它理解成一套**让 AI 担任长期老师的工作规则**。

例如，你希望学习 AI 相关概念，逐步理解模型和 Agent 如何工作。学习范围可能包括 LLM、Token、Context Window、Prompt、Harness、工具调用、Skill、MCP等。

Teach 会先了解你的目标和已有基础，再查找可靠资料，把学习内容拆成短课，通过练习和反馈判断下一步应该教什么。

## 1、核心思路

Teach 将学习分为三个部分：

| 部分           | 含义             | 实现方式              |
| ------------ | -------------- | ----------------- |
| Knowledge：知识 | 理解概念和原理        | 阅读可信资料，学习必要的解释    |
| Skills：技能    | 能够实际运用所学内容     | 练习、测验、操作任务和即时反馈   |
| Wisdom：实践判断  | 知道真实情境下如何选择和行动 | 实际应用，与其他学习者和实践者交流 |

课程会先提供完成练习所需的知识，再让你尝试运用。

具体来说，了解学习目标：

-> 查找可靠资料
-> 学习一个小知识点
-> 完成练习
-> 获得反馈
-> 记录关键收获
-> 决定下一课

## 2、每节课只解决一个小问题

Teach 要求课程短小、范围明确，并与你的实际目标相关。

例如，学习 AI 概念时，某一课可以只解决：

```text
能够解释 Token 为什么不等于一个字或一个单词?
```

另一课可以解决：
```text
能够区分 LLM 和 Harness 各自负责什么
```

课程难度会参考你的已有知识和学习记录，让你在当前基础上向前迈一步。

## 3、通过文件延续学习

Teach 将学习状态保存在工作目录中。

后续教学时，AI 可以读取学习目标、已有记录和偏好，继续安排课程。因此，这些文件承担了**跨会话延续学习**的作用。

**保存的是课程与学习状态；能否记住所学内容，仍然需要练习和复习。**

它强调主动回忆、间隔练习，以及相关技能的交错练习，帮助知识长期保留。

# 二、如何使用

## 1、准备独立的学习目录

建议一个学习目标对应一个工作目录。

例如：

```text
ai-concepts-learning/
```

将这个目录作为学习工作区后，再调用 Teach。

学习另一项不相关的技能时，可以使用另一个目录。这样课程、资源和记录都围绕同一个目标组织。

## 2、明确调用技能

在当前支持技能引用的 Agent 中，可以选择或引用 `teach`，再附上学习要求，例如：

```text
$teach 我想学习 AI 相关的概念。
```

Teach 的配置包含：

```yaml
disable-model-invocation: true
```

这项配置表达了需要由用户主动调用的意图，而不是由模型来根据情况调用。

## 3、告诉它目标、基础和偏好

第一次使用时，最好说明以下信息：

| 信息   | 要回答的问题      | 示例                             |
| ---- | ----------- | ------------------------------ |
| 学习主题 | 想学什么？       | AI 模型和 Agent 相关概念              |
| 学习目的 | 学完以后要做什么？   | 看懂 AI 技术文章，理解工具的工作方式           |
| 已有基础 | 目前懂什么？      | 已了解 LLM、Token 和 Context Window |
| 学习约束 | 有哪些时间或方式限制？ | 中文，每课约 10 分钟，多用实例              |

一个完整请求可以写成：

```text
$teach 我想逐步学习 AI 相关概念，目的是看懂 AI 技术文章，
理解日常使用的 AI 工具是如何工作的。

学习范围包括 LLM、Token、Context Window、Prompt、
Harness、工具调用、Skill、MCP 等概念，并根据需要逐步扩展。

我已经初步了解 LLM、Token 和 Context Window，
但还不太清楚这些概念之间的关系。

请用中文教学，每节课控制在 10 分钟左右，
先讲具体例子，再解释概念，配少量练习。

请根据我的基础安排课程。
```

如果学习目的不明确，Teach 会先追问你为什么想学这个主题，再确定课程方向。

**目标越具体，课程越容易贴近真实用途。**

例如，“能够看懂 AI 技术文章，并解释模型、上下文和工具如何配合”，比“了解 AI”更容易指导教学。

## 4、阅读课程并完成练习

Teach 的主要课程产物是**HTML**文件，通常保存在 `lessons/` 中。

每节课会围绕一个小目标展开，可以包含解释、例子、测验或实际操作步骤，并提供反馈。课程还会链接参考资料，方便继续阅读。

阅读后，可以直接向 AI 追问：

```
我还是不清楚 Harness 和模型的区别，
请用 AI 搜索资料的过程举例。
```

或者：

```
我完成了练习，请检查我的理解，
看看是否可以进入下一个概念
```

## 5、继续学习与复习

后续在同一工作区中调用 Teach，可以说：

```
$teach 根据我的学习目标和已有记录，继续下一课。
```

也可以请求复习：

```
$teach 检查我对 LLM 和 Harness 的理解。
尤其是它们之间的关系，再决定下一步什么。
```

学习记录应依据你展示出的理解、练习表现或明确说明的已有知识更新。

**“课程讲过了”不等于“已经学会了”。**

## 6、调整学习目标

随着学习深入，你的目标可能发生变化。

例如，从：

```
看懂 AI 技术文章，理解常见概念
```

转向：

```
能够利用这些概念设计一个简单的 AI 工作流程
```

这时可以告诉 Teach 调整目标。技能要求在你确认后更新 `MISSION.md`，并记录目标变化，供后续课程参考。

# 三、目录结构

Teach 要求实际学习时使用一个工作目录，实际课程和学习状态保存在学习工作区中。

下面是一个示意结构，课程名称和资源文件名会随主题变化：

```text
ai-concepts-learning/
├── MISSION.md
├── RESOURCES.md
├── NOTES.md
├── GLOSSARY.md
├── lessons/
│   ├── 0001-token-basics.html
│   ├── 0002-context-window.html
│   └── 0003-model-and-harness.html
├── reference/
│   └── ai-concepts-cheat-sheet.html
├── learning-records/
│   ├── 0001-prior-knowledge.md
│   └── 0002-distinguish-model-and-harness.md
└── assets/
    ├── styles.css
    └── quiz.js
```

这些文件和目录会根据学习过程逐步建立，不需要在第一课之前全部准备好。

### （1）MISSION.md：学习目标

保存你为什么学习，以及怎样判断学习取得了成果。

主要内容包括：

| 部分                 | 内容            |
| ------------------ | ------------- |
| Why                | 学习的实际动机       |
| Success looks like | 学完后能够完成的可观察行为 |
| Constraints        | 时间、预算、已有基础和偏好 |
| Out of scope       | 当前暂不学习的相邻主题   |

例如：

```markdown
# Mission: AI 概念学习

## Why
我希望看懂 AI 技术文章，理解日常使用的 AI 工具如何工作，
并逐步建立模型、上下文、Agent 和工具之间的概念联系。

## Success looks like
- 能用自己的话解释常见 AI 概念
- 能区分模型、应用和工具各自的职责
- 能解释一次 AI 工具调用的大致过程
- 阅读技术文章时，能识别关键术语及其关系

## Constraints
- 使用中文，保留必要的英文术语
- 每节课约 10 分钟
- 已初步了解 LLM、Token 和 Context Window
- 偏好具体例子和简短练习

## Out of scope
- 暂不深入模型训练的数学推导
- 暂不开发完整的 Agent 系统
```
### （2）RESOURCES.md：可信资源

保存经过筛选的资料，并说明每个来源适合用于什么问题。

它通常区分：

```
Knowledge：书籍、官方文档、论文、专家资料
Wisdom：实践社区、论坛、线下课程或交流渠道
```

每条资源应附带简短说明，方便之后判断何时使用。

### （3）lessons/：课程

保存每节课的 HTML 文件，按顺序编号：

```
0001-主题.html
0002-主题.html
```

课程是主要教学单元，每节围绕一个明确的小目标，包含必要知识、练习和反馈。

例如，在 AI 概念学习中，一节课可以介绍一个概念，也可以专门解释几个已学概念之间的关系。

### （4）reference/：速查资料

保存适合反复查阅的 HTML 参考材料，例如：

- AI 概念对照 表
- 模型与 Agent 的关系图
- 工具调用流程
- 常见术语速查表

课程帮助你学习，速查资料帮助你在使用时快速回忆。

### （5）learning-records/：学习记录

保存会影响后续教学的关键收获，按顺序编号：

```
0001-主题.md
0002-主题.md
```

适合记录的内容包括：

- 你展示了对一个概念的理解；
- 你说明了已有知识及其深度；
- 一个重要误区被纠正；
- 学习目标发生变化。
    
它用于判断你下一步适合学习什么，无需记录每次对话的全部过程。

### （6）GLOSSARY.md：术语表

根据配套格式文件，可以在工作区维护统一的术语表。

每个术语使用简短定义，后续课程沿用同一套表达。按照技能规则，应在你能够正确使用某个概念后，再将它纳入术语表。

例如，逐步收录：

```text
LLM
Token
Context Window
Prompt
Harness
Tool Calling
MCP
```
### （7）assets/：共用组件

保存课程复用的样式和交互组件，例如：

```
styles.css：统一课程排版
quiz.js：测验与反馈组件
```

随着课程增加，这些组件可以反复使用，让整个学习工作区保持一致的阅读体验。

### （8）NOTES.md：教学偏好

记录影响教学方式的偏好和工作笔记，例如：

```
喜欢先看具体例子，再理解抽象定义。
希望保留英文术语，并附中文解释。
喜欢编号标题、对照表和分步骤说明。
每次学习时间约 10 分钟。
```
