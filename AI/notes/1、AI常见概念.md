
# 一、LLM

LLM（Large Language Model，大语言模型）是一类能够理解和生成自然语言的人工智能模型。具体来说，它是一个通过大量文本数据训练出来的“语言预测模型”，能够根据已有上下文预测接下来最可能出现的内容。

LLM 通常基于 Transformer 神经网络架构，通过海量数据训练，使模型学习语言中的规律、知识和表达方式。

常见 LLM：

| 公司        | 模型        |
| --------- | --------- |
| OpenAI    | GPT 系列    |
| Anthropic | Claude 系列 |
| Google    | Gemini 系列 |

LLM 能回答问题的关键在于训练过程，大致分为三个阶段：预训练、指令微调、人类反馈强化学习。

![[assets/Pasted image 20260811224631.png|600]]

- 预训练（Pre-training）：提供海量文本数据（网页、书籍、代码、文章等），让模型学习语言规律和世界知识。
- 指令微调（Instruction Tuning / SFT）：这一阶段训练数据变成用户问题 + 标准答案，让模型学会理解人类需求，并按要求完成任务。
- 人类反馈强化学习（RLHF）：即使模型会听指令，也可能回答啰嗦、不安全、不符合永远期待，因此加入人类反馈。模型生成多个答案，人类评价哪个好，根据评价优化模型
