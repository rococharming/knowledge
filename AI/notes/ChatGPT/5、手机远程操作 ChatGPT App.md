# 一、连接条件

## 1、账号与版本

手机端和电脑端需要登录同一个 ChatGPT 账号，并位于同一个工作区。

设备上需要安装支持 Remote 的 ChatGPT App。手机端通常从 ChatGPT App 的 Remote 入口发起配对；电脑端需要运行桌面版 ChatGPT App，并在连接设置里允许其他设备接入。

入口名称、按钮文案和可用性可能会因账号、系统、工作区策略和版本灰度而变化。

## 2、主机状态

被连接的电脑是 Remote 的主机。主机需要保持在线、唤醒，并运行 ChatGPT App；如果电脑睡眠、断网或关闭 App，手机端就不能继续访问这台电脑上的任务。

Mac 笔记本作为主机时，长时间任务最好保持供电并打开屏幕。合上屏幕时，是否还能稳定远程访问取决于系统和外接显示器等条件；选择睡眠会直接中断 Remote。

# 三、电脑端

## 1、进入连接

在电脑端 ChatGPT App 打开 **设置**，进入左侧 **编码** 分组下的 **连接**。页面顶部可以看到 **控制这台 Mac**、**控制其他设备** 和 **SSH** 三个入口。

![[assets/Pasted image 20260803001321.png]]

截图中选中的是 **控制这台 Mac**。这表示当前 Mac 将作为主机，允许经过授权的设备来连接它。这里的 **添加** 不是添加项目或账号，而是添加一台可以控制这台 Mac 的设备，例如手机。

三个入口的职责可以这样区分：

| 入口 | 含义 |
|---|---|
| 控制这台 Mac | 让手机或另一台支持的设备控制当前 Mac |
| 控制其他设备 | 从当前电脑去连接另一台已经配对的主机 |
| SSH | 连接远程开发主机或服务器，不是手机配对入口 |

## 2、开始设置

点击 **添加** 后，会出现“将设备连接到此 Mac”的引导页。

![[assets/Pasted image 20260803001421.png|400]]


这一步说明了 Remote 连接后的基本能力：可以从另一台设备继续桌面端未完成的任务，在任务完成或需要注意时收到提醒，也可以向这台 Mac 发送新消息来开始新的工作。

这里要把“连接设备”和“运行任务”分开理解。手机只是新的控制入口，真正承载任务上下文的仍然是这台 Mac。

## 3、允许控制

继续设置时，桌面端会要求确认是否允许设备控制这台电脑。

![[assets/Pasted image 20260803001443.png|400]]

点击 **允许** 后，ChatGPT App 才会进入配对流程。这一步是在打开主机侧的远程控制权限，并不表示任意设备都能直接接入。后续仍需要账号一致、设备配对和必要的身份验证。

## 4、生成二维码

授权后，桌面端会显示二维码，用于和控制设备配对。

![[assets/Pasted image 20260803001553.png|600]]

截图里的 **电话** 和 **电脑**，区分的是“准备用哪类设备来控制这台 Mac”：

| 选项 | 适用情况 |
|---|---|
| 电话 | 用 iPhone 或 Android 上的 ChatGPT App 控制这台 Mac |
| 电脑 | 用另一台支持 Remote 的 Mac 或 Windows 设备控制这台 Mac |

选择 **电话** 后，二维码就用于手机端 ChatGPT App 扫码或输入配对码。通常每台控制设备都需要和每台主机单独配对；换手机、换主机，或希望多台设备都能控制同一台 Mac 时，需要分别完成连接。

# 四、手机端

## 1、打开 Remote

在手机 ChatGPT App 的侧边栏中，进入 **Remote**。

![[assets/Pasted image 20260803002023.png|600]]

Remote 不是普通聊天列表，也不是项目列表。它专门用于查看和控制已经配对的桌面端主机。进入后，手机会根据当前账号和工作区，引导你完成桌面端连接。

## 2、确认桌面端

首次使用时，手机端会出现“设置远程控制”的引导页。

![[assets/015598e3d69f7f3c0ad2359642c7d7d8.jpg|600]]

这张截图强调了 Remote 的前置条件：桌面端需要安装并登录同一个 ChatGPT 账号。如果还没有准备好桌面端，可以先发送下载链接；如果电脑端已经登录，就选择 **我已在桌面端登录** 继续。

## 3、完成配对

手机端随后会提示获取配对码。

![[assets/47fb7d42f4546cb8ba779c93ce07056e.jpg|600]]

这里的配对码对应电脑端生成的二维码。电脑端已经显示二维码时，选择 **我有配对码**，然后按手机端提示扫码或输入。配对完成后，这台 Mac 会出现在手机端 Remote 的可访问主机里。

# 五、连接设置

配对成功后，电脑端会显示 **已连接**，并展示几个与远程体验相关的开关。

![[assets/Pasted image 20260803001813.png|600]]

这些开关决定了 Remote 的稳定性，以及远程任务能否继续使用电脑上的本地能力：

| 设置 | 作用 | 适合场景 |
|---|---|---|
| 让这台 Mac 保持唤醒状态 | 插电且远程访问启用时，尽量避免电脑睡眠导致连接中断 | 长时间运行 Codex 任务 |
| 锁屏状态下使用 Mac 应用程序 | 允许远程任务在锁屏状态下继续使用 Mac 应用 | 需要 Computer Use 或本地 App 协作 |
| 设置 Chrome 扩展程序 | 帮助 ChatGPT 使用浏览器能力 | 任务需要网页、登录态或浏览器交互 |

如果只是查看进度、回复文字或批准操作，不一定需要打开所有增强能力。若希望 Codex 继续使用浏览器、本地应用或更完整的电脑端操作能力，就需要按任务需要补齐这些权限。
