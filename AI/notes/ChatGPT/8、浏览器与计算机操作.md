# 一、能力边界

ChatGPT App 有三类容易混淆的网页和界面能力：

| 能力 | 主要用途 | 是否操作界面 |
|---|---|---|
| Web Search | 搜索当前公开信息 | 否 |
| Browser | 打开、查看和操作网页 | 是 |
| Computer Use | 查看和操作桌面应用 | 是 |

Web Search 适合回答“网上现在有什么信息”；Browser 适合“打开这个网站并完成网页任务”；Computer Use 适合“操作一个没有专用工具接口的桌面应用”。

# 二、Browser

## 1、内置浏览器

ChatGPT App 的内置 Browser 为你和 ChatGPT 提供同一个网页视图，可以：

- 打开公开网页或本地 Web App
- 点击、输入和导航
- 查看渲染状态
- 截图验证
- 在网页上留下视觉反馈
- 完成多步骤网页任务

内置 Browser 使用独立于日常浏览器的 Profile，不会自动共享现有标签页、Cookie 或登录状态。任务确实需要账号时，可以在该独立 Profile 中登录。

浏览器数据和下载位置可以在 **Settings > Browser** 中管理。默认下载到系统 Downloads 目录。

## 2、打开方式

可以通过以下方式打开 Browser：

- 点击工具栏中的 Browser
- 点击 Chat 中的 URL
- 让 ChatGPT 打开指定页面
- 使用 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>B</kbd>
- Windows 使用 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>B</kbd>

使用 ChatGPT Work 或 Codex 操作网页时，需要安装并启用 Browser Plugin。提示中也可以直接引用 `@Browser`。

示例：

```text
使用 Browser 打开本地 http://localhost:3000/settings，
复现窄窗口下按钮溢出的问题。
先截图和说明复现步骤，不要修改代码。
```

## 3、网页检查

Browser 适合验证网页的真实渲染结果。对于前端任务，可以要求 ChatGPT：

1. 打开指定 URL。
2. 复现交互路径。
3. 截取修改前状态。
4. 修改代码。
5. 刷新页面并重复相同步骤。
6. 对比修改前后截图。

代码能够编译不代表页面行为正确，浏览器验证是独立的验收层。

# 三、Chrome 扩展

内置 Browser 使用隔离 Profile；Chrome 扩展用于 ChatGPT 必须操作你现有 Chrome 标签页或登录状态的场景。

| 场景 | 推荐 |
|---|---|
| 希望使用隔离环境，避免接触日常账号 | 内置 Browser |
| 必须使用已经登录的网站 | Chrome 扩展 |
| 测试本地网页或公开页面 | 内置 Browser |
| 任务依赖现有标签页和 Chrome Profile | Chrome 扩展 |

Chrome Profile 可能包含历史记录、登录状态、内部网址和其他敏感信息。连接前应检查允许的网站范围，任务结束后撤销不再需要的权限。

# 四、Computer Use

## 1、用途

Computer Use 让 ChatGPT 查看和操作 macOS 或 Windows 的图形界面。它适合命令行或专用 Plugin 无法完成的任务，例如：

- 测试桌面 App
- 修改必须点击界面的设置
- 复现只在 GUI 中出现的问题
- 操作没有 Connector 的数据源
- 完成跨多个桌面应用的流程

官方 Computer Use Plugin 图标：

![[chatgpt-computer-use-plugin.png|100]]

## 2、启用

在 ChatGPT App 中选择 Work 或 Codex，然后：

1. 打开 Plugins。
2. 找到并安装 Computer Use。
3. 启用对应 Server 和 Skill。
4. 从 **Try now** 开始，或在任务中明确要求使用 Computer Use。
5. 在 **Settings > Computer Use** 检查应用访问范围。

macOS 第一次使用时通常需要：

- **Screen Recording**：让 ChatGPT 看见目标 App。
- **Accessibility**：让 ChatGPT 点击、输入和导航。

Windows 上应让目标 App 保持在当前可见桌面中。

## 3、任务范围

Computer Use 能影响 Project 工作区之外的应用和系统状态，因此提示中应明确：

- 允许操作哪个 App
- 需要完成哪条路径
- 哪些动作只允许查看
- 哪些动作必须先确认
- 何时停止

示例：

```text
使用 Computer Use 打开系统设置，只检查 ChatGPT 当前拥有的屏幕录制权限。
不要切换任何开关，不要访问其他设置页面。
把看到的状态告诉我。
```

# 五、Appshots

Appshot 是从桌面应用获取的视觉上下文。它可以包含：

- 当前窗口画面
- 控件和文本
- 辅助功能树中的内容
- 可能位于当前滚动区域之外的文字

Appshot 适合解释界面、提供视觉反馈或验证操作结果，但不适合在未检查窗口内容时随意截取。

使用前应：

1. 关闭无关窗口。
2. 隐藏账号、密钥和公司敏感信息。
3. 确认目标 App。
4. 告诉 ChatGPT 要检查的具体区域。

示例：

```text
获取当前预览窗口的 Appshot。
只检查顶部导航和右侧按钮是否对齐，
不要读取或总结页面中的用户数据。
```

# 六、安全操作

Browser 和 Computer Use 都会接触外部内容。网页、邮件和界面文字可能包含试图改变任务方向的恶意指令。

安全任务应遵循：

- 把网页内容视为不可信输入
- 不因网页提示而扩大权限
- 登录、付款、发送、发布和删除前人工确认
- 限制允许访问的网站和应用
- 不在提示中粘贴密码或密钥
- 完成后检查实际发生的操作

涉及外部服务的结构化数据和动作时，优先使用 [[9、Plugins 与外部服务|Plugin]]；只有没有合适接口或任务依赖真实 GUI 时，再使用 Computer Use。
