# 一、简介

ChatGPT App 是 OpenAI 的桌面应用。它把对话、知识工作和软件开发放在同一个工作环境中，不仅可以回答问题，还可以围绕项目组织资料、处理本地文件、调用工具并完成多步骤任务。

ChatGPT App 主要包含三个工作入口：

- **Chat**：通过对话提问、理解知识和梳理想法
- **Work**：研究、分析并创建文档、表格、演示文稿和网站等成果
- **Codex**：结合代码库和开发工具完成软件开发任务

原来的独立 Codex App 已经并入 ChatGPT 桌面应用。Codex 并没有消失，而是作为专用的编程工作区继续存在，同时仍可通过 CLI 和 IDE 扩展使用。

## 1、产品形态

ChatGPT 和 Codex 提供多种使用形态，适合不同的工作场景。

| 形态 | 适合的场景 | 主要特点 |
|---|---|---|
| ChatGPT 桌面 App | 本地文件、复杂任务、多项目协作 | 可连接本地目录、终端、浏览器和桌面应用 |
| ChatGPT Web | 云端聊天与知识工作 | 无需安装，适合跨设备使用和云端任务 |
| Codex CLI | 终端中的代码开发 | 基于当前目录读取代码、修改文件并执行命令 |
| Codex IDE Extension | 编辑器内的代码开发 | 能结合当前工作区、打开文件和选中代码 |

本系列以 **ChatGPT 桌面 App** 为主。Codex CLI 适合终端工作流，具体用法参考 [[补充资料/1、Codex  CLI|Codex CLI]]。

## 2、Chat、Work 与 Codex

三种工作模式的主要区别不在于任务是否困难，而在于希望获得什么结果。

| 模式 | 适合的任务 | 主要结果 |
|---|---|---|
| Chat | 提问、解释知识、讨论想法 | 回答、解释、建议和短内容 |
| Work | 研究、分析和制作完整成果 | 文档、表格、演示文稿和网站等 |
| Codex | 软件开发和代码库操作 | 代码修改、测试结果和可审查的 Diff |

可以按照最终目标进行选择：

- 主要需要一个回答，选择 **Chat**
- 需要一份可以审阅和继续修改的成果，选择 **Work**
- 需要实际操作软件项目，选择 **Codex**

在 ChatGPT App 中，Chat 和 Work 位于 ChatGPT 工作区；Codex 可以通过工作区选择菜单进入。

# 三、开始一项工作

开始任务时，需要依次确定工作上下文、工作模式和任务要求。

## 1、选择工作上下文

工作上下文决定 ChatGPT 可以获得哪些背景信息，以及可以操作哪些文件。

| 入口 | 适合的场景 | 上下文来源 |
|---|---|---|
| 普通聊天 | 临时提问或一次性任务 | 当前对话中提供的信息和文件 |
| 项目 | 围绕同一主题持续工作 | 项目中的聊天、文件和指令 |
| 本地文件夹 | 处理本地文档或代码项目 | 所选文件夹中的文件 |

### 普通聊天

普通聊天不属于任何项目，适合临时提问、讨论想法或完成一次性任务。

### 项目

项目用于集中管理围绕同一主题的内容，可以包含：

- 多个聊天记录
- 上传的文件
- 项目级指令

例如，可以为一个长期学习主题或工作任务创建独立项目，让其中的聊天共享相关背景。

### 本地文件夹

打开本地文件夹后，ChatGPT 可以在获得授权的范围内读取和修改其中的文件。

例如，打开一个代码项目后，Codex 可以分析项目结构、修改代码并运行测试；打开一个资料目录后，Work 可以读取其中的文件并生成文档或表格。

项目和文件夹不是互斥关系。项目可以附加本地文件夹，让项目中的多个聊天共享相关文件和指令。更完整的组织方式参考 [[4、对话与 Projects]]。

## 2、选择执行位置

使用 Work 时，还可以根据任务需要选择执行位置：

- **Work locally**：适合需要读取本地文件、使用本地应用或操作浏览器的任务
- **Cloud**：适合长时间运行、定时执行，或者关闭电脑后仍需继续的任务

![[assets/Pasted image 20260730172439.png|600]]

如果任务依赖电脑中的文件或应用，选择本地执行；如果希望任务不依赖电脑保持开机，可以在支持时选择云端执行。

## 3、提出第一个任务

选择好上下文和工作模式后，就可以发送第一条消息：

![[assets/Pasted image 20260730170427.png|600]]

官方建议在消息中说明：

- Goal（目标）：想要 ChatGPT 做什么
- Context（背景）：完成任务所需的背景信息
- Output（输出）：预期输出格式、长度、详细程度等
- Boundaries（边界）：哪些事情必须保持不变、ChatGPT 应该避免什么，或者哪些操作需要先确认

例如：

> 阅读我提供的资料，整理三个关键结论并生成一页汇报。保留原始文件；遇到不确定的信息时明确标注，不要自行补充。

不需要把每一步操作都提前规定好。只要明确目标、提供必要上下文并说明重要约束，ChatGPT 就可以判断需要使用哪些文件和工具，并逐步完成任务。

> 使用 ChatGPT App 的核心不是告诉 AI 每一步怎么操作，而是明确说明要完成什么、可以使用什么以及需要遵守哪些限制。

更完整的提问方法参考 [[3、提问与提供上下文]]。
