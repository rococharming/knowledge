# 一、安装

ChatGPT 桌面 App 支持 macOS 和 Windows。桌面端适合处理本地文件、较长任务和多个并行项目；如果不需要访问本地环境，也可以直接使用 Web 端。

## 1、macOS

进入 [ChatGPT desktop app](https://learn.chatgpt.com/docs/app)，下载 macOS 版本并完成安装。

当前官方下载入口默认提供 Apple Silicon 版本。安装前可以点击菜单栏的苹果图标，选择“关于本机”，确认 Mac 使用的是 Apple 芯片还是 Intel 处理器。

安装后，从“应用程序”目录启动 ChatGPT。第一次使用本地文件、麦克风、屏幕内容或桌面应用时，macOS 会分别请求相应的系统权限。

## 2、Windows

从同一个官方页面下载 Windows 版本并按安装向导完成安装。

Windows 上使用本地目录、终端或 Computer Use 时，具体行为还会受到 Windows 沙箱、PowerShell 和系统权限影响。普通聊天和 Work 不要求先配置开发环境。

> App 的界面和功能会持续更新。如果官方页面展示的入口与本机不同，应以当前 App 中可见的菜单和 Settings 为准。

# 二、登录

打开 App 后，使用 ChatGPT 账号登录。登录完成后，Web 端的 ChatGPT 对话和 ChatGPT Projects 可以在支持的情况下同步到桌面端。

软件开发场景还可能使用 API Key 登录 Codex，但部分 ChatGPT 功能可能不可用。对于本系列介绍的完整 App 体验，优先使用 ChatGPT 账号。

# 三、界面

## 1、侧边栏

侧边栏用于在不同工作入口之间切换，通常可以看到：

- 新建 Chat
- 搜索
- Scheduled
- Plugins
- Sites
- Projects
- 最近的 Chats

Project 和 Chat 可以固定在侧边栏中。固定只改变显示位置，不会增加 ChatGPT 能访问的上下文。

## 2、主工作区

主工作区显示当前 Chat、任务进度和生成结果。根据当前工作方式，它可能包含：

- 对话消息
- 计划与工具调用
- 权限确认
- 文件或网页预览
- 代码 Diff
- 终端输出
- 长期任务状态

工作区右侧或底部出现的面板取决于当前任务，不是每次对话都会全部显示。

## 3、输入区

输入区用于描述任务、附加上下文和选择执行方式。常见控件包括：

- Chat / Work 切换器
- ChatGPT / Codex 产品选择
- 文件或图片附件
- 工具、Plugin 或 Skill
- 本地 / 云端执行位置
- 模型与推理强度
- 语音输入

不要只关注模型选择。对大多数任务来说，明确目标、提供正确上下文并选对工作方式，比频繁切换模型更重要。

# 四、开始任务

## 1、独立 Chat

任务只需要一次对话、不依赖共享资料时，直接选择 **New chat**。

适合的例子：

- 解释一个术语
- 改写一段文字
- 比较两个工具
- 搜索某项最新信息

## 2、ChatGPT Project

任务需要多次对话共同使用一组文件、来源或指令时，创建 ChatGPT Project。

适合的例子：

- 持续进行一项技术调研
- 围绕同一主题制作报告和演示文稿
- 为同一个课程维护多篇材料

## 3、本地目录

ChatGPT 需要直接读取或修改电脑中的文件时，选择本地 Project 或打开文件夹。附加本地目录意味着 ChatGPT 可能获得其中多个文件的访问权限，选择前应先确认目录范围。

有关三种工作位置的区别，参考 [[4、对话与 Projects|对话与 Projects]]。

# 五、常用操作

以下快捷键在 macOS 使用 <kbd>Cmd</kbd>，在 Windows 使用 <kbd>Ctrl</kbd>：

| 操作 | macOS | Windows |
|---|---|---|
| 打开命令菜单 | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> |
| 打开 Settings | <kbd>Cmd</kbd> + <kbd>,</kbd> | <kbd>Ctrl</kbd> + <kbd>,</kbd> |
| 新建 Chat | <kbd>Cmd</kbd> + <kbd>N</kbd> | <kbd>Ctrl</kbd> + <kbd>N</kbd> |
| 搜索 Chats | <kbd>Cmd</kbd> + <kbd>G</kbd> | <kbd>Ctrl</kbd> + <kbd>G</kbd> |
| 当前 Chat 内查找 | <kbd>Cmd</kbd> + <kbd>F</kbd> | <kbd>Ctrl</kbd> + <kbd>F</kbd> |
| 打开目录 | <kbd>Cmd</kbd> + <kbd>O</kbd> | <kbd>Ctrl</kbd> + <kbd>O</kbd> |
| 显示或隐藏侧边栏 | <kbd>Cmd</kbd> + <kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>B</kbd> |
| 打开快捷键列表 | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>/</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>/</kbd> |

在 **Settings > Keyboard Shortcuts** 中可以搜索、修改或恢复快捷键。

# 六、基础设置

首次使用时，建议检查：

- **General**：是否要求使用 <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + <kbd>Enter</kbd> 发送多行提示；本地任务运行时是否阻止电脑休眠。
- **Keyboard Shortcuts**：查看是否与系统或其他软件的快捷键冲突。
- **Notifications**：选择任务完成、需要权限或需要回答问题时如何提醒。
- **Browser**：管理内置浏览器、Chrome 扩展以及网站访问规则。
- **Computer Use**：检查 ChatGPT 可以操作哪些桌面应用。
- **Personalization**：设置 Personality、Custom Instructions 和 Memories。
- **Archived chats**：查看和恢复已归档的对话。

权限模式会直接影响 ChatGPT 能做什么，详细设置放在 [[12、权限、设置与故障排查|权限、设置与故障排查]] 中说明。
