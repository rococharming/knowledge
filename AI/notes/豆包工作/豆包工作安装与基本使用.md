# 一、豆包工作是什么？

豆包工作是豆包面向电脑办公场景推出的 AI 工作 Agent。

普通豆包更偏向：你问问题  ->  豆包回答

但豆包工作更偏向：

你交代一个任务  ->  豆包自己拆解步骤  ->  读取文件 / 搜索网页 / 调用工具 ->  操作电脑或浏览器  ->  生成文档、表格、PPT 等成果。

比如你可以直接说：

> 帮我读取这个文件夹里的 100 个商品资料，整理产品类型、价格和卖点，最后生成一个 Excel。

或者说：

> 帮我在飞书预定一个会议室，地点在xxx，时间为xxx，参会人员为xxx，xxx，...。如果会议室无空闲或者参会人员时间冲突，请帮我分配更合理的地点和时间。

它的目标不是告诉你怎么做，而是实际执行这个任务。

# 三、基础配置和使用

在使用前，最好完成一些基础配置。

## 1、启用记忆

![[assets/Pasted image 20260924152159.png]]

确保记忆处于已启用状态，这样在每次和豆包对话过程中，豆包工作会自动记住你的一些行为偏好、个人习惯和规则等，这些规则将会在跨对话过程中保留。

## 2、个性化指令

点击左下角设置，在设置界面下点击工作模式设置，点击工作任务偏好指令，可以编辑你的个性化指令：

![[assets/Pasted image 20260924152422.png]]

这相当于也是一个全局跨对话指令，只不过这个指令是由你自己指定的。

比如，作为跨境电商运营，你可以写：

>你是一名专业的跨境电商运营助手，主要协助我处理 Amazon 跨境电商平台的日常运营、市场分析、竞品分析、Listing 分析、产品分类、关键词研究、数据分析和运营问题。


## 3、内容生成与产物设置

在设置的内容生成与产物设置中，找到 AI 生成水印管理，设置生成文档、表格、PPT和生成的图片、视频均为无水印，这样在生成图片等内容时就不会产生水印。

![[assets/Pasted image 20260924152957.png]]

## 4、多条消息跟进行为

多条消息跟进行为，有引导和列队两个选项。

- 引导：当豆包在进行任务过程中，你输入的下一个指令会立即反馈给豆包，豆包会相应按照新的指令规则调整。
- 列队：豆包会一直等上一个任务处理完才处理你发送的下一条消息。

这里选择什么看自己个人习惯。


## 5、模型选择

可以根据不同的任务调整要使用的模型。

![[assets/Pasted image 20260924153452.png]]

模型可以先非常简单地理解成 **“速度、成本、能力”不同的三档**：

| 模型               | 定位        | 适合什么                  |
| ---------------- | --------- | --------------------- |
| **豆包 2.1 Lite**  | 轻量、快      | 简单问答、基础整理、轻量任务        |
| **豆包 2.1 Turbo** | 均衡、速度快    | 大多数日常办公任务             |
| **豆包 2.1 Pro**   | 能力最强、推理更深 | 复杂分析、长任务、代码、多步骤 Agent |
也可以选择自动，让豆包工作自己判断该调用 Lite、Turbo 还是 Pro。

推理强度可以选择低、中、高，强度越高，模型思考的程度越深，给出的回答和执行效果质量可能更高。
