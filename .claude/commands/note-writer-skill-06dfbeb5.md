# note-writer

This skill handles: 把材料变成一篇可长期保存的结构化技术笔记、写到用户指定文件时使用——这是要产出一个带章节、示例、交叉引用的笔记文件，而不是在对话里随口回答。接受任意一类输入：URL、本地文件、内联文本片段、某个主题、或刚才的对话。凡意图是"把…整理成笔记""做成学习笔记""系统梳理…存下来""写成带章节的笔记""存到笔记目录"，或任何旨在生成一篇已保存笔记的表述（即使没有"笔记"二字），都应触发。按统一风格（中文序数标题、概念先行、维基链接交叉引用）只产出单篇笔记。不适用于：查询或检索已有知识库、修改已有笔记、ingest 多篇素材并维护整个 wiki 索引。
