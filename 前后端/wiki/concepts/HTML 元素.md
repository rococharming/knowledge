# HTML 元素

HTML 使用 **元素（element）** 表示网页内容。元素是 [[HTML 基础]] 中"描述内容和结构"这一职责的最小组成单元。

## 元素的基本结构

大多数元素由三部分组成：

1. 开始标签
2. 内容
3. 结束标签

```html
<p>每天学习一点前端知识。</p>
```

- `<p>` 是开始标签
- `每天学习一点前端知识。` 是元素的内容
- `</p>` 是结束标签

开始标签和结束标签都使用尖括号包围标签名。结束标签的左尖括号后面多了一个正斜杠 `/`。

## 元素的嵌套

元素的内容不仅可以是文本，也可以是其他 HTML 元素：

```html
<section>
  <h2>今日学习内容</h2>
  <p>认识 HTML 元素和属性。</p>
</section>
```

## 标签名大小写

HTML 标签名不区分大小写，但开发中约定使用 **小写标签名**，更统一也更易于阅读。

## 空元素（void element）

有些 HTML 元素只有开始标签，不能包含文本或其他元素，也不需要结束标签。这类元素称为 **空元素（void element）**。

例如 `img` 用于显示图片：

```html
<img>
```

实际开发中也可能看到在右尖括号前添加 `/` 的写法：

```html
<img />
```

在 HTML 中两种写法都很常见。末尾的 `/` 并不会让元素"自行闭合"，在 HTML 语法中没有实际作用；一些代码格式化工具会自动保留这种形式。

> [!note] 空元素没有内容
> 空元素只能有开始标签，但仍然可以在标签中使用属性（如 `src`、`alt`，详见 [[HTML 属性]]）。
