# 一、估算
## 1、估算原则

示例：

23456

保留两位：23000。
误差值：-456。
误差： 456 / 23456 ≈ 2%

保留三位：23500
误差值：44
误差：44 / 23456 ≈ 0.2%

估算原则：

- 任何数字保留三位，最大误差 5‰
- 任何数字保留两位，最大误差 5%

> 资料分析题，保留三位有效是上限

## 2、判断原则

看选项之间的差距。

- 选项之间的误差在 10%  以上，保留两位
- 选项之间的误差在 10%  以内，保留三位

![[assets/Pasted image 20260825161546.png|400]]

或者：

- 首位均不同，保留两位
- 首位有相同，保留三位
