# Frontend Development Resources

## Knowledge

- [MDN: Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development)
  Use for: the core beginner-to-comfortable path across HTML, CSS, JavaScript, accessibility, tooling, and web fundamentals.
- [MDN: Web technology for developers](https://developer.mozilla.org/en-US/docs/Web)
  Use for: reference lookups on browser APIs, HTML, CSS, JavaScript, accessibility, performance, privacy, and web platform concepts.
- [freeCodeCamp: Learn](https://www.freecodecamp.org/learn/)
  Use for: supplementary hands-on practice, especially Responsive Web Design, JavaScript, Front-End Development Libraries, and project-style certification exercises.
- [freeCodeCamp GitHub curriculum](https://github.com/freeCodeCamp/freeCodeCamp)
  Use for: understanding the structure of freeCodeCamp's open-source curriculum and selecting suitable practice projects or challenge sequences.
- [React: Learn React](https://react.dev/learn)
  Use for: official React concepts, components, state, Hooks, and modern React mental models.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
  Use for: TypeScript basics, everyday types, narrowing, functions, object types, modules, and type-system behavior.
- [Vite Guide](https://vite.dev/guide/)
  Use for: modern frontend tooling, local development, builds, project structure, and browser support assumptions.
- [web.dev: Learn Core Web Vitals](https://web.dev/explore/learn-core-web-vitals)
  Use for: performance metrics, measurement, debugging, and improving real user experience.
- [Vitest Guide](https://vitest.dev/guide/)
  Use for: JavaScript and TypeScript unit testing in Vite-based frontend projects.
- [Playwright Docs](https://playwright.dev/docs/intro)
  Use for: end-to-end testing of real browser flows in product projects.

## Wisdom (Communities)

- [GitHub trending TypeScript projects](https://github.com/trending/typescript)
  Use for: discovering current frontend and full-stack projects to read, compare, and eventually dissect.
- [Reactiflux Discord](https://www.reactiflux.com/)
  Use for: React ecosystem questions and observing how working developers discuss frontend tradeoffs.
- [Stack Overflow: JavaScript questions](https://stackoverflow.com/questions/tagged/javascript)
  Use for: debugging patterns, common mistakes, and practical explanations from real-world cases.
- [freeCodeCamp Forum](https://forum.freecodecamp.org/)
  Use for: beginner-friendly community support, curriculum questions, and seeing how learners debug HTML, CSS, JavaScript, and React problems.
