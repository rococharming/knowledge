网页三层分工

遇到任何网页问题，先问一句：这是内容结构、视觉样式，还是用户行为？这个问题会让前端学习清楚很多。

HTML

负责内容和结构。比如标题、段落、链接、列表、图片、表单。

<h1>我的博客</h1>

CSS

负责样式和布局。比如颜色、字体、间距、边框、网格、响应式。

h1 { color: #5f3d18; }

JavaScript

负责行为和变化。比如点击按钮、提交表单、请求数据、更新页面。

button.addEventListener("click", fn)

判断口诀

看见什么内容，多半是 HTML；长成什么样，多半是 CSS；点了以后发生什么，多半是 JavaScript。
