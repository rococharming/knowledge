博客首页常用 HTML 标签

先不要追求标签数量。零基础阶段，掌握这几个就能写出个人博客首页的内容骨架。

页面结构

<header>：页头，通常放网站名和导航。

<main>：页面主要内容，一个页面通常一个。

<section>：一块有主题的内容区域。

<article>：一篇文章或一张文章卡片。

文本内容

<h1> 到 <h6>：标题层级，按结构使用，不按字号使用。

<p>：段落。

<ul> / <li>：无序列表和列表项。

<a href="...">：链接。
