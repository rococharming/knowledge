CSS 第一组规则

CSS 规则回答三个问题：选中谁，改什么，改成什么。

CSS 规则结构

.post-card {
  padding: 16px;
  border: 1px solid #e6d4b7;
  background: #fffaf0;
}

.post-card 是选择器，padding / border / background 是属性，冒号后面是属性值。

常用选择器

h1：选中所有 h1 元素。

.post-card：选中 class 为 post-card 的元素。

header a：选中 header 里面的链接。

常用属性

color：文字颜色。

background：背景。

padding：内容和边框之间的内边距。

border：边框。

border-radius：圆角。
