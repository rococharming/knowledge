# Mission: Frontend Development

## Why
Learn frontend development from zero to the point where the user can independently build useful products, especially data dashboards, management systems, and a personal blog. The course should also strengthen full-stack and AI-product programming ability, while keeping job readiness as an important secondary outcome.

## Success looks like
- Build and deploy a polished personal blog that records learning and presents projects.
- Build a data dashboard or management system with routing, tables, filters, forms, charts, API interaction, and production-quality UI states.
- Explain frontend project decisions clearly enough for portfolio reviews and job interviews.
- Read selected high-quality GitHub frontend projects, understand their structure, and rebuild key features.

## Constraints
- Start from zero foundation.
- Early lessons should use explanation plus small exercises.
- Later lessons should switch to project-based feature lessons.
- Learning should favor real product skills over memorizing isolated interview facts.

## Out of scope
- Chasing every frontend framework at once.
- Interview-cram-only learning that does not produce usable projects.
