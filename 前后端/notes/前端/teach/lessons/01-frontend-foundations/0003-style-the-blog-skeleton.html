Lesson 0003

用 CSS 给博客骨架加样式

第 2 课的 HTML 已经说明了页面内容。今天只练一件事：写几条 CSS 规则，让博客首页从“能读”变成“有层次、像作品”。

  • 预计 20 分钟
  • 承接第 2 课
  • 目标：读懂第一组 CSS 规则

Concept

CSS 规则就是一句样式命令

MDN 把 CSS 描述为用来设置网页样式和布局的语言。我们先不碰复杂布局，只学最小单位：一条 CSS 规则。

一条规则回答三个问题：选中谁，改什么，改成什么。

.post-card {
  padding: 16px;
  background: #fffaf0;
}

对应的 CSS

下面这几条 CSS 是右侧预览里最关键的规则，和预览使用同一组 class 与内容。先看意思，不急着背。

.post-card {
  border: 1px solid #e6d4b7;
  border-radius: 8px;
  padding: 16px;
  background: #fffaf0;
}

.site-nav a {
  color: white;
  background: #5f3d18;
  padding: 4px 9px;
  text-decoration: none;
}

选择器：选中谁

.post-card 会选中 class 叫 post-card 的元素。class 是给元素贴的名字，方便 CSS 找到它。

声明：改什么

padding: 16px; 是一条声明。冒号前是属性，冒号后是值，最后用分号结束。

Practice

小练习：读懂三条 CSS

看下面三条声明，说出它们分别改变了什么。

  1. color: #5f3d18;
  2. padding: 16px;
  3. border-radius: 8px;

参考答案：1 改文字颜色，2 改内边距，3 改圆角。

Recall

即时小测

在 .post-card { padding: 16px; } 里，.post-card 是什么？

今天的检查清单

  • CSS 用来控制页面样式和布局。
  • 选择器负责选中元素。
  • 属性说明要改哪一项。
  • 属性值说明要改成什么。
  • 不要用 CSS 改内容身份，内容身份仍然属于 HTML。

推荐阅读

主读：MDN: Styling the content。重点看 CSS 文件如何连接到 HTML，以及颜色、字体、间距怎样改变页面。

补读：MDN: CSS styling basics。它会继续展开选择器、盒模型、背景、边框等基础模块。

配套练习：freeCodeCamp: Learn Basic CSS by Building a Cafe Menu。重点练 CSS 选择器、颜色、间距和菜单式页面样式。

速查卡：CSS 第一组规则。
