Lesson 0001

网页到底由什么组成

今天只抓住一件事：一个网页通常由三层一起完成。HTML 负责内容结构，CSS 负责视觉样式，JavaScript 负责交互行为。你会用这个三层模型读懂一个最小博客卡片。

  • 预计 15 分钟
  • 零基础可学
  • 目标：读懂网页三层分工

Concept

先把网页想成一张会动的文章页

你未来要做个人博客、数据看板和管理后台。它们看起来复杂，但入口都一样：页面上有什么内容，这些内容怎么摆放，用户操作以后页面怎么变化。

MDN 的入门资料也把简单网页作为起点：先组织内容，再添加样式，最后添加交互。这个顺序很适合零基础，因为它符合浏览器理解网页的方式。

HTML：内容骨架

告诉浏览器“这里是标题、这里是段落、这里是链接”。没有 HTML，浏览器不知道内容的身份。

CSS：视觉外观

告诉浏览器“标题多大、卡片多宽、背景是什么、手机上怎么排”。没有 CSS，页面也能读，但很朴素。

JavaScript：用户行为

告诉浏览器“点击按钮后切主题、输入关键词后筛选文章、请求接口后刷新表格”。没有 JavaScript，页面很难变成应用。

Example

一个最小博客卡片

先看它的最终效果。现在你不需要会写，只需要能判断每一部分属于哪一层。

前端学习

我的第一篇博客

今天我学会了：网页由内容、样式和行为三层共同组成。

开始练习

这张卡片的 HTML

下面这段代码只关心内容身份：标签、标题、段落、链接。

<article class="blog-card">
  <span class="tag">前端学习</span>
  <h3>我的第一篇博客</h3>
  <p>今天我学会了：网页由内容、样式和行为三层共同组成。</p>
  <a href="#practice">开始练习</a>
</article>

这张卡片的 CSS

下面这段代码只关心视觉：宽度、边框、留白、颜色。

.blog-card {
  max-width: 420px;
  border: 1px solid #e6d4b7;
  padding: 20px;
  background: #fffaf0;
}

这张卡片未来的 JavaScript

当你点击“开始练习”、切换主题、搜索文章时，JavaScript 就会开始工作。

themeButton.addEventListener("click", function () {
  document.body.classList.toggle("dark");
});

Practice

小练习：三次判断

不用写代码，先训练判断力。看到需求后，说出它主要属于 HTML、CSS 还是 JavaScript。

  1. 把“我的第一篇博客”改成“前端学习日记”。
  2. 把卡片背景改成浅黄色。
  3. 点击按钮以后切换夜间主题。

参考答案：1 是 HTML，2 是 CSS，3 是 JavaScript。

Recall

即时小测

如果你想让博客卡片在手机上从两列变成一列，主要应该修改哪一层？
