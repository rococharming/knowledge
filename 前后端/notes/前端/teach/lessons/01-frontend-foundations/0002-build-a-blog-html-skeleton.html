Lesson 0002

写出博客首页的 HTML 骨架

上一课我们知道 HTML 负责内容结构。今天只练一件事：把“个人博客首页上应该有什么”翻译成 HTML 标签。

  • 预计 20 分钟
  • 承接第 1 课
  • 目标：写出首页内容骨架

Concept

HTML 不是排版工具，是内容说明书

HTML 的核心工作不是“让字变大”，而是告诉浏览器：这段内容在页面里扮演什么角色。MDN 的 HTML 基础文章强调，HTML 用元素包住内容，从而定义网页内容的结构。

所以，写 HTML 时先不要想颜色、边框和动画。先问：这是网站标题、导航、主要内容、一篇文章，还是一个链接？

Model

一个博客首页可以先分成三块

header：网站名字和导航入口。
main：这个页面最重要的内容。
section：一个有主题的内容区域，例如“最新文章”。
article：一篇文章，或文章列表里的一张文章卡片。

对应的 HTML

下面的代码和上面的预览使用同一份内容：标题、导航文字、文章标题、文章摘要、链接文字都保持一致。

<header>
  <h1>Song 的前端学习笔记</h1>
  <nav>
    <a href="#top">首页</a>
    <a href="#posts">文章</a>
    <a href="#about">关于</a>
  </nav>
</header>

<main>
  <section>
    <h2>最新文章</h2>
    <ul>
      <li>
        <article>
          <h3>网页到底由什么组成</h3>
          <p>理解 HTML、CSS、JavaScript 的分工。</p>
          <a href="#practice">阅读全文</a>
        </article>
      </li>
    </ul>
  </section>
</main>

标题：h1 到 h3

h1 是页面主标题；h2 是大区域标题；h3 是区域里的小标题。不要为了字号乱跳层级，字号以后交给 CSS。

链接：a

a 需要 href 才知道要去哪里。没有 href 的链接就像写了门牌但没有地址。

Practice

小练习：把需求翻译成标签

先不用真的保存文件。请在脑子里或草稿里把下面 4 个内容写成 HTML 标签。

  1. 页面主标题：我的个人博客。
  2. 导航链接：文章，指向 /posts。
  3. 区域标题：最新文章。
  4. 文章摘要：记录我的前端学习过程。

参考答案可以和上方代码对照：主标题用 h1，导航链接用 a href="/posts"，区域标题用 h2，摘要用 p。

Recall

即时小测

在博客首页里，“最新文章”最适合扮演哪个角色？

今天的检查清单

  • 一个页面先有一个清楚的 h1。
  • 页面主要内容放进 main。
  • 同一组内容可以放进 section。
  • 文章或文章卡片可以用 article。
  • 链接文字要清楚，href 要写目标地址。
