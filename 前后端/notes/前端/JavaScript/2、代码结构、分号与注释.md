# 一、语句与代码块

语句（statement）是一条可执行的指令；表达式（expression）会计算出一个值。变量声明、赋值和函数调用都是常见语句，`price * count` 则是表达式。

```js
const price = 10;
const count = 3;
const total = price * count;

console.log(total);
```

花括号包住的多条语句叫代码块。后续的 `if`、循环和函数都会用它表示“一起执行的代码”。

```js
{
  const message = "只在这个代码块里使用";
  console.log(message);
}
```

# 二、分号与严格模式

## 1、分号

分号可以分隔语句。JavaScript 有自动分号插入（ASI）机制，所以省略分号的代码通常也能运行；但 ASI 不是“每次换行都插入分号”。项目应统一使用一种格式化规则，而不是依赖猜测。

```js
const name = "Ada";
console.log(name);
```

> [!tip]
> 本系列示例显式写分号，便于初学时看清语句边界。真实项目通常由 ESLint 或格式化工具统一风格。

## 2、严格模式

`"use strict";` 会启用旧脚本的严格模式，让部分容易误写的代码直接报错。ES 模块天然处于严格模式；入门练习如果是普通脚本，先认识这个写法即可。

```js
"use strict";

const appName = "demo";
console.log(appName);
```

# 三、注释

注释写给读代码的人，JavaScript 执行时会忽略它。注释应解释原因、限制或不明显的意图，不重复代码已经说清的事情。

## 1、单行注释

```js
// 为空时用访客身份继续流程。
const displayName = "Guest";
```

## 2、多行注释

```js
/*
  这个示例只用于演示字符串拼接。
  真实页面应由组件负责显示。
*/
const greeting = "Hello";
```

多行注释不能嵌套；在一段 `/* ... */` 中再写 `/*` 很容易导致语法错误。
