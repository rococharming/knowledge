# 一、变量

变量是给值起名字的方式。程序里很多值需要反复使用或随着操作更新，用变量保存后，就可以通过名字读取和修改这些值。

示例：

```js
let score = 0;

console.log(score);
```

这里 `score` 是变量名，`0` 是它当前保存的值。结合 [[2、值与数据类型|值与数据类型]] 来看，变量本身是名字，真正具有类型的是它保存的值。

# 二、声明与赋值

## 1、声明

**声明（declaration）** 是告诉 JavaScript：“我要创建一个名字。”

现代 JavaScript 中，常用 `let` 和 `const` 声明变量。

示例：

```js
let age;

console.log(age);
```

`let age;` 创建了变量 `age`，但还没有给具体值，所以输出结果是 `undefined`。

## 2、初始化

**初始化（initialization）** 是在声明时给变量一个初始值。

示例：

```js
let age = 18;

console.log(age);
```

这里 `let age` 是声明，`= 18` 是初始化。`=` 在 JavaScript 中是赋值运算符，不是数学里的“相等判断”。

## 3、重新赋值

`let` 声明的变量可以重新赋值。重新赋值时，不需要再写 `let`。

示例：

```js
let score = 0;

score = score + 10;

console.log(score);
```

这里 `score = score + 10` 的意思是：先读取旧的 `score`，计算出新值，再把新值放回 `score`。

# 三、let 与 const

## 1、let

`let` 适合保存后续会变化的值，例如计数器、当前选中项、表单输入状态、游戏分数。

示例：

```js
let count = 0;

count = count + 1;
count = count + 1;

console.log(count);
```

因为 `count` 会随着程序运行而改变，所以用 `let` 更符合含义。

## 2、const

`const` 适合保存不希望重新赋值的名字。`const` 声明时必须立刻初始化，之后不能把这个名字重新指向另一个值。

示例：

```js
const maxScore = 100;

console.log(maxScore);
```

下面的写法会报错：

```js
const maxScore = 100;

maxScore = 200;
```

`const` 的重点是“变量名不能重新绑定到另一个值”，不是“值内部永远不能变”。

## 3、对象修改

如果 `const` 保存的是对象，不能把变量名重新指向新对象，但可以修改这个对象内部的属性。

示例：

```js
const user = {
  name: "Ada",
  points: 0
};

user.points = 10;

console.log(user.points);
```

这段代码可以运行，因为 `user` 仍然指向同一个对象，只是对象内部的 `points` 属性变了。

| 写法 | 是否允许 | 原因 |
|---|---|---|
| `user.points = 10` | 允许 | 修改同一个对象的属性 |
| `user = { name: "Grace" }` | 不允许 | 试图让 `user` 指向另一个对象 |

> 简单规则：默认优先用 `const`，确实需要重新赋值时再用 `let`。

# 四、命名规则

## 1、语法规则

变量名必须是合法标识符。入门阶段先记住这几条：

- 可以用字母、数字、下划线 `_`、美元符号 `$`。
- 不能以数字开头。
- 不能包含空格。
- 不能使用 JavaScript 保留字，例如 `let`、`const`、`function`、`return`。
- 大小写敏感，`age` 和 `Age` 是两个不同名字。

示例：

```js
let age;
let userName;
let _privateValue;
let $button;
```

不合法示例：

```js
let 1stPlace;
let user name;
let return;
```

## 2、命名习惯

变量名应该表达值的含义，而不是只图短。

| 不推荐 | 推荐 | 原因 |
|---|---|---|
| `x` | `age` | 看得出保存的是年龄 |
| `s` | `totalScore` | 看得出保存的是总分 |
| `flag` | `isLoggedIn` | 看得出真假判断的含义 |

JavaScript 变量名通常使用 camelCase，即第一个单词小写，后续单词首字母大写。

示例：

```js
const userName = "Ada";
const totalScore = 95;
const isLoggedIn = true;
```

布尔变量常用 `is`、`has`、`can` 开头，让读者一眼看出它表达真假。

# 五、var

早期 JavaScript 主要使用 `var` 声明变量。现代代码更推荐 `let` 和 `const`，因为它们的作用域规则更清晰，也能减少重复声明和意外覆盖带来的问题。

示例：

```js
var oldName = "legacy";
let currentName = "modern";
const appName = "learning-demo";
```

入门阶段可以先遵循：

| 需求 | 推荐 |
|---|---|
| 名字不需要重新赋值 | `const` |
| 名字后续需要重新赋值 | `let` |
| 阅读旧代码时遇到 | 认识 `var`，但新代码少用 |

作用域、提升和模块会进一步解释为什么现代 JavaScript 把 `let` 和 `const` 作为默认选择。
