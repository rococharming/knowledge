# 一、变量、声明与赋值

变量是给值起名字的方式。先 **声明** 名字，再在声明时或之后为它 **赋值**；声明时给出的第一个值叫初始化。

```js
let score;          // 声明，值为 undefined
score = 0;          // 赋值

const maxScore = 100; // 声明并初始化
```

变量保存的值具有类型，而变量名本身不固定绑定某种类型。类型的完整概览见 [[4、值与数据类型|值与数据类型]]。

# 二、let 与 const

## 1、let：后续需要重新赋值

`let` 适合计数器、当前选择和输入状态等会变化的值。重新赋值时不能再次写 `let`。

```js
let count = 0;

count = count + 1;
count += 1;

console.log(count); // 2
```

## 2、const：绑定不再改变

`const` 必须在声明时初始化，之后不能让这个名字指向另一个值。默认优先用 `const`，确定需要重新赋值时再用 `let`。

```js
const maxScore = 100;

// maxScore = 200; // TypeError
```

`const` 约束的是变量绑定，而不是对象内部一定不可变：

```js
const user = { name: "Ada", points: 0 };

user.points = 10; // 允许：仍是同一个对象
// user = { name: "Grace" }; // 不允许：重新绑定
```

# 三、命名

标识符可以使用字母、数字、下划线 `_` 和美元符号 `$`，不能以数字开头、包含空格或使用保留字。JavaScript 通常使用 camelCase。

```js
const userName = "Ada";
const totalScore = 95;
const isLoggedIn = true;
```

| 不推荐 | 推荐 | 原因 |
|---|---|---|
| `x` | `age` | 能看出值的含义 |
| `s` | `totalScore` | 能看出计算目标 |
| `flag` | `isLoggedIn` | 能看出布尔判断 |

布尔变量常以 `is`、`has`、`can` 开头。名字应表达业务含义，而不是实现细节。

# 四、var

`var` 是早期声明方式。它的作用域和重复声明规则与 `let`、`const` 不同，容易产生意外覆盖。新代码使用 `const` 或 `let`；阅读旧代码时再理解 `var`。

```js
var legacyName = "old code";
let currentName = "modern code";
```
