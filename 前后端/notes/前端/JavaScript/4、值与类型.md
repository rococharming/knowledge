# 一、值与动态类型

JavaScript 程序处理的是值，数据类型描述值能进行什么操作。JavaScript 是动态类型语言：变量不需要预先声明类型，变量当前保存的值才有类型。

```js
let result = 10;
result = "完成";
```

这段代码合法，但同一变量应保持稳定的业务含义；不要因为语言允许就随意在数字、字符串和对象之间切换。

# 二、原始值

JavaScript 有七种原始类型：

| 类型 | 含义 | 示例 |
|---|---|---|
| `string` | 文本 | `"hello"` |
| `number` | 普通数字 | `42`、`3.14` |
| `bigint` | 任意精度整数 | `9007199254740993n` |
| `boolean` | 真或假 | `true`、`false` |
| `undefined` | 尚未得到值 | `undefined` |
| `symbol` | 唯一标识 | `Symbol("id")` |
| `null` | 主动表示没有值 | `null` |

原始值不可变。比如变量重新保存一个字符串，是变量改为保存新值，不是旧字符串被原地修改。字符串见 [[5、字符串|字符串]]；数字细节见 [[7、数字|数字]]。

`undefined` 常表示“尚未赋值”，`null` 表示“有意设为空”。二者的比较规则会在 [[10、比较与逻辑|比较与逻辑]] 中说明。

# 三、对象与函数

原始类型之外，值通常以对象形式组织。对象用属性描述一个实体；数组是有顺序的一组值；函数是可重复调用的逻辑。

```js
const user = { name: "Ada", age: 28 };
const scores = [80, 95, 100];

function add(a, b) {
  return a + b;
}

console.log(user.name);
console.log(scores[0]);
console.log(add(2, 3));
```

数组和函数都可被视为对象家族的一员，但有各自专门的语法与用途。

`const` 限制的是变量绑定，不能让名字改为指向另一个对象；它不阻止修改同一个对象的属性：

```js
const user = { name: "Ada", points: 0 };

user.points = 10; // 允许：仍是同一个对象
// user = { name: "Grace" }; // 不允许：重新绑定
```

# 四、typeof

`typeof` 返回一个描述值类型的字符串，适合做初步观察。

```js
console.log(typeof 42);          // "number"
console.log(typeof "hello");     // "string"
console.log(typeof true);        // "boolean"
console.log(typeof undefined);   // "undefined"
console.log(typeof 123n);        // "bigint"
console.log(typeof Symbol("id")); // "symbol"
console.log(typeof {});          // "object"
console.log(typeof function () {}); // "function"
```

> [!warning] typeof null
> `typeof null` 会返回 `"object"`，这是历史遗留行为。判断 `null` 应写 `value === null`，不要依赖 `typeof`。
