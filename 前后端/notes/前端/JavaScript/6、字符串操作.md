# 一、拼接

字符串不可变，拼接会返回新字符串。少量简单文本可用 `+`，插入变量时优先使用 [[5、字符串#二、模板字符串|模板字符串]]。

```js
const firstName = "Ada";
const lastName = "Lovelace";
const fullName = firstName + " " + lastName;

let message = "Hello";
message += ", JavaScript!";
```

`concat()` 也能拼接字符串，但日常代码中通常不如模板字符串直观。

# 二、查找与截取

`indexOf()` 返回匹配起始索引，找不到时返回 `-1`；只关心是否存在时用返回布尔值的 `includes()`。两者都区分大小写。

```js
const sentence = "JavaScript is fun";

console.log(sentence.indexOf("fun"));    // 14
console.log(sentence.indexOf("Rust"));   // -1
console.log(sentence.includes("fun"));   // true
```

`slice(start, end)` 截取从 `start` 到 `end` 前的部分，并返回新字符串。省略 `end` 会截取到末尾，负数索引从末尾倒数。

```js
const message = "Hello, world!";

console.log(message.slice(0, 5)); // "Hello"
console.log(message.slice(7));    // "world!"
console.log(message.slice(-6));   // "world!"
```

# 三、规范与替换

用户输入和外部数据常带有多余空白或大小写差异。先 `trim()`，再统一大小写，能让后续比较更稳定。

```js
const rawAnswer = "  YES ";
const normalizedAnswer = rawAnswer.trim().toLowerCase();

console.log(normalizedAnswer); // "yes"
```

`replace()` 返回替换后的新字符串。传入普通字符串时默认只替换第一次；要替换所有完全相同的文本可使用 `replaceAll()`。

```js
const phrase = "world and world";

console.log(phrase.replace("world", "universe"));
console.log(phrase.replaceAll("world", "universe"));
```

# 四、重复

`repeat(count)` 将字符串重复指定次数。次数必须是非负且有限的数；`0` 返回空字符串。

```js
console.log("Hi!".repeat(3)); // "Hi!Hi!Hi!"
```
