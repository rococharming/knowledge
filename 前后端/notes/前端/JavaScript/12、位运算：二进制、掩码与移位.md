# 一、二进制与位

位（bit）只有 `0` 和 `1` 两种状态。二进制数每一位代表 2 的幂，例如 `1010` 等于 `8 + 2`，即十进制 `10`。

| 二进制位 | `1` | `0` | `1` | `0` |
|---|---:|---:|---:|---:|
| 对应权重 | 8 | 4 | 2 | 1 |

位运算直接处理这些二进制位，常用于标志位、权限掩码和底层数据格式；日常业务计算通常不需要它。

# 二、按位逻辑运算

`&`、`|` 和 `^` 分别表示按位与、按位或和按位异或；`~` 对每一位取反。

```js
const a = 0b101; // 5
const b = 0b011; // 3

console.log(a & b); // 1，0b001
console.log(a | b); // 7，0b111
console.log(a ^ b); // 6，0b110
console.log(~a);    // -6
```

按位或常用于合并权限，按位与常用于检查某一权限是否存在。`~x` 的结果看似反直觉，是 32 位补码表示的结果。

# 三、移位

`<<` 向左移动位，`>>` 向右移动并保留符号位，`>>>` 向右移动并在左侧补零。

```js
console.log(5 << 1);  // 10
console.log(5 >> 1);  // 2
console.log(-5 >> 1); // -3
console.log(-5 >>> 1); // 2147483645
```

对非负小整数，左移一位看起来像乘以 2，右移一位看起来像除以 2 后取整；但溢出、负数和 32 位截断会改变结果，因此不要把移位当作普通算术的替代写法。

# 四、32 位转换边界

对 `number` 使用位运算时，JavaScript 会先把它转换为 32 位整数，小数部分和高位可能丢失。

```js
console.log(1.9 | 0);        // 1
console.log(2 ** 32 | 0);    // 0
```

> [!warning]
> 不要用 `value | 0` 作为通用取整技巧，它会截断到 32 位。普通取整请按意图选择 `Math.trunc()`、`Math.floor()` 或 `Math.round()`，见 [[9、类型转换与数值处理|类型转换与数值处理]]。
