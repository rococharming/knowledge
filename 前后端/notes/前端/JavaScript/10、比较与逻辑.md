# 一、比较与相等

比较运算符会产生布尔值。比较数值大小可使用 `>`、`>=`、`<`、`<=`；比较两个值是否相同则使用相等或不等运算符。

## 1、大小比较

```js
console.log(6 < 9);  // true
console.log(6 >= 6); // true
```

两个操作数都是字符串时，大小比较按字符串顺序进行；其他常见情形会尝试把操作数转为数值再比较。`null >= 0` 为 `true`，因为这里的 `null` 会转为 `0`；它与下面的宽松相等规则无关。

## 2、相等与不等

`===` 是严格相等：基本类型只有 **类型相同且值相同** 才返回 `true`；对象和函数必须是同一个引用才相等。它不会为了比较而转换类型。`!==` 是严格相等结果的取反；只要 `===` 为 `false`，`!==` 就为 `true`。

```js
console.log(5 === 5);   // true：类型和值都相同
console.log(5 === "5"); // false：number 与 string 类型不同
console.log(5 !== "5"); // true：严格相等的结果为 false
```

两个内容相同但分别创建的对象不是同一个对象：

```js
const firstUser = { name: "Ada" };
const secondUser = { name: "Ada" };
const sameUser = firstUser;

console.log(firstUser === secondUser); // false
console.log(firstUser === sameUser);   // true
```

对数字还有两个边界：`NaN === NaN` 为 `false`，`0 === -0` 为 `true`。

`==` 是宽松相等：当两侧类型不同时，它会按一套固定规则继续比较；`!=` 则是宽松相等结果的取反。这个过程不能简单理解成“两边都调用 `Number()`”：字符串和数字会进行数值转换，布尔值会先转成数字，而 `null` 与 `undefined` 是专门的一组规则。

```js
console.log(5 == "5");        // true："5" 转为数字 5
console.log(false == 0);       // true：false 转为数字 0
console.log(null == undefined); // true：宽松相等的特殊规则
console.log(null == 0);        // false：null 不会在这里转为 0
console.log(5 != "5");        // false：宽松相等的结果为 true
```

因此，新代码默认使用 `===` 和 `!==`。只有想同时检查 `null` 与 `undefined` 时，`value == null` 才是一个可读的受控用法：

```js
let selectedUser;  // undefined

console.log(selectedUser == null); // true
console.log(null === undefined);   // false
```

不要依赖 `null >= 0`、`null == 0` 这类不同运算符之间的转换差异；应先明确处理空值。

# 二、真假值

条件位置会把任意值转为布尔值。下面是 JavaScript 的 falsy 值：`false`、`0`、`-0`、`0n`、空字符串、`null`、`undefined` 和 `NaN`；其他值均为 truthy，包括空数组和空对象。

```js
if ("") {
  console.log("不会执行");
}

if ([]) {
  console.log("会执行");
}
```

如果业务真正要判断布尔值，应把条件写清楚，不要用 truthy/falsy 代替必需的格式校验。

# 三、逻辑运算与短路

`&&`、`||` 和 `??` 不一定返回布尔值，而是返回决定结果的原始操作数，并且会短路：不需要判断右侧时，右侧不会执行。`??` 称为 **空值合并运算符**，只把 `null` 和 `undefined` 视作“缺失”。

| 运算符 | 返回规则 | 常见用途 |
|---|---|---|
| `&&` | 第一个 falsy 值；全为 truthy 时返回最后一个值 | 多个前置条件 |
| \|\| | 第一个 truthy 值；没有则返回最后一个值 | 允许任意 falsy 值时的默认值 |
| `??` | 左侧不是 `null`/`undefined` 时返回左侧 | 只把空值视作缺失 |

```js
console.log("ready" && 42); // 42
console.log(0 && "next");   // 0
console.log("Ada" || "Guest"); // "Ada"
console.log(0 || 10);        // 10
console.log(0 ?? 10);        // 0
console.log(null ?? "Guest"); // "Guest"
```

`!` 先把值转换为布尔值再取反。`!!value` 可以得到明确布尔值，但只有确实需要布尔类型时才使用。

```js
console.log(!true);      // false
console.log(!!"hello"); // true
```

> [!warning]
> 不能把 `??` 与 `&&` 或 `||` 不加括号地直接混用。需要组合时，用括号表达优先顺序，例如 `(name ?? "Guest") || "Anonymous"`。
