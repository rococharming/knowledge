# 一、拼接文本

字符串拼接就是把多个字符串连接成一个新字符串。JavaScript 字符串不可变，所以拼接、替换、截取等操作都会返回新字符串，不会原地修改旧字符串。

## 1、加号拼接

`+` 可以把多个字符串连接成一个新字符串。

示例：

```js
const firstName = "Ada";
const lastName = "Lovelace";

const fullName = firstName + " " + lastName;

console.log(fullName);
```

## 2、追加拼接

`+=` 可以在原变量的基础上追加新字符串。

示例：

```js
let message = "Hello";

message += ", ";
message += "JavaScript";
message += "!";

console.log(message);
```

虽然写法像是在“修改字符串”，但实际发生的是：每次拼接都会创建一个新的字符串，然后让变量 `message` 指向新字符串。

## 3、concat 方法

`concat()` 是字符串对象上的方法，也可以把多个字符串连接起来。

示例：

```js
const greeting = "Hello";
const target = "Console";

const result = greeting.concat(", ", target, "!");

console.log(result);
```

日常写字符串时，简单拼接可以用 `+`；需要插入变量和表达式时，[[5、字符串基础#二、创建方式|模板字符串]] 通常更清晰；`concat()` 认识即可，不必把它作为首选。

| 写法 | 适合场景 | 示例 |
|---|---|---|
| `+` | 少量简单拼接 | `"Hello, " + name` |
| `+=` | 分步骤累加文本 | `message += "!"` |
| 模板字符串 | 插入变量或表达式 | `` `Hello, ${name}` `` |
| `concat()` | 认识字符串方法 | `a.concat(b)` |

# 二、查找文本

## 1、indexOf

子字符串（substring）是一段出现在更大字符串里的连续文本。比如在 `"JavaScript is fun"` 中，`"JavaScript"` 和 `"fun"` 都是子字符串。

查找子字符串的位置时，可以使用 `indexOf()` 方法。

示例：

```js
const sentence = "JavaScript is fun";
const position = sentence.indexOf("fun");

console.log(position);
```

`"fun"` 从索引 `14` 开始，所以 `indexOf()` 返回 `14`。

如果没有找到目标子字符串，`indexOf()` 会返回 `-1`。

```js
const sentence = "JavaScript is fun";

console.log(sentence.indexOf("Rust"));
```

这里返回 `-1`，表示 `"Rust"` 不在这个字符串里。

## 2、起始位置

`indexOf()` 可以接收第二个参数，表示从哪个索引位置开始查找。

示例：

```js
const text = "JavaScript and JavaScript";

console.log(text.indexOf("JavaScript"));
console.log(text.indexOf("JavaScript", 1));
```

第一次从开头查找，返回 `0`；第二次从索引 `1` 开始查找，会跳过第一个 `"JavaScript"`，找到后面那一次。

`indexOf()` 区分大小写：

```js
console.log("freeCodeCamp".indexOf("F"));
```

这段代码返回 `-1`，因为字符串里没有大写的 `"F"`。

## 3、includes

如果只关心“有没有包含某段文本”，不关心具体位置，可以使用 `includes()`。它返回布尔值：找到返回 `true`，没找到返回 `false`。

示例：

```js
const phrase = "JavaScript is awesome";

console.log(phrase.includes("awesome"));
console.log(phrase.includes("Awesome"));
```

第一次返回 `true`，第二次返回 `false`，因为 `includes()` 也区分大小写。

`includes()` 也可以接收第二个参数，表示从哪个索引位置开始查找：

```js
const text = "Hello, JavaScript world";

console.log(text.includes("JavaScript", 7));
```

# 三、截取文本

## 1、slice 范围

`slice()` 用来从字符串中截取一段文本，并返回新字符串。它不会修改原字符串。

示例：

```js
const message = "Hello, world!";
const greeting = message.slice(0, 5);

console.log(greeting);
console.log(message);
```

`slice(0, 5)` 从索引 `0` 开始，到索引 `5` 之前结束，所以结果是 `"Hello"`。结束索引本身不会被包含进去。

## 2、省略结束

如果省略第二个参数，`slice()` 会从起始索引一直截取到字符串末尾。

示例：

```js
const message = "Hello, world!";
const target = message.slice(7);

console.log(target);
```

这里从索引 `7` 开始，得到 `"world!"`。

## 3、负数索引

`slice()` 可以使用负数索引。负数会从字符串末尾往前数。

示例：

```js
const message = "JavaScript is fun!";
const lastPart = message.slice(-4);

console.log(lastPart);
```

`slice(-4)` 会取最后四个字符，结果是 `"fun!"`。

# 四、规范文本

## 1、大小写

`toUpperCase()` 返回全大写的新字符串，`toLowerCase()` 返回全小写的新字符串。

示例：

```js
const greeting = "Hello, World!";

console.log(greeting.toUpperCase());
console.log(greeting.toLowerCase());
console.log(greeting);
```

原字符串 `greeting` 不会被修改。大小写转换常用于统一用户输入，或者做不区分大小写的比较。

## 2、去除空白

空白包括空格、制表符和换行等不可见字符。`trim()` 可以去掉字符串开头和结尾的空白，但不会处理中间的空白。

示例：

```js
const message = "   Hello, world!   ";

console.log(message.trim());
console.log(message);
```

如果只想去掉开头或结尾，可以使用 `trimStart()` 和 `trimEnd()`。

```js
const message = "   Hello!   ";

console.log(message.trimStart());
console.log(message.trimEnd());
```

## 3、输入清理

从用户输入或外部数据拿到字符串后，常见做法是先清理空白、统一大小写，再参与比较。

示例：

```js
const rawAnswer = "  YES ";
const normalizedAnswer = rawAnswer.trim().toLowerCase();

console.log(normalizedAnswer);
```

这里先去掉两端空白，再转成小写，结果是 `"yes"`。

# 五、替换文本

## 1、replace

`replace()` 可以把字符串中的一段内容替换成另一段内容，并返回新字符串。

示例：

```js
const text = "I love JavaScript!";
const updatedText = text.replace("JavaScript", "coding");

console.log(updatedText);
console.log(text);
```

结果是 `"I love coding!"`，原来的 `text` 不会被修改。

## 2、大小写敏感

`replace()` 默认区分大小写。

示例：

```js
const sentence = "I enjoy JavaScript.";

console.log(sentence.replace("javascript", "coding"));
```

因为 `"javascript"` 和 `"JavaScript"` 大小写不同，所以不会发生替换。

## 3、只替换首次

当第一个参数是普通字符串时，`replace()` 默认只替换第一次出现的内容。

示例：

```js
const phrase = "world and world";
const updatedPhrase = phrase.replace("world", "universe");

console.log(updatedPhrase);
```

结果是 `"universe and world"`。如果要替换所有出现位置，后续可再学习 `replaceAll()` 或正则表达式。

# 六、重复文本

## 1、repeat

`repeat()` 可以把字符串重复指定次数，并返回新字符串。

示例：

```js
const word = "Hi!";

console.log(word.repeat(3));
```

结果是 `"Hi!Hi!Hi!"`。

## 2、次数规则

`repeat()` 的次数必须是非负、有限的数字。

示例：

```js
const word = "Test";

console.log(word.repeat(0));
console.log(word.repeat(2.5));
```

`repeat(0)` 返回空字符串 `""`；`repeat(2.5)` 会按 `2` 次处理。

下面这类写法会报错：

```js
const word = "Test";

console.log(word.repeat(-1));
console.log(word.repeat(Infinity));
```

负数和 `Infinity` 都不是有效重复次数，会导致 `RangeError`。

# 七、浏览器输入

## 1、prompt

`prompt()` 是浏览器提供的简单输入弹窗。它会暂停当前脚本，显示一个对话框，让用户输入文本，然后把输入结果交回 JavaScript。

示例：

```js
const userName = prompt("请输入你的名字：", "Guest");

console.log(userName);
```

这里第一个参数是提示文字，第二个参数是输入框里的默认值。用户点击确定后，`prompt()` 会返回输入框里的文本。

> [!note] 浏览器 API
> `prompt()` 不是 JavaScript 核心语言语法，而是浏览器提供的 Web API。它只能在浏览器环境中使用，不能直接当作所有 JavaScript 运行环境都有的能力。

## 2、返回值

用户输入内容并点击确定时，`prompt()` 返回字符串；用户点击取消时，`prompt()` 返回 `null`。

示例：

```js
const answer = prompt("你正在学习什么？", "JavaScript");

console.log(answer);
console.log(answer === null);
```

即使用户输入的是数字，`prompt()` 拿到的也仍然是字符串。后续如果要把它当作数字计算，需要先做类型转换。

## 3、使用边界

`prompt()` 适合初学时快速观察“用户输入如何进入 JavaScript”。但真实网页应用里通常较少使用它，因为它会打断用户操作，样式也不容易自定义，不适合复杂交互。

练习时可以只写一个最小脚本：

```js
const rawName = prompt("请输入你的名字：", "Guest");

console.log(rawName);
```

这个示例只关注输入结果，没有使用按钮、DOM 查询或事件监听。
