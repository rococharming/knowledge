# 一、函数与调用

函数是一段可复用的代码：先声明它要完成的工作，再在需要时调用它。声明函数只是在定义这段代码，不会立刻执行函数体；调用时才会执行。

```js
function greet() {
  console.log("你好！");
}

greet(); // 输出“你好！”
```

`greet` 是函数名，`greet()` 是一次函数调用。括号不能省略：不带括号的 `greet` 表示函数本身，而不是执行它。

# 二、输入与输出

## 1、参数与实参

参数是声明函数时写在括号里的占位名称；实参是调用函数时传入的实际值。参数让同一段函数逻辑可以处理不同输入。

```js
function greet(name) {
  console.log(`你好，${name}！`);
}

greet("Alice");
greet("Nick");
```

这里的 `name` 是参数，`"Alice"` 和 `"Nick"` 是实参。每次调用时，函数都会把当前实参的值交给对应参数使用。

## 2、默认参数

默认参数为没有传入实参的情况准备一个值。调用时没有提供该位置的实参，或者传入 `undefined` 时，才会使用默认值；传入 `null` 不会触发默认值。

```js
function greet(name = "访客") {
  console.log(`你好，${name}！`);
}

greet();            // “你好，访客！”
greet(undefined);   // “你好，访客！”
greet("Anna");      // “你好，Anna！”
greet(null);        // “你好，null！”
```

## 3、返回值

函数执行结束后一定会得到一个返回值。没有写 `return` 时，返回值是 `undefined`；`console.log()` 只是输出信息，不会把输出内容作为函数结果返回。

```js
function doSomething() {
  console.log("正在处理");
}

const result = doSomething();
console.log(result); // undefined
```

`return` 用于把一个值交给调用函数的地方，之后可以继续使用这个结果：

```js
function calculateSum(first, second) {
  return first + second;
}

const total = calculateSum(3, 4);
console.log(total); // 7
```

# 三、函数的写法

## 1、函数声明

函数声明使用 `function` 关键字和函数名，适合为一段逻辑提供清晰、可复用的名称。

```js
function calculateArea(width, height) {
  return width * height;
}
```

## 2、函数表达式

函数也是一种值，因此可以创建一个没有名称的函数，再把它保存到变量中。这种写法称为函数表达式；调用时使用变量名。

```js
const calculateSum = function (first, second) {
  return first + second;
};

console.log(calculateSum(3, 4)); // 7
```

这里 `calculateSum` 是变量名，不是函数内部的名字。因为它用 `const` 声明，之后不能让这个变量改为保存另一个函数。

## 3、箭头函数

箭头函数是函数表达式的另一种语法。它省略 `function` 关键字，用 `=>` 把参数列表和函数体连接起来。

```js
const greet = name => {
  console.log(`你好，${name}！`);
};
```

参数列表的括号取决于参数数量：

```js
const greet = name => console.log(`你好，${name}！`);
const getGreeting = () => "你好！";
const calculateArea = (width, height) => width * height;
```

- 只有一个参数时，括号可以省略。
- 没有参数或有多个参数时，必须保留括号。
- 函数体只有一个表达式且省略花括号时，这个表达式会被自动返回；上例的 `getGreeting()` 和 `calculateArea()` 都有返回值。
- 写了花括号后，不会自动返回值；需要结果时必须显式写 `return`。

```js
const calculateArea = (width, height) => {
  return width * height;
};
```

> [!note]
> 箭头函数不只是“更短的函数声明”，与普通函数还存在当前阶段未展开的行为差异。先按代码库已有风格选择写法，不要只为了省略几处字符而混用两种风格。
