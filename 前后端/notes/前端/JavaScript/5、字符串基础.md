# 一、字符串

字符串（string）是 JavaScript 中用来表示文本的原始值。用户名、按钮文案、提示信息、表单输入、接口返回的文本字段，都经常用字符串表示。

示例：

```js
const title = "JavaScript";
const buttonText = "保存";

console.log(title);
console.log(buttonText);
```

字符串看起来像一段普通文字，但在程序里，它是一个可以被保存、拼接、读取长度和读取字符的值。

# 二、创建方式

## 1、普通引号

字符串可以用单引号或双引号创建。两者在创建普通字符串时没有本质区别，关键是同一个字符串的开头和结尾必须匹配。

示例：

```js
const singleQuoteText = '使用单引号';
const doubleQuoteText = "使用双引号";

console.log(singleQuoteText);
console.log(doubleQuoteText);
```

下面的写法是错误的，因为开头是双引号，结尾却是单引号：

```js
const brokenText = "引号没有配对';
```

真实项目中更重要的是保持一致。一个团队可以统一使用双引号，也可以统一使用单引号；只要风格稳定，阅读成本就会低很多。

## 2、转义字符

有些字符在字符串里有特殊含义。比如双引号字符串中的 `"` 会被 JavaScript 理解为字符串边界。如果想让它作为普通文本出现，需要使用反斜杠 `\` 转义。

示例：

```js
const quote = "She said, \"Hello!\"";

console.log(quote);
```

这里 `\"` 表示“这是文本里的双引号，不是字符串结束标记”。

常见转义写法：

| 写法 | 含义 | 示例结果 |
|---|---|---|
| `\"` | 双引号 | `"` |
| `\'` | 单引号 | `'` |
| `\\` | 反斜杠 | `\` |
| `\n` | 换行 | 输出到下一行 |

示例：

```js
const poem = "第一行\n第二行\n第三行";

console.log(poem);
```

`\n` 会在字符串中产生换行。

## 3、模板字符串

反引号可以创建模板字符串。模板字符串最常见的用途是把变量或表达式插入文本中，这叫字符串插值（string interpolation）。

示例：

```js
const userName = "Ada";
const points = 95;

const message = `${userName} 的分数是 ${points}`;

console.log(message);
```

`${userName}` 和 `${points}` 会被替换为对应表达式的结果。相比手动拼接，模板字符串更适合生成包含变量的句子。

模板字符串也可以自然书写多行文本，不必使用 `\n`：

```js
const cardText = `学习目标：
1. 理解字符串
2. 学会读取字符`;

console.log(cardText);
```

需要注意的是，模板字符串会保留源码中的换行和空格。多行文本如果缩进很多，输出里也可能带上这些空白。

# 三、字符访问

## 1、索引

字符串可以看作一串按顺序排列的字符。每个字符都有位置，这个位置叫索引（index）。JavaScript 的字符串索引从 `0` 开始。

示例：

```js
const word = "hello";

console.log(word[0]);
console.log(word[1]);
console.log(word[2]);
```

输出结果分别是 `"h"`、`"e"`、`"l"`。第一位字符不是索引 `1`，而是索引 `0`。

## 2、长度

`length` 属性表示字符串里有多少个 UTF-16 码元。对于常见英文字母、数字和半角符号，可以先把它理解为“字符个数”。

示例：

```js
const word = "hello";

console.log(word.length);
```

`"hello"` 的长度是 `5`。因为索引从 `0` 开始，所以最后一个位置的索引是 `length - 1`。

示例：

```js
const word = "hello";
const lastIndex = word.length - 1;

console.log(word[lastIndex]);
```

这里 `word.length - 1` 得到 `4`，所以 `word[4]` 是最后一个字符 `"o"`。

# 四、字符编码

## 1、ASCII

ASCII（American Standard Code for Information Interchange）是一套早期字符编码标准，用数字表示常见英文字符、数字、标点和控制字符。

常见例子：

| 字符 | ASCII 数值 |
|---|---:|
| `A` | `65` |
| `a` | `97` |
| `0` | `48` |
| `!` | `33` |

JavaScript 字符串内部使用 Unicode 的 UTF-16 表示方式，不过 ASCII 的前 128 个字符和 Unicode 的前 128 个码位一致，所以用英文字母、数字和常见符号演示时，ASCII 数值和 JavaScript 取到的 UTF-16 码元值相同。

## 2、charCodeAt

`charCodeAt()` 可以读取指定索引位置的 UTF-16 码元值。对于 ASCII 范围内的字符，这个值正好等于 ASCII 数值。

示例：

```js
const letter = "A";
const symbol = "!";

console.log(letter.charCodeAt(0));
console.log(symbol.charCodeAt(0));
```

`"A".charCodeAt(0)` 返回 `65`，`"!".charCodeAt(0)` 返回 `33`。

> [!warning] 不要把 charCodeAt 简化成“取 ASCII”
> `charCodeAt()` 返回的是 UTF-16 码元值。只是对 `A`、`a`、`0`、`!` 这类基础英文字符来说，它刚好和 ASCII 数值一致。

## 3、fromCharCode

`String.fromCharCode()` 可以把 UTF-16 码元值转换成字符串。对于 ASCII 范围内的数字，它会得到对应的基础英文字符或符号。

示例：

```js
const upperA = String.fromCharCode(65);
const lowerA = String.fromCharCode(97);

console.log(upperA);
console.log(lowerA);
```

这里 `65` 转成 `"A"`，`97` 转成 `"a"`。

# 五、不可变性

## 1、字符不能原地改

字符串是不可变的。不可变的意思是：字符串一旦创建，它里面的字符序列不会被原地修改。

示例：

```js
const word = "cat";

word[0] = "b";

console.log(word);
```

这段代码不会把 `"cat"` 改成 `"bat"`。用方括号可以读取某个位置的字符，但不能通过给某个位置赋值来修改原字符串。

## 2、变量可以换值

字符串不可变，不代表保存字符串的变量永远不能变化。`let` 声明的变量可以重新指向另一个字符串。

示例：

```js
let currentUser = "Ada";
console.log(currentUser);

currentUser = "Grace";
console.log(currentUser);
```

这里不是把 `"Ada"` 这个字符串改成了 `"Grace"`，而是让变量 `currentUser` 保存了一个新的字符串。这个区别和 [[3、变量声明|变量声明]] 中的重新赋值有关。

> 简单来说：字符串值本身不能被原地修改；变量名可以重新指向另一个字符串值。
