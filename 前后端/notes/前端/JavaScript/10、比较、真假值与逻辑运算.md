# 一、比较与相等

比较运算符会产生布尔值。比较数值大小可使用 `>`、`>=`、`<`、`<=`；比较两个值是否相同时，默认使用严格相等 `===` 和严格不等 `!==`。

```js
console.log(6 < 9);       // true
console.log(6 >= 6);      // true
console.log(5 === "5");  // false
console.log(5 !== "5");  // true
```

`==` 与 `!=` 会在比较前尝试类型转换，容易制造难以发现的错误。只有想同时检查 `null` 和 `undefined` 时，`value == null` 才是一个可读的受控用法；其余场景使用严格比较。

```js
let selectedUser;

console.log(selectedUser == null); // true
console.log(null === undefined);   // false
```

`null >= 0` 为 `true`、`null == 0` 为 `false` 是不同转换规则造成的结果。不要依赖这种行为，应先明确处理空值。

# 二、真假值

条件位置会把任意值转为布尔值。下面是 JavaScript 的 falsy 值：`false`、`0`、`-0`、`0n`、空字符串、`null`、`undefined` 和 `NaN`；其他值均为 truthy，包括空数组和空对象。

```js
if ("") {
  console.log("不会执行");
}

if ([]) {
  console.log("会执行");
}
```

如果业务真正要判断布尔值，应把条件写清楚，不要用 truthy/falsy 代替必需的格式校验。

# 三、逻辑运算与短路

`&&`、`||` 和 `??` 不一定返回布尔值，而是返回决定结果的原始操作数，并且会短路：不需要判断右侧时，右侧不会执行。

| 运算符 | 返回规则 | 常见用途 |
|---|---|---|
| `&&` | 第一个 falsy 值；全为 truthy 时返回最后一个值 | 多个前置条件 |
| `||` | 第一个 truthy 值；没有则返回最后一个值 | 允许任意 falsy 值时的默认值 |
| `??` | 左侧不是 `null`/`undefined` 时返回左侧 | 只把空值视作缺失 |

```js
console.log("ready" && 42); // 42
console.log(0 && "next");   // 0
console.log("Ada" || "Guest"); // "Ada"
console.log(0 || 10);        // 10
console.log(0 ?? 10);        // 0
console.log(null ?? "Guest"); // "Guest"
```

`!` 先把值转换为布尔值再取反。`!!value` 可以得到明确布尔值，但只有确实需要布尔类型时才使用。

```js
console.log(!true);      // false
console.log(!!"hello"); // true
```

> [!warning]
> 不能把 `??` 与 `&&` 或 `||` 不加括号地直接混用。需要组合时，用括号表达优先顺序，例如 `(name ?? "Guest") || "Anonymous"`。
