# 一、值与类型

## 1、变量和值

JavaScript 程序处理的是一个个 **值（value）**，而 **数据类型（data type）** 描述这个值属于哪一类。数字、文本、真假、空值、对象，都是不同类型的值。

示例：

```js
console.log(18);
console.log("Kamen Rider");
console.log(true);
```

这三个值分别是数字、字符串和布尔值。类型会影响值能做什么操作：数字可以参与计算，字符串适合表示文本，布尔值适合表达判断结果。

JavaScript 是动态类型语言。变量名本身不固定绑定某一种类型，真正有类型的是变量当前保存的值。

```js
let result = 10;
result = "完成";
```

这段代码中，`result` 先保存数字，后来保存字符串。能不能这样写，不代表应该随意混用；实际开发中，同一个变量最好保持稳定含义，否则代码会很难读。

## 2、动态类型

动态类型（dynamic typing）指的是：声明变量时不用提前写死变量类型，JavaScript 会根据运行时保存的值来判断类型。

示例：

```js
let data = 100;
console.log(data);

data = "New data";
console.log(data);
```

第一次输出 `100`，第二次输出 `"New data"`。这说明 `data` 这个变量名先保存了数字，后来又保存了字符串。变化的是变量当前保存的值，变量名本身没有固定类型。

这和 Rust 这类静态类型语言不同。Rust 也可以根据初始值推断类型，但类型一旦确定，同一个变量绑定就不能随意从数字变成字符串。

示例：

```rust
let mut count = 42;
count = "Hello"; // 错误：count 已经被推断为整数
```

动态类型的好处是写小脚本、做快速实验时很灵活；代价是某些类型错误可能到运行时才暴露。初学阶段可以先养成一个习惯：同一个变量尽量只表达同一种含义，不要一会儿放数字，一会儿放字符串。

> [!note] 动态类型不等于弱类型
> 动态类型强调“变量名不固定绑定某种类型”；弱类型强调“运算时可能发生隐式类型转换”。这两个概念有关联，但不是同一个意思。

# 二、原始类型

## 1、七种原始值

JavaScript 的原始类型有七种：`string`、`number`、`bigint`、`boolean`、`undefined`、`symbol`、`null`。

| 类型 | 含义 | 示例 |
|---|---|---|
| `string` | 文本 | `"hello"` |
| `number` | 普通数字 | `42`、`3.14` |
| `bigint` | 任意精度整数 | `9007199254740993n` |
| `boolean` | 真或假 | `true`、`false` |
| `undefined` | 尚未赋值 | `undefined` |
| `symbol` | 唯一标识 | `Symbol("id")` |
| `null` | 主动表示“没有值” | `null` |

原始值本身是不可变的。比如字符串 `"hello"` 不会被原地改成另一个字符串；如果变量后来保存了新字符串，那是变量指向了新值，而不是旧字符串被修改。

## 2、Number

`number` 用来表示普通整数和小数。

示例：

```js
console.log(7);
console.log(3.14);
console.log(-20);
```

JavaScript 的 `number` 适合大多数日常计算，但它不是无限精度。超大整数如果超过安全范围，可能出现精度问题。

```js
console.log(Number.MAX_SAFE_INTEGER);
console.log(9007199254740991 + 1);
console.log(9007199254740991 + 2);
```

最后两行可能得到相同结果，因为普通 `number` 无法安全表达所有特别大的整数。需要保存超大整数时，可以使用 `bigint`。

## 3、String

`string` 用来表示文本。字符串可以用双引号、单引号或反引号包裹。

示例：

```js
console.log("Hello");
console.log('JavaScript');
console.log(`score: ${100}`);
```

反引号创建的是模板字符串，适合把变量或表达式嵌入文本中：

```js
const name = "Ada";
const message = `Hello, ${name}!`;

console.log(message);
```

这里 `${name}` 会被替换为变量 `name` 当前保存的值。

更完整的字符串创建、拼接和不可变性，可继续看 [[5、字符串|字符串]]。

## 4、Boolean

`boolean` 只有两个值：`true` 和 `false`。它通常用来表达判断结果或开关状态。

示例：

```js
const isLoggedIn = false;

if (isLoggedIn) {
  console.log("显示用户面板");
} else {
  console.log("显示登录入口");
}
```

这里 `isLoggedIn` 表示“用户是否已登录”。后续学习条件判断时，布尔值会成为控制程序分支的核心。

# 三、空与缺失

## 1、undefined

`undefined` 表示“还没有得到值”。常见场景是变量已经声明，但没有初始化。

示例：

```js
let nickname;

console.log(nickname);
```

这段代码会输出 `undefined`，意思是 `nickname` 这个变量存在，但当前没有保存具体值。

## 2、null

`null` 表示开发者主动把某个位置设为“没有值”。

示例：

```js
let selectedUser = null;

console.log(selectedUser);
```

`undefined` 更像“还没给”，`null` 更像“明确为空”。实际写程序时，这个区别可以帮助读者理解某个值到底是遗漏了，还是有意为空。

> [!warning] `typeof null` 的历史遗留
> `typeof null` 会得到 `"object"`，这是 JavaScript 早期留下来的历史行为。判断一个值是否为 `null`，应直接使用 `value === null`。

# 四、对象类型

## 1、Object

除七种原始类型外，JavaScript 还有对象类型。对象适合把一组相关信息放在一起，使用键值对描述一个实体。

示例：

```js
const user = {
  name: "Ada",
  age: 28,
  isMember: true
};

console.log(user.name);
```

这里 `user` 是一个对象，`name`、`age`、`isMember` 是它的属性。对象不是简单的单个值，而是一组可组织、可访问、可修改的数据。

## 2、数组与函数

数组和函数也属于对象家族，只是它们有更专门的用途。

示例：

```js
const scores = [80, 95, 100];

function add(a, b) {
  return a + b;
}

console.log(scores[0]);
console.log(add(2, 3));
```

数组适合保存一组有顺序的值，函数适合保存一段可重复执行的逻辑。后续学习对象、数组和函数时，会继续展开它们的结构和用法。

# 五、类型观察

`typeof` 可以查看大多数值的类型，适合初学时快速观察。

示例：

```js
console.log(typeof 42);
console.log(typeof "hello");
console.log(typeof true);
console.log(typeof undefined);
console.log(typeof 123n);
console.log(typeof Symbol("id"));
console.log(typeof {});
console.log(typeof null);
```

常见输出如下：

| 表达式 | 结果 |
|---|---|
| `typeof 42` | `"number"` |
| `typeof "hello"` | `"string"` |
| `typeof true` | `"boolean"` |
| `typeof undefined` | `"undefined"` |
| `typeof 123n` | `"bigint"` |
| `typeof Symbol("id")` | `"symbol"` |
| `typeof {}` | `"object"` |
| `typeof null` | `"object"` |

`typeof null` 返回 `"object"` 是 JavaScript 早期实现留下来的历史行为，不能说明 `null` 真的是普通对象。判断一个值是不是 `null`，应直接使用严格相等：

```js
const selectedUser = null;

console.log(selectedUser === null);
```

理解类型后，再学习 [[3、变量声明|变量声明]] 会更顺：变量只是给值起名字，类型真正跟着值走。
