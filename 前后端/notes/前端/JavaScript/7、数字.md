# 一、Number

JavaScript 用 `number` 类型同时表示常见整数和小数，没有单独的 `int` 或 `float` 类型。`50`、`4.5`、`-7` 的 `typeof` 都是 `"number"`。

```js
console.log(typeof 50);  // "number"
console.log(typeof 4.5); // "number"
console.log(typeof -7);  // "number"
```

# 二、数值写法

数字字面量可以使用不同进制；这些只是写法不同，最终仍是同一个 `number` 值。

```js
const decimal = 42;        // 十进制
const binary = 0b101010;   // 二进制
const octal = 0o52;        // 八进制
const hexadecimal = 0x2a;  // 十六进制
const scientific = 1.5e3;  // 科学计数法

console.log(decimal, binary, octal, hexadecimal, scientific);
```

# 三、精度

## 1、安全整数

`number` 使用双精度浮点表示，能精确保存的整数范围有限。超过 `Number.MAX_SAFE_INTEGER` 后，连续整数可能变成同一个值。

```js
console.log(Number.MAX_SAFE_INTEGER); // 9007199254740991
console.log(Number.isSafeInteger(9007199254740991)); // true
console.log(Number.isSafeInteger(9007199254740992)); // false
```

## 2、浮点误差

小数也可能出现二进制浮点误差：

```js
console.log(0.1 + 0.2); // 0.30000000000000004
```

> [!warning] 金额
> 不要把 `number` 的小数计算直接当作精确货币计算。常见做法是以“分”这类最小货币单位保存整数；需要任意精度小数时再选择合适的十进制库。

# 四、BigInt

`bigint` 用于任意精度整数，字面量以 `n` 结尾。它适合超出安全整数范围的 ID、计数或整数计算，不是 `number` 的日常替代品。

```js
const largeId = 9007199254740993n;

console.log(typeof largeId); // "bigint"
console.log(largeId + 2n);   // 9007199254740995n
```

`number` 和 `bigint` 不能直接混合运算：

```js
const count = 10n;

// count + 1; // TypeError
console.log(count + 1n);
```

只有确认不会丢失精度时，才使用 `Number(bigintValue)` 转回 `number`。

# 五、特殊值

`NaN`、`Infinity`、`-Infinity` 和 `-0` 都属于 `number` 类型，但不能把它们当作普通数字处理。

## 1、NaN 与无穷

`NaN` 表示一次数值运算没有得到有效结果；`Infinity` 和 `-Infinity` 分别表示正无穷和负无穷。

```js
console.log(0 / 0); // NaN
console.log("hello" / 2); // NaN
console.log(1 / 0); // Infinity
console.log(-1 / 0); // -Infinity
```

`NaN` 不等于任何值，也不等于自己。要检查它，使用 `Number.isNaN()`；把输入解析成数值后是否有效，见 [[9、类型转换|类型转换]]。

## 2、带符号的零

JavaScript 的浮点数中有 `0` 和 `-0` 两种零：

- `0`：正零，也可以写成 `+0`。
- `-0`：负零。

在大多数情况下，它们可以当作相同的值使用：

```js
console.log(0 === -0); // true
```

符号仍会影响某些运算：

```js
console.log(1 / 0);  // Infinity
console.log(1 / -0); // -Infinity
```

需要区分两者时使用 `Object.is()`：

```js
console.log(Object.is(0, -0)); // false
```

日常开发通常不需要处理 `-0`；在浮点计算、方向或符号信息有意义的场景，它才可能影响结果。

# 六、显示数字

`toFixed(digits)` 按固定小数位生成文本，返回值是 **字符串**，因此适合展示而不是继续计算。

```js
const price = 19.99;

console.log(price.toFixed(2)); // "19.99"
console.log((3.14159).toFixed(2)); // "3.14"
```
