# 一、语句

语句（statement）可以先理解为 JavaScript 中的一条完整指令。程序运行时，会按顺序执行一条条语句。

示例：

```js
const price = 10;
const count = 3;

console.log(price * count);
```

这里有三条语句：

- `const price = 10;`：声明变量，并保存数字 `10`。
- `const count = 3;`：声明变量，并保存数字 `3`。
- `console.log(price * count);`：把计算结果输出到控制台。

前面学过 [[3、变量声明|变量声明]] 后，再看语句会更清楚：变量声明是一种语句，控制台输出也是一种语句。

# 二、分号

JavaScript 用分号表示一条语句的结束，它也有有自动分号插入机制，通常叫 ASI（Automatic Semicolon Insertion）。当代码里省略某些分号时，JavaScript 在解析代码时可能会自动补上分号。

示例：

```js
const name = "Ada"
console.log(name)
```

这段代码通常可以运行，因为 JavaScript 会在合适位置自动补分号。它大致会被理解为：

```js
const name = "Ada";
console.log(name);
```

虽然 ASI 让省略分号的代码经常可以运行，但仍然建议统一显式写分号。

原因有三个：

- **边界清楚**：每条语句在哪里结束，一眼可见。
- **习惯稳定**：以后读项目代码时，不容易在有分号和无分号风格之间摇摆。
- **减少意外**：ASI 有规则，不是“每次换行都补分号”。少数写法可能和直觉不同。

# 三、注释

## 1、单行注释

注释是写给人看的说明，JavaScript 执行代码时会忽略注释。单行注释从 `//` 开始，一直到这一行结束。

示例：

```js
// 保存用户当前分数
const score = 100;

console.log(score);
```

这条注释解释了变量 `score` 的用途。它不会影响代码运行。

## 2、多行注释

多行注释使用 `/*` 开始，用 `*/` 结束，适合写较长说明。

示例：

```js
/*
  这里记录用户欢迎语。
  后续可以根据登录状态显示不同文本。
*/
const greeting = "Hello";

console.log(greeting);
```

多行注释不能随意嵌套。也就是说，不要在一个 `/* ... */` 注释里面再放另一个 `/* ... */`，否则很容易提前结束注释，造成语法错误。
