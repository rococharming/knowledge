# 一、字符串

字符串（string）是 JavaScript 中用来表示文本的原始值。用户名、按钮文案、提示信息、表单输入、接口返回的文本字段，都经常用字符串表示。

示例：

```js
const title = "JavaScript 练习";
const buttonText = "保存";

console.log(title);
console.log(buttonText);
```

字符串属于 [[2、值与数据类型|值与数据类型]] 中的原始类型。它看起来像一段普通文字，但在程序里，它是一个可以被保存、拼接、读取长度、传给函数的值。

# 二、创建方式

## 1、普通引号

字符串可以用单引号或双引号创建。两者在创建普通字符串时没有本质区别，关键是同一个字符串的开头和结尾必须匹配。

示例：

```js
const singleQuoteText = '使用单引号';
const doubleQuoteText = "使用双引号";

console.log(singleQuoteText);
console.log(doubleQuoteText);
```

下面的写法是错误的，因为开头是双引号，结尾却是单引号：

```js
const brokenText = "引号没有配对';
```

真实项目中更重要的是保持一致。一个团队可以统一使用双引号，也可以统一使用单引号；只要风格稳定，阅读成本就会低很多。

## 2、模板字符串

反引号可以创建模板字符串。模板字符串最常见的用途是把变量或表达式插入文本中。

示例：

```js
const userName = "Ada";
const points = 95;

const message = `${userName} 的分数是 ${points}`;

console.log(message);
```

`${userName}` 和 `${points}` 会被替换为对应表达式的结果。相比手动拼接，模板字符串更适合生成包含变量的句子。

模板字符串也可以自然书写多行文本：

```js
const cardText = `学习目标：
1. 理解字符串
2. 学会查看控制台输出`;

console.log(cardText);
```

# 三、不可变性

## 1、字符不能原地改

字符串是不可变的。不可变的意思是：字符串一旦创建，它里面的字符序列不会被原地修改。

示例：

```js
const word = "cat";

word[0] = "b";

console.log(word);
```

这段代码不会把 `"cat"` 改成 `"bat"`。用方括号可以读取某个位置的字符，但不能通过给某个位置赋值来修改原字符串。

```js
const word = "cat";

console.log(word[0]);
console.log(word[1]);
console.log(word[2]);
```

这里的索引从 `0` 开始，所以 `word[0]` 是 `"c"`。

## 2、变量可以换值

字符串不可变，不代表保存字符串的变量永远不能变化。`let` 声明的变量可以重新指向另一个字符串。

示例：

```js
let currentUser = "Ada";
console.log(currentUser);

currentUser = "Grace";
console.log(currentUser);
```

这里不是把 `"Ada"` 这个字符串改成了 `"Grace"`，而是让变量 `currentUser` 保存了一个新的字符串。这个区别和 [[3、变量声明|变量声明]] 中的重新赋值有关。

> 简单来说：字符串值本身不能被原地修改；变量名可以重新指向另一个字符串值。

# 四、字符串拼接

## 1、加号拼接

`+` 可以把多个字符串连接成一个新字符串。

示例：

```js
const firstName = "Ada";
const lastName = "Lovelace";

const fullName = firstName + " " + lastName;

console.log(fullName);
```

这里 `" "` 是一个只包含空格的字符串。如果漏掉这个空格，结果会挤在一起：

```js
const firstName = "Ada";
const lastName = "Lovelace";

console.log(firstName + lastName);
```

所以使用 `+` 拼接句子时，要特别留意空格、标点和换行。

## 2、追加拼接

`+=` 可以在原变量的基础上追加新字符串。

示例：

```js
let message = "Hello";

message += ", ";
message += "JavaScript";
message += "!";

console.log(message);
```

虽然写法像是在“修改字符串”，但实际发生的是：每次拼接都会创建一个新的字符串，然后让变量 `message` 指向新字符串。

## 3、concat 方法

`concat()` 是字符串对象上的方法，也可以把多个字符串连接起来。

示例：

```js
const greeting = "Hello";
const target = "Console";

const result = greeting.concat(", ", target, "!");

console.log(result);
```

这里的 `concat()` 是一个方法。可以先粗略理解为：方法是挂在某个值或对象上的函数，调用时通常写成 `某个值.方法名()`。

日常写字符串时，简单拼接可以用 `+`；需要插入变量和表达式时，模板字符串通常更清晰；`concat()` 认识即可，不必把它作为首选。

| 写法 | 适合场景 | 示例 |
|---|---|---|
| `+` | 少量简单拼接 | `"Hello, " + name` |
| `+=` | 分步骤累加文本 | `message += "!"` |
| 模板字符串 | 插入变量或表达式 | `` `Hello, ${name}` `` |
| `concat()` | 认识字符串方法 | `a.concat(b)` |
