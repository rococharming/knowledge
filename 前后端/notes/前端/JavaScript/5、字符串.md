# 一、字符串与创建方式

字符串（`string`）表示文本，例如用户名、按钮文案和接口返回的文字。单引号与双引号都能创建普通字符串，关键是起止引号必须配对。

```js
const singleQuoteText = '使用单引号';
const doubleQuoteText = "使用双引号";
```

反斜杠可以让引号或换行等特殊字符作为文本出现：

```js
const quote = "She said, \"Hello!\"";
const poem = "第一行\n第二行";
```

| 写法 | 含义 |
|---|---|
| `\"`、`\'` | 在字符串中写引号 |
| `\\` | 写反斜杠 |
| `\n` | 换行 |

# 二、模板字符串

反引号创建模板字符串。它最适合把变量或表达式放进一段文本，也可以自然写多行内容。

```js
const userName = "Ada";
const points = 95;
const message = `${userName} 的分数是 ${points}`;

console.log(message);
```

`${...}` 内是 JavaScript 表达式。模板字符串会保留源码中的换行和空白，因此多行文本的缩进也会出现在结果中。

# 三、访问字符

字符串按位置访问，索引从 `0` 开始；`length` 表示 UTF-16 码元数。对常见英文、数字和半角符号，可以先把它理解为字符数。

```js
const word = "hello";

console.log(word[0]);          // "h"
console.log(word.length);      // 5
console.log(word[word.length - 1]); // "o"
```

# 四、编码边界

JavaScript 字符串使用 UTF-16。ASCII 是早期英文字符编码，其前 128 个编码与 Unicode 对应位置一致；因此 `A` 的 ASCII 数值和它的 UTF-16 码元值都为 `65`。

```js
console.log("A".charCodeAt(0));      // 65
console.log(String.fromCharCode(65)); // "A"
```

> [!warning]
> `charCodeAt()` 读取的是 UTF-16 码元，不是“读取一个 ASCII 字符”。遇到 emoji 等由多个码元组成的字符时，不能把 `length` 和索引简单等同于用户看到的字符数。

# 五、不可变性

字符串创建后不能原地改字符。字符串操作会生成新字符串；`let` 变量则可以重新保存新值。

```js
const word = "cat";
word[0] = "b";

console.log(word); // "cat"

let currentUser = "Ada";
currentUser = "Grace";
```
