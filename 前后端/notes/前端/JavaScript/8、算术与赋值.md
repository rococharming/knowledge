# 一、算术表达式

## 1、二元算术运算

算术运算符接收操作数并计算出新值。`+` 在两个操作数都是数字时做加法；字符串参与 `+` 时的转换规则见 [[9、类型转换|类型转换]]。

| 运算符 | 含义 | 示例 |
|---|---|---|
| `+` | 加法 | `10 + 5` 为 `15` |
| `-` | 减法 | `10 - 5` 为 `5` |
| `*` | 乘法 | `10 * 5` 为 `50` |
| `/` | 除法 | `10 / 4` 为 `2.5` |
| `%` | 余数 | `10 % 3` 为 `1` |
| `**` | 幂 | `2 ** 3` 为 `8` |

`%` 是余数运算符，不是数学上的通用模运算；结果符号跟左操作数一致。

```js
console.log(-10 % 3); // -1
```

## 2、一元加号

上表中的 `+` 与 `-` 各有两个操作数，例如 `10 + 5`；它们也可以只放在一个值前面，称为一元 `+` 和一元 `-`。一元 `+` 会尝试把值转为 `number`，但不会修改原值或变量。

```js
const text = "42";

console.log(+text);    // 42
console.log(+true);    // 1
console.log(+null);    // 0
console.log(+"hello"); // NaN
console.log(text);     // "42"，原值没有改变
```

它的转换规则与 `Number(value)` 对常见值相同，但可读性较弱。处理输入时，通常优先写 `Number(value)`，让“正在转换类型”的意图更明确。

## 3、一元减号

一元 `-` 会先得到数值，再取相反数；因此它既能处理普通数字，也能处理可转成数字的字符串或布尔值。

```js
console.log(-8);      // -8
console.log(-"42");   // -42
console.log(-true);   // -1
console.log(-null);   // -0
console.log(-"hello"); // NaN
```

`bigint` 是两者的边界：一元 `+1n` 会因为必须转为 `number` 而抛出 `TypeError`；一元 `-1n` 则得到 `-1n`，仍是 `bigint`。

# 二、更新变量

## 1、复合赋值

`=` 把右侧计算出的值保存到左侧变量。复合赋值将“计算再赋值”写得更短。

```js
let score = 10;

score += 5; // 等同于 score = score + 5
score -= 2;
score *= 3;
score /= 2;
score %= 4;
score **= 2;
```

复合赋值也有位运算和逻辑运算版本；先理解对应的普通运算符，再使用缩写。

## 2、自增与自减

`++` 和 `--` 只能用于可写变量。前缀先修改再取值，后缀先取旧值再修改；单独写成一条语句时两者效果相同。

```js
let a = 5;
const before = a++;

let b = 5;
const after = ++b;

console.log(before, a); // 5 6
console.log(after, b);  // 6 6
```

在复杂表达式里混用 `++`、`--` 会降低可读性。能写成独立的一次更新时，优先拆开写。

# 三、运算顺序

表达式中优先级高的运算先执行：乘除与幂先于加减。括号可以明确覆盖默认顺序，应优先用于表达业务意图，而不是死记完整优先级表。

```js
console.log(2 + 3 * 4);   // 14
console.log((2 + 3) * 4); // 20
```

同优先级的运算符还要看结合性。减法通常从左到右，幂运算从右到左：

```js
console.log(10 - 2 + 3); // 11
console.log(2 ** 3 ** 2); // 512，即 2 ** (3 ** 2)
```

# 四、Math 工具

`Math` 提供数学计算工具；它处理的是计算结果，不负责把数字格式化为展示文本。

## 1、取整与绝对值

| 方法 | 结果 |
|---|---|
| `Math.floor(4.7)` | 向下取整，得到 `4` |
| `Math.ceil(4.3)` | 向上取整，得到 `5` |
| `Math.round(4.5)` | 四舍五入，得到 `5` |
| `Math.trunc(4.9)` | 直接去掉小数，得到 `4` |
| `Math.abs(-5)` | 绝对值，得到 `5` |

负数时 `floor()`、`trunc()` 和 `round()` 的结果不同，应按业务含义选择，不能一概当作“取整”。

## 2、范围、开方与随机数

```js
console.log(Math.min(1, 5, 3)); // 1
console.log(Math.max(1, 5, 3)); // 5
console.log(Math.sqrt(81));     // 9
```

下面生成闭区间 `[min, max]` 内的随机整数：

```js
const min = 5;
const max = 10;
const randomInteger = Math.floor(Math.random() * (max - min + 1)) + min;
```

> [!warning]
> `Math.random()` 适合界面和练习中的随机效果，不适合密码、令牌或安全验证码。
