# 一、HTML 的定位

HTML（HyperText Markup Language，超文本标记语言）负责描述网页的 **内容结构与语义**。它告诉浏览器“这里是一段标题、那里是一段正文、这是一张图片、那是一个链接”，而不是主要负责视觉样式或交互逻辑。

在一个现代网页中，HTML、CSS 和 JavaScript 通常分工如下：

| 技术 | 核心职责 | 类比 |
|---|---|---|
| HTML | 内容、结构、语义 | 建筑的梁柱与房间划分 |
| CSS | 颜色、排版、布局、响应式样式 | 装修与视觉设计 |
| JavaScript | 交互、状态、动态更新 | 开关、电路与自动化控制 |

示例：

```html
<h1>我的前端学习记录</h1>
<p>今天开始学习 HTML 元素和属性。</p>
```

这段代码不会定义复杂样式，也不会添加交互，但已经表达出“页面标题”和“正文段落”的结构。

# 二、元素是 HTML 的基本单位

## 1、元素的组成

HTML 使用 **元素（element）** 表示页面中的一块内容。大多数元素由开始标签、内容和结束标签组成：

```html
<p>每天学习一点前端知识。</p>
```

其中：

- `<p>` 是开始标签。
- `每天学习一点前端知识。` 是元素内容。
- `</p>` 是结束标签。

元素之间可以嵌套，用来表达内容之间的层级关系：

```html
<section>
  <h2>今日学习内容</h2>
  <p>认识 HTML 元素、属性和基础语义。</p>
</section>
```

HTML 标签名不区分大小写，但实际开发中通常使用小写，便于阅读和团队协作。

## 2、语义决定元素选择

选择元素时，不应只问“它长什么样”，更要问“它表示什么含义”。例如：

| 语义 | 常用元素 | 说明 |
|---|---|---|
| 一级标题 | `h1` | 页面或主要内容的最高级标题 |
| 段落 | `p` | 一段连续正文 |
| 链接 | `a` | 跳转到另一个位置或资源 |
| 图片 | `img` | 嵌入图像资源 |
| 独立主题区域 | `section` | 页面中具有明确主题的一组内容 |

语义清晰的 HTML 对开发者、搜索引擎和辅助技术都更友好。后续涉及通用分组和语义化结构时，可继续看 [[3、语义化分组、标识符与脚本加载|语义化分组]]。

## 3、空元素

有些元素不能包含文本或子元素，只由一个开始标签组成，这类元素称为 **空元素（void element）**。

常见空元素包括：

| 元素 | 作用 |
|---|---|
| `img` | 嵌入图片 |
| `br` | 换行 |
| `hr` | 主题分隔 |
| `input` | 表单输入控件 |
| `meta` | 文档元数据 |
| `link` | 关联外部资源 |

示例：

```html
<img src="./images/html-card.png" alt="HTML 学习卡片">
```

> [!note] 空元素没有结束标签
> 在 HTML 中，`<img />` 这种写法也常见，但末尾的 `/` 不会让它变成真正的 XML 式自闭合语法。写作时保持团队约定一致即可。

# 三、属性为元素补充信息

## 1、属性的基本语法

**属性（attribute）** 写在开始标签中，用来补充元素信息或调整元素行为。

```html
<element attribute="value">内容</element>
```

常见属性包括：

| 属性 | 常见元素 | 作用 |
|---|---|---|
| `href` | `a` | 指定链接目标 |
| `src` | `img`、`script`、`iframe` | 指定外部资源地址 |
| `alt` | `img` | 提供图片替代文本 |
| `id` | 大多数元素 | 提供文档内唯一标识 |
| `class` | 大多数元素 | 提供可复用分类名 |

属性值通常使用双引号包裹。即使某些场景下引号可以省略，初学和团队协作时也建议统一写引号。

## 2、链接属性：href 与 target

`a` 元素用于创建超链接，`href` 指定跳转目标：

```html
<a href="https://developer.mozilla.org/zh-CN/docs/Web/HTML">
  阅读 MDN HTML 文档
</a>
```

如果希望在新标签页打开链接，可以使用 `target="_blank"`：

```html
<a
  href="https://html.spec.whatwg.org/"
  target="_blank"
  rel="noopener"
>
  查看 HTML 标准
</a>
```

`target="_blank"` 常搭配 `rel="noopener"`，避免新页面通过 `window.opener` 影响原页面。

## 3、图片属性：src 与 alt

`img` 通过 `src` 加载图片，通过 `alt` 提供替代文本：

```html
<img
  src="./images/html-practice.png"
  alt="蓝色背景上写着 HTML Practice 的练习图片"
>
```

`alt` 的作用不只是图片加载失败时显示文字，更重要的是帮助屏幕阅读器用户理解图片内容。

| 图片类型 | alt 写法 |
|---|---|
| 传达信息的图片 | 描述图片传达的关键信息 |
| 操作性图标 | 描述操作目的，如 `搜索` |
| 纯装饰图片 | 使用空值 `alt=""` |

更复杂的图片加载、响应式图片和 SVG 会在 [[6、响应式图片、版权与SVG|响应式图片与 SVG]] 中展开。

## 4、布尔属性

**布尔属性（boolean attribute）** 由“是否存在”决定状态，不依赖 `true` 或 `false` 字符串。

示例：

```html
<label>
  <input type="checkbox" checked>
  我已经完成今天的 HTML 练习
</label>
```

常见布尔属性：

| 属性 | 作用 |
|---|---|
| `checked` | 默认选中复选框或单选框 |
| `disabled` | 禁用控件 |
| `readonly` | 内容只读 |
| `required` | 表单提交前必须填写 |
| `controls` | 显示媒体播放控件 |
| `muted` | 媒体初始静音 |

> [!warning] 不要写 `checked="false"`
> 对布尔属性来说，只要属性存在，就表示启用。`checked="false"` 仍然会让复选框默认选中。

# 四、完整示例

下面把标题、段落、链接、图片和布尔属性组合成一个小页面片段：

```html
<main>
  <h1>我的 HTML 学习页</h1>

  <p>今天学习了 HTML 元素、属性和基础语义。</p>

  <a
    href="https://html.spec.whatwg.org/"
    target="_blank"
    rel="noopener"
  >
    查看 HTML 标准
  </a>

  <img
    src="./images/html-practice.png"
    alt="绿色背景上写着 HTML Practice 的练习图片"
  >

  <label>
    <input type="checkbox" checked>
    我已经完成今天的练习
  </label>
</main>
```

这里的关键是：HTML 先把内容结构表达清楚，再交给 CSS 和 JavaScript 做样式与交互。

# 五、小结

- HTML 用于描述网页内容、结构和语义。
- 元素是 HTML 的基本单位，大多数元素由开始标签、内容和结束标签组成。
- 空元素没有内容和结束标签，但仍然可以拥有属性。
- 属性写在开始标签中，为元素补充信息或控制行为。
- `href` 指定链接目标，`src` 指定外部资源，`alt` 提供图片替代文本。
- 布尔属性由是否存在决定状态，不应依赖 `true` 或 `false` 字符串。
- 建立元素和属性的基础后，可以继续学习 [[2、HTML文档骨架与资源引用|HTML 文档骨架]]。
