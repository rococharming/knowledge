# 一、细微语义元素解决什么问题

HTML 里有些元素默认显示效果很像，例如 `i` 和 `em` 默认都像斜体，`b` 和 `strong` 默认都像粗体。但它们的语义并不相同。

学习这些元素时，要把“看起来是什么样”与“表达什么含义”分开。视觉样式可以交给 CSS，HTML 元素应该优先表达内容含义。这一点和 [[9、语义化HTML|语义化 HTML 与表现分离]] 是同一条原则。

简单对照：

| 视觉效果 | 偏语义的选择 | 偏提醒但不强调重要性 |
|---|---|---|
| 斜体 | `em` | `i` |
| 粗体 | `strong` | `b` |

这张表只是帮助记忆，真正选择时要看文本在上下文中的作用。

# 二、i 与 em：不同语气还是强调含义

## 1、i 表示与周围文本不同的语气或类别

`i` 是 idiomatic text element，常用于表示与周围正文不同的文本，例如外语短语、术语、作品名、内心想法或另一种语气。

示例：

```html
<p>
  这家小店有一种
  <i lang="fr">je ne sais quoi</i>
  的气质。
</p>
```

这里 `i` 表示中间的法语短语和周围中文正文不同。`lang="fr"` 说明这段内容是法语，有助于浏览器、翻译工具和辅助技术更准确地处理文本。

`i` 不表示“这段内容更重要”，只表示“这段内容在语气、语言或类别上不同”。

## 2、em 表示语义上的强调

`em` 是 emphasis element，用来表示语义上的强调。它通常强调一句话中的少量词语，并可能改变句子的重点。

示例：

```html
<p>
  不要放弃 <em>你的</em> 目标。
</p>
```

这里强调的是“你的”，句子的重点变成：不是别人的目标，而是你自己的目标。

`em` 默认也常显示为斜体，但它的关键不是“斜体”，而是“强调”。屏幕阅读器等辅助技术可能会根据语义以不同语调读出。

## 3、如何选择 i 和 em

| 问题 | 选择 |
|---|---|
| 这几个词是否改变句子的语气重点？ | 用 `em` |
| 这是不是外语短语、术语、作品名或另一种声音？ | 用 `i` |
| 只是想让文字变斜，没有特殊语义？ | 用 CSS |

对比示例：

```html
<p>
  按下 <i>Enter</i> 键提交表单。
</p>
```

这里 `Enter` 是按键名称，属于和普通正文不同的术语类文本，可以用 `i`。

```html
<p>
  请 <em>不要</em> 在密码里使用生日。
</p>
```

这里 `em` 强调“不要”，改变了句子的警示重点。

> [!warning] 不要只为了斜体使用 i 或 em
> 如果文本没有特殊语义，只是视觉上想变成斜体，应使用 CSS，例如 `font-style: italic;`。

# 三、b 与 strong：吸引注意还是表达重要

## 1、b 用于吸引注意

`b` 是 bring attention to element，用于把读者注意力引到某些文本上，但不表示这些文本更重要或更紧急。

常见场景包括摘要中的关键词、评论中的产品名、搜索结果中的匹配词。

示例：

```html
<p>
  本次测试比较了 <b>Quiet Keyboard</b>、
  <b>Fast Charger</b> 和 <b>Desk Lamp</b> 三款产品。
</p>
```

这里产品名需要被快速识别，但它们并不比句子其他部分更紧急。

## 2、strong 表示重要性或紧急性

`strong` 用于表示内容很重要、关键或紧急。它不仅让文本默认显示为粗体，还表达更强的语义。

示例：

```html
<p>
  <strong>警告：</strong> 使用前请先断开电源。
</p>
```

这里“警告”不是普通关键词，而是需要用户认真对待的安全信息，因此应该用 `strong`。

## 3、如何选择 b 和 strong

| 问题 | 选择 |
|---|---|
| 只是让读者注意关键词、产品名、摘要重点？ | 用 `b` |
| 这段信息是否重要、关键、紧急或有风险提示？ | 用 `strong` |
| 只是想变粗，没有语义目的？ | 用 CSS |

对比示例：

```html
<p>
  搜索结果中匹配到了 <b>HTML</b> 和 <b>CSS</b>。
</p>
```

这里 `b` 用于突出匹配词。

```html
<p>
  <strong>重要：</strong> 提交后无法撤销。
</p>
```

这里 `strong` 表示用户必须特别注意后果。

> [!note] 默认样式相似不等于语义相同
> `b` 和 `strong` 默认都常显示为粗体，但 `strong` 会传达重要性，`b` 只是把注意力带到某段文本上。

# 四、样式应该交给 CSS

如果目标只是视觉效果，不要为了“斜体”选择 `i` 或 `em`，也不要为了“粗体”选择 `b` 或 `strong`。

例如，一段普通提示语只是设计上需要斜体：

```html
<p class="hint-text">所有字段均可稍后修改。</p>
```

```css
.hint-text {
  font-style: italic;
}
```

同理，只是设计上需要粗体：

```html
<p class="card-title">今日推荐</p>
```

```css
.card-title {
  font-weight: 700;
}
```

这样 HTML 仍然表达内容结构，CSS 负责视觉表现。`class` 作为样式挂载点的用法可回看 [[3、HTML分组与脚本#三、id 与 class|id 与 class]]。

# 五、描述列表 dl、dt 与 dd

## 1、描述列表的基本结构

描述列表用于表达“术语 - 描述”或“键 - 值”这类成对信息。它适合词汇表、规格参数、常见问题、联系人信息、元数据等内容。

描述列表由三个元素组成：

| 元素 | 作用 |
|---|---|
| `dl` | description list，包住整个描述列表 |
| `dt` | description term，表示术语、名称或标签 |
| `dd` | description details，表示描述、解释或对应值 |

示例：

```html
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language，用于描述网页结构。</dd>

  <dt>CSS</dt>
  <dd>Cascading Style Sheets，用于控制网页样式。</dd>
</dl>
```

浏览器默认通常会让 `dd` 比 `dt` 更缩进，帮助读者区分术语和解释。

## 2、描述列表不只用于词典

描述列表的本质是“一个标签对应一段相关说明”，因此不局限于术语定义。

产品规格示例：

```html
<dl>
  <dt>屏幕尺寸</dt>
  <dd>14 英寸</dd>

  <dt>重量</dt>
  <dd>1.3 千克</dd>

  <dt>接口</dt>
  <dd>USB-C、HDMI、3.5mm 耳机孔</dd>
</dl>
```

常见问题示例：

```html
<dl>
  <dt>是否支持离线使用？</dt>
  <dd>核心阅读功能可以离线使用，同步功能需要网络连接。</dd>

  <dt>可以导出数据吗？</dt>
  <dd>可以导出为 Markdown 或 JSON 文件。</dd>
</dl>
```

这些内容如果用普通段落也能显示，但 `dl`、`dt`、`dd` 能更明确地表达“问题与回答”“属性与值”的关系。

## 3、什么时候使用描述列表

适合使用描述列表的场景：

- **词汇表**：术语和定义。
- **产品规格**：参数名和参数值。
- **常见问题**：问题和回答。
- **联系人信息**：字段名和联系方式。
- **元数据**：作者、发布日期、版本号等信息。

不适合使用描述列表的场景：

- 只是普通项目清单，用 `ul`。
- 有明确步骤顺序，用 `ol`。
- 需要二维数据对比，用 `table`。

列表结构本身也是语义的一部分。选择 `dl`、`ul`、`ol` 或 `table` 时，应该看内容关系，而不是默认样式。

# 六、完整示例

下面把细微文本语义和描述列表放在一个产品说明片段中：

```html
<article>
  <h2>智能台灯说明</h2>

  <p>
    本产品支持 <b>护眼模式</b>、<b>定时关闭</b> 和
    <b>亮度记忆</b>。
  </p>

  <p>
    <strong>警告：</strong> 请勿在潮湿环境中使用。
  </p>

  <p>
    产品包装上标注的 <i lang="fr">mode nuit</i> 表示夜间模式。
  </p>

  <p>
    请 <em>先关闭电源</em> 再清洁灯罩。
  </p>

  <dl>
    <dt>额定功率</dt>
    <dd>10W</dd>

    <dt>色温范围</dt>
    <dd>2700K - 6500K</dd>

    <dt>控制方式</dt>
    <dd>触控、手机 App</dd>
  </dl>
</article>
```

这里：

- `b` 突出产品功能名，但不表示紧急。
- `strong` 表示安全警告。
- `i` 标记外语短语。
- `em` 强调操作顺序中的重点。
- `dl` 表达产品规格的“字段 - 值”关系。

# 七、小结

- `i` 表示与周围文本不同的语气、语言或类别；`em` 表示语义强调。
- `b` 用于吸引注意；`strong` 表示重要性、关键性或紧急性。
- 如果只是想要斜体或粗体，应使用 CSS，而不是滥用语义元素。
- `dl`、`dt`、`dd` 用于表达术语与描述、标签与值、问题与回答等成对信息。
- 选择 HTML 元素时，先判断内容关系和语义，再考虑视觉样式。
