# 一、三大特性

CSS 的三大特性通常指 **层叠性**、**继承性** 和 **优先级**。它们共同回答一个问题：当一个元素可能受到多条样式影响时，浏览器最终到底用哪个值。

可以先这样理解：

| 特性  | 解决的问题                   |
| --- | ----------------------- |
| 层叠性 | 多条声明冲突时，谁最终生效           |
| 继承性 | 子元素没有直接设置样式时，能不能沿用父元素的值 |
| 优先级 | 多个选择器都命中同一元素时，谁更具体      |

# 二、层叠性

层叠性指的是：当多个 CSS 声明都可能给同一个元素的同一个属性设置值时，浏览器会按规则选出最终生效的那个值。

## 1、样式冲突

样式冲突通常需要同时满足三个条件：

1. 多条规则都能匹配到同一个元素。
2. 它们设置的是同一个 CSS 属性。
3. 它们给出的属性值不同。

示例：

```html
<p class="intro">这段文字最终是什么颜色？</p>
```

```css
p {
  color: gray;
}

.intro {
  color: blue;
}
```

两条规则都匹配这个 `p` 元素，也都设置了 `color`。浏览器需要比较它们，最终 `.intro` 的蓝色会生效。

## 2、相关性

浏览器首先会过滤“不相关”的规则。选择器没有匹配到当前元素，或者媒体查询条件不成立，这条规则就不会参与本次比较。

> [!note] 什么是媒体查询
> 媒体查询可以理解成 CSS 里的条件判断：只有当浏览器环境满足某个条件时，里面的样式才生效。最常见的条件是视口宽度，所以它经常用于响应式布局。

示例：

```css
p {
  color: blue;
}

@media (max-width: 600px) {
  p {
    color: green;
  }
}
```

这段代码里的 `@media (max-width: 600px)` 可以拆开看：

- `@media`：声明一段“有条件才生效”的 CSS 规则。
- `(max-width: 600px)`：条件是视口宽度最大为 `600px`，也就是小于或等于 `600px`。
- 花括号内部的规则：只有条件成立时，才会参与本次样式比较。

当视口宽度大于 `600px` 时，媒体查询里的 `p { color: green; }` 不参与比较，段落是蓝色。当视口宽度小于或等于 `600px` 时，它才会进入层叠流程，并可能把段落变成绿色。

## 3、比较顺序

过滤掉不相关规则后，浏览器会继续比较这些维度：

1. **来源和重要性**：浏览器默认样式、用户样式、作者样式，以及是否带有 `!important`。
2. **优先级**：同一来源、同一重要性下，选择器越具体，越容易胜出。
3. **出现顺序**：前面都相同时，后写的规则覆盖先写的规则。

平时写页面时，主要接触的是作者样式，也就是自己写的外部样式表、内部样式和行内样式。浏览器默认样式可回看 [[1、CSS基础#四、默认样式|默认样式]]。

示例：

```css
.notice {
  color: blue;
}

.notice {
  color: green;
}
```

两条规则选择器完全一样，优先级也一样，所以后出现的绿色生效。

# 三、继承性

继承性指的是：当子元素没有直接设置某个属性时，有些属性会自动沿用父元素的计算值。

## 1、默认继承

文本相关属性通常会继承，例如 `color`、`font-family`、`font-size`、`line-height`、`text-align`。

示例：

```html
<section class="article">
  <h2>继承示例</h2>
  <p>这段文字会继承文章区域的文字样式。</p>
</section>
```

```css
.article {
  color: #1f2937;
  font-family: Arial, "Microsoft YaHei", sans-serif;
  line-height: 1.8;
}
```

`.article` 里的 `h2` 和 `p` 没有单独设置文字颜色、字体和行高时，会继承父元素 `.article` 的这些值。文本样式可回看 [[3、CSS文本样式|CSS 文本样式]]。

## 2、不会继承

布局和盒模型相关属性通常不会默认继承，例如 `margin`、`padding`、`border`、`background-color`、`width`、`height`。

```css
.article {
  padding: 24px;
  border: 1px solid #d1d5db;
  background-color: #f9fafb;
}
```

这里 `padding`、`border` 和 `background-color` 只作用在 `.article` 自己身上，不会自动复制到里面的标题和段落上。

常见属性可以先这样记：

| 常见会继承 | 常见不会继承 |
|---|---|
| `color` | `margin` |
| `font-family` | `padding` |
| `font-size` | `border` |
| `line-height` | `background-color` |
| `text-align` | `width` / `height` |

## 3、显式继承

如果确实希望一个属性继承父元素的值，可以使用 `inherit`。

示例：

```html
<section class="card">
  <p>普通段落</p>
  <p class="same-padding">继承父元素内边距</p>
</section>
```

```css
.card {
  padding: 20px;
}

.same-padding {
  padding: inherit;
}
```

`padding` 默认不继承，但 `padding: inherit;` 会明确要求 `.same-padding` 从父元素 `.card` 那里取得 `padding` 的值。

> [!note] 直接命中优先于继承
> 如果某个元素被选择器直接设置了属性，这个直接设置通常会覆盖从父元素继承来的值。继承只是“没有直接设置时”的一种取值来源，不参与选择器优先级计算。

# 四、优先级

优先级用于比较“多个选择器都直接命中同一个元素”时，哪条声明和这个元素更相关。它不是层叠流程的第一步，只有在 **同一来源、同一重要性** 的规则之间，才会继续比较选择器优先级。

这里的“同一来源”是指规则来自同一类样式来源。例如我们平时写的外部 CSS、内部 CSS、行内样式，都属于作者样式；浏览器自带的默认样式属于浏览器样式。

“同一重要性”主要看声明有没有 `!important`。普通声明和带 `!important` 的声明不在同一层级；只有都是普通声明，或都带 `!important` 时，才继续比较选择器优先级。

## 1、计算方式

为了入门时好记，可以把优先级写成四段：

```text
行内样式 - ID - 类/属性/伪类 - 元素/伪元素
```

常见选择器权重如下：

| 类型 | 示例 | 权重 |
|---|---|---|
| 行内样式 | `style="color: red;"` | `1-0-0-0` |
| ID 选择器 | `#title` | `0-1-0-0` |
| 类选择器 | `.title` | `0-0-1-0` |
| 属性选择器 | `[type="text"]` | `0-0-1-0` |
| 伪类 | `:hover` | `0-0-1-0` |
| 元素选择器 | `p` | `0-0-0-1` |
| 伪元素 | `::before` | `0-0-0-1` |
| 通用选择器 | `*` | `0-0-0-0` |

比较时从左到右看，先比行内样式，再比 ID，再比类/属性/伪类，最后比元素/伪元素。越靠左的列越重要。

## 2、权重叠加

一个复杂选择器会把内部各部分权重叠加。

示例：

```css
#nav .item a {
  color: black;
}
```

这个选择器包含：

| 部分 | 类型 | 权重 |
|---|---|---|
| `#nav` | ID 选择器 | `0-1-0-0` |
| `.item` | 类选择器 | `0-0-1-0` |
| `a` | 元素选择器 | `0-0-0-1` |

叠加后得到：

```text
0-1-1-1
```

也就是说，`#nav .item a` 比 `.item a` 更具体，因为它多了一个 ID 选择器。

再看一个表格行的例子：

```css
.data tr:first-child {
  background-color: #8fbcf1;
  color: #fff;
}
```

这个选择器包含：

| 部分 | 类型 | 权重 |
|---|---|---|
| `.data` | 类选择器 | `0-0-1-0` |
| `tr` | 元素选择器 | `0-0-0-1` |
| `:first-child` | 伪类 | `0-0-1-0` |

叠加后得到：

```text
0-0-2-1
```

这里容易漏掉 `tr`。它虽然只是标签名，但标签名也属于元素选择器，会给最后一列增加 `1`。

> [!note] 叠加不进位
> 优先级的四段权重是分开的层级，不是普通十进制数字。`0-0-10-0` 不会进位成 `0-1-0-0`，所以再多类选择器也不会因为“进位”变成 ID 选择器。

## 3、不进位示例

示例：

```html
<p id="notice" class="a b c d e f g h i j">保存成功。</p>
```

```css
p#notice {
  color: red;
}

.a.b.c.d.e.f.g.h.i.j {
  color: blue;
}
```

两条规则的权重分别是：

| 选择器 | 权重 |
|---|---|
| `p#notice` | `0-1-0-1` |
| `.a.b.c.d.e.f.g.h.i.j` | `0-0-10-0` |

虽然第二个选择器有 10 个类选择器，但它仍然在第三列；第一个选择器有 1 个 ID，在第二列。比较时先看第二列，所以 `p#notice` 胜出，文字是红色。

这就是“不进位”的含义：权重可以叠加，但每一列各比各的，不会因为后面数量多就进到前一列。

## 4、完整比较

示例：

```html
<p id="notice" class="message">保存成功。</p>
```

```css
p {
  color: gray;
}

.message {
  color: green;
}

p.message {
  color: blue;
}

#notice {
  color: red;
}
```

这几条规则的优先级是：

| 选择器 | 记法 | 结果 |
|---|---|---|
| `p` | `0-0-0-1` | 低 |
| `.message` | `0-0-1-0` | 中 |
| `p.message` | `0-0-1-1` | 比 `.message` 更具体 |
| `#notice` | `0-1-0-0` | 高 |

最终 `#notice` 的红色生效。

> 不建议为了“赢”而不断加长选择器。选择器越长，后面维护时越容易陷入互相覆盖。

## 5、!important

`!important` 不是选择器优先级的一部分，它会改变声明的重要性，让这条声明先进入更高的比较层级。

示例：

```css
.message {
  color: blue !important;
}

#notice {
  color: red;
}
```

如果同一个元素同时匹配这两条规则，蓝色会生效，因为 `!important` 先改变了层叠比较的位置。只有当多条声明都带 `!important` 时，才继续比较它们的选择器优先级。

`!important` 应该少用。更好的做法通常是降低原选择器复杂度、调整 CSS 顺序，或用更清楚的类选择器表达当前状态。
