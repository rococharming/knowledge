# 一、选择器

CSS 选择器用于描述“哪些 HTML 元素应该应用这组样式”。如果把声明看成“设置什么样式”，选择器就是“找哪些元素”。

# 二、基础选择器

## 1、元素选择器

元素选择器也称标签选择器，根据 HTML 标签名匹配元素，适合设置某类元素的基础样式。

示例：

```html
<h1>今日任务</h1>
<p>整理 CSS 选择器笔记。</p>
<p>完成一个小练习。</p>
```

```css
p {
  color: #374151;
  line-height: 1.7;
}
```

这里所有 `p` 元素都会被选中。元素选择器覆盖面比较大，适合写通用基础样式，不适合表达某个具体模块的特殊外观。

## 2、类选择器

元素选择器会选择某类所有元素，使用类选择器可以选择1个或多个元素。

类选择器根据元素的 `class` 属性匹配元素，写法以点号开头。

示例：

```html
<div class="spring">春</div>
<div class="summer">夏</div>
<div class="autumn">秋</div>
<div class="winter">冬</div>
```

```css
/* 类选择器：选中所有 class="spring" 的元素 */
.spring {
  color: green;
  /* 设置文字颜色为绿色 */
  font-size: 20px;
 /* 设置字体大小为 20 像素 */
}

/* 类选择器：选中所有 class="summer" 的元素 */
.summer {
  color: pink;
  /* 设置文字颜色为粉色 */
  font-size: 20px;
  /* 设置字体大小为 20 像素 */
}

/* 类选择器：选中所有 class="autumn" 的元素 */
.autumn {
  color: red;
  /* 设置文字颜色为红色 */
  font-size: 20px;
  /* 设置字体大小为 20 像素 */
}

/* 类选择器：选中所有 class="winter" 的元素 */
.winter {
  color: blue;
  /* 设置文字颜色为蓝色 */
  font-size: 20px;
  /* 设置字体大小为 20 像素 */
}
```

类选择器是日常写 CSS 最常用的选择器，因为同一个类可以复用在多个元素上，也不会像 ID 那样把样式绑定得太死。

## 3、ID 选择器

ID 选择器用于选择具有特定`id`的唯一元素，写法以井号开头。

示例：

```html
<h1 id="page-title">CSS 学习页</h1>
```

```css
#page-title {
  color: #111827;
}
```

一个页面中同一个 `id` 应该只出现一次。`id` 与 `class` 的 HTML 基础可回看 [[前后端/notes/前端/HTML/3、HTML分组与脚本#三、id 与 class|id 与 class]]。

>后期修改样式基本都是类选择器，而 id 选择器后期主要配合 JavaScript 添加交互效果。


## 4、通用选择器

通用选择器也称为通配符选择器，使用 `*` 选择所有元素。它常用于设置全局基础规则，例如清理默认间距或统一盒模型。

示例：
	
```css
* {
  margin: 0;
  padding: 0;  
}
```

清理所有元素的默认边距和填充，统一不同浏览器的默认样式。

```css
* {
  box-sizing: border-box;  /* 统一盒模型 */
}
```

# 三、选择器列表

## 1、共享声明

如果多个选择器需要同一组声明，可以把它们写成选择器列表，用逗号分隔：

```css
h1,
h2,
.lead {
  color: #1e3a8a;
}
```

这表示 `h1`、`h2` 和 `.lead` 都会使用同一组声明。逗号不是“并且”，而是“这些选择器分别匹配到的元素都算”。

## 2、可读写法

选择器列表通常每个选择器单独占一行：

```css
.card-title,
.dialog-title,
.section-title {
  margin: 0;
  font-weight: 700;
}
```

这种写法便于增加、删除或检查某个选择器。不要为了省行数把很多选择器挤在一行，尤其是选择器变长以后，很容易漏看逗号或误读关系。

# 四、关系选择器

关系选择器用于表达选择器之间的结构关系。它们不会凭空创建关系，只是根据 HTML 文档树中已经存在的父子、后代、兄弟关系来匹配元素。

## 1、后代选择器

后代选择器用一个空格表示，用于选择某个元素的后代元素（不限层级，包括子元素、孙元素）

示例：
 
```css
.box p {
  color: pink;
}
```

`.box p` 会选中 `.box`内部的所有`p`元素。

## 2、子代选择器

子代选择器用 `>` 表示，但只选择某个元素的直接子元素。

示例：

```html
<div>
  <span>我是儿子</span>
  <p>
    <span>我是孙子</span>
  </p>
</div>
```

```css
div>span {
  color: pink;
}
```

这里选择的是`div`的直接子元素，即“我是儿子”会变成粉色。

> 实际使用中，后代选择器更常见。

## 3、相邻兄弟选择器

相邻兄弟选择器用 `+` 表示，匹配紧跟在前一个元素后面的兄弟元素。

示例：

```html
<h2>安装步骤</h2>
<p>先下载工具。</p>
<p>再运行安装命令。</p>
```

```css
h2+p {
  color: pink;
}
```

`h2 + p` 只会选中紧跟在 `h2` 后面的第一个 `p`。第二个 `p` 虽然也是 `h2` 后面的兄弟元素，但不是“紧挨着”的那个。

## 4、通用兄弟选择器

通用兄弟选择器用 `~` 表示，匹配某个元素后面所有符合条件的兄弟元素。

示例：

```html
<h2>注意事项</h2>
<p>不要直接改线上文件。</p>
<p>修改前先保存当前版本。</p>
<div>示例区域</div>
<p>最后再做验证。</p>
```

```css
h2~p {
  color: pink;
```

这里 `h2` 后面的三个 `p` 都会被选中。中间出现的 `div` 不会中断匹配，因为 `~` 看的是“后面所有同级兄弟”，不是“紧挨着”。
