# 一、选择器

CSS 选择器用于描述“哪些 HTML 元素应该应用这组样式”。如果把声明看成“设置什么样式”，选择器就是“找哪些元素”。

# 二、基础选择器

## 1、元素选择器

元素选择器也称标签选择器，根据 HTML 标签名匹配元素，适合设置某类元素的基础样式。

示例：

```html
<h1>今日任务</h1>
<p>整理 CSS 选择器笔记。</p>
<p>完成一个小练习。</p>
```

```css
p {
  color: #374151;
  line-height: 1.7;
}
```

这里所有 `p` 元素都会被选中。元素选择器覆盖面比较大，适合写通用基础样式，不适合表达某个具体模块的特殊外观。

## 2、类选择器

元素选择器会选择某类所有元素，使用类选择器可以选择1个或多个元素。

类选择器根据元素的 `class` 属性匹配元素，写法以点号开头。

示例：

```html
<div class="spring">春</div>
<div class="summer">夏</div>
<div class="autumn">秋</div>
<div class="winter">冬</div>
```

```css
/* 类选择器：选中所有 class="spring" 的元素 */
.spring {
  color: green;
  /* 设置文字颜色为绿色 */
  font-size: 20px;
 /* 设置字体大小为 20 像素 */
}

/* 类选择器：选中所有 class="summer" 的元素 */
.summer {
  color: pink;
  /* 设置文字颜色为粉色 */
  font-size: 20px;
  /* 设置字体大小为 20 像素 */
}

/* 类选择器：选中所有 class="autumn" 的元素 */
.autumn {
  color: red;
  /* 设置文字颜色为红色 */
  font-size: 20px;
  /* 设置字体大小为 20 像素 */
}

/* 类选择器：选中所有 class="winter" 的元素 */
.winter {
  color: blue;
  /* 设置文字颜色为蓝色 */
  font-size: 20px;
  /* 设置字体大小为 20 像素 */
}
```

类选择器是日常写 CSS 最常用的选择器，因为同一个类可以复用在多个元素上，也不会像 ID 那样把样式绑定得太死。

## 3、ID 选择器

ID 选择器用于选择具有特定`id`的唯一元素，写法以井号开头。

示例：

```html
<h1 id="page-title">CSS 学习页</h1>
```

```css
#page-title {
  color: #111827;
}
```

一个页面中同一个 `id` 应该只出现一次。`id` 与 `class` 的 HTML 基础可回看 [[前后端/notes/前端/HTML/3、HTML分组与脚本#三、id 与 class|id 与 class]]。

>后期修改样式基本都是类选择器，而 id 选择器后期主要配合 JavaScript 添加交互效果。


## 4、通用选择器

通用选择器也称为通配符选择器，使用 `*` 选择所有元素。它常用于设置全局基础规则，例如清理默认间距或统一盒模型。

示例：
	
```css
* {
  margin: 0;
  padding: 0;  
}
```

清理所有元素的默认边距和填充，统一不同浏览器的默认样式。

```css
* {
  box-sizing: border-box;  /* 统一盒模型 */
}
```


# 三、关系选择器

关系选择器用于表达选择器之间的结构关系。它们不会凭空创建关系，只是根据 HTML 文档树中已经存在的父子、后代、兄弟关系来匹配元素。

## 1、后代选择器

后代选择器用一个空格表示，用于选择某个元素的后代元素（不限层级，包括子元素、孙元素）

示例：
 
```css
.box p {
  color: pink;
}
```

`.box p` 会选中 `.box`内部的所有`p`元素。

## 2、子代选择器

子代选择器用 `>` 表示，但只选择某个元素的直接子元素。

示例：

```html
<div>
  <span>我是儿子</span>
  <p>
    <span>我是孙子</span>
  </p>
</div>
```

```css
div>span {
  color: pink;
}
```

这里选择的是`div`的直接子元素，即“我是儿子”会变成粉色。

> 实际使用中，后代选择器更常见。

## 3、相邻兄弟选择器

相邻兄弟选择器用 `+` 表示，匹配紧跟在前一个元素后面的兄弟元素。

示例：

```html
<h2>安装步骤</h2>
<p>先下载工具。</p>
<p>再运行安装命令。</p>
```

```css
h2+p {
  color: pink;
}
```

`h2 + p` 只会选中紧跟在 `h2` 后面的第一个 `p`。第二个 `p` 虽然也是 `h2` 后面的兄弟元素，但不是“紧挨着”的那个。

## 4、通用兄弟选择器

通用兄弟选择器用 `~` 表示，匹配某个元素后面所有符合条件的兄弟元素。

示例：

```html
<h2>注意事项</h2>
<p>不要直接改线上文件。</p>
<p>修改前先保存当前版本。</p>
<div>示例区域</div>
<p>最后再做验证。</p>
```

```css
h2~p {
  color: pink;
```

这里 `h2` 后面的三个 `p` 都会被选中。中间出现的 `div` 不会中断匹配，因为 `~` 看的是“后面所有同级兄弟”，不是“紧挨着”。


# 四、分组选择器

分组选择器也称选择器列表或并集选择器。它用逗号把多个选择器放在一起，让它们共享同一组声明。

它解决的是“多个元素需要同一套样式”这个问题。比如标题、按钮和提示文字都需要使用同一种品牌色，就不必重复写三条规则。

示例：

```html
<h1 class="page-title">CSS 选择器</h1>
<h2 class="section-title">基础选择器</h2>
<p class="tip">先理解选择器，再理解优先级。</p>
```

```css
.page-title,
.section-title,
.tip {
  color: #1d4ed8;
}
```

这表示：只要元素匹配 `.page-title`、`.section-title`、`.tip` 其中任意一个选择器，就会应用同一组声明。

## 1、逗号是关键

分组选择器的关键是逗号 `,`。逗号表示“或者”：匹配第一个选择器，或者匹配第二个选择器，或者匹配后面的选择器。

下面两种写法效果相同：

```css
h1,
h2,
h3 {
  font-weight: 700;
}
```

```css
h1, h2, h3 {
  font-weight: 700;
}
```

实际项目代码时，更推荐换行写。选择器多了以后，每个选择器单独一行更容易阅读，也更方便以后新增或删除其中一项。

## 2、可以混合不同选择器

分组选择器里不要求每一项都是同一种选择器。元素选择器、类选择器、ID 选择器、关系选择器都可以放在同一个列表里。

示例：

```html
<main id="app">
  <article class="card">
    <h2>今日计划</h2>
    <p class="summary">整理 CSS 选择器笔记。</p>
  </article>
</main>
```

```css
#app,
.card,
.card h2,
.summary {
  font-family: Arial, "Microsoft YaHei", sans-serif;
}
```

这里四个选择器匹配的是不同范围的元素，但它们共享同一套字体设置。

需要注意的是，分组选择器只是把多个选择器“并列放在一起”，不会改变每个选择器原本的匹配方式。比如 `.card h2` 仍然是后代选择器，`.summary` 仍然是类选择器。


3、无效选择器会影响整组

分组选择器有一个容易忽略的规则：如果列表里有一个选择器语法无效，整条规则都会失效。

示例：

```css
h1,
:wrong-pseudo,
p {
  color: #dc2626;
}
```

这里 `:wrong-pseudo` 是无效伪类，浏览器会忽略整条规则。因此 `h1` 和 `p` 也不会得到这条规则里的红色。

如果不确定某个较新的选择器是否可用，不要轻易把它和基础选择器写在同一组里。可以先拆开写，降低一处错误影响整组样式的风险。

```css
h1,
p {
  color: #dc2626;
}

/* 较新的或不确定的选择器单独写 */
article:has(img) {
  color: #dc2626;
}
```
