# 一、背景图片

背景图片是 CSS 负责的视觉层。它画在元素背后，适合做横幅背景、卡片封面、装饰纹理或氛围图。

它和 HTML 的 `img` 分工不同：

| 写法 | 角色 | 适合内容 |
|---|---|---|
| `img` | 页面内容 | 商品图、头像、文章插图、图表 |
| `background-image` | 页面表现 | 横幅背景、装饰图、纹理、封面氛围 |

如果图片本身是内容，应该优先用 HTML 图片，并提供替代文本。HTML 图片可回看 [[前后端/notes/前端/HTML/6、HTML图片|HTML 图片]]。

下面的示例都使用 `/Users/songpengfei/Learn/HTML/mountain.png` 这张山野图片。图片本身是宽图，中间有山峰和道路，两侧有树，所以很适合观察背景图的裁剪、留白和定位。

如果 HTML 文件和图片都放在 `/Users/songpengfei/Learn/HTML/` 下，代码里就写：

```css
background-image: url("./mountain.png");
```

# 二、显示前提

背景图片能显示，至少要满足两个条件：`url()` 能找到图片，元素本身有可见尺寸。

示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>背景图片显示前提</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 240px;
      margin: 40px auto;
      border: 4px solid #111827;
      background-color: #d1d5db;
      background-image: url("./mountain.png");
    }
  </style>
</head>
<body>
  <section class="hero"></section>
</body>
</html>
```

这里故意给 `.hero` 加了 `border` 和灰色 `background-color`，是为了看清楚元素本身占了多大区域。

`min-height` 表示“最小高度”。如果没有它，空的 `<section class="hero"></section>` 没有内容，高度可能是 `0`。背景图虽然设置成功，但没有地方显示。

元素高度也可以来自内容和 `padding`：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>内容撑开背景区域</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      margin: 40px auto;
      padding: 48px;
      border: 4px solid #111827;
      background-image: url("./mountain.png");
    }
  </style>
</head>
<body>
  <section class="hero">
    <h1>山野徒步路线</h1>
  </section>
</body>
</html>
```

简单来说：`background-image` 负责“画什么图”，元素尺寸负责“在哪里画”。

# 三、显示方式

背景图片默认按原始尺寸显示，并且会重复平铺。真实页面里，通常会同时设置 `background-size`、`background-repeat` 和 `background-position`。

## 1、尺寸

`background-size` 控制背景图画多大。最常用的是 `cover` 和 `contain`。

| 值 | 含义 | 适合场景 |
|---|---|---|
| `auto` | 使用图片原始尺寸 | 默认行为，较少单独使用 |
| `contain` | 整张图完整放进元素 | logo、图标、必须完整可见的图 |
| `cover` | 图片覆盖整个元素 | 横幅、封面、卡片背景 |

`cover` 优先铺满元素。下面把 `.hero` 故意做成比较矮的横幅，你会看到图片上下可能被裁掉：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>background-size: cover</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 220px;
      margin: 40px auto;
      border: 4px solid #111827;
      background-color: #d1d5db;
      background-image: url("./mountain.png");
      background-size: cover;
      background-repeat: no-repeat;
      background-position: center;
    }
  </style>
</head>
<body>
  <section class="hero"></section>
</body>
</html>
```

`contain` 优先完整显示图片。还是同一个 `.hero`，只把 `background-size` 改成 `contain`，你会看到图片完整了，但灰色背景可能露出来：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>background-size: contain</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 220px;
      margin: 40px auto;
      border: 4px solid #111827;
      background-color: #d1d5db;
      background-image: url("./mountain.png");
      background-size: contain;
      background-repeat: no-repeat;
      background-position: center;
    }
  </style>
</head>
<body>
  <section class="hero"></section>
</body>
</html>
```

这两个值的区别可以记成一句话：`cover` 优先铺满，`contain` 优先完整。

## 2、重复

`background-repeat` 控制背景图是否平铺。默认值是 `repeat`，也就是横向、纵向都重复。

为了让重复更明显，下面把同一张山野图缩小成 `180px` 宽。如果不关闭重复，图片会像瓷砖一样铺满 `.hero`：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>background-repeat: repeat</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 260px;
      margin: 40px auto;
      border: 4px solid #111827;
      background-color: #d1d5db;
      background-image: url("./mountain.png");
      background-size: 180px auto;
      background-repeat: repeat;
    }
  </style>
</head>
<body>
  <section class="hero"></section>
</body>
</html>
```

横幅、封面、照片背景通常会关闭重复：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>background-repeat: no-repeat</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 260px;
      margin: 40px auto;
      border: 4px solid #111827;
      background-color: #d1d5db;
      background-image: url("./mountain.png");
      background-size: 180px auto;
      background-repeat: no-repeat;
      background-position: center;
    }
  </style>
</head>
<body>
  <section class="hero"></section>
</body>
</html>
```

`repeat-x` 只横向重复，`repeat-y` 只纵向重复。初学时先掌握 `repeat` 和 `no-repeat` 就够了。

## 3、位置

`background-position` 控制背景图对齐到元素的哪里。它经常和 `cover` 一起使用，因为 `cover` 可能裁剪图片，位置会影响哪一部分更容易保留下来。

这张山野图的山峰在中上部，所以 `center top` 比单纯 `center` 更容易保留天空和山峰：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>background-position</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 180px;
      margin: 40px auto;
      border: 4px solid #111827;
      background-image: url("./mountain.png");
      background-size: cover;
      background-repeat: no-repeat;
      background-position: center top;
    }
  </style>
</head>
<body>
  <section class="hero"></section>
</body>
</html>
```

你可以只改这一行观察变化：

```css
background-position: center;
background-position: center top;
background-position: left center;
background-position: right center;
```

常见写法：

| 写法 | 含义 |
|---|---|
| `center` | 居中 |
| `left top` | 左上 |
| `right bottom` | 右下 |
| `center top` | 水平居中，垂直靠上 |

## 4、滚动

`background-attachment` 控制背景图和滚动之间的关系。默认值是 `scroll`，也就是背景跟着页面正常滚动。

有些页面会用 `fixed` 让背景固定在视口上，页面滚动时背景看起来不动：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>background-attachment</title>
  <style>
    body {
      min-height: 180vh;
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      min-height: 80vh;
      border-bottom: 4px solid #111827;
      background-image: url("./mountain.png");
      background-size: cover;
      background-repeat: no-repeat;
      background-position: center;
      background-attachment: fixed;
    }

    main {
      width: 720px;
      margin: 40px auto;
      line-height: 1.8;
    }
  </style>
</head>
<body>
  <section class="hero"></section>
  <main>
    <h1>继续向下滚动</h1>
    <p>当页面滚动时，背景图看起来停在视口上，内容从它上方经过。</p>
  </main>
</body>
</html>
```

`fixed` 能做出类似视差的视觉效果，但不适合作为默认选择。它可能影响阅读节奏，也可能在移动浏览器中表现不完全一致。

# 四、横幅与渐变

## 1、真实横幅

等背景图本身能显示后，再加入真实内容。因为这张图片中间偏亮，直接放白字可能不够稳定：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>横幅背景</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 320px;
      margin: 40px auto;
      padding: 48px;
      box-sizing: border-box;
      color: white;
      background-color: #1f2937;
      background-image: url("./mountain.png");
      background-size: cover;
      background-repeat: no-repeat;
      background-position: center top;
    }
  </style>
</head>
<body>
  <section class="hero">
    <h1>山野徒步路线</h1>
    <p>整理适合周末出发的短途路线。</p>
  </section>
</body>
</html>
```

这里的 `color: white;` 表示把 `.hero` 里的文字设为白色。`h1` 和 `p` 会继承这个颜色。

它不是背景图片必须写的属性，只是因为文字放在图片上时，需要保证能看清。如果图片很亮，白色文字反而可能不合适。

## 2、背景渐变

CSS 渐变是一种由浏览器生成的背景图，不需要单独准备图片文件。它常用于柔和背景、按钮底色，或者给图片叠一层遮罩。

线性渐变沿着一条直线过渡：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>线性渐变</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 240px;
      margin: 40px auto;
      border: 4px solid #111827;
      background-image: linear-gradient(to right, #2563eb, #f97316);
    }
  </style>
</head>
<body>
  <section class="hero"></section>
</body>
</html>
```

`to right` 表示颜色从左向右过渡。也可以使用角度，例如 `45deg`。

径向渐变从一个中心点向外扩散：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>径向渐变</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 240px;
      margin: 40px auto;
      border: 4px solid #111827;
      background-image: radial-gradient(circle at center, #fde68a, #0f172a);
    }
  </style>
</head>
<body>
  <section class="hero"></section>
</body>
</html>
```

初学阶段先掌握线性渐变即可。径向渐变更适合光晕、聚焦背景和装饰效果。

## 3、文字可读性

背景上有文字时，最重要的是对比度。复杂图片、过亮图片或颜色变化太多的渐变，都会让文字变难读。

更稳定的写法是给背景图叠一层半透明渐变，让文字区域变暗一点：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>渐变遮罩</title>
  <style>
    body {
      margin: 0;
      font-family: system-ui, sans-serif;
      background-color: #f3f4f6;
    }

    .hero {
      width: 720px;
      min-height: 320px;
      margin: 40px auto;
      padding: 48px;
      box-sizing: border-box;
      color: white;
      background-color: #1f2937;
      background-image:
        linear-gradient(rgb(0 0 0 / 60%), rgb(0 0 0 / 20%)),
        url("./mountain.png");
      background-size: cover;
      background-repeat: no-repeat;
      background-position: center top;
    }
  </style>
</head>
<body>
  <section class="hero">
    <h1>山野徒步路线</h1>
    <p>整理适合周末出发的短途路线。</p>
  </section>
</body>
</html>
```

这里有两层背景：渐变在上，图片在下。写在前面的背景层会画在更上面，所以渐变能压暗图片，帮助文字更容易阅读。

> 文字和背景的对比度要足够。通常正文文字至少需要约 `4.5:1` 的对比度，较大的标题文字至少需要约 `3:1`。

# 五、排查顺序

背景图没显示或显示不对时，按这个顺序检查：

1. `url()` 路径是否写对。
2. 图片文件名大小写是否一致。
3. 元素是否有内容、`padding`、`height` 或 `min-height`。
4. 是否需要 `background-size: cover;` 或 `contain;`。
5. 普通照片是否忘了写 `background-repeat: no-repeat;`。
6. 图片主体是否需要用 `background-position` 调整。
7. 是否用了 `background-attachment: fixed;` 改变滚动表现。
8. 背景图上有文字时，文字颜色和背景对比度是否足够。

背景图片的主线可以记成一句话：先让图片找到位置并显示出来，再决定它是完整显示、裁剪填满，还是重复平铺。
