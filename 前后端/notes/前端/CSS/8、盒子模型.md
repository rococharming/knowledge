# 一、元素如何占据页面空间

浏览器排版页面时，会把每个 HTML 元素当作一个盒子来计算位置和尺寸。文字、图片、按钮和容器都在这些盒子里；理解盒子模型，才能准确控制元素的大小、间距和排列。

盒子的外部排版方式主要由 `display` 决定。入门阶段最常见的是 **区块盒子** 和 **行内盒子**：前者像一整行的区域，后者像穿插在一句话里的词。

| 特性 | 区块盒子（`block`） | 普通行内盒子（`inline`） |
|---|---|---|
| 换行 | 在正常文档流中通常独占一行，后一个盒子从新行开始 | 与同一行的文字、其他行内盒子一起排列；空间不足时会换到下一行 |
| `width` / `height` | 可以直接设置 | 对非替换行内元素不生效 |
| 默认宽度 | `width: auto`，会填满父元素中的可用行内空间 | 宽度由内容决定 |
| 外边距 | 四个方向都会参与布局；相邻区块的上下外边距还可能折叠 | 左右外边距参与布局；上下外边距不会把所在行推开 |
| 内边距和边框 | 会参与盒子的实际尺寸 | 左右会拉开内容；上下会绘制出来，但通常不撑开所在行的行高 |
| 常见元素 | `div`、`p`、`h1` - `h6`、`ul` | `span`、`em`、`a`、`strong` |

![[css-block-inline-boxes-handdrawn.png|600]]

图中左侧蓝色盒子各占一行，表示区块盒子的换行特性；右侧橙色小盒子连续排在两行中，表示行内盒子随文本流动。

> [!note] `width: auto` 不等于 `width: 100%`
> 普通区块盒子默认是 `width: auto`。浏览器会在计算外边距、内边距和边框后，让内容区域填满剩余可用空间；直接写 `width: 100%` 时，内边距和边框可能会额外把盒子撑宽。

下面的示例可以直接观察两种盒子的差异：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>区块盒子和行内盒子</title>
  <style>
    .block-box {
      width: 240px;
      height: 56px;
      margin: 12px 0;
      padding: 12px;
      border: 2px solid #2563eb;
      background-color: #dbeafe;
    }

    .inline-box {
      width: 240px; /* 对普通行内元素不生效 */
      height: 56px; /* 对普通行内元素不生效 */
      margin: 24px 12px;
      padding: 8px 12px;
      border: 2px solid #ea580c;
      background-color: #ffedd5;
    }
  </style>
</head>
<body>
  <div class="block-box">我是区块盒子</div>
  <div class="block-box">我会换到下一行</div>

  <p>
    这是一段文字，<span class="inline-box">我是行内盒子</span>，文字仍会接着排。
  </p>
</body>
</html>
```

`.block-box` 的宽高和四周间距都会参与排版；`.inline-box` 的左右间距可见，但给它设置的宽高不会让这个 `span` 变成固定大小的矩形。若希望元素既能同一行排列又能设置宽高，后面会使用 `inline-block`、Flex 或 Grid 等布局方式。

# 二、盒子模型的四层结构

学习中常说的 CSS 盒子模型，重点是区块盒子的尺寸和间距。它从内到外由 **内容（content）**、**内边距（padding）**、**边框（border）** 和 **外边距（margin）** 组成。

![[css-box-model-layers-handdrawn.png|620]]

图中从内到外依次是蓝色内容区、黄色内边距、珊瑚色边框和灰色外边距。外边距是盒子与周围元素的距离，所以它通常没有背景色，也不会被元素本身的背景填充。

| 部分 | 作用 | 尺寸由什么决定 |
|---|---|---|
| 内容区 | 显示文字、图片或子元素 | 内容本身，或 `width`、`height` |
| 内边距 | 拉开内容和边框 | `padding` |
| 边框 | 包住内容与内边距，并提供轮廓 | `border` |
| 外边距 | 拉开当前盒子和其他盒子 | `margin` |

例如，一张卡片的文字不会紧贴边框，通常就是依靠内边距：

```css
.card {
  width: 320px;
  padding: 24px;
  border: 1px solid #cbd5e1;
  margin: 24px 0;
  background-color: #ffffff;
}
```

# 三、边框与圆角

## 1、设置边框

`border` 是同时设置边框宽度、样式和颜色的简写属性。完整写法通常把三部分用空格分开；三者没有固定先后顺序，但习惯写成“宽度 → 样式 → 颜色”。

```css
.notice {
  border: 2px solid #2563eb;
}
```

其中 `2px` 是粗细，`solid` 是样式，`#2563eb` 是颜色。简写中可以省略某个部分，此时浏览器会使用该子属性的初始值；但要画出可见边框，通常应明确写出宽度、样式和颜色。

常见的 `border-style` 值如下：

| 值 | 外观 | 常见用途 |
|---|---|---|
| `solid` | 实线 | 卡片、输入框、分隔轮廓 |
| `dashed` | 虚线 | 占位区、可拖放区域、提示框 |
| `dotted` | 点线 | 较轻量的分隔或提示 |
| `double` | 双线 | 少见，适合强调性装饰 |
| `none` | 无边框 | 显式移除已有边框 |

也可以只控制某一条边：

```css
.article {
  border-top: 4px solid #2563eb;
  border-right: 1px dashed #cbd5e1;
  border-bottom: 1px solid #cbd5e1;
  border-left: 4px solid #f97316;
}
```

`border-top`、`border-right`、`border-bottom`、`border-left` 都是单边的简写属性，也能继续细分为 `border-top-width`、`border-top-style` 和 `border-top-color`。

## 2、圆角边框

`border-radius` 用来切掉矩形四角，让边框和背景呈现圆角。属性值可以是长度（如 `12px`）或百分比（如 `50%`）。

```css
.panel {
  border-radius: 12px;
}
```

多个值按顺时针方向对应四个角：左上、右上、右下、左下。

| 写法 | 对应的圆角 |
|---|---|
| `border-radius: 12px;` | 四个角都是 `12px` |
| `border-radius: 12px 24px;` | 左上/右下为 `12px`，右上/左下为 `24px` |
| `border-radius: 12px 24px 36px;` | 左上为 `12px`，右上/左下为 `24px`，右下为 `36px` |
| `border-radius: 12px 24px 36px 48px;` | 依次为左上、右上、右下、左下 |

圆角的本质是：浏览器在每个角上用四分之一椭圆替代尖角，圆角半径越大，角越圆。半径不能把相邻圆角挤到超过盒子边长；空间不足时，浏览器会按比例缩小它们。

两个常见形状：

```css
.pill {
  width: 160px;
  height: 48px;
  border-radius: 24px; /* 高度的一半 */
}

.circle {
  width: 120px;
  height: 120px;
  border-radius: 50%; /* 正方形的每条边的一半 */
}
```

胶囊形要求圆角至少达到盒子高度的一半；圆形要求盒子本身是正方形。若把 `border-radius: 50%` 用在长方形上，得到的是椭圆而不是圆。

# 四、内边距与外边距

## 1、内边距 `padding`

`padding` 是内容与边框之间的空白。元素的背景色和背景图会延伸到内边距区域，因此它适合做按钮、卡片内部的留白。

```css
.button {
  padding: 10px 16px;
  border: 0;
  border-radius: 6px;
  background-color: #2563eb;
  color: white;
}
```

`padding` 多值写法同样按上、右、下、左展开：

| 写法 | 含义 |
|---|---|
| `padding: 16px;` | 四个方向都是 `16px` |
| `padding: 12px 20px;` | 上下 `12px`，左右 `20px` |
| `padding: 12px 20px 16px;` | 上 `12px`，左右 `20px`，下 `16px` |
| `padding: 12px 16px 20px 24px;` | 上、右、下、左依次设置 |

## 2、外边距 `margin`

`margin` 是盒子外面一圈看不见的空间，用来拉开不同元素之间的距离。它不属于元素绘制出来的背景和边框范围。

```css
.section {
  margin: 32px 0;
}
```

`margin` 的多值规则与 `padding` 完全相同：

| 写法 | 含义 |
|---|---|
| `margin: 16px;` | 四个方向都是 `16px` |
| `margin: 12px 20px;` | 上下 `12px`，左右 `20px` |
| `margin: 12px 20px 16px;` | 上 `12px`，左右 `20px`，下 `16px` |
| `margin: 12px 16px 20px 24px;` | 上、右、下、左依次设置 |

> [!warning] 普通行内元素的上下间距
> 对普通行内元素，`margin-left` 和 `margin-right` 能拉开同一行内容；`margin-top` 和 `margin-bottom` 不会把所在行推开。它的上下 `padding` 和 `border` 虽然可能画出来，但也通常不会增大这一行的行高。需要稳定控制尺寸和四周间距时，不要只依赖 `span` 这类普通行内元素。

## 3、区块盒子的水平居中

让普通区块盒子水平居中的经典写法是设置左右 `margin: auto`。前提是盒子有明确可计算的宽度，并且该宽度小于父元素的可用宽度。

```css
.dialog {
  width: 640px;
  margin: 0 auto;
}
```

浏览器在计算区块盒子时，会把父元素剩余的水平空间分给左右两个 `auto` 外边距。因此左右两侧得到相同空间，盒子就处于中间。

常见写法及含义：

```css
.box-a {
  margin: auto; /* 水平方向会居中；普通文档流中的上下 auto 通常按 0 处理 */
}

.box-b {
  margin: 0 auto; /* 最常用：上下为 0，左右自动分配剩余空间 */
}

.box-c {
  margin-left: auto;
  margin-right: auto;
}
```

如果盒子宽度本来就占满父元素，左右没有剩余空间可分，写 `margin: 0 auto` 也看不出居中效果。实际页面常用 `max-width` 兼顾窄屏：

```css
.page-content {
  width: min(100% - 32px, 960px);
  margin: 0 auto;
}
```

# 五、垂直外边距的两个现象

区块盒子在普通文档流中，垂直方向的 `margin` 有两个容易意外的浏览器规则：**外边距折叠** 和 **外边距塌陷**。它们不是浏览器错误，而是 CSS 的排版特性。

![[css-margin-collapse-handdrawn.png|700]]

图左表示相邻兄弟盒子：两个蓝色盒子交界处的上下外边距会合并。图右表示父子盒子：父盒子顶部没有边框或内边距时，子盒子的上外边距可能跑到父盒子外面，使父盒子一起向下移动。

## 1、外边距折叠

相邻的两个普通区块盒子，前一个的下外边距和后一个的上外边距不会简单相加，而是折叠为一个外边距。两者都是正值时，最终间距等于其中较大的那个。

```html
<div class="first">第一个盒子</div>
<div class="second">第二个盒子</div>
```

```css
.first {
  margin-bottom: 32px;
}

.second {
  margin-top: 16px;
}
```

两个盒子之间的最终间距是 `32px`，不是 `48px`。这样只需给其中一个盒子设置垂直间距，也能避免重复制造更大的空白。

> [!note] 适用范围
> 这里的“取最大值”只适用于两个外边距都是正数的常见情况。若存在负外边距，折叠结果会按正、负值一起计算。Flex、Grid 容器中的项目，以及绝对定位元素，也不会按这一套普通文档流规则发生外边距折叠。

## 2、外边距塌陷

父盒子的顶部没有 `border-top`、`padding-top`、行内内容或其他能把父子内容隔开的条件时，首个子盒子的 `margin-top` 可能与父盒子的上外边距折叠。视觉上会像是子盒子把父盒子整体推走了，这常被称为“外边距塌陷”。

```html
<section class="parent">
  <div class="child">子盒子</div>
</section>
```

```css
.parent {
  background-color: #e0f2fe;
}

.child {
  margin-top: 32px;
  background-color: #bae6fd;
}
```

可根据真实需求选下面的解决办法：

```css
/* 方案一：边框把父子外边距隔开 */
.parent-with-border {
  border-top: 1px solid transparent;
}

/* 方案二：改为父盒子的内部留白 */
.parent-with-padding {
  padding-top: 32px;
}

/* 方案三：建立新的块格式化上下文 */
.parent-with-overflow {
  overflow: hidden;
}

/* 若不需要裁剪溢出内容，通常更适合这个现代写法 */
.parent-with-flow-root {
  display: flow-root;
}
```

`border-top` 和 `padding-top` 会改变盒子的外观或尺寸，适合它们本来就符合设计的情况。`overflow: hidden` 能阻止塌陷，但它也会裁剪超出父盒子的阴影、提示框等内容；只为解决塌陷时，优先考虑 `display: flow-root`。

# 六、尺寸计算与 `box-sizing`

默认的 `box-sizing: content-box` 中，`width` 和 `height` 只指定内容区尺寸。左右 `padding` 和 `border` 会额外加到最终宽度，所以下面这个盒子的实际外部宽度不是 `300px`：

```css
.content-box {
  width: 300px;
  padding: 20px;
  border: 4px solid #2563eb;
}
```

它的实际外部宽度为：`300px + 20px × 2 + 4px × 2 = 348px`。

![[css-box-sizing-handdrawn.png|700]]

图中虚线表示声明的宽度范围：左侧在 `content-box` 下，黄色内边距和珊瑚色边框被额外加在虚线外；右侧在 `border-box` 下，它们都被算在虚线范围内。

`box-sizing` 用来决定 `width` 和 `height` 如何计算：

| 值 | `width` / `height` 包含什么 | 适合什么情况 |
|---|---|---|
| `content-box` | 只包含内容区 | CSS 默认值；需要单独精确控制内容尺寸时 |
| `border-box` | 包含内容、内边距和边框 | 页面布局、卡片、表单控件等大多数开发场景 |

`margin` 始终在盒子外部，**不属于** `content-box` 或 `border-box` 的 `width`、`height` 计算范围。

```css
/* 让页面中常见元素都使用更直观的尺寸计算方式 */
*,
*::before,
*::after {
  box-sizing: border-box;
}

.border-box {
  width: 300px;
  padding: 20px;
  border: 4px solid #2563eb;
  box-sizing: border-box;
}
```

此时 `.border-box` 的外部宽度仍是 `300px`，浏览器会在这 `300px` 内扣除内边距和边框，再分配剩余空间给内容区。它能避免“加一点内边距，布局就比设计尺寸更宽”的问题。

# 七、实践：制作一张尺寸可控的卡片

下面把本页的主要属性放进一个完整示例。卡片使用 `border-box` 保持宽度稳定，用 `padding` 留出内部空间，用 `margin: 24px auto` 居中，并用 `border-radius` 做圆角。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>盒子模型卡片</title>
  <style>
    *,
    *::before,
    *::after {
      box-sizing: border-box;
    }

    body {
      margin: 0;
      background-color: #f8fafc;
      font-family: Arial, "Microsoft YaHei", sans-serif;
    }

    .profile-card {
      width: min(100% - 32px, 420px);
      margin: 24px auto;
      padding: 24px;
      border: 1px solid #cbd5e1;
      border-radius: 16px;
      background-color: #ffffff;
      box-shadow: 0 8px 24px rgb(15 23 42 / 12%);
    }

    .profile-card h1 {
      margin: 0 0 12px;
      font-size: 24px;
    }

    .profile-card p {
      margin: 0;
      color: #475569;
      line-height: 1.7;
    }
  </style>
</head>
<body>
  <article class="profile-card">
    <h1>盒子模型</h1>
    <p>内边距让内容不贴边，边框给出轮廓，外边距负责与其他元素保持距离。</p>
  </article>
</body>
</html>
```

这张卡片的最大外部宽度是 `420px`。视口较窄时，`width: min(100% - 32px, 420px)` 会让它始终给左右各预留 `16px`；`margin: 24px auto` 则只在有剩余空间时把卡片放到中间。
