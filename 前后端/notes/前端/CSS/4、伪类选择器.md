# 一、伪类选择器

伪类选择器是在普通选择器后面追加的特殊条件，用来选择“处在某种状态、位置或条件下”的元素。它仍然是在选择 HTML 元素，只是比 [[2、CSS选择器|基础选择器]] 多了一层判断。

伪类用一个冒号 `:` 表示，基本写法是：

```css
选择器:伪类 {
  属性: 值;
}
```

例如：

```css
.demo-link:hover {
  color: #dc2626;
}
```

`.demo-link` 先选中带有 `class="demo-link"` 的元素，`:hover` 再进一步要求“鼠标指针正停在这个元素上”。只有两个条件同时满足时，里面的样式才会生效。

伪类常见可以先分成三类理解：

| 类型 | 选择依据 | 示例 |
|---|---|---|
| 状态伪类 | 元素当前状态或用户行为 | `:hover`、`:focus`、`:active` |
| 结构伪类 | 元素在同级或父子结构中的位置 | `:first-child`、`:nth-child()` |
| 表单伪类 | 表单控件自身状态 | `:checked`、`:disabled` |

# 二、状态伪类选择器

状态伪类选择器用于根据元素“此刻处于什么状态”来添加样式。最常见的场景是链接、按钮、卡片和表单输入框：用户看过、悬停、点击或聚焦时，页面给出不同的视觉反馈。

## 1、链接状态

链接有一组专门的状态伪类，用于区分链接是否访问过，以及用户是否正在与链接交互。

| 伪类 | 含义 |
|---|---|
| `:link` | 尚未访问过的链接 |
| `:visited` | 已经访问过的链接 |
| `:hover` | 鼠标指针悬停在链接上 |
| `:active` | 链接正在被激活，例如鼠标按下还没松开 |

示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>链接状态伪类</title>
  <style>
    .demo-link:link {
      color: #2563eb;
    }

    .demo-link:visited {
      color: #6d28d9;
    }

    .demo-link:hover {
      color: #dc2626;
      text-decoration: underline;
    }

    .demo-link:active {
      color: #ea580c;
    }
  </style>
</head>
<body>
  <a class="demo-link" href="https://developer.mozilla.org/">打开 MDN</a>
</body>
</html>
```

这组规则都在选择同一个链接，只是状态不同。为了让状态覆盖更符合预期，链接伪类通常按 `:link`、`:visited`、`:hover`、`:active` 的顺序书写，也就是常说的 LVHA 顺序。

需要注意的是，`:visited` 受浏览器隐私保护限制，实际开发中主要用它改变文字、边框、下划线等颜色类样式，不应该依赖它读取或暴露用户访问历史。

## 2、用户行为状态

除了链接，很多元素也会根据用户行为进入不同状态。入门阶段最常用的是 `:hover` 和 `:focus`。

| 伪类 | 含义 | 常见场景 |
|---|---|---|
| `:hover` | 鼠标指针悬停在元素上 | 导航项、按钮、商品卡片 |
| `:focus` | 元素获得焦点 | 输入框、按钮、可键盘访问的链接 |

示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>用户行为状态伪类</title>
  <style>
    body {
      font-family: Arial, "Microsoft YaHei", sans-serif;
      padding: 24px;
    }

    .demo-card {
      width: 240px;
      padding: 16px;
      border: 1px solid #d1d5db;
      border-radius: 8px;
      transition: background-color 0.2s, transform 0.2s;
    }

    .demo-card:hover {
      background-color: #eff6ff;
      transform: translateY(-2px);
    }

    .demo-field {
      display: block;
      width: 240px;
      margin-top: 16px;
      padding: 10px 12px;
      border: 1px solid #9ca3af;
      border-radius: 6px;
      font-size: 16px;
    }

    .demo-field:focus {
      border-color: #2563eb;
      outline: 3px solid #bfdbfe;
    }
  </style>
</head>
<body>
  <div class="demo-card">
    鼠标经过这张卡片时，背景和位置会变化。
  </div>

  <input class="demo-field" type="text" placeholder="点击或用 Tab 聚焦">
</body>
</html>
```

`:hover` 适合给鼠标用户提供“这里可以操作”的反馈，但手机和平板上不一定有稳定的悬停状态，所以关键操作不能只依赖 `:hover` 才能看见。`:focus` 对键盘用户尤其重要，输入框、按钮和链接获得焦点时应该有清晰的可见样式。

状态伪类的核心思路是：HTML 不需要额外变化，浏览器会根据当前状态临时匹配对应选择器；状态消失后，对应样式也会自动失效。

# 三、结构伪类选择器

结构伪类选择器根据元素在“同一个父元素下的一组兄弟元素”中的位置来选择目标元素。它适合处理列表、导航、商品卡片等重复结构，让第一个、最后一个、奇偶项或指定序号的元素拥有不同样式。

常用结构伪类可以先掌握这三个：

| 伪类 | 含义 |
|---|---|
| `:first-child` | 选择一组兄弟元素中的第一个元素 |
| `:last-child` | 选择一组兄弟元素中的最后一个元素 |
| `:nth-child(n)` | 选择一组兄弟元素中的第 n 个元素 |

## 1、首尾元素

`:first-child` 和 `:last-child` 用来选择同一个父元素下的第一个或最后一个子元素。它们常用于给列表首项、尾项去边框或突出显示。

示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>结构伪类选择器</title>
  <style>
    .menu-list {
      width: 280px;
      padding: 0;
      border: 1px solid #d1d5db;
      list-style: none;
    }

    .menu-list li {
      padding: 12px 16px;
      border-bottom: 1px solid #e5e7eb;
    }

    .menu-list li:first-child {
      color: #dc2626;
      font-weight: 700;
    }

    .menu-list li:last-child {
      border-bottom: none;
      color: #16a34a;
    }
  </style>
</head>
<body>
  <ul class="menu-list">
    <li>上新精选</li>
    <li>小米众筹</li>
    <li>有品秒杀</li>
    <li>生活优选</li>
    <li>小米自营</li>
  </ul>
</body>
</html>
```

这里 `.menu-list li:first-child` 选择的是 `.menu-list` 里面的第一个 `li`，所以“上新精选”会变成红色加粗。`.menu-list li:last-child` 选择最后一个 `li`，所以“小米自营”会变成绿色，并且去掉底部边框。

> 注意：`li:first-child` 的意思不是“所有 `li` 中的第一个”，而是“这个 `li` 必须是它父元素下的第一个子元素”。如果父元素的第一个子元素不是 `li`，这个选择器就不会匹配它后面的 `li`。

## 2、指定序号

`:nth-child(n)` 用来按序号选择元素。这里的 `n` 可以是数字、关键字，也可以是一个简单公式。

沿用上面的 HTML，只修改 CSS：

```css
.menu-list li:nth-child(2) {
  color: #2563eb;
}

.menu-list li:nth-child(odd) {
  background-color: #f9fafb;
}

.menu-list li:nth-child(even) {
  background-color: #eef2ff;
}
```

这段 CSS 中：

- `:nth-child(2)` 选择第 2 个列表项。
- `:nth-child(odd)` 选择第 1、3、5……个奇数项。
- `:nth-child(even)` 选择第 2、4、6……个偶数项。

`:nth-child()` 也可以写公式，适合表达更规律的选择：

| 写法 | 匹配结果 |
|---|---|
| `:nth-child(3n)` | 第 3、6、9……个元素 |
| `:nth-child(n + 3)` | 第 3 个以及后面的所有元素 |
| `:nth-child(-n + 3)` | 前 3 个元素 |

公式里的计数结果从 1 开始匹配页面元素，但公式变量 `n` 从 0 开始代入。例如 `3n` 代入后得到 0、3、6、9……，其中 0 不会匹配任何元素，所以实际匹配第 3、6、9……个元素。

## 3、使用边界

结构伪类适合选择“位置本身有意义”的元素，例如第一个导航项、最后一个列表项、奇偶行背景色。它不适合表达业务含义，例如“热销商品”“当前选中的频道”这类语义状态更适合使用类选择器。

也就是说，选择器应该优先表达样式意图：如果样式来自结构规律，用结构伪类；如果样式来自内容含义或业务状态，用类选择器。

# 四、表单伪类选择器

表单伪类选择器用于根据表单控件自身的状态选择元素。它常用于让禁用按钮变灰、让选中的复选框或单选按钮对应的文字更醒目。

入门阶段先掌握这两个：

| 伪类 | 含义 | 常见元素 |
|---|---|---|
| `:disabled` | 选择被禁用的表单控件 | `input`、`button`、`select`、`textarea` |
| `:checked` | 选择已选中的控件 | 复选框、单选按钮 |

## 1、禁用状态

`:disabled` 匹配带有禁用状态的表单控件。禁用控件通常不能被点击、输入，也不能获得焦点，所以页面需要用更弱的颜色告诉用户“这个控件暂时不可用”。

示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>表单伪类选择器</title>
  <style>
    body {
      font-family: Arial, "Microsoft YaHei", sans-serif;
      padding: 24px;
    }

    .signup-form {
      width: 320px;
    }

    .signup-form input {
      box-sizing: border-box;
      width: 100%;
      margin-bottom: 12px;
      padding: 10px 12px;
      border: 1px solid #d1d5db;
      border-radius: 6px;
      font-size: 16px;
    }

    .signup-form button {
      width: 100%;
      padding: 10px 12px;
      border: none;
      border-radius: 6px;
      background-color: #f97316;
      color: white;
      font-size: 16px;
      cursor: pointer;
    }

    .signup-form button:disabled {
      background-color: #d1d5db;
      color: #6b7280;
      cursor: not-allowed;
    }
  </style>
</head>
<body>
  <form class="signup-form">
    <input type="text" placeholder="用户名">
    <input type="password" placeholder="密码">
    <button type="submit" disabled>注册</button>
  </form>
</body>
</html>
```

这里按钮带有 `disabled` 属性，因此 `.signup-form button:disabled` 会匹配它。按钮会显示成灰色，并且鼠标样式变成 `not-allowed`，让用户知道它当前不能提交。

## 2、选中状态

`:checked` 匹配已经选中的复选框或单选按钮。它通常不只用来改控件本身，也会配合兄弟选择器修改旁边的文字样式。

示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>选中状态伪类</title>
  <style>
    body {
      font-family: Arial, "Microsoft YaHei", sans-serif;
      padding: 24px;
    }

    .agreement {
      display: flex;
      align-items: center;
      gap: 8px;
      color: #6b7280;
    }

    .agreement input:checked + span {
      color: #f97316;
      font-weight: 700;
    }
  </style>
</head>
<body>
  <label class="agreement">
    <input type="checkbox">
    <span>我已阅读并同意用户协议</span>
  </label>
</body>
</html>
```

这里 `input:checked + span` 会在复选框被选中时，选择紧跟在它后面的 `span`。所以勾选复选框后，协议文字会变成橙色加粗。

`+` 是 [[2、CSS选择器#3、相邻兄弟选择器|相邻兄弟选择器]]，表示选择紧挨着前一个元素后面的兄弟元素。这个例子里，伪类负责判断“复选框是否选中”，兄弟选择器负责找到“要改变样式的文字”。

## 3、使用边界

表单伪类适合表达控件自身状态，例如禁用、选中、获得焦点。它不负责判断业务是否通过，比如“密码是否足够安全”“手机号是否已经注册”这类逻辑通常需要表单校验配合，不能只靠 CSS 判断。

另外，不要只用颜色表达表单状态。禁用按钮可以同时降低对比、改变鼠标样式；选中协议可以同时改变颜色和字重。这样即使用户对颜色不敏感，也能看出状态变化。
