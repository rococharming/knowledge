# 一、伪元素选择器

伪元素选择器用于选择元素中的某个“特定部分”，或者在元素内部生成一小段装饰性内容。它和 [[4、伪类选择器|伪类选择器]] 很像，都要追加在普通选择器后面；区别是伪类多用于选择元素的状态，伪元素多用于选择元素的一部分。

伪元素使用双冒号 `::`，基本写法是：

```css
选择器::伪元素 {
  属性: 值;
}
```

示例：

```css
.article::first-line {
  color: #dc2626;
}
```

这里 `.article` 先选中文章元素，`::first-line` 再选中这个元素显示出来的第一行文字。

常见伪元素可以先分成两类：

| 类型 | 作用 | 示例 |
|---|---|---|
| 选择局部 | 选择元素中特定的一部分 | `::first-line`、`::first-letter`、`::placeholder` |
| 插入内容 | 在元素内部生成装饰性内容 | `::before`、`::after` |

> 现代 CSS 推荐使用双冒号 `::` 写伪元素。部分早期伪元素也能写成单冒号，例如 `:before`，但学习和实际书写时统一使用 `::before` 更清楚。

# 二、选择局部

## 1、首行和首字母

`::first-line` 选择元素显示出来的第一行文字，`::first-letter` 选择第一行中的第一个字母、数字或符号。它们常用于文章排版，例如首行强调、首字下沉。

示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>首行和首字母</title>
  <style>
    body {
      font-family: Arial, "Microsoft YaHei", sans-serif;
      padding: 24px;
    }

    .article {
      width: 360px;
      line-height: 1.8;
      color: #374151;
    }

    .article::first-line {
      color: #b91c1c;
      font-weight: 700;
    }

    .article::first-letter {
      float: left;
      margin-right: 8px;
      font-size: 42px;
      line-height: 1;
      color: #f97316;
    }
  </style>
</head>
<body>
  <p class="article">
    CSS 负责控制页面的视觉表现。选择器越准确，样式越容易维护，页面结构也越清楚。
  </p>
</body>
</html>
```

这里第一行会变成深红色并加粗，第一个字会放大形成类似文章开头的装饰效果。需要注意的是，第一行不是固定文本，而是浏览器根据容器宽度、字体大小、换行结果计算出来的。

## 2、占位文字

`::placeholder` 用于选择输入框或文本域里的占位文字，也就是 `placeholder` 属性显示出来的提示内容。

示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>占位文字</title>
  <style>
    body {
      font-family: Arial, "Microsoft YaHei", sans-serif;
      padding: 24px;
    }

    .search-box {
      width: 280px;
      padding: 10px 12px;
      border: 1px solid #d1d5db;
      border-radius: 6px;
      font-size: 16px;
    }

    .search-box::placeholder {
      color: #9ca3af;
    }
  </style>
</head>
<body>
  <input class="search-box" type="text" placeholder="搜索课程、文章或工具">
</body>
</html>
```

这里 `::placeholder` 只修改提示文字的颜色，不会影响用户真正输入的内容。输入后的文字仍然由 `.search-box` 本身的文本样式控制，可回看 [[3、CSS文本样式|CSS 文本样式]]。

# 三、插入内容

## 1、前后装饰

`::before` 和 `::after` 会在元素内容的前面或后面生成一个伪元素。它们常用于添加小图标、分隔符、角标这类装饰内容。

示例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>前后伪元素</title>
  <style>
    body {
      font-family: Arial, "Microsoft YaHei", sans-serif;
      padding: 24px;
    }

    .badge {
      display: inline-block;
      padding: 10px 14px;
      border-radius: 6px;
      background-color: #eff6ff;
      color: #1d4ed8;
      font-weight: 700;
    }

    .badge::before {
      content: "开始";
      margin-right: 8px;
      color: #dc2626;
    }

    .badge::after {
      content: "结束";
      margin-left: 8px;
      color: #dc2626;
    }
  </style>
</head>
<body>
  <div class="badge">文字</div>
</body>
</html>
```

页面中真实的 HTML 只有“文字”，但浏览器会在渲染时通过 `::before` 和 `::after` 显示出“开始”和“结束”。

## 2、使用边界

`::before` 和 `::after` 通常必须写 `content` 属性；如果没有生成内容，它们就不会显示出来。即使只是为了做一个装饰形状，也可以写 `content: "";`。

这些插入内容更适合做装饰，不适合承载页面的核心信息。核心文字应该写在 HTML 中，因为屏幕阅读器、复制文本、搜索索引等场景未必会把伪元素内容当成真正内容处理。

伪元素也不能随意用在所有元素上。例如 `::before` 和 `::after` 不能可靠地作用在 `img` 这类由外部资源替换显示内容的元素上。遇到图片角标、遮罩等效果时，通常把图片包在一个普通容器里，再给容器添加伪元素。
