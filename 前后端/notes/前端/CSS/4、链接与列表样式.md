# 一、文本元素

链接和列表都是 HTML 里很常见的内容结构。CSS 可以改变它们的视觉表现，但不应该抹掉它们原本承担的功能：链接要让人看出“可以点击”，列表要让人看出“这些内容属于同一组”。

这些元素的 HTML 语义已经在 [[前后端/notes/前端/HTML/8、HTML链接|HTML 链接]] 和 [[前后端/notes/前端/HTML/10、HTML文本语义与描述列表#五、描述列表 dl、dt 与 dd|描述列表]] 中出现过。本篇只处理 CSS 表现层。

# 二、链接状态

## 1、默认样式

浏览器默认会把链接设计得很容易识别：未访问链接通常是蓝色并带下划线，访问过的链接通常会变成紫色。这个默认外观不是随意的，它在帮助用户快速扫视页面、区分普通文字和可点击内容。

示例：

```html
<p>
  阅读 <a href="/docs/css">CSS 笔记</a>，
  或查看 <a href="/docs/html">HTML 笔记</a>。
</p>
```

如果完全移除链接的颜色差异和下划线，用户可能很难判断哪里可以点击。自定义链接样式时，可以改变视觉风格，但要保留清晰的互动线索。

## 2、伪类状态

链接的不同状态可以通过 **伪类（pseudo-class）** 选择器设置。伪类是在选择器后面添加的状态关键词，用来匹配元素的特殊状态。

常见链接状态包括：

| 伪类 | 含义 |
|---|---|
| `:link` | 尚未访问过的链接 |
| `:visited` | 已经访问过的链接 |
| `:hover` | 指针悬停在链接上 |
| `:focus` | 链接获得键盘焦点 |
| `:active` | 链接正在被点击或激活 |

示例：

```css
a:link {
  color: #2563eb;
}

a:visited {
  color: #7c3aed;
}

a:hover {
  text-decoration-thickness: 2px;
}

a:focus {
  outline: 2px solid #f59e0b;
  outline-offset: 3px;
}

a:active {
  color: #dc2626;
}
```

这里 `:focus` 对键盘用户很重要。不要只设计鼠标悬停效果，而忘记键盘导航时的焦点样式。

## 3、书写顺序

多个链接状态可能同时成立。例如一个链接被点击时，常常也处于悬停状态。为了让状态覆盖更符合预期，常见书写顺序是：

```css
a:link {}
a:visited {}
a:focus {}
a:hover {}
a:active {}
```

这个顺序让基础状态先出现，用户交互状态后出现。若多个规则优先级相同，后出现的规则会覆盖前面的同属性声明；这一点属于 [[3、层叠、继承与优先级#二、层叠|层叠]] 的判断。

> [!note] `:visited` 有隐私限制
> 浏览器会限制 `:visited` 可修改的样式范围，避免网页通过样式检测用户访问历史。实际使用时，通常只把它用于颜色相关差异。

# 三、列表标记

## 1、标记类型

`list-style-type` 控制列表项前面的标记类型。无序列表常见值有 `disc`、`circle`、`square`；有序列表常见值有 `decimal`、`lower-alpha`、`upper-roman`。

示例：

```html
<ul class="task-list">
  <li>阅读 CSS 基础</li>
  <li>练习选择器</li>
  <li>整理错题</li>
</ul>
```

```css
.task-list {
  list-style-type: square;
}
```

如果列表顺序本身有意义，应该使用 `ol`，再通过 CSS 调整编号样式，而不是用 `ul` 模拟编号。

## 2、标记位置

`list-style-position` 控制标记放在内容盒子的外侧还是内侧，常见值是 `outside` 和 `inside`。

```css
.notes-outside {
  list-style-position: outside;
}

.notes-inside {
  list-style-position: inside;
}
```

`outside` 是默认行为，标记位于文本内容外侧，多行文本换行后通常能保持更整齐的文本边界。`inside` 会把标记放进内容区域，多行文本换行时可能和标记对齐在一起，适合少数需要紧凑排版的场景。

## 3、图片标记

`list-style-image` 可以用图片作为列表标记：

```css
.check-list {
  list-style-image: url("/assets/check-marker.png");
}
```

图片标记应该小而清晰。如果图片太复杂、尺寸太大，列表会变得难读。真实项目中如果需要更稳定的图标控制，也常用伪元素或内联图标实现，而不是依赖大图片做列表标记。

## 4、简写属性

`list-style` 是 `list-style-type`、`list-style-position` 和 `list-style-image` 的简写。

```css
.reading-list {
  list-style: square outside;
}
```

如果同时写了标记图片和标记类型，当图片无法加载时，标记类型可以作为后备显示：

```css
.reading-list {
  list-style: square outside url("/assets/book-marker.png");
}
```

# 四、列表间距

## 1、外边距

如果要控制不同列表项之间的距离，通常直接给 `li` 设置 `margin`。

示例：

```html
<ul class="study-steps">
  <li>先读一遍概念。</li>
  <li>再写一个最小示例。</li>
  <li>最后修改示例观察变化。</li>
</ul>
```

```css
.study-steps li {
  margin-bottom: 12px;
}
```

如果不希望最后一项也有额外间距，可以配合伪类：

```css
.study-steps li:last-child {
  margin-bottom: 0;
}
```

这里的 `:last-child` 也是伪类，它匹配父元素中的最后一个子元素。

## 2、行高

`line-height` 控制一行文字占据的高度。它主要影响同一个列表项内部的多行文本，而不是专门用来制造列表项之间的间距。

```css
.study-steps li {
  line-height: 1.6;
}
```

当每个 `li` 都只有一行文字时，增大 `line-height` 看起来也会让列表更松。但如果列表项包含多行文本，`line-height` 调整的是行与行之间的距离；列表项与列表项之间的距离仍应优先使用 `margin`。

## 3、选择方式

| 目标 | 推荐属性 | 原因 |
|---|---|---|
| 拉开不同列表项 | `margin-bottom` | 直接控制项与项之间的外部距离 |
| 提高多行文字可读性 | `line-height` | 控制同一项内部的行距 |
| 控制标记样式 | `list-style-type` | 改变圆点、方块或编号形式 |
| 控制标记位置 | `list-style-position` | 决定标记在内容内侧或外侧 |

列表样式的关键不是“越花越好”，而是让分组、顺序和阅读节奏更清楚。

# 五、可用性

## 1、链接可识别

链接样式应该让用户在扫视页面时立刻知道哪里可以点击。常见做法是保留至少一种稳定线索：

- 使用与正文有明显区分的颜色。
- 保留或替换下划线，例如用 `border-bottom`。
- 为 `:hover` 和 `:focus` 提供清楚反馈。
- 不要只靠颜色表达状态，尤其是重要导航或正文链接。

示例：

```css
.article-link {
  color: #1d4ed8;
  text-decoration: none;
  border-bottom: 1px solid currentColor;
}

.article-link:hover,
.article-link:focus {
  border-bottom-width: 2px;
}
```

`currentColor` 表示使用当前文字颜色。这样边框颜色会跟着链接颜色变化，维护起来更统一。

## 2、列表可扫描

列表通常用于让内容更容易扫描。样式调整不应该破坏这个目的。

```css
.checklist {
  padding-left: 1.5rem;
  list-style-type: disc;
}

.checklist li {
  margin-bottom: 0.5rem;
  line-height: 1.6;
}
```

这里 `padding-left` 给标记和文字留出横向空间，`margin-bottom` 拉开不同列表项，`line-height` 让每一项内部更容易阅读。三者职责不同，放在一起时要知道各自解决的是哪个问题。
