Node.js 核心模块速查表

核心模块是 Node.js 自带的能力，不需要 npm install。这一课先记三个：文件、路径、进程。

一、三件套

模块 负责什么 常见入口
node:fs读写文件readFileSync、writeFileSync
node:path拼接和解析路径join、resolve、dirname
node:process当前 Node.js 进程信息argv、env、cwd()

二、最小示例

import { writeFileSync, readFileSync } from "node:fs";
import { join } from "node:path";
import process from "node:process";

const filePath = join(process.cwd(), "message.txt");

writeFileSync(filePath, "Hello core modules");
console.log(readFileSync(filePath, "utf8"));
