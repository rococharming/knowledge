Node.js 异步速查表

异步不是“代码乱跑”，而是“先登记一件以后完成的事，主线继续往下走，完成后再回来处理结果”。

一、三个阶段

阶段 你会看到 先怎么理解
同步代码console.log("start")立即执行。
登记异步任务setTimeout(...)把“以后再做”的事交出去。
回调执行console.log("later")主线代码结束后，异步结果再回来。

二、三种常见写法

Callback

setTimeout(() => {
  console.log("later");
}, 1000);

Promise

Promise.resolve("done")
  .then((value) => {
    console.log(value);
  });

async/await

const value = await promise;

console.log(value);

三、一句话边界

Callback

把一个函数交出去，等事情完成后调用它。

Promise

用一个对象表示“未来会完成或失败的结果”。

async/await

用更像同步代码的写法等待 Promise。
