package.json 速查表

读一个 npm 项目时，先不要被字段数量吓到。入门阶段只抓三类信息：项目是谁、能执行什么命令、依赖谁。

一、最小可运行版本

{
  "name": "hello-package-json",
  "version": "1.0.0",
  "scripts": {
    "dev": "node index.js"
  }
}

二、入门必看字段

字段 作用 先怎么理解
name 项目或包的名字 发布包时尤其重要；本地练习也建议写清楚。
version 项目或包的版本 发布包时和 name 一起标识一个具体版本。
scripts 项目命令菜单 npm run dev 会读取 scripts.dev。
dependencies 运行时依赖 应用真正运行时需要的包放这里。
devDependencies 开发期依赖 测试、编译、格式化等开发工具通常放这里。
private 是否禁止发布 练习项目或应用项目可以设为 true，避免误发布。

三、JSON 易错点

双引号

字段名和字符串必须用双引号，例如 "name"，不是 name。

英文逗号

字段之间用英文逗号分隔，最后一个字段后面不要逗号。

不能写注释

package.json 是 JSON 文件，不能写 // 注释。
