Node.js 模块系统速查表

模块解决的是“把一个大文件拆成多个小文件，再让它们互相使用”的问题。

一、两种写法

CommonJS

const tools = require("./tools.js");

module.exports = {
  message: "hello"
};

ES Module

import { message } from "./message.js";

export const message = "hello";

二、Node.js 如何判断

标记 含义
"type": "module"当前 package 里的 .js 文件按 ES Module 解释。
"type": "commonjs"当前 package 里的 .js 文件按 CommonJS 解释。
.mjs始终按 ES Module 解释。
.cjs始终按 CommonJS 解释。
