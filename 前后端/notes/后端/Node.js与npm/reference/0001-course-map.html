Node.js 与 npm 课程地图

这门课按能力递进，而不是按工具名堆清单。最终目标是：能做 Node.js 后端项目，也能理解 npm 包、CLI 工具和开发者工具的工程边界。

一、入门段：知道谁在工作

第 1 课
Node.js 与 npm 的边界：谁运行代码，谁管理项目，谁保存包。
第 2 课
JSON 与 package.json：读懂项目身份证，区分描述、脚本和依赖。
第 3 课
npm scripts：把零散命令变成项目约定，理解 npm run 的执行位置。
第 4 课
模块系统：CommonJS、ESM、type、入口文件和导入导出。

二、基础段：能写可运行项目

第 5 课
Node.js 核心模块：fs、path、process，把脚本接到操作系统。
第 6 课
异步模型：callback、Promise、async/await 与 Event Loop。
第 7 课
TypeScript 项目化：tsconfig、类型边界、编译输出和运行方式。
第 8 课
依赖安装：dependencies、devDependencies、package-lock.json 和可复现安装。

三、后端段：能做真实 API

第 9 课
HTTP 请求响应：方法、状态码、Header、Body 与 API 契约。
第 10 课
Express 路由与中间件：从请求进入应用，到响应离开应用。
第 11 课
错误处理与输入校验：把“能跑”提升为“可预期”。
第 12 课
数据库基础：PostgreSQL、Prisma、schema、migration 和查询。
第 13 课
认证与授权：Cookie、Session、JWT、RBAC 和常见风险。

四、工程段：能维护项目

第 14 课
测试体系：单元测试、集成测试、HTTP 测试和测试数据。
第 15 课
配置与环境变量：本地、测试、生产环境如何分开。
第 16 课
日志与可观测性：定位一次请求为什么失败。
第 17 课
Docker 与部署入口：把项目从“我电脑能跑”变成“环境可复制”。

五、进阶段：npm 包与开发者工具

第 18 课
发布 npm package：版本、files、exports、README、license 与 publish。
第 19 课
CLI 工具：bin 字段、参数解析、退出码和终端交互。
第 20 课
Workspace 与 monorepo：多个包如何共享依赖与脚本。
第 21 课
进程管理：child_process、调用外部二进制、处理 stdout/stderr。
第 22 课
性能与稳定性：Stream、worker_threads、限流、缓存和背压。
第 23 课
Node 调 Rust：N-API、native addon、二进制分发和边界设计。
第 24 课
毕业项目：一个 TypeScript CLI + HTTP API + npm package 的开发者工具。

每课固定结构

真实场景

先说明这个知识点在项目中解决什么问题。

最小模型

用一个能记住的心智模型解释核心概念。

可运行例子

每课至少有一段能放进项目里运行的代码或配置。

即时反馈

通过测验、检查清单或小练习，让学习变成可验证的动作。
