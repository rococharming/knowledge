npm scripts 速查表

scripts 是 npm 项目的命令菜单。团队成员不用记住底层命令，只要记住项目约定的入口。

一、最小结构

{
  "scripts": {
    "dev": "node index.js",
    "test": "node test.js",
    "hello": "node hello.js"
  }
}

二、脚本怎么对应

你输入 npm 读取 真正执行
npm run devscripts.devnode index.js
npm run helloscripts.hellonode hello.js
npm testscripts.testnode test.js

三、常用规则

普通脚本

大多数自定义脚本用 npm run 脚本名 执行。

快捷脚本

npm test 是 test 脚本的常见快捷入口；npm start 是 start 脚本的常见快捷入口。

列出脚本

忘记项目有哪些脚本时，运行 npm run 查看列表。

本地命令

脚本运行时，本地依赖提供的命令通常可以直接写，比如 eslint .。
