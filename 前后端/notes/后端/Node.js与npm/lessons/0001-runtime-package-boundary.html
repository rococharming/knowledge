第 1 课：Node.js 与 npm 的边界

这一课的目标很小，但很关键：看到一个 JavaScript 项目时，你能判断“现在是 Node.js 在运行代码，还是 npm 在管理项目”。这会影响后面所有安装、运行、调试和发布。

一、真实场景

你下载了一个 Node.js 项目，README 写着：

npm install
npm run dev

很多初学者会把这两行都理解成“用 npm 启动项目”。这不够精确。第一行主要是在准备依赖；第二行是让 npm 找到 `package.json` 里的脚本，再由脚本启动真正的程序。那个程序通常最终由 `node`、`vite`、`tsx`、`nest` 等命令运行。

本课胜利条件：你能用自己的话解释 `node index.js`、`npm install`、`npm run dev` 三者分别在做什么。

二、最小模型

Node.js

Node.js 是 JavaScript 的运行时。它让 JavaScript 可以在浏览器之外执行，并访问文件、网络、进程等系统能力。

node index.js

这句话的主语是 Node.js：运行 `index.js`。

npm CLI

npm CLI 是项目管理工具。它会读取 `package.json`，安装依赖、运行脚本、发布包。

npm install

这句话的主语是 npm：根据项目描述准备依赖。

npm Registry

npm Registry 是远程包仓库。安装依赖时，npm CLI 会向 Registry 查询包和版本信息。

npm install picocolors

这句话背后有网络请求：本机 npm CLI 去远程仓库拿包。

三、一次完整运行发生了什么

假设项目里有这个 `package.json`：

{
  "name": "hello-node",
  "version": "1.0.0",
  "scripts": {
    "dev": "node index.js"
  },
  "dependencies": {
    "picocolors": "^1.0.0"
  }
}
安装
`npm install` 读取 `package.json`，解析依赖版本，访问 npm Registry，下载包，生成或更新 `package-lock.json` 和 `node_modules`。
运行
`npm run dev` 读取 `scripts.dev`，找到右侧命令 `node index.js`，然后执行它。
执行
`node index.js` 启动 Node.js 运行时，执行 JavaScript 文件里的代码。

常见误区：`npm run dev` 不一定等于 Node.js 直接运行代码。它只是执行 `package.json` 里配置的脚本。脚本右侧可能是 `node`，也可能是 `vite`、`tsx`、`nest start` 或其他工具。

四、你需要掌握的判断法

看到一个命令时，先问三个问题：

1. 它是否直接执行 JS 文件？

如果是 `node xxx.js`，主角通常是 Node.js。

2. 它是否读取 package.json？

如果是 `npm install` 或 `npm run xxx`，主角通常是 npm CLI。

3. 它是否需要下载包？

如果要安装新依赖，本机 npm CLI 通常会访问 npm Registry。

六、课后小任务

这一题不考你会不会写 JavaScript。先复制粘贴，把项目跑起来，再观察 `npm run dev` 和 `node index.js` 的关系。

1. 创建一个练习目录

在终端里复制执行：

mkdir hello-node
cd hello-node

`mkdir hello-node` 的意思是创建一个叫 `hello-node` 的文件夹；`cd hello-node` 的意思是进入这个文件夹。后面的文件都会放在这里。

2. 创建 package.json

新建一个叫 `package.json` 的文件，把下面内容完整复制进去：

{
  "name": "hello-node",
  "version": "1.0.0",
  "scripts": {
    "dev": "node index.js"
  }
}

先只关注 `scripts`：它给项目定义了一个叫 `dev` 的命令。这个命令真正执行的是右边的 `node index.js`。

3. 创建 index.js

新建一个叫 `index.js` 的文件，把下面内容完整复制进去：

console.log("Hello Node.js");
console.log("This file is running through node.");

你现在不需要完全理解 JavaScript 语法。先记住：`console.log(...)` 会在终端输出一行文字。

4. 运行项目

在刚才的 `hello-node` 目录里执行：

npm run dev

如果看到下面两行输出，就说明成功了：

Hello Node.js
This file is running through node.

5. 对照观察

再执行一次：

node index.js

你会看到同样的输出。区别是：`npm run dev` 先读取 `package.json` 的 `scripts.dev`，再执行 `node index.js`；而 `node index.js` 是直接启动 Node.js 运行这个文件。

本题只要完成一个判断：当输出来自 `index.js` 时，真正运行 JavaScript 文件的是 Node.js；npm 只是帮你找到并执行项目脚本。
