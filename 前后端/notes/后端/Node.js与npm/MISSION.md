# Mission: Node.js 与 npm 后端课程

## Why
学习 Node.js 与 npm，不是为了记住一堆命令，而是为了能独立构建真实的 JavaScript/TypeScript 后端项目、理解 npm 生态如何组织代码，并逐步进入 CLI 工具、开发者工具和自动化平台方向。

## Success looks like
- 能解释 Node.js、npm CLI、npm Registry、package.json、依赖和脚本之间的关系。
- 能从零创建一个 TypeScript Node.js 项目，并用 npm scripts 组织开发、测试和构建流程。
- 能写出 HTTP API，连接数据库，处理认证、错误、日志、配置和测试。
- 能设计并发布一个小型 npm package 或 CLI 工具，理解版本、入口、发布和依赖边界。
- 能读懂常见 Node.js 后端项目结构，并判断下一步该查官方文档、源码还是社区经验。

## Constraints
- 默认使用中文教学。
- 每课只聚焦一个关键能力，但内容要讲透：场景、概念、代码、常见误区、练习和反馈都要有。
- 优先使用官方文档和高信任资源，不用零散博客当主要依据。
- 课程要适合反复复习，输出为可打开的 HTML lesson 和 reference。

## Out of scope
- 暂不把课程做成传统全栈前端路线。
- 暂不深入浏览器 DOM、CSS 框架或前端 UI 组件库。
- 暂不把 Kubernetes、Kafka、复杂微服务作为入门阶段主线。
