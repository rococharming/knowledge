## 3 代码编译

## 3.1 编译流程

编译流程保持和之前一致：./build.sh -p PD2337 -t xxx -m xxx \[可选：-b xxx -n xxx\]

\-t image/lib：全编出包or单独编译某个/全部模块，不做打包

\-m user/eng： user/eng模式

\-b blueos: -t image时会编译originos-env下面的所有模块。第一次编译出完整镜像包时，不要选-b blueos，下次编译选-b blueos可以跳过originos-env的编译

\-n xxx: 这里的-n是再-t 选择lib时，可以基于-n只编译自身的模块（-n选择toml中配置的模块）

## 3.2 添加模块

在build/products/PD2337/PD2337.toml中添加模块进行编译

①\[\[system\_module\]\]为系统模块（至少一个）：name（模块名称，必填）,path (模块路径，必填）

②\[\[system\_module.capability\]\]为模块的系统能力（至少一个）：name（名称，必填），path（构建路径，必填，根目录开始，然后通过：指定构建目标名称），depend（功能裁剪，可为\[\]）

\[\[system\_module\]\]

name = "os\_framework"

path = "os\_framework"

\[\[system\_module.capability\]\]

name = "features"

path = \["os\_framework/quickapp\_runtime/core/features:quickapp"\]

depend = \[\]

## 3.3 预编译产物引入

如果依赖一些预编译的库。将库放置到对应的prebuilt\_libs下面（eng/user目录都需要添加），并添加gn文件，最小系统的目录对应于prebuilt\_libs/SM8650/user或prebuilt\_libs/SM8650/eng，以eng的库为例子，动态库放置在dynamic。静态库放置在static。

![](http://veditor.vivo.xyz/api/v1/attachment/file/v-kyrRAlKZQP81LAl-JhcpxeL9TJQ1QiimZdtbFddE3tDs8Gd337JuBztr6IDzBf)

将对应的库引入后添加对应的GN文件

// c的动态库

字段：source：对应的库名称

path：库的位置

cc\_prebuilts\_shared("lp") {

sources = \["liblp.so"\]

path = "."

}

// c的静态库

字段：source：对应的库名称

path：库的位置

cc\_prebuilts\_static("avb") {

sources = \["libavb.a"\]

path = "."

}

// rust动态库

字段：source：对应的库名称

path：库的位置

crate\_name: 引入改库的crate name

sorces: 库名

dependency：rust代码较为特殊，需要配置-L指定依赖的库的路径，这里配置的为依赖库的路径

rust\_prebuilts\_dylib("xxx"){

sources = \["libxxx.so"\]

path = "."

crate\_name = "xxx"

dependency = "."

}

// rust静态库

字段：source：对应的库名称

path：库的位置

crate\_name: 引入改库的crate name

sorces: 库名

dependency：rust代码较为特殊，需要配置-L指定依赖的库的路径，这里配置的为依赖库的路径

rust\_prebuilts\_rlib("xxx"){

sources = \["libxxx.rib"\]

path = "."

crate\_name = "xxx"

dependency = "."

}

代码中引入该预编译的库

//在需要链接该库的地方进行引入

build\_rust("xxx") {

xxxx

prebuilt\_deps = \[

"//prebuilt\_libs/$hardware\_platform/$compile\_type/static:xxx",

"//prebuilt\_libs/$hardware\_platform/$compile\_type/shard:xxxx",

\]

}

build\_c("xxx") {

xxxxx

prebuilt\_deps = \[

"//prebuilt\_libs/$hardware\_platform/$compile\_type/static:xxx",
