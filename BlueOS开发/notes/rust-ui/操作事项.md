
1、AGENTS.md  Mattpocock Skills 指南问题

AGENTS.md 已经被远程跟踪，但不想将本地新增的 Mattpocock Skills 指南部分进入提交。

将它标记为`skip-worktree`，让这份`AGENTS.md`只在本地生效：

```shell
git update-index --skip-worktree AGENTS.md
```

验证：

```shell
git status --short -- AGENTS.md
git ls-files -v -- AGENTS.md
```

但切换到另一个分支时，如果该分支的`AGENTS.md`内容不同，`skip-worktree`仍可能触发 checkout 冲突。

此时：

```shell
git update-index --no-skip-worktree AGENTS.md
git stash push -m "preserve local AGENTS.md" -- AGENTS.md
git switch <new-branch>
git stash pop
git update-index --skip-worktree AGENTS.md
```
