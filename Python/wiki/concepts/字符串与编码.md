# 字符串与编码

Python 3 中 `str` 与 `bytes` 是两种不同的类型，理解二者的区别是处理文本与二进制数据的基础。

## str vs bytes

| 类型 | 本质 | 字面量 | 元素 |
|---|---|---|---|
| `str` | **Unicode 文本**字符序列 | `"中文"` `'a'` | 字符 |
| `bytes` | **字节**序列 | `b"abc"` | 0-255 整数 |

`str` 不是 UTF-8 字节序列，而是抽象的 Unicode 字符序列。`bytes` 字面量必须为 ASCII，非 ASCII 字节用 `\x` 转义。

### 字符与编码点

| 函数/写法 | 作用 |
|---|---|
| `ord(c)` | 字符 → Unicode 码点（整数） |
| `chr(n)` | 码点 → 字符 |
| `hex(n)` | 整数 → 十六进制字符串 |
| `中` | 用 4 位十六进制表示 Unicode 字符（等价于直接写 `中`） |

## 编码与解码

```
str  --encode-->  bytes   (str→bytes)
bytes --decode-->  str    (bytes→str)
```

```python
"中文".encode('utf-8')      # b'\xe4\xb8\xad\xe6\x96\x87'
b'\xe4\xb8\xad'.decode('utf-8')  # '中'
```

常见编码：`ascii`/`utf-8`/`gbk`。**编码与解码必须用同一编码**，否则抛 `UnicodeDecodeError`。

`errors` 参数控制解码失败行为：`strict`（默认抛错）/`ignore`（忽略）/`replace`（替换为 `�`）。

## 源文件编码

- Python 3 源文件默认 UTF-8
- Shebang：`#!/usr/bin/env python3`
- 显式编码声明：`# -*- coding: utf-8 -*-`

## 字符串不可变

`str` 不可变，任何「修改」操作都返回**新字符串**。索引赋值 `s[0]='H'` 抛 `TypeError`。

## 切片

```python
s[start:stop:step]   # stop 不含
s[::-1]              # 反转字符串
```

`len(s)` 返回**字符数**，不是字节数。

## 三种格式化

| 方式 | 示例 | 说明 |
|---|---|---|
| `%` 格式化 | `"%d-%.2f" % (5, 3.14)` | C 风格，`%d`/`%s`/`%f`/`%x`/`%%`，`%02d`/`%.2f` |
| `str.format()` | `"{} {}".format(a, b)` | `{0}`/`{1}` 位置、命名参数、`{1:.1f}` |
| f-string | `f"{s:.2f}"` | 3.6+，`{}` 内可写表达式和方法调用 |

f-string 最现代、最简洁，新代码优先使用。
