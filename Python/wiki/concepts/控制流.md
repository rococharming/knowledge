# 控制流

Python 控制流由**条件判断**与**循环**构成。代码块靠**缩进**（4 空格）界定，缩进错误抛 `IndentationError`。

## 条件判断

### if 结构

```python
if cond:
    ...
elif cond2:   # else if 的缩写，从上到下判断
    ...
else:
    ...
```

具体条件应放在前面，通用条件放后面。`pass` 可作空占位。

### Truthy 与 Falsy

下列值视为 Falsy，其余为 Truthy：

| Falsy 值 |
|---|
| `None` |
| `False` |
| `0` `0.0` |
| `""`（空字符串） |

`bool(x)` 可显式转换。

### 布尔运算符与短路求值

| 运算符 | 行为 |
|---|---|
| `and` | x 为假返回 x，否则返回 y |
| `or` | x 为真返回 x，否则返回 y |
| `not` | 总返回布尔值 |

`and`/`or` **返回原始值而非布尔值**，常用于设默认值：`name = input_name or "Anonymous"`。

### 三元表达式

```python
value_if_true if condition else value_if_false
```

Python 没有其他语言的 `?:` 三元符。

## 循环

### for...in 与 while

```python
for x in iterable:   # 遍历可迭代对象
    ...
while condition:     # 条件成立反复执行，需更新条件避免死循环
    ...
```

字符串可遍历每个字符。嵌套循环中外层每执行一次，内层完整执行一轮。

### 循环控制

| 语句 | 作用 |
|---|---|
| `break` | 结束当前循环 |
| `continue` | 跳过本次 |
| `else` | **仅未 break 时执行** |

循环 `else` 适合「正常遍历完未找到」的场景。

### range / enumerate / zip

| 函数 | 作用 |
|---|---|
| `range(start, stop, step)` | 生成整数序列，`stop` 不含，返回 `range` 对象非列表 |
| `enumerate(iter, start)` | 同时拿索引和元素，可指定起始索引 |
| `zip(*iters)` | 并行遍历，**以最短为准** |

### 推导式与函数式工具

```python
[expr for x in iterable if cond]
```

`filter()`/`map()` 返回迭代器；`lambda` 配合使用但不推荐赋值给变量。逻辑复杂时普通 `for` 循环更清晰。
