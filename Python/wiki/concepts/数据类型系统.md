# 数据类型系统

Python 是**动态类型**语言：变量没有固定类型，对象才有类型。同一个变量可先后绑定不同类型的对象。

```python
x = 10        # x 绑定 int
x = "hello"   # 合法，x 重新绑定 str
```

## 内置类型分类

| 类别 | 类型 | 示例 |
|---|---|---|
| 数值 | `int` `float` `bool` | `12` `12.0` `True` |
| 序列 | `str` `list` `tuple` `range` | `"hi"` `[1,2]` `(1,2)` `range(3)` |
| 映射 | `dict` | `{"a": 1}` |
| 集合 | `set` | `{1, 2, 3}` |
| 空值 | `NoneType` | `None` |

`bool` 是 `int` 的子类（`True==1`，`False==0`）；`12` 与 `12.0` 值相等但类型不同。

## 可变与不可变

| 不可变 | 可变 |
|---|---|
| `int` `float` `bool` `str` `tuple` `range` | `list` `dict` `set` |

不可变对象一旦创建，其值不能修改：

```python
s = "hello"
s[0] = "H"   # TypeError: 'str' object does not support item assignment
```

`tuple` 的「不可变」指**引用不可改**——不能重新赋值 `t[i] = x`；但如果元素本身是可变对象，元素自身仍可改：

```python
t = (1, 2, [3, 4])
t[2][0] = 'X'   # 合法，修改的是列表元素自身
```

## 可哈希

`dict` 的 key 与 `set` 的元素必须**可哈希**。可哈希需满足：

- 生命周期内哈希值不变
- 相等对象哈希值相同（`a == b` ⇒ `hash(a) == hash(b)`）

一般规律：**可哈希通常意味着不可变**，但不可变不一定可哈希（如含可变元素的元组）。常见可哈希：`str`/`int`/`float`/`bool`/`tuple`（元素均可哈希时）；不可哈希：`list`/`dict`/`set`。

## 类型检查

| 方式 | 说明 |
|---|---|
| `type(x)` | 返回对象确切类型，不传参抛 `TypeError` |
| `isinstance(x, T)` | 判断是否为 T 或其子类实例，可同时检查多类型 `isinstance(x, (int, float, str))` |

优先用 `isinstance`，它考虑继承关系，更健壮。
