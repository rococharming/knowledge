# 函数与作用域

函数用 `def` 定义，函数名本身是对象，可赋值、作参数传递。函数体靠缩进界定，**调用时才执行**。

## 参数体系

Python 函数参数种类丰富，组合时遵循固定顺序：**必选 → 默认 → 可变 → 命名关键字 → 关键字**。

| 参数类型 | 定义 | 函数内类型 |
|---|---|---|
| 位置参数 | `def f(a, b)` | 按位置 |
| 默认参数 | `def f(a, b=10)` | — |
| 可变参数 | `def f(*args)` | `tuple` |
| 命名关键字 | `def f(*, city, job)` | 必须用关键字传 |
| 关键字参数 | `def f(**kw)` | `dict` |

### 注意点

- **默认参数必须放在必选参数之后**，否则 `SyntaxError`
- **默认参数避免用可变对象**，推荐 `items=None` 后在函数内初始化，否则默认值会在多次调用间共享
- 可变参数用 `*` 展开：`f(*[1,2,3])`
- 关键字参数用 `**` 展开：`f(**{'a':1})`

## 返回值

- `return` 无值则返回 `None`
- 返回多个值本质是返回 `tuple`，按位置解包：

```python
def min_max(lst):
    return min(lst), max(lst)

lo, hi = min_max([3, 1, 2])
```

## 作用域 LEGB

变量查找顺序：

| 层 | 含义 |
|---|---|
| **L**ocal | 函数内部 |
| **E**nclosing | 外层嵌套函数 |
| **G**lobal | 模块全局 |
| **B**uilt-in | 内置（`len`/`print` 等） |

局部变量外部访问抛 `NameError`。修改外层变量：

| 语句 | 作用 |
|---|---|
| `nonlocal x` | 修改**外层函数**的变量 |
| `global x` | 修改**模块全局**变量（谨慎使用） |

## 内置函数

常用内置：`print`（逗号分隔加空格）、`input`（返回 `str`）、`int`/`float`/`str`/`bool`、`help`、`len`/`range`/`enumerate`/`zip`/`sum`/`map`/`filter`/`sorted`。
