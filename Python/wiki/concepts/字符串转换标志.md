# 字符串转换标志 `!r` `!s` `!a`

转换标志（conversion flag）是 Python f-string 和 `str.format()` 中控制值在字符串中如何呈现的语法。

## 三个转换标志

| 标志 | 等价调用 | 效果 |
|---|---|---|
| `!s` | `str(value)` | 字符串形式（**默认**，可省略） |
| `!r` | `repr(value)` | 开发者可读的调试形式 |
| `!a` | `ascii(value)` | ASCII 转义形式，非 ASCII 字符转 `\x`/`\u`/`\U` |

## 用法

f-string 和 `str.format()` 均支持：

```python
name = "Alice"
age = 30

# f-string
f"{name!r}"          # → "'Alice'"
f"{name!s} is {age}" # → "Alice is 30"

# str.format()
"{!r}".format(name)             # → "'Alice'"
"Name: {!r}, Age".format(name)  # → "Name: 'Alice', Age"
```

## `!r` — 最常用的调试利器

`!r` 的核心价值在于**保留类型边界**。当日志中含 `None`、空字符串 `""`、或特殊字符时，普通 `str()` 看不出区别，但 `repr()` 会保留这些信息：

```python
# 不用 !r — None 和空字符串消失
print(f"User: {user} | Action: {action}")
# → User: admin | Action:

# 用 !r — 清晰展示
print(f"User: {user!r} | Action: {action!r}")
# → User: 'admin' | Action: ''
# → User: None | Action: None
```

结合 `__repr__` 最佳实践（只定义一个时优先 `__repr__`），`!r` 可获取对象的完整调试信息：

```python
from datetime import datetime

now = datetime.now()
f"{now}"      # → '2026-06-29 10:30:00.123456'  (__str__)
f"{now!r}"    # → 'datetime.datetime(2026, 6, 29, 10, 30, 0, 123456)'  (__repr__)
```

## `!a` — 非 ASCII 转义

```python
f"{'中文'!a}"  # → "'\\u4e2d\\u6587'"
```

适用于需要确保输出只含 ASCII 字符的场景（如日志文件、网络协议）。

## 与 `%` 格式化的对应

| 现代写法 | `%` 风格等价 |
|---|---|
| `f"{x!r}"` | `"%r" % x` |
| `f"{x!s}"` | `"%s" % x` |
| `f"{x!a}"` | `"%a" % x` |
