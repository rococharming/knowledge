# 多态

多态表示不同类型的对象可以通过相同的接口执行各自的行为。外部代码只需调用统一方法，不必为每种对象分别编写调用逻辑。它与 [[继承]]、[[封装]] 同为 OOP 核心原则，整体概览见 [[面向对象]]。

## 基本含义

多个类定义同名方法，外部代码统一调用该方法，不同对象产生不同结果：

```python
class Cat:
    def speak(self):
        return 'Meow'

class Bird:
    def speak(self):
        return 'Tweet'

def print_sound(animal):
    print(animal.speak())   # 不判断类型，只要求有 speak()
```

`print_sound()` 不需知道参数是猫还是鸟，只要求传入对象具有 `speak()` 方法。同一个函数调用相同方法、不同对象产生不同结果，就是多态。

## 鸭子类型（Python 的主要方式）

Python 常通过**鸭子类型**实现多态：关注对象能做什么，而非属于哪个类。只要对象提供所需方法，即可在相同代码中使用，**不要求继承关系**。

```python
class EmailNotifier:
    def send(self, message): ...

class SmsNotifier:
    def send(self, message): ...

class ConsoleNotifier:
    def send(self, message): ...

def notify(notifier, message):
    print(notifier.send(message))   # 三个类无共同父类，都能用
```

三个类没有共同父类，但都提供 `send()` 方法，`notify()` 用同一种方式处理它们。鸭子类型不要求对象之间存在 [[继承]] 关系。

## 基于继承的多态

多态也可通过继承和方法重写实现：父类定义统一方法，子类分别重写。Python 根据对象实际类型选择对应实现。

```python
class Animal:
    def speak(self):
        return 'Some generic sound'

class Cat(Animal):
    def speak(self):
        return 'Meow'

class Dog(Animal):
    def speak(self):
        return 'Woof'

animals = [Cat(), Dog()]
for animal in animals:
    print(animal.speak())   # 循环不关心具体子类
```

循环不需知道每个元素的具体子类，只调用统一的 `speak()`。

## 多态如何复用代码

没有多态时，可能需按类型写多个条件分支：

```python
if isinstance(notifier, EmailNotifier):
    ...
elif isinstance(notifier, SmsNotifier):
    ...
```

用统一接口后调用代码只写一次。新增类型只要提供该方法，通常无需修改调用方——多态减少类型判断和重复分支，让程序更易扩展。

## 继承与多态的关系

| 概念 | 关注 |
|---|---|
| [[继承]] | 如何复用和扩展已有类的属性与方法 |
| 多态 | 如何通过相同接口操作不同类型的对象 |

继承可以实现多态，但 Python 的鸭子类型允许没有继承关系的类也表现出多态行为。

## 选择原则

- 优先复用接口而非依赖具体类型：调用代码依赖统一接口（如 `send()`），而非某个具体类
- 这样既可传入已有对象，也便于以后添加新类型

合理使用 [[继承]] 减少重复代码，合理使用多态减少类型判断，两者结合让程序结构更清晰、更易扩展。
