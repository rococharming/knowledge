# 面向对象

Python 是面向对象语言：一切皆对象，类是创建对象的模板，定义数据与行为。类名用 **PascalCase**。

## 定义与实例化

```python
class Dog:
    species = 'French Bulldog'   # 类属性，所有实例共享

    def __init__(self, name, age):
        self.name = name         # 实例属性
        self.age = age

    def bark(self):              # 实例方法
        print(f"{self.name} says woof!")

dog_1 = Dog('Jack', 3)
```

| 概念 | 说明 |
|---|---|
| `__init__()` | 实例创建时自动调用的初始化方法 |
| `self` | 当前对象，实例方法第一参数，调用时自动传入 |
| 实例属性 | 在 `__init__` 中通过 `self` 设置，各对象不同 |
| 类属性 | 属于类本身，被所有实例共享 |

## 特殊方法（dunder）

以双下划线开头结尾，由特定语法或内置函数触发，不直接调用：

| 操作 | 触发 |
|---|---|
| `a + b` | `__add__` |
| `len(obj)` | `__len__` |
| `str(obj)` / `print(obj)` | `__str__` |
| `obj1 == obj2` | `__eq__` |
| `item in obj` | `__contains__` |
| `obj[index]` | `__getitem__` |

### __str__ 与 __repr__

- `__str__`：给**用户**看的可读文本
- `__repr__`：给**开发者**看的调试文本
- 只定义一个时**优先 `__repr__`**

通过定义 `__len__`/`__getitem__`/`__contains__`/`__iter__` 等，自定义对象可像容器一样被遍历、`len()`、索引、`in` 判断。

## 动态属性

属性名运行时才知道（来自用户输入、配置、字典）时使用：

| 函数 | 作用 |
|---|---|
| `getattr(obj, name, default)` | 按名读，不存在抛 `AttributeError`（无默认值时） |
| `setattr(obj, name, value)` | 动态创建或修改 |
| `hasattr(obj, name)` | 判断是否存在 |
| `delattr(obj, name)` | 动态删除 |

普通场景优先点语法，仅当属性名来自运行时数据时才用动态属性函数。

## 自定义异常

继承 `Exception` 定义业务异常，是面向对象在错误处理中的应用：

```python
class InsufficientFundsError(Exception):
    pass
```

适合表达余额不足、权限不足、状态不合法等业务错误。详见 [[异常处理]]。

## 模块中的类

类通常组织在模块中，通过 `import` 复用：

```python
import datetime
birthday = datetime.date(1959, 7, 15)   # 模块.类
```

`if __name__ == '__main__'` 模式让模块既可直接运行主逻辑，又可被导入只提供类与函数。详见 [[模块]]。
