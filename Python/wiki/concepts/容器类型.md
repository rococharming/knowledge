# 容器类型

Python 内置容器分四类，选型取决于「是否需要改」「是否需要键」「是否需要去重」。

| 类型 | 可变 | 有序 | 键/索引 | 典型用途 |
|---|---|---|---|---|
| `list` | ✅ | ✅（按位置） | 索引 | 有序、可增删改的序列 |
| `tuple` | ❌ | ✅（按位置） | 索引 | 不可变记录（坐标、RGB） |
| `dict` | ✅ | ✅（保留插入顺序） | key | 按 key 查 value |
| `set` | ✅ | ❌ | 无 | 去重、成员判断、集合运算 |
| `range` | ❌ | ✅ | 索引 | 整数序列（惰性） |

## 共性操作

序列类型（`list`/`tuple`/`str`/`range`）都支持：

- 索引（含负向索引）、切片 `[start:stop:step]`
- `len()`、`in` 成员判断
- 解包（`*` 收集剩余，数量不匹配抛 `ValueError`）

## 可变与不可变的精确含义

`tuple` 不可变指**引用不可改**，但可变元素自身可改：

```python
t = (1, 2, [3, 4])
t[2][0] = 'X'   # 合法
t[0] = 'X'      # TypeError
```

`list` 可随时增删改。`dict`/`set` 底层哈希，要求 key/元素**可哈希**。

## 选型建议

| 需求 | 推荐 |
|---|---|
| 频繁增删改 | `list` |
| 固定不变的数据记录 | `tuple` |
| 按 key 快速查找 | `dict` |
| 去重 / 成员判断 / 集合运算 | `set` |

`set` 做成员判断通常比 `list` 更合适；`set()` 转换可去重但不保证顺序。

## 关键 API 速查

- list：`append`/`extend`/`insert`/`remove`/`pop`/`sort`/`sorted`/`reverse`/`index`
- tuple：`count`/`index`（无 `sort`，`sorted` 返回新列表）
- dict：`get`/`keys`/`values`/`items`/`pop`/`popitem`/`update`/`clear`
- set：`add`/`remove`/`discard`/`clear` 及集合运算 `|` `&` `-` `^`

注意：`dict.keys()/values()/items()` 返回**视图对象**非列表；遍历 dict 时不建议同时增删 key。
