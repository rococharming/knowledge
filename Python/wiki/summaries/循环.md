# 循环

Python 循环主要有 `for...in` 与 `while`，配合 `range`、`enumerate`、`zip` 及推导式。

## for...in

遍历可迭代对象（列表、元组、字符串、`range` 等）。字符串可遍历每个字符。

```python
for language in ['Rust', 'Java']:
    print(language)
```

循环体需缩进，错误抛 `IndentationError`。

## while

条件成立时反复执行循环体，**需更新条件避免无限循环**。

## 嵌套循环

外层每执行一次，内层完整执行一轮。

## 循环控制

| 语句 | 作用 |
|---|---|
| `break` | 立即结束当前循环 |
| `continue` | 跳过本次，进入下一次 |
| `else` | **仅未 break 时执行**（for/while 均可） |

循环 `else` 常用于「正常遍历完未找到」的场景。

## range

```python
range(start, stop, step)
```

- `start` 默认 0，`stop` 必填不含，`step` 默认 1
- 负步长生成递减序列
- 至少 1 参数且必须整数，否则抛 `TypeError`
- 返回 `range` 对象**非列表**，`list()` 转换查看

## enumerate 与 zip

| 函数 | 作用 |
|---|---|
| `enumerate(iter, start)` | 同时拿索引和元素，本质元组解包，可指定起始索引 |
| `zip(*iters)` | 并行遍历，相同位置组合元组，**以最短为准** |

```python
for i, lang in enumerate(['a', 'b'], 1):
    print(i, lang)

for name, id in zip(names, ids):
    ...
```

## 列表推导式

```python
[expr for x in iterable if cond]
```

前半部分可用条件表达式：

```python
[(n, 'Even') if n % 2 == 0 else (n, 'Odd') for n in nums]
```

逻辑复杂时普通 `for` 循环更清晰。

## 函数式工具

| 函数 | 说明 |
|---|---|
| `filter(fn, iter)` | 筛选，返回**迭代器** |
| `map(fn, iter)` | 逐元素应用函数，返回**迭代器** |
| `sum(iter, start)` | 求和，可传初始值 |
| `lambda` | 匿名函数，配 map/filter；**不推荐赋值给变量**，复杂逻辑用 `def` |

循环与条件判断共同构成控制流，见 [[控制流]]。
