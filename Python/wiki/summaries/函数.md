# 函数

`def` 定义函数，缩进表函数体，调用才执行。函数名本身也是对象，可赋值给变量。

```python
def greet(name: str) -> str:
    return f'Hello {name}'
```

## 参数体系

| 参数类型 | 语法 | 说明 |
|---|---|---|
| 位置参数 | `def f(a, b)` | 按位置传递 |
| 默认参数 | `def f(a, b=10)` | **必选在前**，否则 `SyntaxError` |
| 可变参数 | `def f(*args)` | 函数内为 `tuple`，调用时 `*` 展开 |
| 关键字参数 | `def f(**kw)` | 函数内为 `dict`，调用时 `**` 展开 |
| 命名关键字 | `def f(*, city, job)` | 必须用关键字传 |

### 默认参数陷阱

不要用可变对象作默认值，推荐 `items=None` 后在函数内初始化：

```python
def add(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

### 组合顺序

必选 → 默认 → 可变 → 命名关键字 → 关键字。

## 返回值

- `return` 返回，无 `return` 默认返回 `None`
- 返回多值本质是返回 `tuple`，按位置解包：

```python
def min_max(nums):
    return min(nums), max(nums)  # 实际是 tuple

lo, hi = min_max([3, 1, 2])
```

## 作用域 LEGB

查找顺序：**L**ocal → **E**nclosing → **G**lobal → **B**uilt-in。

- 局部变量外部访问抛 `NameError`
- 修改外层（封闭）作用域变量用 `nonlocal`
- 修改全局变量用 `global`（谨慎使用）
- 内置作用域：`print`、`str`、`type`、`isinstance` 等

作用域机制的深入讨论见 [[函数与作用域]]。
