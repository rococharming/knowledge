# 异常处理

异常处理用于捕获和管理运行时错误，避免程序直接崩溃。调试时应**先读错误信息**，不要先猜原因。

## 常见错误类型

| 类型 | 常见原因 |
|---|---|
| `SyntaxError` | 代码不符合语法 |
| `NameError` | 使用未定义的变量名 |
| `TypeError` | 对不合适类型执行不支持操作 |
| `IndexError` | 索引超出范围 |
| `KeyError` | 访问不存在的字典 key |
| `AttributeError` | 访问对象不存在的属性或方法 |
| `ValueError` | 类型正确，但值不合法 |
| `ZeroDivisionError` | 除数为 0 |

## Traceback

异常发生时打印的调用链。**最后一行最重要**（含最终异常类型与说明），再往上找出错行号与调用路径。

## 调试方法

| 方式 | 说明 |
|---|---|
| `print()` | 关键位置打印变量与流程，**调试完应删除临时 print** 避免污染输出 |
| `pdb` | 内置交互式调试器，`pdb.set_trace()` 设断点 |
| IDE 调试器 | 断点/单步/查看变量/调用栈，适合复杂程序 |

`pdb` 常用命令：`n`（下一行）、`s`（进入函数）、`c`（继续）、`p 变量`（打印）、`whatis 变量`（类型）、`q`（退出）。

## try-except

```python
try:
    # 可能出错的代码
except ZeroDivisionError:
    # 出错后处理
```

### 多个 except

不同异常分别处理，按顺序匹配，先触发的异常会阻止后续代码：

```python
try:
    number = int('abc')   # 触发 ValueError
    result = 10 / number
except ValueError:
    print('Not a valid number.')
except ZeroDivisionError:
    print("Can't divide by zero.")
```

### 异常对象 as

```python
except ZeroDivisionError as e:
    print(f'Error: {e}')
```

一个 `except` 可捕获多个异常：`except (ValueError, ZeroDivisionError) as e:`。

### else 与 finally

| 语句 | 执行时机 |
|---|---|
| `try` | 放可能出错的代码 |
| `except` | try 出现指定异常时 |
| `else` | try **没有异常时**执行 |
| `finally` | **无论是否异常都执行** |

`finally` 常用于释放资源（关闭文件、断开连接）。

### 注意点

异常处理应尽量具体，**不推荐过宽捕获**：

```python
try:
    run()
except Exception:
    pass   # 隐藏真正问题，状态可能已不正确
```

## 主动抛出异常

### raise

```python
def check_age(age):
    if age < 0:
        raise ValueError('Age cannot be negative')
    return age
```

### 重新抛出

`except` 中不带参数的 `raise` 重新抛出当前异常，适合先记录日志/清理再交外层处理：

```python
except ValueError:
    print('Logging: Invalid data')
    raise
```

### 自定义异常

继承 `Exception` 定义业务异常：

```python
class InsufficientFundsError(Exception):
    pass
```

适合表达余额不足、权限不足、状态不合法等业务错误。

### 自定义异常进阶

异常也是对象，常见异常继承自 `Exception`，`Exception` 又继承自 `BaseException`。自定义异常本质是定义 `Exception` 子类。

| 要点 | 说明 |
|---|---|
| 继承 `Exception` 而非 `BaseException` | `KeyboardInterrupt`/`SystemExit` 直接继承 `BaseException`；业务异常若也继承 `BaseException`，`except Exception` 将无法捕获 |
| 命名 | `Error` 结尾、**PascalCase** |
| 保存消息 | `pass` 空类已够，消息由 `Exception` 处理 |
| 保存业务数据 | 重写 `__init__()` 并 `super().__init__(...)` |

扩展初始化以保存业务数据：

```python
class InsufficientFundsError(Exception):
    def __init__(self, balance, amount):
        self.balance = balance
        self.amount = amount
        shortage = amount - balance
        super().__init__(f'Insufficient funds: short by {shortage}')
```

可定义公共异常父类再派生具体异常（如 `WalletError` → `InvalidAmountError`/`InsufficientFundsError`），调用方既能按具体类型捕获，也能用父类统一捕获。自定义异常层次是继承的典型应用，详见 [[继承]]、[[面向对象]]。优先捕获具体异常类型，`except Exception` 范围过大。

### 异常链 raise...from

```python
raise ValueError('Invalid number format') from e   # 保留因果关系
raise ValueError('Invalid number format') from None  # 隐藏原始上下文
```

## assert

```python
assert number >= 0, 'Cannot calculate square root of negative number'
```

条件为 `False` 抛 `AssertionError`。**适合开发阶段检查内部假设，不适合代替正式输入校验**——正式业务校验用 `if` 配合 `raise`。

异常处理与类（自定义异常）相关，见 [[面向对象]]。
