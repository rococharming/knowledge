# 字典和集合

Python 两种哈希集合类型 `dict` 与 `set`，底层依赖哈希机制，查找快，但要求元素**可哈希**。

| 类型 | 中文 | 存储 | 主要用途 |
|---|---|---|---|
| `dict` | 字典 | key-value 键值对 | 按 key 快速查 value |
| `set` | 集合 | 不重复元素 | 去重、成员判断、集合运算 |

> `dict` 的 key 和 `set` 元素必须是可哈希对象，通常即不可变对象。

## dict

`{}` 创建，`dict()` 构造函数转换键值对列表。**现代 Python dict 保留插入顺序**。

### 访问与修改

```python
scores['Bob']       # 访问，key 不存在抛 KeyError
scores['Bob'] = 80  # 修改
scores['Adam'] = 67 # key 不存在则新增
```

key 必须唯一，重复写入后者覆盖前者。

### get()

`get(key, default)` 在 key 不存在时返回 `None` 或默认值，**不报错**，比方括号访问更稳妥。

### keys() / values() / items()

返回**视图对象**（非列表），需 `list()` 转换。`items()` 遍历时 `k, v` 本质是元组解包。

### 删除与更新

| 方法 | 说明 |
|---|---|
| `pop(key, default)` | 删除指定 key 并返回 value，不存在可传默认值避免报错 |
| `popitem()` | 删除最后插入的键值对并返回 |
| `update(other)` | 用另一字典更新，存在则覆盖，不存在则新增 |
| `clear()` | 清空 |

### 遍历

- 遍历 dict 默认遍历 key
- `for k in d.keys()` / `for v in d.values()` / `for k, v in d.items()`
- 配合 `enumerate()` 可计数
- **遍历时不建议同时增删 key**，易致逻辑混乱或运行时错误

## set

`{1, 2, 3}` 创建非空集合，**空集合必须用 `set()`**（`{}` 是空字典）。可变、无序，不能索引访问。

### 添加与删除

| 方法 | 说明 |
|---|---|
| `add(x)` | 添加，重复添加无变化 |
| `remove(x)` | 删除，不存在抛 `KeyError` |
| `discard(x)` | 删除，不存在**不报错** |
| `clear()` | 清空 |

`set()` 转换可迭代对象常用于**去重**，但通常不保留原顺序。

### 成员判断

只关心「是否存在」时，`set` 通常比 `list` 更合适。

### 集合运算

| 运算 | 符号 | 方法 |
|---|---|---|
| 并集 | `a \| b` | `a.union(b)` |
| 交集 | `a & b` | `a.intersection(b)` |
| 差集 | `a - b` | `a.difference(b)` |
| 对称差集 | `a ^ b` | `a.symmetric_difference(b)` |

均有复合赋值形式 `|=` `&=` `-=` `^=`。

### 关系判断

- `issubset()`：是否子集
- `issuperset()`：是否超集
- `isdisjoint()`：是否无共同元素

## 可哈希对象

`hash()` 计算哈希值。可哈希需满足：

- 生命周期内哈希值不变
- 两个相等对象哈希值相同（`a == b` ⇒ `hash(a) == hash(b)`）

常见可哈希：`str`/`int`/`float`/`bool`/`tuple`（元素均可哈希时）。
不可哈希：`list`/`dict`/`set`（可变）。

```python
data = {['Tom', 18]: 'student'}   # TypeError: unhashable type: 'list'
data = {('Tom', 18): 'student'}   # 合法
```

> 可哈希对象一般是不可变对象，但不可变对象不一定可哈希（如含可变元素的元组）。

哈希机制的本质与可变/不可变关系见 [[数据类型系统]]，容器选型见 [[容器类型]]。
