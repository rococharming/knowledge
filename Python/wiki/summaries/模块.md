# 模块

模块是一个可被其他 Python 代码复用的 `.py` 文件，模块名即文件名去掉 `.py`。模块把代码拆分到不同文件，便于复用与维护。

## 标准库

Python 自带丰富标准库，无需安装直接 `import`：

| 模块 | 作用 |
|---|---|
| `math` | 数学计算 |
| `random` | 随机数 |
| `datetime` | 日期和时间 |
| `re` | 正则表达式 |
| `os` | 操作系统相关功能 |
| `pathlib` | 路径处理 |
| `json` | JSON 数据处理 |

## 导入方式

### import 语句

```python
import math
print(math.sqrt(36))   # 模块名.函数名()
print(math.pi)         # 点语法访问常量
```

导入语句通常写在文件顶部。

### 别名 as

```python
import math as m
from math import sqrt as square_root
```

模块名过长或避免命名冲突时使用。

### from...import...

只导入所需名称，调用时无需模块前缀，但可能与当前文件同名产生冲突：

```python
from math import radians, sin, cos
```

### 通配符导入（不推荐）

```python
from math import *  # 不推荐
```

会把所有公开名称倒入当前作用域，易命名冲突且难以追溯来源。推荐 `import math` 或 `from math import sqrt, sin`。

## 使用模块中的类

```python
import datetime
birthday = datetime.date(1959, 7, 15)  # 模块.类
```

## 查看模块内容

- `help(module)`：查看模块帮助文档
- `dir(module)`：返回可用名称列表，初学辅助探索；正式学习 API 以官方文档为准

## 直接执行入口

### __name__

- 文件被**直接运行**时，`__name__` 值为 `'__main__'`
- 文件被**导入**时，`__name__` 值为模块名

### if __name__ == '__main__'

```python
def hello(name):
    return f'Hello {name}'

if __name__ == '__main__':
    print(hello('Tom'))
```

只有直接运行时才执行该代码块，被导入时不自动执行。这种写法让一个文件兼具两种用途：直接运行执行主逻辑，被导入时只提供函数/类。
