# 变量和数据类型

Python 是动态类型语言，变量无需声明类型，赋值即创建。本篇梳理变量、命名、注释与基础数据类型。

## 变量与赋值

用 `=` 给变量赋值，无需指定类型：

```python
name = 'Tom'
age: int = 18  # 可选类型注解
```

类型错误在运行时才暴露，而非编译期。

## 命名规则

- 只能含字母、数字、下划线，**不能以数字开头**
- 大小写敏感（`age` 与 `Age` 不同）
- 不能使用关键字（如 `if`、`for`、`class`）
- 违反规则抛 `SyntaxError`

命名约定使用**蛇形命名法**（snake_case）：`user_name`、`total_count`。

## 注释

- 单行注释以 `#` 开头
- Python 没有专门的多行注释语法，连续多个 `#` 即可
- 注释可独占一行，也可跟在代码行尾

## print()

`print()` 可同时输出多个值，用逗号分隔，自动加空格：

```python
print('Name:', name, 'Age:', age)
```

## 常见数据类型

| 类型 | 说明 | 示例 |
|---|---|---|
| `int` | 整数 | `18` |
| `float` | 浮点数 | `3.14` |
| `str` | 字符串 | `'Tom'` |
| `bool` | 布尔 | `True` |
| `list` | 列表（可变） | `[1, 2]` |
| `tuple` | 元组（不可变） | `(1, 2)` |
| `dict` | 字典 | `{'a': 1}` |
| `set` | 集合 | `{1, 2}` |
| `range` | 整数序列 | `range(3)` |
| `NoneType` | 空值 | `None` |

更系统的类型组织见 [[数据类型系统]]，字符串细节见 [[字符串]]，数字运算见 [[数字和数学运算]]。

## 类型判断

### type()

`type()` 返回对象的类型，不传参数抛 `TypeError`。

```python
print(type(18))   # <class 'int'>
```

### isinstance()

`isinstance(obj, type)` 判断对象是否为某类型，**推荐使用**。可同时检查多个类型：

```python
print(isinstance(18, (int, float, str)))  # True
```

`isinstance()` 支持继承关系，比 `type()` 直接比较更稳健。详见 [[面向对象]]。
