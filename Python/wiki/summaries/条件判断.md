# 条件判断

Python 用 `if` / `elif` / `else` 实现分支，依赖缩进表达代码块。

## 比较运算符

`==` `!=` `>` `<` `>=` `<=`。

## if 结构

```python
if condition:
    ...
elif another:
    ...
else:
    ...
```

- `elif` 即 `else if`，从上到下判断
- **具体条件放前面**，更通用的放后面
- 缩进统一 4 空格，错误抛 `IndentationError`
- `pass` 用于占位空代码块

## Truthy 与 Falsy

以下值视为 `False`（Falsy），其余皆为 Truthy：

- `None`
- `False`
- `0`、`0.0`
- `''`（空字符串）
- 空容器：`[]`、`{}`、`()`

`bool(x)` 可显式转换。

## 布尔运算符

`and` / `or` / `not`。

### 短路求值

- `and`：`x` 为假返回 `x`，为真返回 `y`
- `or`：`x` 为真返回 `x`，为假返回 `y`
- `and` / `or` **返回原始值而非布尔**，`not` 总返回布尔

```python
print(0 and 1)   # 0
print(3 or 5)    # 3
```

## 三元表达式

```python
value_if_true if condition else value_if_false
```

Python 没有 `?:` 三元运算符，用上述表达式形式替代。

条件判断与循环结构共同构成控制流，见 [[控制流]]。
