# 字符串

Python 字符串 `str` 是 Unicode 文本序列，属于不可变类型。本篇梳理定义、操作、编码与格式化。

## 定义

- 单引号 `'...'` 与双引号 `"..."` 等价
- 三重引号 `"""..."""` / `'''...'''` 用于多行字符串
- 含引号时可用相反引号包裹，或用 `\` 转义

```python
msg = "It's a girl"
quote = 'He said "Hello"'
escaped = 'It\'s ok'
```

## 不可变性

字符串创建后不可修改，`greeting[0] = 'H'` 抛 `TypeError`，但可重新赋值指向新对象。`int`/`float`/`bool`/`tuple`/`range` 同为不可变类型。

## 常见操作

| 操作 | 方法/语法 | 说明 |
|---|---|---|
| 成员判断 | `'x' in s` | 返回布尔 |
| 长度 | `len(s)` | **字符数非字节数** |
| 索引 | `s[0]` / `s[-1]` | 正向从 0，负向从 -1 |
| 拼接 | `s1 + s2` | 仅限字符串之间；与数字需 `str()` 转换 |
| 插值 | `f"{name}"` | f-string，自动转换类型 |
| 大小写 | `upper()` / `lower()` | 返回新字符串 |
| 判断大小写 | `isupper()` / `islower()` | 返回布尔 |
| 去空白 | `strip()` | 移除前导尾随字符 |
| 替换 | `replace(old, new)` | 返回新字符串 |
| 分隔 | `split(sep)` | 返回列表，无参按空白拆 |
| 连接 | `sep.join(iterable)` | 用分隔符连接 |
| 前后缀 | `startswith()` / `endswith()` | 返回布尔 |
| 查找 | `find(sub)` | 返回首索引，找不到 -1 |
| 计数 | `count(sub)` | 出现次数 |
| 首字母大写 | `capitalize()` / `title()` | 句首 / 每词首 |

## 切片

```python
s[start:stop:step]   # stop 不含
```

- 省略 `start` 从 0 开始，省略 `stop` 到末尾
- `s[::-1]` 反转字符串（step=-1）

切片语法对所有序列类型通用，见 [[列表和元组]]。

## str 与 bytes

| 类型 | 含义 | 字面量 |
|---|---|---|
| `str` | Unicode 文本序列 | `"中文"` |
| `bytes` | 字节序列（0-255 整数） | `b"ABC"` |

> `str` 不是 UTF-8 字节序列，而是 Unicode 文本序列。编码后才变为字节。

- `bytes` 字面量必须 ASCII，非 ASCII 用 `\x##` 转义
- `bytes` 元素是整数：`b"ABC"[0]` → `65`
- `ord()` 取码点，`chr()` 转字符，`hex()` 看十六进制
- `中` 用 4 位十六进制表示 Unicode 字符（等价于直接写 `中`）

### 编码与解码

```python
'中文'.encode('utf-8')              # str → bytes
b'\xe4\xb8\xad'.decode('utf-8')     # bytes → str
```

编码与解码必须匹配，否则报错或乱码。错误处理：`errors='strict'`（默认报错）、`'ignore'`（忽略）、`'replace'`（替换）。

### 源文件编码

- Python 3 源文件默认 UTF-8
- Shebang `#!/usr/bin/env python3` 指定解释器（类 Unix 系统可 `./hello.py` 直接执行）
- 编码声明 `# -*- coding: utf-8 -*-` 告诉解释器按 UTF-8 读取（声明不改变文件实际编码）

## 格式化

三种方式：

| 方式 | 示例 | 说明 |
|---|---|---|
| `%` 格式化 | `"Hi, %s" % name` | C 风格，`%d`/`%x`/`%f`/`%s`，`%%` 输出 `%` |
| `format()` | `"Hi, {}".format(name)` | `{}` 占位，`{0}`/`{1:.1f}`/命名参数 |
| f-string | `f"Hi, {name}"` | **3.6+ 推荐**，`{}` 可写表达式与方法调用 |

f-string 格式化参数：`f"{s:.2f}"` 保留 2 位小数。

更深入的编码原理与三种格式化对比见 [[字符串与编码]]。
