# 列表和元组

Python 序列类型 `list`（可变）与 `tuple`（不可变），都支持索引、负向索引、切片、解包。

| 类型 | 中文 | 可变 | 常见用途 |
|---|---|---|---|
| `list` | 列表 | ✅ | 需增删改的元素集合 |
| `tuple` | 元组 | ❌ | 创建后不希望修改的数据 |

## list

`[]` 定义，可嵌套，`list()` 转换可迭代对象，`len()` 取长度。索引越界抛 `IndexError`。

### 修改与删除

```python
lst[0] = 'new'      # 修改，越界抛 IndexError
del lst[1]          # 删除指定位置
```

### 切片

```python
lst[start:stop]     # stop 不含
lst[1::2]           # 步长
```

### 成员判断

`'x' in lst` 返回布尔。

### 解包

```python
name, age, job = lst
name, *rest = lst   # * 收集剩余到列表
```

变量数与元素数不匹配抛 `ValueError`。

### 常用方法

| 方法 | 说明 |
|---|---|
| `append(x)` | 末尾追加一个元素（传列表整体作为单个元素） |
| `extend(iter)` | 逐个追加可迭代对象元素 |
| `insert(i, x)` | 指定位置插入 |
| `remove(x)` | 按值删第一个 |
| `pop(i)` | 删除并返回，默认最后 |
| `clear()` | 清空 |
| `sort()` | **原地**排序 |
| `sorted()` | 返回**新列表**，不改原 |
| `reverse()` | 原地反转 |
| `index(x)` | 查找首次位置，找不到抛 `ValueError` |

## tuple

`()` 定义，不可改。**单元素必须加逗号** `(1,)`，否则 `(1)` 被当数学括号。

### 不可变性的精确含义

> 不可变指元组中每个位置保存的**对象引用**不能改变，而非引用对象本身不可变。

```python
t = ('a', 'b', ['A', 'B'])
t[2][0] = 'X'   # 合法！列表自身可变
t[0] = 'x'      # TypeError，引用不能改
```

### 常用方法

- `count(x)`：统计次数
- `index(x, start)`：查找位置，可指定范围，找不到抛 `ValueError`
- `sorted()`：返回**新列表**（非元组），`tuple` 无 `sort()` 方法

## 选择

- 需增删改 → `list`
- 创建后不变 → `tuple`（如 `point = (3, 5)`、`rgb = (255, 128, 0)`）
