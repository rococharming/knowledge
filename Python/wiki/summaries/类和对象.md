# 类和对象

类是创建对象的模板，定义一类对象的数据与行为；对象是根据类创建的具体实例。类名使用 **PascalCase**（如 `Dog`、`BankAccount`）。

## 定义与实例化

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f"{self.name} says woof!")

dog_1 = Dog('Jack', 3)   # 实例化
dog_1.bark()
```

| 部分 | 含义 |
|---|---|
| `class Dog` | 定义类 |
| `__init__()` | 对象创建时自动调用的初始化方法 |
| `self` | 当前对象，实例方法第一个参数，调用时自动传入 |
| `bark()` | 实例方法 |

`self` 无需手动传入，Python 自动把调用对象传给它。

## 属性与方法

### 实例属性

在 `__init__()` 中通过 `self` 设置，不同对象可有不同值。用点语法访问 `对象.属性名`。

### 类属性

属于类本身，被该类所有对象共享：

```python
class Dog:
    species = 'French Bulldog'   # 类属性
    def __init__(self, name):
        self.name = name         # 实例属性
```

`Dog.species` 与 `dog_1.species` 都能访问同一个类属性。

### 实例方法

定义在类内部的函数，通过 `self` 访问/修改对象自身数据，用点语法调用 `对象.方法名()`。

## 特殊方法（魔术方法 / dunder 方法）

以双下划线开头结尾，通常不直接调用，而由特定语法或内置函数触发：

| 操作 | 背后调用 |
|---|---|
| `a + b` | `__add__()` |
| `len(obj)` | `__len__()` |
| `str(obj)` | `__str__()` |
| `obj1 == obj2` | `__eq__()` |
| `item in obj` | `__contains__()` |
| `obj[index]` | `__getitem__()` |

### __str__ 与 __repr__

- `__str__()`：偏向给**用户**看的可读文本
- `__repr__()`：偏向给**开发者**看的调试文本
- 只定义一个时**优先 `__repr__()`**，对调试更有帮助

不应直接写 `obj.__len__()`，而用 `len(obj)` 这种自然写法。

### 让对象支持容器操作

通过定义 `__len__`/`__getitem__`/`__contains__`/`__iter__` 等，自定义对象可像容器一样被遍历、`len()`、索引访问、`in` 判断。

## 动态属性

属性名在运行时才知道（来自用户输入、配置、字典）时，需动态处理。

| 函数 | 作用 |
|---|---|
| `getattr(obj, name, default)` | 按字符串名读属性，无默认值且不存在抛 `AttributeError` |
| `setattr(obj, name, value)` | 动态创建或修改属性 |
| `hasattr(obj, name)` | 判断是否有某属性 |
| `delattr(obj, name)` | 动态删除属性 |
| `dir(obj)` | 查看对象可用属性名 |
| `callable(obj)` | 判断是否可像函数调用 |

```python
for attr_name, attr_value in settings_data.items():
    setattr(config, attr_name, attr_value)
```

> 动态属性灵活但降低可读性。普通场景优先点语法，仅当属性名确实来自运行时数据时才用 `getattr`/`setattr`。

类、特殊方法与异常类（自定义异常继承 `Exception`）共同构成面向对象体系，见 [[面向对象]]。
