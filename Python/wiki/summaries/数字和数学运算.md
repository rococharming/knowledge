# 数字和数学运算

Python 数字类型主要 `int` 与 `float`，以及常用数学函数。

## 类型

- `int` 整数：`12`
- `float` 浮点数：`12.0`（`12` 与 `12.0` 类型不同）

```python
print(type(12))    # <class 'int'>
print(type(12.0))  # <class 'float'>
```

## 算术运算符

| 运算符 | 说明 | 示例 |
|---|---|---|
| `+` `-` `*` | 加减乘 | `1 + 2` |
| `/` | 除法，**整数相除也得 float** | `10 / 3` → `3.333` |
| `%` | 取模 | `10 % 3` → `1` |
| `//` | 地板除，向下取整 | `10 // 3` → `3` |
| `**` | 指数 | `2 ** 3` → `8` |

### 浮点精度

浮点数有精度问题：

```python
print(0.1 + 0.2)  # 0.30000000000000004
```

这是 IEEE 754 二进制浮点的固有特性，非 Python 独有。

## 类型转换

- `float(x)`：转浮点
- `int(x)`：去小数（**不是四舍五入**，向零取整）
- 字符串转数字：`int('42')`，非法值抛 `ValueError`

```python
print(int(3.9))   # 3
print(int('42'))  # 42
```

## 常用数学函数

| 函数 | 说明 |
|---|---|
| `round(x, n)` | 四舍五入，中间值倾向偶数 |
| `abs(x)` | 绝对值 |
| `pow(a, b)` | 等价 `a ** b`；第三参数取模 `pow(2, 3, 5)` → `3` |

`round()` 的「银行家舍入」：`round(2.5)` → `2`，`round(3.5)` → `4`。

## 扩充赋值

`+=` `-=` `*=` `/=` `//=` `%=` `**=`。

- 字符串支持 `+=`（拼接）和 `*=`（重复）
- 字符串不支持 `-=` `/=`
- **无 `++`/`--`**：`++x` 只是连续两个一元正号，不改变值
