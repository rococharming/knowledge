# 一、数字类型

Python 中常用的数字类型主要有两种：`int`和`float`。

|类型|中文名称|含义|示例|
|---|---|---|---|
|`int`|整数|没有小数部分的数字|`56`、`-4`|
|`float`|浮点数|带小数部分的数字|`3.14`、`-0.5`|

## 1、整数

整数是没有小数点的数字，可以是正数、负数或`0`。

示例：

```python
my_int_1 = 56
my_int_2 = -4

print(type(my_int_1))
print(type(my_int_2))
```

输出：

```text
<class 'int'>
<class 'int'>
```

## 2、浮点数

浮点数是带有小数点的数字。

示例：

```python
my_float_1 = -12.0
my_float_2 = 4.9

print(type(my_float_1))
print(type(my_float_2))
```

输出：

```text
<class 'float'>
<class 'float'>
```

需要注意，`12`是整数，`12.0`是浮点数。它们在数学意义上大小相等，但在 Python 中属于不同类型。


# 二、基本数学运算

Python 可以直接使用常见的数学运算符对数字进行计算。

|运算符|含义|示例|
|---|---|---|
|`+`|加法|`a + b`|
|`-`|减法|`a - b`|
|`*`|乘法|`a * b`|
|`/`|除法|`a / b`|

## 1、整数运算

整数之间可以进行加法、减法和乘法运算。

示例：

```python
my_int_1 = 56
my_int_2 = 12

sum_ints = my_int_1 + my_int_2
diff_ints = my_int_1 - my_int_2
product_ints = my_int_1 * my_int_2

print('Integer Addition:', sum_ints)
print('Integer Subtraction:', diff_ints)
print('Integer Multiplication:', product_ints)
```

输出：

```text
Integer Addition: 68
Integer Subtraction: 44
Integer Multiplication: 672
```

整数相除时，即使可以整除，使用`/`得到的结果也是`float`。

```python
my_int_1 = 56
my_int_2 = 12

div_ints = my_int_1 / my_int_2

print('Division:', div_ints)
print(type(div_ints))
```

输出：

```text
Division: 4.666666666666667
<class 'float'>
```

## 2、浮点数运算

浮点数也可以进行加法、减法、乘法和除法运算。

示例：

```python
my_float_1 = 5.4
my_float_2 = 12.0

float_addition = my_float_1 + my_float_2
float_subtraction = my_float_2 - my_float_1
float_multiplication = my_float_2 * my_float_1
float_division = my_float_2 / my_float_1

print('Float Addition:', float_addition)
print('Float Subtraction:', float_subtraction)
print('Float Multiplication:', float_multiplication)
print('Float Division:', float_division)
```

输出：

```text
Float Addition: 17.4
Float Subtraction: 6.6
Float Multiplication: 64.80000000000001
Float Division: 2.222222222222222
```

这里的`64.80000000000001`不是算错，而是浮点数精度问题，后面会单独说明。

## 3、整数和浮点数混合运算

当整数和浮点数一起参与运算时，Python 会自动把结果转换为浮点数。

示例：

```python
my_int = 56
my_float = 5.4

sum_int_and_float = my_int + my_float

print(sum_int_and_float)
print(type(sum_int_and_float))
```

输出：

```text
61.4
<class 'float'>
```

减法、乘法和除法也遵循类似规则。只要运算中出现`float`，结果通常就是`float`。


# 三、取模、地板除和指数运算

除了加减乘除外，Python 还提供了几个常用的数学运算符。

|运算符|含义|示例|
|---|---|---|
|`%`|取模，返回余数|`a % b`|
|`//`|地板除，向下取整|`a // b`|
|`**`|指数运算|`a ** b`|

## 1、取模运算

取模运算符`%`返回左侧数字除以右侧数字后的余数。

示例：

```python
my_int_1 = 56
my_int_2 = 12

mod_ints = my_int_1 % my_int_2

print('Integer Modulo:', mod_ints)
```

输出：

```text
Integer Modulo: 8
```

因为`56`除以`12`，商是`4`，余数是`8`。

浮点数也可以使用取模运算：

```python
my_float_1 = 5.4
my_float_2 = 12.0

mod_floats = my_float_2 % my_float_1

print('Float Modulo:', mod_floats)
```

输出：

```text
Float Modulo: 1.1999999999999993
```

## 2、地板除

地板除使用`//`，它会将两个数字相除，并返回小于或等于真实结果的最大整数。

示例：

```python
my_int_1 = 56
my_int_2 = 12

floor_div_ints = my_int_1 // my_int_2

print('Integer Floor Division:', floor_div_ints)
```

输出：

```text
Integer Floor Division: 4
```

`56 / 12`的结果是`4.666...`，地板除会得到`4`。

如果参与运算的是浮点数，结果也是浮点数：

```python
my_float_1 = 5.4
my_float_2 = 12.0

floor_div_floats = my_float_2 // my_float_1

print('Float Floor Division:', floor_div_floats)
```

输出：

```text
Float Floor Division: 2.0
```

## 3、指数运算

指数运算使用`**`，表示把一个数字提升到另一个数字的幂。

示例：

```python
my_int_1 = 2
my_int_2 = 3

result = my_int_1 ** my_int_2

print(result)
```

输出：

```text
8
```

这里的`2 ** 3`表示`2`的`3`次方，也就是`2 * 2 * 2`。


# 四、浮点数精度问题

在 Python 中，浮点数计算有时会出现看起来不符合直觉的结果。

示例：

```python
result = 0.1 + 0.2

print(result)
```

输出：

```text
0.30000000000000004
```

这不是 Python 算错了，而是因为计算机底层使用二进制保存数字。有些十进制小数无法用有限位数的二进制精确表示，只能保存为一个近似值。

可以类比十进制中无法用有限位数精确表示`1 / 3`：

```text
0.333333...
```

浮点数的小误差通常不会影响普通计算，但在比较金额、精确小数或科学计算时，需要格外注意。


# 五、数字类型转换

Python 提供了`int()`和`float()`函数用于数字类型转换。

## 1、转换为浮点数

`float()`函数可以将整数转换为浮点数。

示例：

```python
my_int = 56
my_float = float(my_int)

print(my_float)
print(type(my_float))
```

输出：

```text
56.0
<class 'float'>
```

## 2、转换为整数

`int()`函数可以将浮点数转换为整数。

示例：

```python
my_float = 12.92563
my_int = int(my_float)

print(my_int)
print(type(my_int))
```

输出：

```text
12
<class 'int'>
```

需要注意，`int()`把浮点数转换为整数时，不是四舍五入，而是直接去掉小数部分。

## 3、字符串转换为数字

如果字符串内容本身符合数字格式，也可以使用`int()`或`float()`转换。

示例：

```python
my_str_int = '45'
my_str_float = '7.8'

converted_int = int(my_str_int)
converted_float = float(my_str_float)

print(converted_int, type(converted_int))
print(converted_float, type(converted_float))
```

输出：

```text
45 <class 'int'>
7.8 <class 'float'>
```

如果字符串内容不是合法数字，就会抛出`ValueError`：

```python
number = int('hello')
```

报错：

```text
ValueError: invalid literal for int() with base 10: 'hello'
```


# 六、常用数字函数

Python 提供了一些常用内置函数，用来处理数字。

## 1、round()

`round()`用于将数字舍入到指定的小数位数。

示例：

```python
num_1 = 4.798
num_2 = 4.253

rounded_num_1 = round(num_1)
rounded_num_2 = round(num_2, 1)

print(rounded_num_1)
print(rounded_num_2)
```

输出：

```text
5
4.3
```

如果没有传入第二个参数，`round()`默认返回最接近的整数。

需要注意，`round()`并不是所有情况下都等同于日常理解中的“四舍五入”。当数字刚好位于两个结果中间时，Python 会倾向于舍入到偶数。

## 2、abs()

`abs()`用于返回一个数字的绝对值。

示例：

```python
num = -15

absolute_value = abs(num)

print(absolute_value)
```

输出：

```text
15
```

## 3、pow()

`pow()`用于计算幂运算。

示例：

```python
result = pow(2, 3)

print(result)
```

输出：

```text
8
```

`pow(2, 3)`等价于`2 ** 3`。

`pow()`还可以传入第三个参数，表示先计算幂，再取模。

```python
result = pow(2, 3, 5)

print(result)
```

输出：

```text
3
```

这里等价于：

```python
(2 ** 3) % 5
```


# 七、扩充赋值

扩充赋值是把二元运算和赋值合并为一步。

基本语法：

```python
variable <operator>= value
```

它等价于：

```python
variable = variable <operator> value
```

## 1、加法扩充赋值

示例：

```python
my_var = 10
my_var += 5

print(my_var)
```

输出：

```text
15
```

上面的代码等价于：

```python
my_var = 10
my_var = my_var + 5

print(my_var)
```

扩充赋值的好处是写法更简洁，也减少了重复写变量名带来的拼写错误。

## 2、常见扩充赋值操作符

|操作符|等价写法|含义|
|---|---|---|
|`+=`|`x = x + y`|加法后赋值|
|`-=`|`x = x - y`|减法后赋值|
|`*=`|`x = x * y`|乘法后赋值|
|`/=`|`x = x / y`|除法后赋值|
|`//=`|`x = x // y`|地板除后赋值|
|`%=`|`x = x % y`|取模后赋值|
|`**=`|`x = x ** y`|指数运算后赋值|

示例：

```python
count = 14
count -= 3
print(count)  # 11

product = 65
product *= 7
print(product)  # 455

price = 100
price /= 4
print(price)  # 25.0

total_pages = 23
total_pages //= 5
print(total_pages)  # 4

bits = 35
bits %= 2
print(bits)  # 1

power = 2
power **= 3
print(power)  # 8
```

## 3、字符串中的扩充赋值

扩充赋值也可以用于字符串，但只能使用字符串支持的运算。

`+=`可以用于字符串拼接：

```python
greet = 'Hello'
greet += ' World'

print(greet)
```

输出：

```text
Hello World
```

`*=`可以用于重复字符串：

```python
greet = 'Hello'
greet *= 3

print(greet)
```

输出：

```text
HelloHelloHello
```

但字符串不支持减法和除法，因此下面的写法会抛出`TypeError`：

```python
greet = 'Hello'
greet -= ' World'
```

报错：

```text
TypeError: unsupported operand type(s) for -=: 'str' and 'str'
```

## 4、Python没有++和--

Python 中没有 C、JavaScript 等语言里的递增和递减操作符`++`和`--`。

如果要让变量增加`1`，应该写成：

```python
my_var = 5
my_var += 1

print(my_var)
```

输出：

```text
6
```

在 Python 中，`++x`只是连续使用两个一元加号，并不会改变变量的值。

```python
my_var = 5

print(+my_var)
print(++my_var)
print(+++my_var)

print(my_var)
```

输出：

```text
5
5
5
5
```
