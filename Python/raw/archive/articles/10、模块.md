# 一、模块和标准库

## 1、模块的基本含义

模块可以理解为一个可以被其他 Python 代码使用的代码文件。

一个普通的`.py`文件就可以是一个模块。模块中可以定义变量、常量、函数、类等内容，然后在其他文件中导入使用。

例如，如果有一个`tools.py`文件：

```python
def hello(name):
    return f'Hello {name}'
```

那么`tools.py`就是一个模块，模块名通常就是文件名去掉`.py`后的部分，也就是`tools`。

使用模块的好处是可以把代码拆分到不同文件中，让代码更容易复用和维护。

## 2、标准库

库可以理解为一组已经写好的、可复用的代码。

Python 自带了丰富的标准库，里面包含很多常用模块，用于解决日常开发中的常见问题。

常见标准库模块如下：

|模块|作用|
|---|---|
|`math`|数学计算|
|`random`|随机数|
|`datetime`|日期和时间|
|`re`|正则表达式|
|`os`|操作系统相关功能|
|`pathlib`|路径处理|
|`json`|JSON 数据处理|

这些模块不需要额外安装，只要安装了 Python，就可以直接导入使用。


# 二、导入模块

## 1、import语句

使用模块前，需要先通过`import`语句导入模块。

基本语法：

```python
import 模块名
```

示例：

```python
import math

print(math.sqrt(36))
```

输出：

```text
6.0
```

这里先导入`math`模块，然后通过点语法调用模块中的`sqrt()`函数。

基本形式是：

```python
模块名.函数名()
```

点语法也可以访问模块中的常量。

```python
import math

print(math.pi)
```

输出：

```text
3.141592653589793
```

导入语句通常写在文件顶部，这样可以让文件依赖关系更清晰。

## 2、使用别名导入模块

如果模块名较长，或者希望避免名称冲突，可以使用`as`给模块起别名。

基本语法：

```python
import 模块名 as 别名
```

示例：

```python
import math as m

print(m.sqrt(36))
```

输出：

```text
6.0
```

起别名后，后续代码中就使用别名访问模块内容。


# 三、导入模块中的名称

## 1、from...import...

如果只需要模块中的某几个名称，可以使用`from...import...`。

基本语法：

```python
from 模块名 import 名称1, 名称2
```

示例：

```python
from math import radians, sin, cos

angle_degrees = 40
angle_radians = radians(angle_degrees)

sine_value = sin(angle_radians)
cos_value = cos(angle_radians)

print(sine_value)
print(cos_value)
```

输出：

```text
0.6427876096865393
0.766044443118978
```

使用这种写法后，可以直接调用`radians()`、`sin()`和`cos()`，不需要再写`math.`前缀。

不过，如果当前文件中已经有同名变量或函数，就可能产生命名冲突。

## 2、给导入的名称起别名

`from...import...`也可以配合`as`使用。

```python
from math import sqrt as square_root

print(square_root(36))
```

输出：

```text
6.0
```

这种写法适合在名称容易冲突，或希望让名称更符合当前代码语义时使用。

## 3、不推荐通配符导入

Python 允许使用`*`导入模块中的所有公开名称。

```python
from math import *

print(sqrt(36))
print(pow(5, 2))
print(exp(1))
```

输出：

```text
6.0
25.0
2.718281828459045
```

这种写法通常不推荐。

原因是它会把很多名称直接放到当前文件中，容易产生命名冲突，也不容易看出某个函数或变量到底来自哪里。

实际写代码时，更推荐下面两种方式：

```python
import math
```

或者：

```python
from math import sqrt, sin, cos
```


# 四、使用模块中的类和对象

## 1、使用类

模块中不只可以包含函数，也可以包含类。

例如，`datetime`模块中提供了用于表示日期的`date`类。

```python
import datetime

birthday = datetime.date(1959, 7, 15)

print(birthday.day)
print(birthday.month)
print(birthday.year)
```

输出：

```text
15
7
1959
```

这里的`datetime.date`表示访问`datetime`模块中的`date`类。

## 2、查看模块内容

如果不清楚一个模块中有什么内容，可以查阅官方文档。

也可以在交互环境中使用`help()`查看模块帮助。

```python
import math

help(math)
```

如果只想快速查看模块中有哪些名称，可以使用`dir()`。

```python
import math

print(dir(math))
```

`dir()`会返回模块中可用名称的列表。初学时可以用它辅助探索，但正式学习 API 时仍应以官方文档为准。


# 五、模块的直接执行入口

## 1、__name__

`__name__`是 Python 自动提供的一个特殊变量。

当一个 Python 文件被直接运行时，`__name__`的值是`'__main__'`。

当一个 Python 文件作为模块被其他文件导入时，`__name__`的值通常是模块名。

例如，文件`hello.py`中有下面的代码：

```python
print(__name__)
```

直接运行：

```shell
python3 hello.py
```

输出：

```text
__main__
```

如果它被其他文件导入，`__name__`的值通常会是`hello`。

## 2、if __name__ == '__main__'

在 Python 文件中经常会看到下面这种写法：

```python
if __name__ == '__main__':
    pass
```

它表示：只有当前文件被直接运行时，才执行这个代码块。

示例：

```python
def hello(name):
    return f'Hello {name}'

if __name__ == '__main__':
    print(hello('Tom'))
```

直接运行这个文件时，会输出：

```text
Hello Tom
```

但如果这个文件被其他文件导入，`if __name__ == '__main__':`下面的代码不会自动执行。

这种写法很常见，因为它允许一个文件同时具备两种用途：

- 直接运行时，执行主逻辑
- 被导入时，只提供函数、类等内容，不自动运行主逻辑
