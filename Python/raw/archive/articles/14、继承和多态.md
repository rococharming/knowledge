# 一、继承

## 1、继承的基本含义

继承是面向对象编程的重要原则之一。

通过继承，一个类可以使用另一个类已有的属性和方法，从而减少重复代码，并建立清晰的类层次结构。

继承关系中的类通常有以下称呼：

|名称|其他称呼|含义|
|---|---|---|
|父类|基类、超类|提供通用属性和方法的类|
|子类|派生类|继承并扩展父类的类|

继承的基本语法：

```python
class Parent:
    pass


class Child(Parent):
    pass
```

把父类写在子类名称后的圆括号中，就可以让子类继承父类。

## 2、单继承

一个子类只继承一个直接父类，称为单继承。

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        return f'My name is {self.name}'


class Dog(Animal):
    species = 'dog'


dog = Dog('Jack')

print(dog.name)
print(dog.introduce())
print(dog.species)
```

输出：

```text
Jack
My name is Jack
dog
```

`Dog`类中没有定义`__init__()`和`introduce()`，但可以直接使用从`Animal`类继承的初始化方法和实例方法。

创建`Dog('Jack')`时，Python 找不到`Dog.__init__()`，便沿着继承关系找到并调用`Animal.__init__()`。

## 3、继承如何复用代码

如果多个类具有相同的数据和行为，可以把共同部分放在父类中。

```python
class Employee:
    def __init__(self, name, employee_id):
        self.name = name
        self.employee_id = employee_id

    def clock_in(self):
        return f'{self.name} clocked in'


class Developer(Employee):
    def write_code(self):
        return f'{self.name} is writing code'


class Designer(Employee):
    def create_design(self):
        return f'{self.name} is creating a design'


developer = Developer('Alice', 'D001')
designer = Designer('Bob', 'G001')

print(developer.clock_in())
print(developer.write_code())
print(designer.clock_in())
print(designer.create_design())
```

输出：

```text
Alice clocked in
Alice is writing code
Bob clocked in
Bob is creating a design
```

`name`、`employee_id`和`clock_in()`只需要在`Employee`中定义一次，两个子类都可以复用。

继承适合表达“是一种”的关系。例如，开发者是一种员工，设计师也是一种员工。


# 二、扩展和重写父类行为

## 1、在子类中添加成员

子类可以在继承父类成员的基础上，定义自己的属性和方法。

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        return f'{self.name} is eating'


class Dog(Animal):
    def fetch(self):
        return f'{self.name} is fetching the ball'


dog = Dog('Jack')

print(dog.eat())
print(dog.fetch())
```

输出：

```text
Jack is eating
Jack is fetching the ball
```

`eat()`来自父类，`fetch()`由子类添加。

## 2、方法重写

子类定义与父类同名的方法，称为方法重写。

调用这个方法时，Python 会优先使用子类中的实现。

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def sound(self):
        return f'{self.name} makes a sound'


class Dog(Animal):
    def sound(self):
        return f'{self.name} barks: woof!'


animal = Animal('An animal')
dog = Dog('Jack')

print(animal.sound())
print(dog.sound())
```

输出：

```text
An animal makes a sound
Jack barks: woof!
```

`Dog.sound()`重写了`Animal.sound()`，让狗对象拥有更具体的行为。

方法重写不会修改父类，只会改变子类对象调用该方法时的行为。

## 3、super()

如果子类想在保留父类原有行为的基础上增加功能，可以使用`super()`调用父类中的方法。

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def sound(self):
        return f'{self.name} makes a sound'


class Dog(Animal):
    def sound(self):
        parent_result = super().sound()
        return f'{parent_result}, then barks: woof!'


dog = Dog('Jack')

print(dog.sound())
```

输出：

```text
Jack makes a sound, then barks: woof!
```

`super().sound()`会根据当前类的继承关系调用下一个类中的`sound()`方法。

使用`super()`比直接写`Animal.sound(self)`更灵活，特别是在多继承中，`super()`会按照方法解析顺序继续查找方法。

## 4、扩展初始化方法

子类如果需要新增实例属性，可以重写`__init__()`，再通过`super().__init__()`完成父类部分的初始化。

```python
class Employee:
    def __init__(self, name, employee_id):
        self.name = name
        self.employee_id = employee_id


class Developer(Employee):
    def __init__(self, name, employee_id, language):
        super().__init__(name, employee_id)
        self.language = language

    def describe(self):
        return f'{self.name} uses {self.language}'


developer = Developer('Alice', 'D001', 'Python')

print(developer.employee_id)
print(developer.describe())
```

输出：

```text
D001
Alice uses Python
```

这里的初始化过程分为两部分：

1. `super().__init__(name, employee_id)`初始化父类定义的`name`和`employee_id`
2. `self.language = language`初始化子类特有的`language`

如果子类重写了`__init__()`却没有调用父类的初始化方法，父类中定义的实例属性不会被自动创建。


# 三、继承关系检查

## 1、isinstance()

`isinstance()`可以判断一个对象是否属于指定类或其子类。

```python
class Animal:
    pass


class Dog(Animal):
    pass


dog = Dog()

print(isinstance(dog, Dog))
print(isinstance(dog, Animal))
print(isinstance(dog, str))
```

输出：

```text
True
True
False
```

`dog`既是`Dog`的对象，也可以被视为`Animal`的对象。

## 2、issubclass()

`issubclass()`可以判断一个类是否是另一个类的子类。

```python
class Animal:
    pass


class Dog(Animal):
    pass


print(issubclass(Dog, Animal))
print(issubclass(Animal, Dog))
print(issubclass(Dog, object))
```

输出：

```text
True
False
True
```

Python 中的类最终都继承自`object`类。


# 四、自定义异常和继承

## 1、异常类的继承关系

Python 中的异常也是对象，每一种异常都由对应的异常类表示。

`ValueError`、`TypeError`和`FileNotFoundError`等常见异常都继承自`Exception`。

常见的异常继承关系如下：

```text
BaseException
└── Exception
    ├── ValueError
    ├── TypeError
    ├── LookupError
    │   ├── IndexError
    │   └── KeyError
    └── 自定义异常
```

因此，在[[11、异常处理#3、自定义异常|自定义异常]]中使用的下面这段代码，本质上是在定义一个`Exception`的子类：

```python
class InsufficientFundsError(Exception):
    pass
```

`InsufficientFundsError`继承了异常对象已有的行为，同时通过新的类名表达更具体的业务错误。

```python
print(issubclass(InsufficientFundsError, Exception))
```

输出：

```text
True
```

## 2、为什么继承Exception

大多数程序中的自定义异常应当继承`Exception`，而不是直接继承`BaseException`。

`KeyboardInterrupt`和`SystemExit`等用于控制程序退出的异常直接继承自`BaseException`。如果普通业务异常也直接继承`BaseException`，常见的`except Exception`将无法捕获它。

自定义异常类通常使用`Error`结尾，并使用`PascalCase`命名。

```python
class InsufficientFundsError(Exception):
    pass


def withdraw(balance, amount):
    if amount <= 0:
        raise ValueError('Amount must be positive')

    if amount > balance:
        raise InsufficientFundsError('Insufficient funds')

    return balance - amount


try:
    withdraw(100, 150)
except InsufficientFundsError as e:
    print(f'Transaction failed: {e}')
```

输出：

```text
Transaction failed: Insufficient funds
```

因为`InsufficientFundsError`是`Exception`的子类，所以既可以按具体类型捕获，也可以通过父类捕获：

```python
try:
    withdraw(100, 150)
except Exception as e:
    print(type(e).__name__)
    print(e)
```

输出：

```text
InsufficientFundsError
Insufficient funds
```

实际编程时，应优先捕获具体异常类型。捕获`Exception`的范围较大，可能把没有预料到的其他错误也一起捕获。

## 3、扩展Exception的初始化方法

如果只需要保存错误消息，只有`pass`的空类已经足够。传给异常对象的消息会由`Exception`处理。

如果还需要保存余额和取款金额等业务数据，可以重写`__init__()`，再使用`super().__init__()`调用父类的初始化方法：

```python
class InsufficientFundsError(Exception):
    def __init__(self, balance, amount):
        self.balance = balance
        self.amount = amount
        shortage = amount - balance

        super().__init__(f'Insufficient funds: short by {shortage}')


def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError(balance, amount)

    return balance - amount


try:
    withdraw(100, 150)
except InsufficientFundsError as e:
    print(e)
    print(f'Balance: {e.balance}')
    print(f'Requested amount: {e.amount}')
```

输出：

```text
Insufficient funds: short by 50
Balance: 100
Requested amount: 150
```

这里：

|代码|作用|
|---|---|
|`self.balance`|保存异常发生时的余额|
|`self.amount`|保存请求取出的金额|
|`super().__init__(...)`|调用`Exception`的初始化方法，设置异常消息|

调用`str(e)`或直接打印异常对象时，会显示传给`Exception`的消息。

## 4、自定义异常层次

同一个业务模块可以先定义一个公共异常父类，再从它派生出更具体的异常。

```python
class WalletError(Exception):
    pass


class InvalidAmountError(WalletError):
    pass


class InsufficientFundsError(WalletError):
    pass


def withdraw(balance, amount):
    if amount <= 0:
        raise InvalidAmountError('Amount must be positive')

    if amount > balance:
        raise InsufficientFundsError('Insufficient funds')

    return balance - amount
```

调用方可以只捕获某一种具体异常：

```python
try:
    withdraw(100, 150)
except InsufficientFundsError as e:
    print(e)
```

也可以通过共同的父类处理钱包模块中的所有已知业务异常：

```python
try:
    withdraw(100, -10)
except WalletError as e:
    print(e)
```

`InvalidAmountError`和`InsufficientFundsError`都是`WalletError`的子类，因此`except WalletError`可以捕获这两种异常。

这既体现了继承对公共类型的复用，也为后面的多态奠定了基础。


# 五、多继承

## 1、多继承的基本含义

一个子类直接继承多个父类，称为多继承。

基本语法：

```python
class ParentA:
    pass


class ParentB:
    pass


class Child(ParentA, ParentB):
    pass
```

子类可以组合多个父类提供的功能。

```python
class Walker:
    def walk(self):
        return 'I can walk on land'


class Swimmer:
    def swim(self):
        return 'I can swim in water'


class Frog(Walker, Swimmer):
    def __init__(self, name):
        self.name = name

    def introduce(self):
        return f"I'm {self.name}. {self.walk()} and {self.swim()}."


frog = Frog('Freddy')

print(frog.introduce())
```

输出：

```text
I'm Freddy. I can walk on land and I can swim in water.
```

`Frog`同时继承`Walker`和`Swimmer`，因此可以调用`walk()`和`swim()`。

## 2、同名方法和方法解析顺序

多个父类拥有同名方法时，Python 会按照方法解析顺序查找要调用的方法。

方法解析顺序简称 MRO。

```python
class ParentA:
    def identify(self):
        return 'ParentA'


class ParentB:
    def identify(self):
        return 'ParentB'


class Child(ParentA, ParentB):
    pass


child = Child()

print(child.identify())
print(Child.mro())
```

输出类似：

```text
ParentA
[<class '__main__.Child'>, <class '__main__.ParentA'>, <class '__main__.ParentB'>, <class 'object'>]
```

`Child`自身没有`identify()`，Python 按照 MRO 先查找`ParentA`，因此调用`ParentA.identify()`。

父类在类定义中的排列顺序会影响 MRO：

```python
class Child(ParentA, ParentB):
    pass
```

多继承可能增加同名方法、初始化顺序和依赖关系的复杂度，因此应当在确实需要组合多类行为时使用。


# 六、多态

## 1、多态的基本含义

多态表示不同类型的对象可以通过相同的接口执行各自的行为。

多个类可以定义同名方法。外部代码只需要调用这个方法，不需要为每一种对象分别编写调用逻辑。

```python
class Cat:
    def speak(self):
        return 'Meow'


class Bird:
    def speak(self):
        return 'Tweet'


class Monkey:
    def speak(self):
        return 'Ooh ooh aah aah'


def print_sound(animal):
    print(animal.speak())


print_sound(Cat())
print_sound(Bird())
print_sound(Monkey())
```

输出：

```text
Meow
Tweet
Ooh ooh aah aah
```

`print_sound()`不需要判断参数是猫、鸟还是猴子，只要求传入的对象具有`speak()`方法。

同一个函数调用相同的方法，不同对象却产生不同结果，这就是多态。

## 2、鸭子类型

Python 常通过鸭子类型实现多态。

鸭子类型关注对象能做什么，而不是对象具体属于哪个类。

只要一个对象提供了所需的方法，就可以在相同的代码中使用它。

下面使用不同通知方式演示统一接口：

```python
class EmailNotifier:
    def __init__(self, address):
        self.address = address

    def send(self, message):
        return f'Email sent to {self.address}: {message}'


class SmsNotifier:
    def __init__(self, phone_number):
        self.phone_number = phone_number

    def send(self, message):
        return f'SMS sent to {self.phone_number}: {message}'


class ConsoleNotifier:
    def send(self, message):
        return f'Console message: {message}'


def notify(notifier, message):
    print(notifier.send(message))


email = EmailNotifier('alice@example.com')
sms = SmsNotifier('13800000000')
console = ConsoleNotifier()

notify(email, 'The task is complete')
notify(sms, 'The task is complete')
notify(console, 'The task is complete')
```

输出：

```text
Email sent to alice@example.com: The task is complete
SMS sent to 13800000000: The task is complete
Console message: The task is complete
```

这三个类没有共同父类，但都提供了`send()`方法，所以`notify()`可以用同一种方式处理它们。

鸭子类型不要求对象之间存在继承关系。

## 3、基于继承的多态

多态也可以通过继承和方法重写实现。

父类定义统一方法，多个子类分别重写这个方法。

```python
class Animal:
    def speak(self):
        return 'Some generic sound'


class Cat(Animal):
    def speak(self):
        return 'Meow'


class Dog(Animal):
    def speak(self):
        return 'Woof'


class Monkey(Animal):
    def speak(self):
        return 'Ooh ooh aah aah'


animals = [Cat(), Dog(), Monkey()]

for animal in animals:
    print(animal.speak())
```

输出：

```text
Meow
Woof
Ooh ooh aah aah
```

循环不需要知道每个元素的具体子类，只需要调用统一的`speak()`方法。

Python 会根据当前对象的实际类型，选择对应子类中的方法。

## 4、多态如何复用代码

没有多态时，可能需要根据对象类型编写多个条件分支：

```python
if isinstance(notifier, EmailNotifier):
    # 处理邮件通知
    pass
elif isinstance(notifier, SmsNotifier):
    # 处理短信通知
    pass
```

使用统一的`send()`接口后，调用代码只需要写一次：

```python
def notify(notifier, message):
    print(notifier.send(message))
```

以后增加新的通知类时，只要它提供`send()`方法，通常不需要修改`notify()`。

因此，多态可以减少类型判断和重复分支，让程序更容易扩展。


# 七、名称改写

## 1、名称改写的基本含义

在类中，以双下划线开头、但不以双下划线结尾的成员会触发名称改写。

Python 会在内部把名称`__attribute`改写为`_ClassName__attribute`。

```python
class Example:
    def __init__(self):
        self._internal = 'Internal attribute'
        self.__private = 'Name-mangled attribute'


example = Example()

print(example._internal)
print(example.__dict__)
```

输出：

```text
Internal attribute
{'_internal': 'Internal attribute', '_Example__private': 'Name-mangled attribute'}
```

`__dict__`是保存对象实例属性的字典。

从输出可以看到，代码中的`__private`实际保存为`_Example__private`。

## 2、名称改写不是绝对私有

使用原名称从类外部访问会抛出异常：

```python
print(example.__private)
```

输出类似：

```text
AttributeError: 'Example' object has no attribute '__private'
```

但是，仍然可以使用改写后的名称访问这个属性：

```python
print(example._Example__private)
```

输出：

```text
Name-mangled attribute
```

因此，名称改写不是严格的安全或权限机制，也不能保证属性绝对无法从外部访问。

外部代码不应该依赖改写后的名称，因为它属于类的内部实现。

## 3、名称改写和继承

名称改写的主要用途是避免子类意外覆盖父类中的同名成员。

```python
class Parent:
    def __init__(self):
        self.__data = 'Parent data'


class Child(Parent):
    def __init__(self):
        super().__init__()
        self.__data = 'Child data'


child = Child()

print(child.__dict__)
```

输出：

```text
{'_Parent__data': 'Parent data', '_Child__data': 'Child data'}
```

父类中的`__data`被改写为`_Parent__data`，子类中的`__data`被改写为`_Child__data`。

它们是两个不同的属性，因此子类不会意外覆盖父类的数据。

## 4、不使用名称改写时

如果父类和子类使用相同的普通属性名，子类赋值会覆盖父类创建的属性值。

```python
class Parent:
    def __init__(self):
        self.data = 'Parent data'


class Child(Parent):
    def __init__(self):
        super().__init__()
        self.data = 'Child data'


child = Child()

print(child.__dict__)
```

输出：

```text
{'data': 'Child data'}
```

父类先把`data`设置为`'Parent data'`，子类随后给同一个属性赋值，原来的值被覆盖。

## 5、单下划线和双下划线的选择

单下划线和双下划线表达不同的设计意图：

|写法|含义|常见用途|
|---|---|---|
|`name`|公共成员|类对外提供的稳定接口|
|`_name`|内部成员的命名约定|提醒外部代码不要直接依赖|
|`__name`|触发名称改写|避免子类意外覆盖父类成员|

一般情况下，内部成员使用单下划线已经足够。

当一个类可能被继承，并且确实需要降低子类成员与父类成员发生名称冲突的风险时，可以考虑使用双下划线。

双下划线不应仅仅为了模拟其他语言中的私有属性而滥用。


# 八、继承和多态的选择原则

## 1、继承表示“是一种”关系

继承应当表达合理的类型关系。

例如：

- 狗是一种动物
- 开发者是一种员工
- 圆是一种图形

如果两个类只是碰巧具有相似代码，却不存在合理的类型关系，不一定适合使用继承。

## 2、优先复用接口而不是依赖具体类型

多态让调用代码依赖统一接口，而不是依赖某个具体类。

例如，通知函数只关心对象是否提供`send()`方法：

```python
def notify(notifier, message):
    print(notifier.send(message))
```

这样既可以传入已有通知对象，也可以在以后添加新的通知方式。

## 3、继承和多态的关系

继承与多态经常一起使用，但它们不是同一个概念。

|概念|关注的问题|
|---|---|
|继承|如何复用和扩展已有类的属性与方法|
|多态|如何通过相同接口操作不同类型的对象|

继承可以实现多态，但 Python 的鸭子类型也允许没有继承关系的类表现出多态行为。

合理使用继承可以减少重复代码，合理使用多态可以减少类型判断。两者结合能够让程序结构更清晰，也更容易扩展。
