
# 一、变量的声明

在 Python 中，变量就像一个带标签的盒子，用于存储和引用不同类型的数据。

在 Python 中声明变量，只需要用赋值操作符（`=`）将一个值赋值给标识符即可。

示例：

```python
name = 'Tom'
age = 25
```

上例中，变量`name`保存了值`'Tom'`，这个值是一个字符串。字符串用**单引号**和**双引号**书写，例如`'Tom'`和`"Tom"`。

变量命名规则：

1. 变量名只能包含字母（`a~z`、`A~Z`）、数字（`0~9`）和下划线（`_`）
2. 变量名只能以字母和下划线开头，不能以数字开头
3. 变量名大小写敏感，因此`name`和`NAME`是不同的变量名
4. 变量名不能是 Python 的保留关键字，例如`if`、`class`、`def`等

如果违反这些规则，Python 程序会抛出一个`SyntaxError`：

![[assets/Pasted image 20260615211152.png|200]]

除了上述必要规则外，还有一些 Python 变量的常见命名约定：

1. 变量名应全部小写，多个单词使用下划线隔开（蛇形命名法）
2. 变量名取名要见名知意，使用描述性名称
3. 避免使用单字母变量名

# 二、Python注释

## 1、注释的作用

注释是写给人看的说明文字，解释代码意图、关键逻辑、注意事项或临时标记。

Python 解释器执行代码时会忽略注释内容，注释不会参与程序运行。

## 2、单行注释

在 Python 中，单行注释以`#`开头，Python 解释器会忽略 `#`之后的所有内容。

```python
# 用户姓名
name = "Alice"
age = 18 # 用户年龄
```

行尾注释适合写非常短的补充说明。如果说明较长，通常单独写在上一行更清晰。

## 3、多行注释

Python 没有专门的多行注释语法。

如果需要写多行说明，通常连续使用多个`#`：

```python
# 这是
# 多行
# 注释
```

# 三、print函数

在 Python 中，可以使用 `print` 函数将数据打印到终端。

示例：

```python
print('Hello world!') # 打印 Hello world!
```

后续将学习到更多关于 Python 中的字符串和函数。现在只需知道字符串是由单引号`'`或双引号`"`包围的一系列字符。

也可以使用 `print` 函数通过**逗号**分隔一次显示多值或多个参数。

示例：

```python
print("我最喜欢的动物是：", "狗")
```

输出：

```text
我最喜欢的动物是： 狗
```

使用逗号分隔每个项时，Python 会自动在它们之间添加一个**空格**。这在想要一起打印多条信息时非常有用。

# 四、数据类型

## 1、动态类型语言

使用 Python 变量之前，理解数据类型非常重要。

简单来说，数据类型描述了变量所保存值的种类。例如，一个数字、一段文本和列表项。

Python 和 JavaScript 一样，属于**动态类型语言**。这意味着无需明确指定变量的类型即可定义变量，Python 会根据你为变量赋的值判断该变量的数据类型。

示例：

```python
name = "Alice" # Python 推断类型是字符串
age = 18 # Python 推断类型为整型
```

这和C、C++等静态类型语言完全不同，它们必须为变量指定类型。

Python 的动态类型特性使得编码速度更快、更灵活。不过，这也可能引发一些意外错误，因为类型错误只有在程序运行时才能被检测出来，而在程序编译时则无法发现。

由于 Python 是在程序运行时才确定数据类型的，因此与类型相关的错误也只有在程序运行时才能被发现。当程序运行时，Python 会逐行执行代码。如果遇到某一行中，某个对象的行为不符合预期，Python 就会停止执行并显示错误信息。


## 2、常见数据类型

### （1）整数

整数：没有小数的数字，例如 `10` 或 `-5` 。

```python
my_integer_var = 10
print('Integer:', my_integer_var)
```

### （2）浮点数

浮点数：带小数点的数字。例如`3.14`。

```python
my_float_var = 3.14  
print("Float:", my_float_var)
```


### （3）字符串

字符串：用单引号或双引号括起来的字符序列，例如`'Hello world!'` 。

```python
my_string_var = "hello"  
print("String:", my_string_var)
```

### （4）布尔值

布尔值：一种表示“真”或“假”的数据类型，只有两个值`True`和`False`。

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) 
```


### （5）列表

列表：一种有序的元素集合，可以容纳不同类型的数据。例如`[10, "Hello", 3.14]`。

```python
my_list_var = [10, "Hello", 3.14]  
print("List:", my_list_var)
```

### （6）元组

元组：一种不可变的有序集合，用括号括起来。例如`(10, False, 3.14)`。

```python
my_tuple_var = (10, False, 3.14)
print("Tuple:", my_tuple_var)
```

### （7）字典

字典：用大括号括起来的键值对集合，比如`{'name': 'Tom', 'age': 25}`。

```python
my_dictionary_var = {'name': 'Tom', 'age': 25}
print('Dictionary:', my_dictionary_var) 
```

### （8）集合

集合：由多个唯一元素组成的无序组合，例如`{10, 3.14, True}`。

```python
my_set_var = {10, 3.14, True}  
print("Set:", my_set_var)
```

> 集合的打印顺序不一定按照值的声明顺序

### （9）范围

Range：一组数字，常用于循环中，例如`range(5)`。

```python
my_range_var = range(5)  
print("Range:", my_range_var)
```

### （10）None

None：一个特殊值，表示没有对应的数值。

```python
my_none_var = None
print('None:', my_none_var) # None: None
```

# 五、查看变量的类型

## 1、type()

`type()`用来查看变量的类型。

示例：

```python
name = 'Tom'  
age = 25  
  
print(type(name))  
print(type(age))
```

## 2、isinstance()

在编程中，在对某个变量操作之前，有时需要确认该变量的类型是否与预期相符合，这时可以使用`isinstance()`函数。

错误示例：

```python
number = '100'  
print(number / 10)
```

`number`是字符串类型，但这里却错误使用了数字除法运算，报错：

![[assets/Pasted image 20260615220914.png|300]]

要判断 `number` 是否为整数，可以使用 `isinstance()` 函数来进行检查，操作方式如下：

```python
number = '100'  
print(isinstance(number,int))
```

结果为`False`。

内置的 `isinstance()` 函数可用于判断某个变量是否属于某种特定的数据类型。该函数接受一个对象以及用于判断的类型作为参数，然后返回一个布尔值。

`isinstance()`函数还允许你同时检查多种类型的数据：

```python
number = '100'  
print(isinstance(number,(int,float,str)))
```

这里返回`True`，因为`number`符合`str`。
