# 一、哈希集合类型

Python 内置了两种常用的哈希集合类型：`dict`和`set`。

|类型|中文名称|存储内容|主要用途|
|---|---|---|---|
|`dict`|字典|`key-value`键值对|根据`key`快速查找`value`|
|`set`|集合|不重复元素|去重、成员判断、集合运算|

`dict`和`set`的底层都依赖哈希机制，因此查找速度通常很快。

但也正因为如此，它们对元素有一个重要要求：

> `dict`的`key`和`set`中的元素必须是可哈希对象，通常也就是不可变对象。


# 二、字典

## 1、字典的基本含义

`dict`全称是 dictionary，中文通常叫字典。

字典使用`key-value`形式存储数据。可以通过`key`快速找到对应的`value`。

示例：

```python
student = {
    'name': 'Tom',
    'age': 18,
    'score': 95,
}
```

这里`'name'`、`'age'`、`'score'`是`key`，对应的`'Tom'`、`18`、`95`是`value`。

## 2、创建字典

最常见的方式是使用花括号`{}`创建字典。

```python
scores = {
    'Michael': 95,
    'Bob': 75,
    'Tracy': 85,
}

print(scores)
```

也可以使用`dict()`构造函数。

```python
scores = dict([
    ('Michael', 95),
    ('Bob', 75),
    ('Tracy', 85),
])

print(scores)
```

输出：

```text
{'Michael': 95, 'Bob': 75, 'Tracy': 85}
```

现代 Python 中，`dict`会保留键值对的插入顺序。

## 3、访问和修改元素

可以使用方括号根据`key`访问对应的`value`。

```python
scores = {
    'Michael': 95,
    'Bob': 75,
    'Tracy': 85,
}

print(scores['Bob'])
```

输出：

```text
75
```

如果访问不存在的`key`，会抛出`KeyError`。

```python
print(scores['Adam'])
```

报错：

```text
KeyError: 'Adam'
```

可以通过赋值修改已有`key`对应的值。

```python
scores['Bob'] = 80

print(scores['Bob'])
```

输出：

```text
80
```

如果`key`不存在，赋值会新增一个键值对。

```python
scores['Adam'] = 67

print(scores)
```

输出：

```text
{'Michael': 95, 'Bob': 80, 'Tracy': 85, 'Adam': 67}
```

字典的`key`必须唯一。如果重复写入同一个`key`，后面的值会覆盖前面的值。

## 4、get()

`get()`用于根据`key`获取值。

和方括号访问不同，`get()`在`key`不存在时不会报错，而是返回`None`或指定的默认值。

```python
scores = {
    'Michael': 95,
    'Bob': 75,
}

print(scores.get('Michael'))
print(scores.get('Adam'))
print(scores.get('Adam', 0))
```

输出：

```text
95
None
0
```

当不确定某个`key`是否存在时，`get()`通常比方括号访问更稳妥。

## 5、keys()、values()和items()

`keys()`返回所有`key`组成的视图对象。

```python
student = {
    'name': 'Tom',
    'age': 18,
    'score': 95,
}

print(student.keys())
```

输出：

```text
dict_keys(['name', 'age', 'score'])
```

`values()`返回所有`value`组成的视图对象。

```python
print(student.values())
```

输出：

```text
dict_values(['Tom', 18, 95])
```

`items()`返回所有键值对组成的视图对象。

```python
print(student.items())
```

输出：

```text
dict_items([('name', 'Tom'), ('age', 18), ('score', 95)])
```

视图对象可以理解为查看字典内容的一种方式，它不是普通列表。如果需要列表，可以使用`list()`转换。

## 6、删除和更新元素

`pop()`用于删除指定`key`对应的键值对，并返回被删除的`value`。

```python
scores = {
    'Michael': 95,
    'Bob': 75,
    'Tracy': 85,
}

score = scores.pop('Bob')

print(score)
print(scores)
```

输出：

```text
75
{'Michael': 95, 'Tracy': 85}
```

如果`key`不存在，`pop(key)`会抛出`KeyError`。可以传入默认值避免报错。

```python
score = scores.pop('Adam', None)

print(score)
```

输出：

```text
None
```

`popitem()`用于删除最后插入的键值对，并返回这个键值对。

```python
scores = {
    'Michael': 95,
    'Bob': 75,
    'Tracy': 85,
}

item = scores.popitem()

print(item)
print(scores)
```

输出：

```text
('Tracy', 85)
{'Michael': 95, 'Bob': 75}
```

`update()`用于用另一个字典更新当前字典。

```python
student = {
    'name': 'Tom',
    'age': 18,
}

student.update({
    'age': 19,
    'city': 'Beijing',
})

print(student)
```

输出：

```text
{'name': 'Tom', 'age': 19, 'city': 'Beijing'}
```

如果`key`已经存在，会覆盖旧值；如果`key`不存在，会新增键值对。

`clear()`用于清空字典。

```python
student.clear()

print(student)
```

输出：

```text
{}
```


# 三、字典遍历

## 1、遍历key

直接遍历字典时，默认遍历的是`key`。

```python
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
}

for product in products:
    print(product)
```

输出：

```text
Laptop
Smartphone
Tablet
```

也可以明确写成：

```python
for product in products.keys():
    print(product)
```

## 2、遍历value

如果只需要值，可以遍历`values()`。

```python
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
}

for price in products.values():
    print(price)
```

输出：

```text
990
600
250
```

## 3、遍历键值对

如果需要同时拿到`key`和`value`，可以遍历`items()`。

```python
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
}

for product, price in products.items():
    print(product, price)
```

输出：

```text
Laptop 990
Smartphone 600
Tablet 250
```

`items()`返回的是键值对，循环中的`product, price`本质上是在做元组解包。

例如，给所有商品打八折：

```python
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
    'Headphones': 70,
}

for product, price in products.items():
    products[product] = round(price * 0.8)

print(products)
```

输出：

```text
{'Laptop': 792, 'Smartphone': 480, 'Tablet': 200, 'Headphones': 56}
```

这里是在修改已有`key`对应的`value`。遍历字典时，不建议一边遍历一边新增或删除`key`，否则容易导致逻辑混乱，甚至触发运行时错误。

## 4、配合enumerate()

如果遍历字典时还需要计数，可以配合`enumerate()`。

```python
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
}

for index, product in enumerate(products, 1):
    print(index, product)
```

输出：

```text
1 Laptop
2 Smartphone
3 Tablet
```

也可以对`items()`使用`enumerate()`。

```python
for index, (product, price) in enumerate(products.items(), 1):
    print(index, product, price)
```

输出：

```text
1 Laptop 990
2 Smartphone 600
3 Tablet 250
```


# 四、集合

## 1、集合的基本含义

`set`是一组不重复元素的集合。

集合是**可变的、无序**的，因此不能通过索引访问元素。

示例：

```python
numbers = {1, 2, 3, 4, 5}

print(numbers)
```

输出可能是：

```text
{1, 2, 3, 4, 5}
```

集合不保证元素显示顺序，实际输出顺序不应该作为程序逻辑依据。

## 2、创建集合

可以使用花括号`{}`创建非空集合。

```python
numbers = {1, 2, 3}

print(numbers)
```

但如果需要创建空集合，必须使用`set()`。

```python
empty_set = set()
empty_dict = {}

print(type(empty_set))
print(type(empty_dict))
```

输出：

```text
<class 'set'>
<class 'dict'>
```

`{}`创建的是空字典，不是空集合。

也可以使用`set()`把其他可迭代对象转换为集合。

```python
numbers = [1, 1, 2, 2, 3, 3]

unique_numbers = set(numbers)

print(unique_numbers)
```

输出可能是：

```text
{1, 2, 3}
```

这常用于去重，但转换为集合后通常不会保留原来的顺序。

## 3、添加和删除元素

`add()`用于添加元素。

```python
numbers = {1, 2, 3}

numbers.add(4)
numbers.add(4)

print(numbers)
```

输出可能是：

```text
{1, 2, 3, 4}
```

重复添加已有元素不会产生变化。

`remove()`和`discard()`都可以删除元素。

```python
numbers = {1, 2, 3, 4}

numbers.remove(4)

print(numbers)
```

输出可能是：

```text
{1, 2, 3}
```

区别是：`remove()`删除不存在的元素时会抛出`KeyError`，`discard()`不会报错。

```python
numbers = {1, 2, 3}

numbers.discard(4)

print(numbers)
```

输出可能是：

```text
{1, 2, 3}
```

`clear()`用于清空集合。

```python
numbers.clear()

print(numbers)
```

输出：

```text
set()
```

## 4、成员判断

`set`很适合做成员判断。

```python
allowed_users = {'Tom', 'Jerry', 'Alice'}

print('Tom' in allowed_users)
print('Bob' in allowed_users)
```

输出：

```text
True
False
```

当只关心“某个元素是否存在”，而不关心顺序和重复次数时，`set`通常比`list`更合适。


# 五、集合运算

## 1、并集、交集和差集

`set`支持数学意义上的集合运算。

示例：

```python
a = {1, 2, 3, 4, 5}
b = {2, 3, 4, 6}
```

并集表示两个集合中的所有元素。

```python
print(a | b)
```

输出可能是：

```text
{1, 2, 3, 4, 5, 6}
```

交集表示两个集合共有的元素。

```python
print(a & b)
```

输出可能是：

```text
{2, 3, 4}
```

差集表示存在于左边集合，但不存在于右边集合的元素。

```python
print(a - b)
print(b - a)
```

输出可能是：

```text
{1, 5}
{6}
```

## 2、对称差集

对称差集表示只存在于其中一个集合，而不是两个集合共有的元素。

```python
a = {1, 2, 3, 4, 5}
b = {2, 3, 4, 6}

print(a ^ b)
```

输出可能是：

```text
{1, 5, 6}
```

常见集合运算如下：

|运算|符号|方法|
|---|---|---|
|并集|`a \| b`|`a.union(b)`|
|交集|`a & b`|`a.intersection(b)`|
|差集|`a - b`|`a.difference(b)`|
|对称差集|`a ^ b`|`a.symmetric_difference(b)`|

这些运算都有对应的复合赋值形式：

```python
|=  &=  -=  ^=
```

例如：

```python
a = {1, 2, 3, 4, 5}
b = {2, 3, 4, 6}

a -= b

print(a)
```

输出可能是：

```text
{1, 5}
```

## 3、集合关系判断

`issubset()`用于判断一个集合是否是另一个集合的子集。

`issuperset()`用于判断一个集合是否是另一个集合的超集。

`isdisjoint()`用于判断两个集合是否没有任何共同元素。

```python
a = {1, 2, 3, 4, 5}
b = {2, 3, 4, 6}
c = {7, 8}

print(b.issubset(a))
print(a.issuperset(b))
print(a.isdisjoint(c))
```

输出：

```text
False
False
True
```


# 六、可哈希对象

`dict`的`key`和`set`中的元素必须是可哈希对象。

Python 可以通过 `hash()` 计算对象的哈希值：

```python
print(hash(10))  
print(hash('hello'))  
print(hash((1, 2, 3)))
```

一个对象通常满足两个条件，才算可哈希：

- 在对象生命周期内，哈希值不能改变
- 两个相等的对象，哈希值必须相同

也就是：

```python
a == b
```

成立时，必须保证：

```python
hash(a) == hash(b)
```

`dict` 和 `set` 会根据哈希值决定对象存放和查找的位置。

假设一个对象作为字典键存入后，它的内容发生了改变，哈希值也随之改变，那么字典无法按照原来的位置找到它。

示例：

```python
data = {}  
  
key = [1, 2]  
data[key] = 'value'
```

运行报错：

```text
TypeError: unhashable type: 'list'
```

常见可哈希对象：

|类型|示例|
|---|---|
|`str`|`'name'`|
|`int`|`1001`|
|`float`|`3.14`|
|`bool`|`True`|
|`tuple`|`('Tom', 18)`|

常见不可哈希对象：

|类型|原因|
|---|---|
|`list`|可变|
|`dict`|可变|
|`set`|可变|

例如，列表不能作为字典的`key`：

```python
data = {
    ['Tom', 18]: 'student'
}
```

报错：

```text
TypeError: cannot use 'tuple' as a dict key (unhashable type: 'list')
```

`tuple`只有在内部元素也都可哈希时，才能作为`dict`的`key`或`set`的元素。

```python
data = {
    ('Tom', 18): 'student'
}

print(data[('Tom', 18)])
```

输出：

```text
student
```

如果`tuple`内部包含列表，它仍然不可哈希。

```python
data = {
    ('Tom', [18]): 'student'
}
```

报错：

```text
TypeError: unhashable type: 'list'
```

简单来说：如果一个对象作为`dict`的`key`或`set`的元素，它必须在哈希意义上保持稳定。

可哈希对象一般是不可变对象，并不意味着不可变对象一定可哈希，典型例子就是元组。只有元组的元素都是可哈希，元组本身才是可哈希对象。
