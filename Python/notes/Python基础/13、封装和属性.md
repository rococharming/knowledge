# 一、面向对象编程和封装

## 1、面向对象编程的基本含义

面向对象编程简称 OOP，是一种以对象组织程序的编程方式。

类是创建对象的模板。对象是根据类创建出的具体实例。

每个对象通常包含两类成员：

|成员|作用|
|---|---|
|属性|保存对象的数据和状态|
|方法|定义对象可以执行的行为|

例如，可以定义一个`Car`类：

```python
class Car:
    def __init__(self, brand, color):
        self.brand = brand
        self.color = color

    def describe(self):
        return f'This is a {self.color} {self.brand}'

car = Car('Toyota', 'red')

print(car.brand)
print(car.describe())
```

输出：

```text
Toyota
This is a red Toyota
```

面向对象编程通常包含四个重要原则：

|原则|基本含义|
|---|---|
|封装|把数据和操作数据的方法组织在一起，并控制数据的访问方式|
|继承|在已有类的基础上创建新类|
|多态|让不同类型的对象以统一方式响应相同操作|
|抽象|隐藏不必要的实现细节，只展示重要接口|

## 2、封装的基本含义

封装是把对象的数据和操作这些数据的方法组合在一个类中，并通过清晰的接口控制外部代码如何访问和修改对象的状态。

例如，钱包的余额不应该被随意修改。存款和取款应当通过方法完成：

```python
class Wallet:
    def __init__(self, balance=0):
        self._balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError('Amount must be positive')
        self._balance += amount

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError('Amount must be positive')
        if amount > self._balance:
            raise ValueError('Insufficient funds')
        self._balance -= amount

    def get_balance(self):
        return self._balance

wallet = Wallet(500)
wallet.deposit(100)
wallet.withdraw(80)

print(wallet.get_balance())
```

输出：

```text
520
```

这里，外部代码通过`deposit()`、`withdraw()`和`get_balance()`使用钱包，而不是直接操作余额。

这种设计有以下作用：

- 集中检查数据是否合法
- 防止对象进入无效状态
- 隐藏内部实现细节
- 以后修改内部实现时，减少对外部代码的影响


# 二、Python中的访问约定

## 1、公共成员

名称没有下划线前缀的属性和方法通常属于公共成员，可以从类的外部正常访问。

```python
class User:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f'Hello, {self.name}!'

user = User('Tom')

print(user.name)
print(user.greet())
```

输出：

```text
Tom
Hello, Tom!
```

`name`和`greet()`都是公共成员，它们构成了这个类对外提供的接口。

## 2、单下划线前缀

名称以单下划线开头，表示该属性或方法仅供类的内部使用。

```python
class Wallet:
    def __init__(self, balance=0):
        self._balance = balance

    def get_balance(self):
        return self._balance
```

`_balance`表示内部属性。

但是，单下划线只是一种命名约定，并不会真正阻止外部访问：

```python
wallet = Wallet(100)

print(wallet._balance)
```

输出：

```text
100
```

虽然语法允许这样访问，但通常不应该从类的外部直接操作`_balance`。

单下划线传达的意思是：这个成员属于内部实现，外部代码不应依赖它。

## 3、双下划线前缀

名称以双下划线开头时，Python 会对名称进行改写，这个过程称为名称改写。

```python
class Wallet:
    def __init__(self, balance=0):
        self.__balance = balance

    def get_balance(self):
        return self.__balance

wallet = Wallet(100)

print(wallet.get_balance())
```

输出：

```text
100
```

如果直接使用原名称访问，会抛出异常：

```python
print(wallet.__balance)
```

输出类似：

```text
AttributeError: 'Wallet' object has no attribute '__balance'
```

Python 会在类的内部把`__balance`改写为类似`_Wallet__balance`的名称。

双下划线的主要作用是避免子类意外覆盖父类中的同名成员，而不是提供绝对安全的私有机制。

外部代码仍然可能通过改写后的名称访问它，因此 Python 的封装主要依靠接口设计和命名约定，而不是强制访问权限。

## 4、私有方法

双下划线也可以用于方法名称。

```python
class Wallet:
    def __init__(self):
        self.__balance = 0

    def __validate_amount(self, amount):
        if amount <= 0:
            raise ValueError('Amount must be positive')

    def deposit(self, amount):
        self.__validate_amount(amount)
        self.__balance += amount

    def withdraw(self, amount):
        self.__validate_amount(amount)
        if amount > self.__balance:
            raise ValueError('Insufficient funds')
        self.__balance -= amount

    def get_balance(self):
        return self.__balance

wallet = Wallet()
wallet.deposit(50)
wallet.withdraw(20)

print(wallet.get_balance())
```

输出：

```text
30
```

`__validate_amount()`只负责类内部的金额校验，不属于类对外提供的接口。


# 三、Getter和Setter

## 1、Getter和Setter的基本含义

Getter 是读取属性值的方法，Setter 是修改属性值的方法。

它们可以在访问或修改数据时执行额外逻辑。

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    def get_radius(self):
        return self._radius

    def set_radius(self, value):
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value

circle = Circle(3)

print(circle.get_radius())

circle.set_radius(8)
print(circle.get_radius())
```

输出：

```text
3
8
```

Setter 不只是完成赋值，还可以在保存数据前检查新值是否合法。

## 2、普通Getter和Setter的不足

使用普通方法时，读取和修改属性都需要调用方法：

```python
circle.get_radius()
circle.set_radius(8)
```

这种写法可以正常工作，但不如普通属性的点语法简洁：

```python
circle.radius
circle.radius = 8
```

Python 可以通过 Property 属性让点语法在背后自动调用 Getter 和 Setter。


# 四、Property属性

## 1、@property装饰器

在方法上方添加`@property`装饰器，可以把这个方法转换为属性的 Getter。

属性在外部看起来像普通属性，但访问时会在内部执行方法。

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

circle = Circle(3)

print(circle.radius)
```

输出：

```text
3
```

访问`circle.radius`时不需要写圆括号，但 Python 实际执行了`radius()`方法。

## 2、只读属性

只有 Getter、没有 Setter 的属性是只读属性。

属性也可以在读取时动态计算结果：

```python
import math


class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @property
    def area(self):
        return math.pi * self._radius ** 2

circle = Circle(3)

print(circle.radius)
print(round(circle.area, 2))
```

输出：

```text
3
28.27
```

`area`没有单独保存结果，而是在每次访问时根据半径进行计算。

如果尝试给没有 Setter 的属性赋值，会抛出`AttributeError`：

```python
circle.area = 100
```

## 3、定义Setter

定义 Setter 时，方法名必须与属性名相同，并使用`@属性名.setter`装饰器。

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value

circle = Circle(3)

print(circle.radius)

circle.radius = 8
print(circle.radius)
```

输出：

```text
3
8
```

执行下面的语句时：

```python
circle.radius = 8
```

Python 会自动调用`radius`属性的 Setter，并把`8`传给`value`。

## 4、在初始化方法中使用Setter

在`__init__()`中通过属性赋值，可以让对象创建时也执行 Setter 中的验证逻辑。

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value
```

创建半径无效的对象时，会立即抛出异常：

```python
circle = Circle(-3)
```

输出类似：

```text
ValueError: Radius must be positive
```

这样可以保证对象从创建开始就处于有效状态。

## 5、避免Setter无限递归

在 Setter 内部不能再次给同名属性赋值：

```python
@radius.setter
def radius(self, value):
    self.radius = value
```

`self.radius = value`会再次调用当前 Setter，Setter 又会执行同一条赋值语句，最终导致无限递归并抛出`RecursionError`。

Setter 应当把数据保存到另一个内部属性中：

```python
@radius.setter
def radius(self, value):
    self._radius = value
```

这里：

|名称|作用|
|---|---|
|`radius`|对外公开的属性|
|`_radius`|在类内部实际保存数据的属性|

## 6、定义Deleter

Deleter 可以控制使用`del`删除属性时执行的逻辑。

定义 Deleter 时，使用`@属性名.deleter`装饰器。

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value

    @radius.deleter
    def radius(self):
        print('Deleting radius...')
        del self._radius

circle = Circle(3)

del circle.radius
```

输出：

```text
Deleting radius...
```

执行`del circle.radius`时，Python 会自动调用`radius`属性的 Deleter。

删除内部属性后，如果再次访问`circle.radius`，会因为`_radius`不存在而抛出`AttributeError`。


# 五、封装的完整示例

## 1、使用Property封装余额

可以把余额定义为只读属性，把余额的修改限制在存款和取款方法中。

```python
class Wallet:
    def __init__(self, balance=0):
        if balance < 0:
            raise ValueError('Initial balance cannot be negative')
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    def _validate_amount(self, amount):
        if amount <= 0:
            raise ValueError('Amount must be positive')

    def deposit(self, amount):
        self._validate_amount(amount)
        self._balance += amount

    def withdraw(self, amount):
        self._validate_amount(amount)
        if amount > self._balance:
            raise ValueError('Insufficient funds')
        self._balance -= amount

wallet = Wallet(500)

wallet.deposit(150)
wallet.withdraw(80)

print(wallet.balance)
```

输出：

```text
570
```

在这个类中：

|成员|作用|
|---|---|
|`balance`|只读属性，对外提供余额|
|`_balance`|内部保存的真实余额|
|`deposit()`|公共方法，安全地存款|
|`withdraw()`|公共方法，安全地取款|
|`_validate_amount()`|内部方法，统一验证金额|

因为`balance`没有 Setter，不能通过下面的方式直接修改余额：

```python
wallet.balance = 1000000
```

输出类似：

```text
AttributeError: property 'balance' of 'Wallet' object has no setter
```

## 2、选择方法还是Property

方法和 Property 都可以隐藏内部实现，但适合的场景不同。

|场景|推荐方式|
|---|---|
|读取或设置对象的一项数据|Property|
|读取时需要进行简单计算|只读 Property|
|执行存款、取款等明确动作|普通方法|
|操作可能耗时较长或产生明显副作用|普通方法|
|操作需要多个参数|普通方法|

例如，`circle.area`表示圆的一项数据，适合使用 Property。

`wallet.deposit(100)`表示执行一次存款动作，适合使用普通方法。

## 3、封装的核心原则

封装并不是简单地给所有属性加上下划线，而是为对象设计稳定、清晰的公共接口。

通常可以遵循以下原则：

- 对外只公开使用对象所需的成员
- 内部实现使用单下划线表示不建议外部访问
- 通过方法或 Property 集中执行验证逻辑
- 保证对象始终处于有效状态
- 不要让外部代码依赖容易变化的内部细节

良好的封装让外部代码只关心对象能做什么，而不必了解对象内部如何完成这些操作。
