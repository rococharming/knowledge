# 一、类和对象

## 1、类的基本含义

类可以理解为创建对象的模板。

类定义一类对象应该具有的数据和行为。对象则是根据类创建出来的具体实例。

例如，可以定义一个`Dog`类，用它创建不同的狗对象：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f"{self.name.upper()} says woof woof! I'm {self.age} years old!")
```

其中：

|部分|含义|
|---|---|
|`class Dog`|定义一个名为`Dog`的类|
|`__init__()`|对象创建时自动调用的初始化方法|
|`self.name`|对象自己的属性|
|`bark()`|对象可以调用的方法|

类名通常使用`PascalCase`命名，也就是每个单词首字母大写，例如`Dog`、`BankAccount`。

## 2、创建对象

根据类创建对象，也称为实例化。

示例：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f"{self.name.upper()} says woof woof! I'm {self.age} years old!")

dog_1 = Dog('Jack', 3)
dog_2 = Dog('Thatcher', 5)

dog_1.bark()
dog_2.bark()
```

输出：

```text
JACK says woof woof! I'm 3 years old!
THATCHER says woof woof! I'm 5 years old!
```

`Dog`是类，`dog_1`和`dog_2`是对象。

它们来自同一个类，但拥有各自不同的`name`和`age`。

## 3、self

`self`表示当前正在被创建或使用的对象。

在实例方法中，`self`通常作为第一个参数。

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        return f'{self.name} says woof woof!'
```

调用方法时，不需要手动传入`self`：

```python
dog = Dog('Jack')

print(dog.bark())
```

输出：

```text
Jack says woof woof!
```

这里调用`dog.bark()`时，Python 会自动把`dog`这个对象传给`self`。


# 二、属性和方法

## 1、实例属性

属性是属于对象的数据。

实例属性通常在`__init__()`中通过`self`设置。不同对象可以拥有不同的实例属性值。

示例：

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

car_1 = Car('red', 'Toyota Corolla')
car_2 = Car('green', 'Lamborghini Revuelto')

print(car_1.model)
print(car_2.model)
print(car_1.color)
print(car_2.color)
```

输出：

```text
Toyota Corolla
Lamborghini Revuelto
red
green
```

可以通过点语法访问对象属性：

```python
对象.属性名
```

## 2、类属性

类属性属于类本身，并被该类创建出的对象共享。

示例：

```python
class Dog:
    species = 'French Bulldog'

    def __init__(self, name):
        self.name = name

dog_1 = Dog('Jack')
dog_2 = Dog('Tom')

print(Dog.species)
print(dog_1.name)
print(dog_1.species)
print(dog_2.name)
print(dog_2.species)
```

输出：

```text
French Bulldog
Jack
French Bulldog
Tom
French Bulldog
```

`species`是类属性，所有`Dog`对象都可以访问它。

`name`是实例属性，不同对象可以不同。

## 3、实例方法

方法是定义在类内部的函数。

实例方法通常通过`self`访问或修改对象自身的数据。

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

car_1 = Car('red', 'Toyota Corolla')
car_2 = Car('green', 'Lamborghini Revuelto')

print(car_1.describe())
print(car_2.describe())
```

输出：

```text
This car is a red Toyota Corolla
This car is a green Lamborghini Revuelto
```

调用实例方法时，也使用点语法：

```python
对象.方法名()
```


# 三、特殊方法

## 1、特殊方法的基本含义

特殊方法是以双下划线开头和结尾的方法，例如`__init__()`、`__len__()`、`__str__()`。

这类方法也常被称为魔术方法或 dunder 方法。

特殊方法通常不直接调用，而是在特定语法或内置函数触发时由 Python 自动调用。

例如：

| 操作             | 背后调用的方法          |
| -------------- | ---------------- |
| `a + b`        | `__add__()`      |
| `len(obj)`     | `__len__()`      |
| `str(obj)`     | `__str__()`      |
| `obj1 == obj2` | `__eq__()`       |
| `item in obj`  | `__contains__()` |
| `obj[index]`   | `__getitem__()`  |

## 2、\_\_str\_\_()、\_\_len\_\_()和__eq\_\_()

如果一个类没有定义合适的特殊方法，Python 不一定知道如何对它执行某些操作。

示例：

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book = Book('Python Notes', 300)

print(str(book))
```

输出类似：

```text
<__main__.Book object at 0x102ed2900>
```

这是对象的默认字符串表现形式，通常不适合阅读。

可以定义特殊方法，让对象更符合预期。

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book_1 = Book('Python Notes', 300)
book_2 = Book('Rust Notes', 300)

print(len(book_1))
print(str(book_1))
print(book_1 == book_2)
```

输出：

```text
300
'Python Notes' has 300 pages
True
```

这里：

- `len(book_1)`会调用`book_1.__len__()`
- `str(book_1)`会调用`book_1.__str__()`
- `book_1 == book_2`会调用`book_1.__eq__(book_2)`

实际代码中，不建议直接写`book_1.__len__()`，而应使用`len(book_1)`这种更自然的写法。

## 3、\_\_repr_\_\()和__str\_\_()

`__str__()`偏向给用户看的可读文本。

`__repr__()`偏向给开发者看的调试文本。

示例：

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __repr__(self):
        return f"Book(title={self.title!r}, pages={self.pages!r})"

    def __str__(self):
        return f"《{self.title}》共有 {self.pages} 页"

book = Book('Python Notes', 300)

print(repr(book))
print(str(book))
```

输出：

```text
Book(title='Python Notes', pages=300)
《Python Notes》共有 300 页
```

如果只定义一个，通常优先定义`__repr__()`，因为它对调试更有帮助。

## 4、让对象支持容器操作

特殊方法还可以让自定义对象像容器一样使用。

示例：

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
cart.add('Wireless mouse')
cart.add('Monitor')

for item in cart:
    print(item)

print(len(cart))
print(cart[2])
print('Monitor' in cart)
```

输出：

```text
Laptop
Wireless mouse
Monitor
3
Monitor
True
```

这里通过特殊方法，让`Cart`对象支持遍历、`len()`、索引访问和`in`成员判断。


# 四、动态属性

## 1、动态属性的基本含义

正常访问属性时，通常使用点语法。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

person = Person('John Doe', 30)

print(person.name)
print(person.age)
```

输出：

```text
John Doe
30
```

但有时属性名在程序运行时才知道，例如来自用户输入、配置文件或字典数据。此时就需要动态处理属性。

## 2、getattr()

`getattr()`用于根据字符串形式的属性名读取属性。

基本语法：

```python
getattr(object, attribute_name, default_value)
```

示例：

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

person = Person('John Doe', 30)

print(getattr(person, 'name'))
print(getattr(person, 'age'))
print(getattr(person, 'city', 'Milano'))
```

输出：

```text
John Doe
30
Milano
```

如果属性不存在，且没有传入默认值，`getattr()`会抛出`AttributeError`。

## 3、setattr()

`setattr()`用于动态创建或修改属性。

```python
class Configuration:
    pass

settings_data = {
    'server_url': 'https://api.example.com',
    'timeout_sec': 30,
    'max_retries': 5,
}

config = Configuration()

for attr_name, attr_value in settings_data.items():
    setattr(config, attr_name, attr_value)

print(config.server_url)
print(config.timeout_sec)
print(config.max_retries)
```

输出：

```text
https://api.example.com
30
5
```

## 4、hasattr()

`hasattr()`用于判断对象是否有某个属性。

```python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

product = Product('T-Shirt', 25)

required_attributes = ['name', 'price', 'inventory_id']

for attr in required_attributes:
    if not hasattr(product, attr):
        print(f"ERROR: Product is missing the required attribute: '{attr}'")
    else:
        print(f'{attr}: {getattr(product, attr)}')
```

输出：

```text
name: T-Shirt
price: 25
ERROR: Product is missing the required attribute: 'inventory_id'
```

## 5、delattr()

`delattr()`用于动态删除属性。

```python
class UserSession:
    def __init__(self, user_id, token):
        self.user_id = user_id
        self.auth_token = token
        self.temp_counter = 0

session = UserSession(101, 'a1b2c3d4e5')

for attr in ['auth_token', 'temp_counter']:
    if hasattr(session, attr):
        delattr(session, attr)
        print(f'Removed attribute: {attr}')

print(session.user_id)
```

输出：

```text
Removed attribute: auth_token
Removed attribute: temp_counter
101
```

## 6、dir()和callable()

`dir()`可以查看对象上有哪些属性名。

`callable()`用于判断一个对象是否可以像函数一样被调用。

结合这两个函数，可以遍历对象中的普通数据属性。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        return f'Hello {self.name}'

person = Person('John Doe', 30)

for attr in dir(person):
    if not attr.startswith('__') and not callable(getattr(person, attr)):
        print(f'{attr}: {getattr(person, attr)}')
```

输出：

```text
age: 30
name: John Doe
```

动态属性很灵活，但也会降低代码的直接可读性。普通场景下优先使用点语法；只有在属性名确实来自运行时数据时，再使用`getattr()`、`setattr()`这类函数。
