# 一、比较运算符

条件判断用于根据某个条件是真还是假，决定程序接下来执行哪一段代码。

在学习`if`语句之前，需要先理解比较运算符。比较运算符用于比较两个值，并返回布尔值`True`或`False`。

常见比较运算符如下：

|运算符|含义|说明|
|---|---|---|
|`==`|等于|判断两个值是否相等|
|`!=`|不等于|判断两个值是否不相等|
|`>`|大于|判断左侧值是否大于右侧值|
|`<`|小于|判断左侧值是否小于右侧值|
|`>=`|大于等于|判断左侧值是否大于或等于右侧值|
|`<=`|小于等于|判断左侧值是否小于或等于右侧值|

示例：

```python
print(3 > 4)
print(3 < 4)
print(3 == 4)
print(4 == 4)
print(3 != 4)
print(3 >= 4)
print(3 <= 4)
```

输出：

```text
False
True
False
True
True
False
True
```

这些比较表达式可以作为条件判断的条件。程序会根据表达式结果是`True`还是`False`，决定是否执行某段代码。


# 二、if语句

## 1、基本语法

`if`语句用于在条件成立时执行某段代码。

基本语法：

```python
if condition:
    pass
```

其中：

- `if`是关键字
- `condition`是一个结果为`True`或`False`的表达式
- 冒号`:`表示后面开始进入代码块
- 缩进部分是`if`语句的代码块

`pass`是一个特殊语句，执行时什么也不会发生。它常用于临时占位，因为 Python 不允许代码块为空。

## 2、缩进表示代码块

Python 使用**缩进**表示代码块。

示例：

```python
age = 18

if age >= 18:
    print('You are an adult')
```

输出：

```text
You are an adult
```

这里`print('You are an adult')`前面有缩进，表示它属于`if`代码块。只有`age >= 18`结果为`True`时，这行代码才会执行。

如果没有正确缩进，会抛出`IndentationError`：

```python
age = 18

if age >= 18:
print('You are an adult')
```

报错：

```text
IndentationError: expected an indented block after 'if' statement
```

Python 风格指南推荐每一级缩进使用**4个空格**。

## 3、条件不成立时

如果`if`条件结果为`False`，代码块就不会执行。

示例：

```python
age = 12

if age >= 18:
    print('You are an adult')
```

上面的代码不会在终端输出任何内容，因为`age >= 18`的结果是`False`。


# 三、if...else语句

`else`用于处理`if`条件不成立时的情况。

基本语法：

```python
if condition:
    pass
else:
    pass
```

示例：

```python
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet')
```

输出：

```text
You are not an adult yet
```

`if`和`else`是同一组条件分支，二者之间不能插入其他普通语句。

错误示例：

```python
age = 12

if age >= 18:
    print('You are an adult')
print('Almost there!')
else:
    print('You are not an adult yet')
```

报错：

```text
SyntaxError: invalid syntax
```

这是因为`else`必须紧跟在对应的`if`代码块之后。


# 四、if...elif...else语句

如果需要判断多个条件，可以使用`elif`。

`elif`可以理解为`else if`，表示前面的条件不成立时，再判断下一个条件。

基本语法：

```python
if condition1:
    pass
elif condition2:
    pass
else:
    pass
```

示例：

```python
age = 12

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')
else:
    print('You are a child')
```

输出：

```text
You are a child
```

程序会从上到下依次判断条件。一旦某个条件成立，就执行对应代码块，后面的分支不会再继续判断。

`elif`可以写多个：

```python
age = 2

if age >= 65:
    print('You are a senior citizen')
elif age >= 30:
    print('You are an adult in your prime')
elif age >= 18:
    print('You are a young adult')
elif age >= 13:
    print('You are a teenager')
elif age >= 3:
    print('You are a young child')
else:
    print('You are a toddler or an infant')
```

输出：

```text
You are a toddler or an infant
```

写多个`elif`时，要注意条件顺序。更具体、更优先的条件通常应该放在前面。


# 五、Truthy和Falsy

## 1、基本含义

在 Python 中，每个值放到条件判断中时，都可以被当作`True`或`False`来理解。

在逻辑上下文中被当作`True`的值，通常称为`Truthy`。

在逻辑上下文中被当作`False`的值，通常称为`Falsy`。

常见`Falsy`值如下：

|值|说明|
|---|---|
|`None`|空值|
|`False`|布尔假|
|`0`|整数0|
|`0.0`|浮点数0|
|`""`|空字符串|

非零数字和非空字符串通常都是`Truthy`。

## 2、bool()

可以使用`bool()`函数查看一个值对应的布尔结果。

示例：

```python
print(bool(False))
print(bool(0))
print(bool(''))

print(bool(True))
print(bool(1))
print(bool('Hello'))
```

输出：

```text
False
False
False
True
True
True
```

因此，`if`后面不一定必须写比较表达式，也可以直接写一个变量。

示例：

```python
name = 'Tom'

if name:
    print('name is not empty')
```

输出：

```text
name is not empty
```

因为`name`是非空字符串，所以在条件判断中被当作`True`。


# 六、布尔运算符

布尔运算符也称为逻辑运算符，用于组合多个条件。

Python 中常见的布尔运算符有三个：

|运算符|含义|说明|
|---|---|---|
|`and`|并且|多个条件都成立，整体才成立|
|`or`|或者|至少一个条件成立，整体就成立|
|`not`|取反|把布尔结果反转|

## 1、and

`and`用于判断多个条件是否同时成立。

示例：

```python
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote')
else:
    print('You are not eligible to vote')
```

输出：

```text
You are eligible to vote
```

这里`is_citizen`是`True`，`age >= 18`也是`True`，所以整个条件成立。

如果不用`and`，也可以写成嵌套的`if`：

```python
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote')
    else:
        print('You are not eligible to vote')
else:
    print('You are not eligible to vote')
```

但当条件较多时，嵌套层级会变深。使用`and`通常更清晰。

## 2、or

`or`用于判断多个条件中是否至少有一个成立。

示例：

```python
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount')
else:
    print('You are not eligible for a student discount')
```

输出：

```text
You are eligible for a student discount
```

这里`age < 18`是`False`，但`is_student`是`True`，因此整个`or`表达式仍然成立。

## 3、not

`not`用于反转一个值的布尔结果。

示例：

```python
print(not '')
print(not 'Hello')
print(not 0)
print(not 1)
print(not False)
print(not True)
```

输出：

```text
True
False
True
False
True
False
```

`not`常用于判断某个条件不成立的情况。

示例：

```python
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.')
else:
    print('Welcome, Administrator!')
```

输出：

```text
Access denied for non-administrators.
```


# 七、短路运算

`and`和`or`都是短路运算符。

短路运算指的是：Python 从左到右计算表达式，一旦已经能够确定最终结果，就不再继续计算后面的表达式。

## 1、and的短路

对于`x and y`：

- 如果`x`是假值，结果直接返回`x`
- 如果`x`是真值，结果返回`y`

示例：

```python
is_citizen = True
age = 25

print(is_citizen and age)
```

输出：

```text
25
```

因为`is_citizen`是真值，所以`and`继续计算并返回右侧的`age`。

再看一个左侧为假值的例子：

```python
print(0 and 'Hello')
```

输出：

```text
0
```

因为`0`是假值，`and`已经可以确定整体是假值，所以不会继续计算右侧的`'Hello'`。

## 2、or的短路

对于`x or y`：

- 如果`x`是真值，结果直接返回`x`
- 如果`x`是假值，结果返回`y`

示例：

```python
age = 19
is_employed = False

print(age or is_employed)
```

输出：

```text
19
```

因为`age`是非零整数，属于真值，所以`or`直接返回`age`。

如果左侧是假值，就会返回右侧：

```python
print('' or 'default')
```

输出：

```text
default
```

需要注意，`and`和`or`不一定直接返回`True`或`False`，它们返回的是参与运算的某个原始值。只有`not`总是返回布尔值。


# 八、Python没有三元运算符符号

很多语言中会使用`? :`写条件表达式，但 Python 没有这种写法。

Python 使用下面这种条件表达式：

```python
value_if_true if condition else value_if_false
```

示例：

```python
age = 20

message = 'adult' if age >= 18 else 'minor'

print(message)
```

输出：

```text
adult
```

这种写法适合非常简单的二选一赋值。如果逻辑较复杂，通常还是使用普通的`if...else`更清晰。
