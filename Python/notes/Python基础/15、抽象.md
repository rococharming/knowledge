# 一、抽象

## 1、抽象的基本含义

抽象是隐藏复杂的实现细节，只向外部展示必要功能的过程。

抽象关注一个对象能做什么，而不是它具体如何完成。

例如，驾驶汽车时，驾驶者通过方向盘、油门和刹车控制汽车，不需要了解发动机如何燃烧燃料、变速箱如何切换齿轮或制动系统内部如何工作。

其中：

|部分|含义|
|---|---|
|方向盘、油门和刹车|对外提供的简单接口|
|发动机、变速箱和制动系统|被隐藏的复杂实现|

驾驶者只需要理解接口的用途，就可以使用整个复杂系统。这就是抽象。

## 2、抽象的作用

在程序中使用抽象，可以把复杂系统拆分成职责明确的层次。

抽象通常有以下作用：

- 隐藏不必要的实现细节
- 为不同对象定义统一接口
- 降低代码之间的依赖
- 让调用方更容易理解和使用对象
- 让系统更容易扩展和维护

例如，支付系统可以规定所有支付方式都必须提供`pay()`方法。

调用支付功能的代码只需要调用`pay()`，不需要了解银行卡、电子钱包或其他方式内部如何完成支付。

## 3、抽象和封装的区别

抽象与[[13、封装和属性#一、面向对象编程和封装|封装]]关系密切，但关注点不同。

|概念|关注的问题|主要作用|
|---|---|---|
|抽象|对象对外提供什么功能|隐藏不重要的细节，定义必要接口|
|封装|如何保护和管理对象内部状态|控制数据的访问和修改方式|

例如，对于汽车：

- 把驾驶者需要的操作简化为方向盘、油门和刹车，属于抽象
- 把发动机内部状态隐藏起来，不允许外部随意修改，属于封装

抽象让使用方式更简单，封装让内部状态更安全。


# 二、抽象基类

## 1、abc模块

Python 通过标准库中的`abc`模块支持抽象基类。

`abc`是 Abstract Base Classes 的缩写。

定义抽象基类时，通常需要导入以下两个名称：

```python
from abc import ABC, abstractmethod
```

其中：

|名称|作用|
|---|---|
|`ABC`|抽象基类的基础类|
|`abstractmethod`|把方法标记为抽象方法的装饰器|

## 2、定义抽象基类

让一个类继承`ABC`，就可以在其中定义抽象方法。

基本语法：

```python
from abc import ABC, abstractmethod


class AbstractClass(ABC):
    @abstractmethod
    def abstract_method(self):
        pass
```

`AbstractClass`是抽象基类，`abstract_method()`是抽象方法。

抽象基类主要用于规定子类必须提供哪些方法，而不是直接创建普通对象。

## 3、抽象方法

抽象方法是在抽象基类中使用`@abstractmethod`标记的方法。

它声明了一个统一接口，要求具体子类提供自己的实现。

```python
from abc import ABC, abstractmethod


class Animal(ABC):
    @abstractmethod
    def make_sound(self):
        pass
```

`Animal`规定所有具体动物类都必须提供`make_sound()`方法，但没有决定每一种动物发出什么声音。

抽象基类负责规定必须做什么，具体子类负责决定如何做。


# 三、实现抽象方法

## 1、具体类

实现了所有抽象方法、可以正常创建对象的子类，称为具体类。

```python
from abc import ABC, abstractmethod


class Animal(ABC):
    @abstractmethod
    def make_sound(self):
        pass


class Dog(Animal):
    def make_sound(self):
        return 'Woof!'


class Cat(Animal):
    def make_sound(self):
        return 'Meow!'


class Monkey(Animal):
    def make_sound(self):
        return 'Ooh ooh aah aah!'


animals = [Dog(), Cat(), Monkey()]

for animal in animals:
    print(animal.make_sound())
```

输出：

```text
Woof!
Meow!
Ooh ooh aah aah!
```

这个示例中：

1. `Animal`继承`ABC`，成为抽象基类
2. `make_sound()`被标记为抽象方法
3. `Dog`、`Cat`和`Monkey`继承`Animal`
4. 每个具体子类分别实现`make_sound()`
5. 循环通过统一接口调用不同对象的方法

这里同时使用了[[14、继承和多态#一、继承|继承]]和[[14、继承和多态#六、多态|多态]]。

## 2、不能实例化抽象基类

如果一个类仍然包含未实现的抽象方法，就不能创建它的对象。

```python
animal = Animal()
```

输出类似：

```text
TypeError: Can't instantiate abstract class Animal with abstract method make_sound
```

`Animal`只定义了动物应当具有的接口，没有提供完整实现，因此不能表示一个可以直接使用的具体对象。

## 3、没有实现抽象方法的子类

子类如果没有实现父类要求的全部抽象方法，它仍然是抽象类，也不能创建对象。

```python
class Bird(Animal):
    pass


bird = Bird()
```

输出类似：

```text
TypeError: Can't instantiate abstract class Bird with abstract method make_sound
```

只有实现`make_sound()`后，`Bird`才会成为具体类：

```python
class Bird(Animal):
    def make_sound(self):
        return 'Tweet!'


bird = Bird()

print(bird.make_sound())
```

输出：

```text
Tweet!
```

这种限制可以尽早发现遗漏的方法，避免程序运行到更晚阶段才因为接口不完整而出错。


# 四、抽象基类中的普通成员

## 1、定义实例属性

抽象基类除了抽象方法，也可以定义初始化方法和实例属性。

```python
from abc import ABC, abstractmethod


class Animal(ABC):
    def __init__(self, name):
        self.name = name

    @abstractmethod
    def make_sound(self):
        pass


class Dog(Animal):
    def make_sound(self):
        return f'{self.name} says woof!'


class Cat(Animal):
    def make_sound(self):
        return f'{self.name} says meow!'


dog = Dog('Jack')
cat = Cat('Lucy')

print(dog.make_sound())
print(cat.make_sound())
```

输出：

```text
Jack says woof!
Lucy says meow!
```

`Dog`和`Cat`没有定义`__init__()`，因此会继承并使用`Animal.__init__()`。

抽象基类可以保存所有子类共有的数据，把具体行为留给子类实现。

## 2、定义普通方法

抽象基类也可以定义已经实现的普通方法，供所有子类直接复用。

```python
from abc import ABC, abstractmethod


class Animal(ABC):
    def __init__(self, name):
        self.name = name

    def introduce(self):
        return f'My name is {self.name}'

    @abstractmethod
    def make_sound(self):
        pass


class Dog(Animal):
    def make_sound(self):
        return 'Woof!'


dog = Dog('Jack')

print(dog.introduce())
print(dog.make_sound())
```

输出：

```text
My name is Jack
Woof!
```

这里，`introduce()`是所有动物都可以复用的完整行为，`make_sound()`则要求每个具体动物类分别实现。

## 3、抽象方法也可以包含实现

抽象方法不一定只能写`pass`，也可以包含一段默认实现。

但是，只要方法仍然带有`@abstractmethod`，子类就必须重写它，才能成为具体类。

子类可以通过`super()`复用抽象方法中的默认逻辑：

```python
from abc import ABC, abstractmethod


class Report(ABC):
    @abstractmethod
    def generate(self):
        return 'Report header'


class SalesReport(Report):
    def generate(self):
        header = super().generate()
        return f'{header}\nSales data'


report = SalesReport()

print(report.generate())
```

输出：

```text
Report header
Sales data
```

这种写法适合让抽象方法既规定子类必须重写，又为子类提供可以选择复用的公共逻辑。


# 五、多个抽象方法

## 1、定义多个必要接口

一个抽象基类可以定义多个抽象方法。

子类必须实现全部抽象方法，才能创建对象。

```python
from abc import ABC, abstractmethod


class FileStorage(ABC):
    @abstractmethod
    def save(self, filename, content):
        pass

    @abstractmethod
    def load(self, filename):
        pass
```

`FileStorage`规定所有存储方式必须同时支持保存和读取。

## 2、完整实现所有抽象方法

```python
class MemoryStorage(FileStorage):
    def __init__(self):
        self._files = {}

    def save(self, filename, content):
        self._files[filename] = content

    def load(self, filename):
        return self._files[filename]


storage = MemoryStorage()

storage.save('notes.txt', 'Python abstraction')
print(storage.load('notes.txt'))
```

输出：

```text
Python abstraction
```

`MemoryStorage`实现了`save()`和`load()`，因此是具体类。

如果只实现其中一个方法，它仍然不能实例化。


# 六、抽象属性

## 1、定义抽象属性

除了方法，还可以要求子类提供统一的属性。

定义抽象属性时，可以组合`@property`和`@abstractmethod`：

```python
from abc import ABC, abstractmethod


class Shape(ABC):
    @property
    @abstractmethod
    def area(self):
        pass
```

装饰器顺序应当是`@property`在上，`@abstractmethod`在下。

`Shape`要求所有具体图形都提供只读的`area`属性。

## 2、实现抽象属性

```python
import math
from abc import ABC, abstractmethod


class Shape(ABC):
    @property
    @abstractmethod
    def area(self):
        pass


class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    @property
    def area(self):
        return math.pi * self.radius ** 2


class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    @property
    def area(self):
        return self.width * self.height


shapes = [Circle(3), Rectangle(4, 5)]

for shape in shapes:
    print(round(shape.area, 2))
```

输出：

```text
28.27
20
```

不同图形使用不同方式计算面积，但外部代码始终通过统一的`area`属性获取结果。

这结合了抽象、[[13、封装和属性#四、Property属性|Property 属性]]和多态。


# 七、抽象的使用原则

## 1、适合使用抽象基类的场景

以下情况通常适合使用抽象基类：

- 多个类需要遵守相同接口
- 希望强制子类实现某些方法或属性
- 多个子类需要复用一部分公共代码
- 调用代码不应该依赖具体实现类
- 系统预计会不断增加新的实现方式

例如，支付方式、文件存储、消息通知和图形计算都可以使用抽象基类定义公共接口。

## 2、不必使用抽象基类的场景

如果程序只有一个简单类，没有多个实现，也不需要强制接口，使用抽象基类可能只会增加复杂度。

Python 也可以通过鸭子类型实现多态。只要对象提供了所需方法，就可以使用它，不一定必须继承共同的抽象基类。

抽象基类的额外价值在于：**它会明确记录接口，并在子类遗漏必要实现时阻止创建对象**。

## 3、面向对象四个重要原则

学习完抽象后，面向对象编程的四个重要原则可以总结为：

|原则|核心作用|
|---|---|
|封装|控制对象内部数据的访问和修改|
|继承|复用和扩展已有类的属性与方法|
|多态|通过相同接口操作不同类型的对象|
|抽象|隐藏实现细节并规定必要接口|

这四个原则经常结合使用。

抽象基类定义接口，继承让具体类获得并实现接口，多态让不同对象通过同一接口工作，封装则保护每个对象内部的状态和实现细节。
