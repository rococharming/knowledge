# 一、序列类型

序列是一组有顺序的数据。Python 中常见的基础序列类型包括`list`、`tuple`和`range`。

本篇先关注`list`和`tuple`：

|类型|中文名称|是否可变|常见用途|
|---|---|---|---|
|`list`|列表|可变|保存一组需要增删改的元素|
|`tuple`|元组|不可变|保存一组创建后不希望修改的元素|

`list`和`tuple`都是有序集合，都支持索引、负向索引、切片和解包。它们最核心的区别是：

> `list`创建后可以修改，`tuple`创建后不能修改自身保存的元素引用。


# 二、列表

## 1、列表的基本含义

`list`是 Python 内置的一种有序集合，可以保存多个元素。

列表使用方括号`[]`定义：

```python
cities = ['Los Angeles', 'London', 'Tokyo']

print(cities)
```

输出：

```text
['Los Angeles', 'London', 'Tokyo']
```

列表中也可以嵌套列表。

```python
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]

print(developer[2])
print(developer[2][1])
```

输出：

```text
['Python', 'Rust', 'C++']
Rust
```

`developer[2]`先取出第三个元素，也就是内部列表；`developer[2][1]`再从内部列表中取出索引`1`的元素。

也可以使用`list()`构造函数把可迭代对象转换为列表。

```python
developer = 'Jessica'

print(list(developer))
```

输出：

```text
['J', 'e', 's', 's', 'i', 'c', 'a']
```

> 可迭代对象是一类特殊的对象，可用于循环遍历每一项，列表，元组，字符串都是可迭代对象。

可以使用`len()`获取列表长度。

```python
numbers = [1, 2, 3, 4, 5]

print(len(numbers))
```

输出：

```text
5
```

## 2、索引和切片

列表按照顺序保存元素，索引从`0`开始。

```python
cities = ['Los Angeles', 'London', 'Tokyo']

print(cities[0])
print(cities[1])
```

输出：

```text
Los Angeles
London
```

Python 也支持负向索引。`-1`表示最后一个元素，`-2`表示倒数第二个元素。

```python
cities = ['Los Angeles', 'London', 'Tokyo']

print(cities[-1])
print(cities[-2])
```

输出：

```text
Tokyo
London
```

如果索引超出范围，会抛出`IndexError`。

```python
cities = ['Los Angeles', 'London', 'Tokyo']

print(cities[10])
```

报错：

```text
IndexError: list index out of range
```

切片用于取出列表的一部分。

```python
desserts = ['Cake', 'Cookies', 'Ice Cream', 'Pie', 'Brownies']

print(desserts[1:4])
```

输出：

```text
['Cookies', 'Ice Cream', 'Pie']
```

`desserts[1:4]`表示从索引`1`开始，取到索引`4`之前，不包含索引`4`。

切片也可以指定步长：

```python
numbers = [1, 2, 3, 4, 5, 6]

print(numbers[1::2])
```

输出：

```text
[2, 4, 6]
```

## 3、修改和删除元素

`list`是可变对象，可以修改指定索引位置的元素。

```python
programming_languages = ['Python', 'Java', 'C++', 'Rust']

programming_languages[0] = 'JavaScript'

print(programming_languages)
```

输出：

```text
['JavaScript', 'Java', 'C++', 'Rust']
```

如果修改时索引越界，也会抛出`IndexError`。

```python
programming_languages = ['Python', 'Java', 'C++', 'Rust']

programming_languages[10] = 'JavaScript'
```

报错：

```text
IndexError: list assignment index out of range
```

可以使用`del`删除指定索引位置的元素。

```python
developer = ['Jane Doe', 23, 'Python Developer']

del developer[1]

print(developer)
```

输出：

```text
['Jane Doe', 'Python Developer']
```

## 4、成员判断

可以使用`in`判断某个元素是否在列表中。

```python
programming_languages = ['Python', 'Java', 'C++', 'Rust']

print('Rust' in programming_languages)
print('JavaScript' in programming_languages)
```

输出：

```text
True
False
```

## 5、列表解包

列表解包可以把列表中的元素一次性赋值给多个变量。

```python
developer = ['Alice', 34, 'Rust Developer']

name, age, job = developer

print(name)
print(age)
print(job)
```

输出：

```text
Alice
34
Rust Developer
```

如果只想接收一部分元素，并把剩余元素收集到一个列表中，可以使用`*`。

```python
developer = ['Alice', 34, 'Rust Developer']

name, *rest = developer

print(name)
print(rest)
```

输出：

```text
Alice
[34, 'Rust Developer']
```

如果左侧变量数量和列表元素数量不匹配，会抛出`ValueError`。

```python
developer = ['Alice', 34, 'Rust Developer']

name, age, job, city = developer
```

报错：

```text
ValueError: not enough values to unpack (expected 4, got 3)
```

## 6、列表常用方法

### （1）append()

`append()`用于在列表末尾追加一个元素。

```python
numbers = [1, 2, 3, 4, 5]

numbers.append(6)

print(numbers)
```

输出：

```text
[1, 2, 3, 4, 5, 6]
```

如果传入的是另一个列表，`append()`会把整个列表作为一个元素添加进去。

```python
numbers = [1, 2, 3]
even_numbers = [4, 6]

numbers.append(even_numbers)

print(numbers)
```

输出：

```text
[1, 2, 3, [4, 6]]
```

### （2）extend()

`extend()`用于把另一个可迭代对象中的元素逐个追加到列表末尾。

```python
numbers = [1, 2, 3]
even_numbers = [4, 6]

numbers.extend(even_numbers)

print(numbers)
```

输出：

```text
[1, 2, 3, 4, 6]
```

### （3）insert()

`insert()`用于在指定索引位置插入元素。

```python
numbers = [1, 2, 3, 4, 5]

numbers.insert(2, 2.5)

print(numbers)
```

输出：

```text
[1, 2, 2.5, 3, 4, 5]
```

### （4）remove()

`remove()`用于按值删除元素，只删除第一次出现的元素。

```python
numbers = [10, 20, 30, 40, 50, 50]

numbers.remove(50)

print(numbers)
```

输出：

```text
[10, 20, 30, 40, 50]
```

### （5）pop()

`pop()`用于删除元素，并返回被删除的元素。

```python
numbers = [1, 2, 3, 4, 5]

value = numbers.pop(1)

print(value)
print(numbers)
```

输出：

```text
2
[1, 3, 4, 5]
```

如果不传索引，`pop()`默认删除最后一个元素。

```python
numbers = [1, 2, 3, 4, 5]

value = numbers.pop()

print(value)
print(numbers)
```

输出：

```text
5
[1, 2, 3, 4]
```

### （6）clear()

`clear()`用于清空列表。

```python
numbers = [1, 2, 3, 4, 5]

numbers.clear()

print(numbers)
```

输出：

```text
[]
```

### （7）sort()和sorted()

`sort()`会原地排序列表，也就是直接修改原列表。

```python
numbers = [19, 2, 35, 1, 67, 41]

numbers.sort()

print(numbers)
```

输出：

```text
[1, 2, 19, 35, 41, 67]
```

`sorted()`会返回一个新的排序列表，不修改原来的列表。

```python
numbers = [19, 2, 35, 1, 67, 41]

sorted_numbers = sorted(numbers)

print(numbers)
print(sorted_numbers)
```

输出：

```text
[19, 2, 35, 1, 67, 41]
[1, 2, 19, 35, 41, 67]
```

### （8）reverse()

`reverse()`用于原地反转列表。

```python
numbers = [6, 5, 4, 3, 2, 1]

numbers.reverse()

print(numbers)
```

输出：

```text
[1, 2, 3, 4, 5, 6]
```

### （9）index()

`index()`用于查找元素第一次出现的位置。

```python
programming_languages = ['Rust', 'Java', 'Python', 'C++']

print(programming_languages.index('Java'))
```

输出：

```text
1
```

如果找不到元素，会抛出`ValueError`。

```python
programming_languages = ['Rust', 'Java', 'Python', 'C++']

print(programming_languages.index('JavaScript'))
```

报错：

```text
ValueError: 'JavaScript' is not in list
```


# 三、元组

## 1、元组的基本含义

`tuple`是 Python 内置的另一种有序集合，中文通常称为元组。

元组使用圆括号`()`定义：

```python
developer = ('Alice', 34, 'Rust Developer')

print(developer)
```

输出：

```text
('Alice', 34, 'Rust Developer')
```

元组和列表很像，都可以通过索引访问元素，但元组创建后不能修改。

## 2、索引、切片和成员判断

元组支持正向索引和负向索引。

```python
developer = ('Alice', 34, 'Rust Developer')

print(developer[1])
print(developer[-1])
```

输出：

```text
34
Rust Developer
```

索引越界会抛出`IndexError`。

```python
numbers = (1, 2, 3, 4, 5)

print(numbers[7])
```

报错：

```text
IndexError: tuple index out of range
```

元组也支持切片。

```python
desserts = ('cake', 'pie', 'cookies', 'ice cream')

print(desserts[1:3])
```

输出：

```text
('pie', 'cookies')
```

可以使用`in`判断某个元素是否在元组中。

```python
programming_languages = ('Python', 'Java', 'C++', 'Rust')

print('Rust' in programming_languages)
print('JavaScript' in programming_languages)
```

输出：

```text
True
False
```

## 3、元组的不可变性

元组创建后，不能替换其中某个位置的元素。

```python
programming_languages = ('Python', 'Java', 'C++', 'Rust')

programming_languages[0] = 'JavaScript'
```

报错：

```text
TypeError: 'tuple' object does not support item assignment
```

元组也不能删除指定位置的元素。

```python
developer = ('Jane Doe', 23, 'Python Developer')

del developer[1]
```

报错：

```text
TypeError: 'tuple' object doesn't support item deletion
```

## 4、元组的定义细节

可以使用`tuple()`构造函数把可迭代对象转换为元组。

```python
developer = 'Jessica'

print(tuple(developer))
```

输出：

```text
('J', 'e', 's', 's', 'i', 'c', 'a')
```

空元组使用`()`表示。

```python
t = ()

print(t)
```

输出：

```text
()
```

**定义只有一个元素的元组时，必须在元素后面加逗号**。

```python
t = (1,)

print(t)
```

输出：

```text
(1,)
```

如果写成`t = (1)`，Python 会把它当作普通数学括号，而不是元组。

## 5、元组解包

元组也可以像列表一样解包。

```python
developer = ('Alice', 34, 'Rust Developer')

name, age, job = developer

print(name)
print(age)
print(job)
```

输出：

```text
Alice
34
Rust Developer
```

也可以使用`*`收集剩余元素。

```python
developer = ('Alice', 34, 'Rust Developer')

name, *rest = developer

print(name)
print(rest)
```

输出：

```text
Alice
[34, 'Rust Developer']
```

需要注意，`rest`得到的是列表，而不是元组。

## 6、元组中包含可变对象

元组的不可变，指的是元组中每个位置保存的对象引用不能改变。

例如：

```python
t = ('a', 'b', ['A', 'B'])
```

不能把`t[0]`改成其他对象，也不能把`t[2]`改成另一个列表。

```python
t[0] = 'x'
t[2] = ['X', 'Y']
```

这两种写法都会报错。

但如果元组中保存的是一个列表，这个列表自身仍然可以修改。

```python
t = ('a', 'b', ['A', 'B'])

t[2][0] = 'X'
t[2][1] = 'Y'

print(t)
```

输出：

```text
('a', 'b', ['X', 'Y'])
```

此时`t[2]`仍然指向原来的列表，只是这个列表内部的元素变了。

## 7、元组常用方法

### （1）count()

`count()`用于统计某个元素在元组中出现的次数。

```python
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')

print(programming_languages.count('Rust'))
print(programming_languages.count('JavaScript'))
```

输出：

```text
2
0
```

### （2）index()

`index()`用于查找某个元素第一次出现的位置。

```python
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')

print(programming_languages.index('Java'))
```

输出：

```text
1
```

如果找不到元素，会抛出`ValueError`。

```python
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')

print(programming_languages.index('JavaScript'))
```

报错：

```text
ValueError: tuple.index(x): x not in tuple
```

`index()`还可以指定查找范围。

```python
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')

print(programming_languages.index('Python', 3))
```

输出：

```text
5
```

### （3）sorted()

`tuple`没有`sort()`方法，但可以使用`sorted()`函数排序。

```python
numbers = (13, 2, 78, 3, 45, 67, 18, 7)

print(sorted(numbers))
```

输出：

```text
[2, 3, 7, 13, 18, 45, 67, 78]
```

需要注意，`sorted()`返回的是一个新的列表，而不是元组。


# 四、list和tuple的选择

如果需要一个可以添加、删除和修改元素的集合，应该使用`list`。

如果一组数据创建后不希望被修改，应该使用`tuple`。

示例：

```python
names = ['Michael', 'Bob', 'Tracy']
point = (3, 5)
rgb = (255, 128, 0)
```

`names`后续可能会增删改，更适合使用列表。`point`和`rgb`更强调整体固定，更适合使用元组。
