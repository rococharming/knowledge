# 一、错误和异常

## 1、错误信息的基本含义

编写 Python 代码时，经常会遇到错误信息。

错误信息不是只告诉你“程序坏了”，而是会说明：

- 哪个文件出错
- 哪一行出错
- 错误类型是什么
- 错误的大致原因是什么

因此调试时不要先猜原因，而是先读错误信息。

常见错误类型如下：

| 错误类型                | 常见原因             |
| ------------------- | ---------------- |
| `SyntaxError`       | 代码不符合 Python 语法  |
| `NameError`         | 使用了未定义的变量名       |
| `TypeError`         | 对不合适的类型执行了不支持的操作 |
| `IndexError`        | 索引超出范围           |
| `KeyError`          | 访问了不存在的字典 key    |
| `AttributeError`    | 访问了对象不存在的属性或方法   |
| `ValueError`        | 类型正确，但值本身不合法     |
| `ZeroDivisionError` | 除数为 0            |

## 2、常见错误示例

`SyntaxError`表示语法错误。

```python
print("Hello, world!"
```

报错：

```text
SyntaxError: '(' was never closed
```

这里少了一个右括号`)`，Python 无法按合法语法解析这段代码。

`NameError`表示名称不存在。

```python
print(name)
```

报错：

```text
NameError: name 'name' is not defined
```

这里使用了变量`name`，但它还没有被定义。

`TypeError`表示类型不匹配。

```python
result = 5 + '5'
```

报错：

```text
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

整数和字符串不能直接相加。

`IndexError`表示索引超出范围。

```python
numbers = [1, 2, 3]

print(numbers[5])
```

报错：

```text
IndexError: list index out of range
```

`AttributeError`表示对象没有这个属性或方法。

```python
num = 42

num.append(5)
```

报错：

```text
AttributeError: 'int' object has no attribute 'append'
```

`int`对象没有`append()`方法。`append()`是列表这类对象才有的方法。

## 3、Traceback

异常发生时，Python 通常会打印一段`Traceback`。

`Traceback`会从调用链中显示错误是如何一路发生的，最后一行通常最重要，因为它包含最终的异常类型和错误说明。

示例：

```python
def divide(a, b):
    return a / b

print(divide(10, 0))
```

报错：

```text
ZeroDivisionError: division by zero
```

实际输出中还会显示出错文件、行号和调用路径。调试时通常先看最后一行确定错误类型，再往上找具体是哪一行触发了错误。


# 二、调试方法

## 1、使用print()

最简单的调试方式是在关键位置打印变量值和执行流程。

示例：

```python
def add(a, b):
    result = a + b
    print(f'Adding {a} and {b} gives {result}')
    return result

add(2, 3)
```

输出：

```text
Adding 2 and 3 gives 5
```

这种方式适合快速确认代码是否执行到某个位置，以及变量值是否符合预期。

需要注意，调试完成后应删除不再需要的临时`print()`，避免污染程序输出。

## 2、使用pdb

`pdb`是 Python 内置的交互式调试模块。

可以使用`pdb.set_trace()`在代码中设置断点。

```python
import pdb

def divide(a, b):
    pdb.set_trace()
    return a / b

print(divide(10, 2))
```

程序执行到`pdb.set_trace()`时会暂停，并进入交互式调试环境。

常见命令：

|命令|作用|
|---|---|
|`n`|执行下一行|
|`s`|进入函数调用|
|`c`|继续运行|
|`p 变量名`|打印变量值|
|`whatis 变量名`|查看变量类型|
|`q`|退出调试|

例如：

```text
(Pdb) whatis a
<class 'int'>
```

## 3、使用IDE调试器

对于复杂程序，IDE 调试器通常比手动加`print()`更方便。

常见能力包括：

- 设置断点
- 单步执行
- 查看局部变量
- 查看调用栈
- 在调试控制台中计算表达式

在 VS Code 中，通常可以这样调试：

1. 在代码行号左侧点击，设置断点
2. 按`F5`或选择`Run > Start Debugging`
3. 选择 Python 文件调试方式
4. 程序运行到断点处会暂停
5. 使用调试工具栏继续、单步跳过、进入函数或跳出函数

在 PyCharm 中，通常可以这样调试：

1. 在代码行号左侧点击，设置断点
2. 右键当前 Python 文件，选择`Debug`
3. 程序运行到断点处会暂停
4. 在`Variables`窗口查看变量值
5. 使用`Step Over`、`Step Into`、`Step Out`控制执行流程

调试工具适合观察程序运行中的真实状态，尤其适合排查循环、函数调用和异常传播问题。


# 三、异常处理

## 1、try和except

异常处理用于捕获和管理程序运行时发生的错误，避免程序直接崩溃。

基本语法：

```python
try:
    可能出错的代码
except 异常类型:
    出错后的处理代码
```

示例：

```python
try:
    x = 10 / 0
except ZeroDivisionError:
    print("You can't divide by zero!")
```

输出：

```text
You can't divide by zero!
```

这里`10 / 0`会触发`ZeroDivisionError`，然后被`except ZeroDivisionError`捕获并处理。

## 2、多个except

不同异常通常应该分别处理。

```python
try:
    number = int('abc')
    result = 10 / number
except ValueError:
    print('That was not a valid number.')
except ZeroDivisionError:
    print("Can't divide by zero.")
```

输出：

```text
That was not a valid number.
```

这里`int('abc')`先触发`ValueError`，所以后面的除法不会执行。

## 3、异常对象

可以使用`as`获取异常对象。

```python
try:
    x = 1 / 0
except ZeroDivisionError as e:
    print(f'Error occurred: {e}')
```

输出：

```text
Error occurred: division by zero
```

异常对象中保存了具体错误信息，常用于打印日志或调试。

也可以在一个`except`中捕获多个异常。

```python
try:
    number = int(input('Enter a number: '))
    result = 10 / number
except (ValueError, ZeroDivisionError) as e:
    print(f'Error occurred: {e}')
```

这种写法适合多个异常可以使用同一种处理逻辑的情况。

## 4、else和finally

`try`语句还可以搭配`else`和`finally`使用。

```python
try:
    x = 10 / 2
except ZeroDivisionError:
    print("You can't divide by zero!")
else:
    print('Division successful:', x)
finally:
    print('This block always runs.')
```

输出：

```text
Division successful: 5.0
This block always runs.
```

各部分含义如下：

|语句|执行时机|
|---|---|
|`try`|放可能出错的代码|
|`except`|`try`中出现指定异常时执行|
|`else`|`try`中没有异常时执行|
|`finally`|无论是否出现异常都会执行|

`finally`常用于释放资源，例如关闭文件、断开连接等。

## 5、异常处理的注意点

异常处理应该尽量具体。

不推荐随手写一个过宽泛的异常捕获：

```python
try:
    run()
except Exception:
    pass
```

这样会隐藏真正的问题，让程序看起来没有报错，但实际状态可能已经不正确。

更好的方式是捕获你预期会出现的异常，并给出明确处理逻辑。


# 四、主动抛出异常

## 1、raise

`raise`用于主动抛出异常。

当某个输入或状态不符合要求时，可以使用`raise`让错误明确暴露出来。

示例：

```python
def check_age(age):
    if age < 0:
        raise ValueError('Age cannot be negative')

    return age

try:
    check_age(-5)
except ValueError as e:
    print(f'Error: {e}')
```

输出：

```text
Error: Age cannot be negative
```

这里`age < 0`违反了函数的要求，因此主动抛出`ValueError`。

## 2、重新抛出异常

在`except`中可以使用不带参数的`raise`重新抛出当前异常。

```python
def process_data(data):
    try:
        result = int(data)
        return result * 2
    except ValueError:
        print('Logging: Invalid data received')
        raise

try:
    process_data('abc')
except ValueError:
    print('Handled at higher level')
```

输出：

```text
Logging: Invalid data received
Handled at higher level
```

这种写法适合先记录日志或做局部清理，然后继续把异常交给外层代码处理。

## 3、自定义异常

可以通过继承`Exception`定义自己的异常类型。

```python
class InsufficientFundsError(Exception):
    pass

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError('Insufficient funds')

    return balance - amount

try:
    withdraw(100, 150)
except InsufficientFundsError as e:
    print(f'Transaction failed: {e}')
```

输出：

```text
Transaction failed: Insufficient funds
```

自定义异常适合表达业务层面的错误，例如余额不足、权限不足、状态不合法等。

## 4、异常链

有时捕获底层异常后，会抛出一个更符合当前业务语义的新异常。

可以使用`raise ... from ...`保留异常之间的因果关系。

```python
def parse_number(text):
    try:
        return int(text)
    except ValueError as e:
        raise ValueError('Invalid number format') from e

parse_number('abc')
```

报错中会显示：

```text
The above exception was the direct cause of the following exception:
```

## 5、assert

`assert`用于断言某个条件必须成立。

如果条件为`False`，会抛出`AssertionError`。

```python
def calculate_square_root(number):
    assert number >= 0, 'Cannot calculate square root of negative number'
    return number ** 0.5

try:
    result = calculate_square_root(-4)
except AssertionError as e:
    print(f'Assertion failed: {e}')
```

输出：

```text
Assertion failed: Cannot calculate square root of negative number
```

需要注意，`assert`更适合用于开发阶段检查内部假设，不适合代替正式的输入校验。正式业务校验通常应该使用`if`配合`raise`。
