# 一、概述

程序之所以能完成自动化任务，核心原因之一是可以根据条件选择不同的执行路径，也可以通过循环重复执行一段代码。

下表给出了三个基础控制结构：

| 控制结构         | 作用                                         |
| ------------ | ------------------------------------------ |
| `if` 条件判断    | 根据条件选择执行不同代码                               |
| `match` 模式匹配 | 针对一个值或结构进行分支匹配                             |
| 循环语句         | 重复执行代码，包括 `for`、`while`、`break`、`continue` |
Python 使用**缩进**表示代码块。

`if`、`elif`、`else`、`match`、`case`、`for`、`while`后面都需要写冒号 `:`。

# 二、if条件判断

## 1、基本用法

`if` 用于根据条件是否成立来决定是否执行某段代码。

```python
age = 20

if age >= 18:
    print("your age is", age)
    print("adult")
```

如果条件结果为 `True`，就执行缩进代码块；如果为 `False`，就跳过。

## 2、if...else

`else` 表示条件不成立时执行的分支。

```python
age = 3

if age >= 18:
    print("your age is", age)
    print("adult")
else:
    print("your age is", age)
    print("teenager")
```

## 3、if..elif..else

如果需要判断多个条件，可以使用 `elif`。

```python
age = 3

if age >= 18:
    print("adult")
elif age >= 6:
    print("teenager")
else:
    print("kid")
```

## 4、条件的简写形式

`if` 后面不一定必须是比较表达式，也可以直接写变量或对象。

```python
x = "hello"

if x:
    print("True")
```

常见真假规则如下：

|值|判断结果|
|---|---|
|`0`、`0.0`|`False`|
|`""`|`False`|
|`[]`、`()`、`{}`|`False`|
|`None`|`False`|
|非零数值|`True`|
|非空字符串|`True`|
|非空列表、元组、字典|`True`|


# 三、match模式匹配

## 1、基本用法

当多个分支都在判断同一个变量时，可以使用 `match`。

例如：

```python
score = "B"

if score == "A":
    print("score is A.")
elif score == "B":
    print("score is B.")
elif score == "C":
    print("score is C.")
else:
    print("invalid score.")
```

可以改写为：

```python
score = "B"

match score:
    case "A":
        print("score is A.")
    case "B":
        print("score is B.")
    case "C":
        print("score is C.")
    case _:
        print("invalid score.")
```

`case _` 表示匹配其他所有情况，通常放在最后。

## 2、匹配多个值

一个 `case` 可以同时匹配多个值，使用 `|` 分隔。

```python
age = 15

match age:
    case 10:
        print("10 years old.")
    case 11 | 12 | 13 | 14 | 15 | 16 | 17 | 18:
        print("11~18 years old.")
    case 19:
        print("19 years old.")
    case _:
        print("not sure.")
```

## 3、带条件的匹配

`case` 后面可以使用 `if` 添加额外条件。

```python
age = 8

match age:
    case x if x < 10:
        print(f"< 10 years old: {x}")
    case 10:
        print("10 years old.")
    case _:
        print("not sure.")
```

这里的 `x` 会绑定当前匹配的值，然后再判断 `x < 10` 是否成立。


## 4、匹配列表结构

`match` 不只能匹配单个值，也可以匹配列表结构。

```python
args = ["gcc", "hello.c", "world.c"]

match args:
    case ["gcc"]:
        print("gcc: missing source file(s).")
    case ["gcc", file1, *files]:
        print("gcc compile: " + file1 + ", " + ", ".join(files))
    case ["clean"]:
        print("clean")
    case _:
        print("invalid command.")
```

| 分支                            | 匹配内容                       |
| ----------------------------- | -------------------------- |
| `case ["gcc"]`                | 只有一个元素 `"gcc"`             |
| `case ["gcc", file1, *files]` | 第一个元素是 `"gcc"`，并且至少还有一个文件名 |
| `case ["clean"]`              | 只有一个元素 `"clean"`           |
| `case _`                      | 其他情况                       |
`*files` 会接收剩余元素，结果是一个列表。

# 四、循环

## 1、for循环

### （1）基本用法

`for...in` 用于依次遍历一个**可迭代对象**中的元素。

```python
names = ["Michael", "Bob", "Tracy"]

for name in names:
    print(name)
```

> 可迭代对象是指可以被逐个取出元素的对象。常见的可迭代对象包括list、tuple、str、dict、set、range


### （2）range()

`range`可以生成整数序列，常用于循环。

```python
print(list(range(5)))
```

输出：

```text
[0, 1, 2, 3, 4]
```

计算 `1` 到 `100` 的整数和：

```python
total = 0

for x in range(101):
    total = total + x

print(total)
```

`range(101)` 生成的是 `0` 到 `100`，所以可以用于计算 `1` 到 `100` 的和，因为加上 `0` 不影响结果。

也可以写得更明确：

```python
total = 0

for x in range(1, 101):
    total = total + x
	
print(total)
```


## 2、while循环

`while` 会在条件成立时不断执行循环体。

```python
n = 1

while n <= 10:
    print(n)
    n = n + 1
```

如果条件一直成立，循环就不会结束，所以 `while` 循环中通常需要更新变量。


## 3、break和continue

### （1）break

`break` 用于提前结束当前循环。

```python
n = 1

while n <= 100:
    if n > 10:
        break
    print(n)
    n = n + 1

print("END")
```

执行到 `break` 后，当前循环立即结束，程序继续执行循环后面的代码。

### （2）continue

`continue` 用于跳过本轮循环剩余代码，直接进入下一轮循环。

```python
n = 0

while n < 10:
    n = n + 1
    if n % 2 == 0:
        continue
    print(n)
```
