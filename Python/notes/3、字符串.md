
# 一、概述

Python 3 中的字符串类型是`str`。`str`表示的是文本字符序列，内部以`Unicode`方式表示，因此可以直接存储英文、中文、日文、Emoji 等多语言字符。

例如：

```python
print("Hello, 世界")
```

学习 Python 字符串时，需要重点区分两类数据：

| 类型      | 含义                    | 示例                            |
| ------- | --------------------- | ----------------------------- |
| `str`   | 文本字符串，表示 Unicode 字符序列 | `"中文"`                        |
| `bytes` | 字节序列，表示原始二进制数据        | `b"\xe4\xb8\xad\xe6\x96\x87"` |

在程序内部处理文本时，通常使用`str`；当数据需要写入文件、通过网络传输、调用底层接口时，通常需要把`str`编码成`bytes`。

# 二、str

## 1、`str` 表示 Unicode 字符序列

在 Python 3 中，字符串是Unicode文本。也就是说，一个字符串中的每个字符都有对应的 Unicode 码点。

例如：

```python
s = "中文"
```

这里的 `s` 是一个 `str`，它包含两个字符：`中`和`文`。

|字符|Unicode 码点|
|---|---|
|`中`|`U+4E2D`|
|`文`|`U+6587`|

>注意，Python中的`str`不是UTF-8字节序列，而是文本字符序列。只有在编码时，`str`才会变成UTF-8、GBK或其他编码形式的字节。

## 2、`ord()`和`chr()`

Python 提供了`ord()`和`chr()`用于字符和Unicode码点之间的转换。

`ord()`用于获取单个字符对应的整数码点：

```python
print(ord('A'))
```

输出：65

```python
print(ord('中'))
```

输出：20013

如果想看十六进制形式，可以使用`hex()`：

```python
print(hex(ord('中')))
```

输出：0x4e2d

`chr`用于把整数码点转换为对应字符：

```python
print(chr(65))
```

输出：A

```python
print(chr(0x4e2d))
```

输出：中

## 3、\u转义写法

如果知道字符的`Unicode`码点，也可以使用`\u`转义字符，它表示一个Unicode字符，由4位16进制表示。

```python
print("\u4e2d\u6587")
```

输出：中文

这和直接写中文是等价的。


# 三、bytes

## 1、bytes的基本含义

`bytes`表示字节序列。它不是文本，而是由一个个字节组成的二进制数据。

Python中使用`b`前缀创建`bytes`：

```python
x = b"ABC"
```

这里的 `x` 是 `bytes`，不是 `str`。

可以使用`type()`查看类型：

```python
print(type("ABC"))  
print(type(b"ABC"))
```

结果：

![[Pasted image 20260528001823.png]]

区别如下：

|表达式|类型|含义|
|---|---|---|
|`"ABC"`|`str`|Unicode 文本字符串|
|`b"ABC"`|`bytes`|字节序列|

## 2、bytes中的元素是整数

`bytes`本质上是一串字节，每个字节的取值范围是`0`到`255`。

例如：

```python
b = b"ABC"
b[0]
```

输出：65

因为字符 `A` 的 ASCII 值是 `65`。

## 3、bytes的显示方式

如果 `bytes` 中的字节可以对应 ASCII 可显示字符，Python 会尽量用字符形式显示。

示例：

```python
b"ABC"
```

输出：b'ABC'

如果字节不能显示为普通ASCII字符，就会使用`\x##`的十六进制显示。

例如：

```python
"中文".encode("utf-8")
```

输出：

```
b'\xe4\xb8\xad\xe6\x96\x87'
```

其中：

```
\xe4\xb8\xad
```

表示对应的十六进制字节。


# 四、编码与解码

## 1、编码：str转为bytes

编码是指把 `str` 转换为 `bytes`。

Python 中使用`encode()`方法编码字符串：

```python
"ABC".encode("ascii")
```

因为 `ABC` 都在 ASCII 范围内，所以可以用 ASCII 编码。

中文不能使用 ASCII 编码，会报错：

![[Pasted image 20260528002934.png|600]]
原因是 ASCII 只能表示 `0x00` 到 `0x7F` 范围内的字符，不能表示中文。

中文通常可以用 UTF-8 编码：

```python
"中文".encode("utf-8")
```

输出：b'\xe4\xb8\xad\xe6\x96\x87'

也可以用 GBK 编码：

```python
"中文".encode("gbk")
```

输出：b'\xd6\xd0\xce\xc4'

同一个 `str`，使用不同编码方式，会得到不同的字节序列。

|字符串|编码方式|`bytes`|
|---|---|---|
|`"中文"`|UTF-8|`b'\xe4\xb8\xad\xe6\x96\x87'`|
|`"中文"`|GBK|`b'\xd6\xd0\xce\xc4'`|

## 2、解码：bytes转为str

解码是指把`bytes`转为`str`。

Python 中使用 `decode()` 方法解码字节序列。

示例：

```python
b"ABC".decode("ascii")
```

输出：'ABC'

UTF-8字节可以按UTF-8解码：

```python
b"\xe4\xb8\xad\xe6\x96\x87".decode("utf-8")
```

输出：'中文'


## 3、解码错误处理

如果使用错误编码解码，就可能报错或产生乱码。

```python
b"\xe4\xb8\xad\xe6\x96\x87".decode("gbk")
```

![[Pasted image 20260528003524.png|500]]

如果`bytes`中只有一小部分无效的字节，可以传入`errors='ignore'`忽略错误的字节：

```python
print(b'\xe4\xb8\xad\xff'.decode('utf-8', errors='ignore'))
```

输出：中

`0xff`属于UTF-8的非法字节，这里忽略了该错误字节。

常见处理方式：

|写法|含义|
|---|---|
|`errors="strict"`|默认方式，遇到错误直接报错|
|`errors="ignore"`|忽略无法解码的字节|
|`errors="replace"`|用替代字符替换无法解码的字节|

> 编码和解码必须匹配

# 六、Python源文件编码

## 1、源文件本身也是文本文件

Python 源代码本身也是一个文本文件。如果源代码中包含中文、日文、Emoji 等非 ASCII 字符，需要确保 `.py` 文件本身使用正确的文本编码保存。

例如：

```python
print("中文")
```

现代 Python 3 项目通常统一使用 UTF-8 保存源文件。

## 2、文件开头的编码声明

有时会在 Python 文件开头看到这两行：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
```

第一行是 `shebang`，主要用于 Linux、macOS 等类 Unix 系统，表示这个脚本应该使用 `python3` 执行。

第二行是源文件编码声明，表示 Python 解释器按 UTF-8 读取这个源代码文件。

在 Python 3 中，源文件默认就是 UTF-8，所以这行通常不是必须写的；但在教程、旧项目或需要明确标注编码的场景中仍然常见。


## 3、编码声明和文件真实编码

编码声明只是告诉 Python 解释器按什么编码读取源文件，并不会自动改变文件本身的编码。

如果 `.py` 文件实际不是 UTF-8 编码，即使写了`# -*- coding: utf-8 -*-`，也仍然可能报错。

因此正确关系应该是编辑器保存编码为UTF-8，Python 解释器按 UTF-8 读取源代码。

# 七、字符串格式化

## 1、字符串格式化的作用

字符串格式化用于把变量插入到字符串中。

例如：

```python
name = "小明"  
month = 5  
cost = 40.1  
balance = 59.9  
  
print(f"亲爱的{name}你好，你{month}月的话费是{cost}元，余额为{balance}元")
```


Python 中常见的字符串格式化方式有三种：

| 方式         | 示例                         | 说明                |
| ---------- | -------------------------- | ----------------- |
| `%格式化`     | `"Hello, %s" % name`       | 旧式格式化方式           |
| `format()` | `"Hello, {}".format(name)` | 字符串方法             |
| `f-string` | `f"Hello, {name}"`         | Python 3.6 以后推荐使用 |

## 2、%格式化

% 格式化和 C语言风格比较接近。

示例：

```python
print("Hello, %s" % "world")
```

输出：Hello, world

多个值需要使用元组传入：

```python
name = "Michael"
money = 1000000

print("Hi, %s, you have $%d." % (name, money))
```

输出：Hi, Michael, you have $1000000.

常见占位符如下：

| 占位符  | 含义     |
| ---- | ------ |
| `%d` | 整数     |
| `%f` | 浮点数    |
| `%s` | 字符串    |
| `%x` | 十六进制整数 |

如果字符串中有多个占位符，后面的值需要按顺序一一对应。

格式化整数时，可以指定宽度和是否补零：

```python
print("%2d-%02d" % (3, 1))
```

其中：

- `%2d`表示整数至少占2位，不足时用空格补全
- `%02d`表示整数至少占2位，不足时用0补全

输出：3-01

格式化浮点数时，可以指定小数位数：

```python
print("%.2f" % 3.1415926)
```

输出：3.14

`%s`具有通用性，可以将对象转换成字符串形式，如果不确定使用哪个占位符，`%s`通常可以作为兜底选择。

```python
print("Age: %s. Gender: %s" % (25, True))
```

如果字符串里要输出普通的 `%`，需要写成 `%%`：

```python
print("growth rate: %d %%" % 7)
```

输出：growth rate: 7 %


## 3、format()格式化

`format()`是字符串对象的方法，会把传入的填入`{}`占位符。

```python
print("Hello, {}".format("world"))
```

多个参数会按顺序填入：

```python
print("Hello, {}, your score is {}.".format("小明", 95))
```

`format()` 可以通过 `{0}`、`{1}` 指定参数位置：

```python
print("Hello, {0}, 成绩提升了 {1:.1f}%".format("小明", 17.125))
```

其中 `{1:.1f}` 表示取第 2 个参数，并按浮点数格式保留 1 位小数。

`format()`也可以使用命名参数：

```python
print("姓名：{name}，成绩：{score}".format(name="小明", score=95))
```

这种写法在模板较长、变量较多时更清晰。


## 4、f-string格式化

`f-string`是 Python 3.6 引入的字符串格式化方法。

写法是在字符串前加 `f`，然后在字符串中使用 `{}` 插入变量或表达式。

示例：

```python
name = "小明"
score = 95

print(f"姓名：{name}，成绩：{score}")
```

`f-string` 的 `{}` 中不仅可以写变量，也可以写表达式。

```python
a = 3
b = 5

print(f"{a} + {b} = {a + b}")
```

也可以调用方法：

```python
name = "python"

print(f"{name.upper()}")
```

`f-string` 可以使用格式化参数：

```python
r = 2.5
s = 3.14 * r ** 2

print(f"The area of a circle with radius {r} is {s:.2f}")
```

其中 `{s:.2f}` 表示按浮点数格式显示，并保留 2 位小数。
