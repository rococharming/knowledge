# 一、调用函数

## 1、函数的基本含义

函数是已经封装好的一段代码，用来完成某个具体任务。

Python内置了很多函数，可以直接调用。例如：

| 函数        | 作用     |
| --------- | ------ |
| `abs()`   | 求绝对值   |
| `max()`   | 求最大值   |
| `int()`   | 转换为整数  |
| `float()` | 转换为浮点数 |
| `str()`   | 转换为字符串 |
| `bool()`  | 转换为布尔值 |
调用函数时，需要知道函数名和它需要的参数。

例如，`abs()`用于求绝对值：

```python
print(abs(100))  
print(abs(-20))  
print(abs(12.34))
```

输出：

```text
100
20
12.34
```

函数的基本调用形式是：

```text
函数名(参数)
```

如果函数需要多个参数，参数之间用逗号分隔：

```text
函数名(参数1, 参数2, 参数3)
```

## 2、查看函数帮助

如果不清楚一个函数怎么使用，可以通过`help()`查看帮助信息。

例如：

```python
print(help(abs))
```

也可以查阅[Python函数文档](https://docs.python.org/3/library/functions.html)。


## 3、参数数量错误

调用函数时，参数数量必须符合函数要求：

例如，`abs()` 只接收一个参数：

```python
abs(1, 2)
```

会报错：

![[Pasted image 20260601204304.png|300]]

`TypeError` 表示类型或调用方式不符合函数要求。这里的问题是参数数量错误。

## 4、参数类型错误

参数数量正确，但参数类型不符合要求，也会报`TypeError`。

例如：

```python
abs("a")
```

会报错：

![[Pasted image 20260601204516.png|300]]

`abs()` 需要接收数字，不能接收字符串 `"a"`。

## 5、接收多个参数的函数

不同函数对参数数量的要求不同。

`abs()`只接收一个参数，而`max()`可以接收多个参数，并返回其中最大的值。

```python
print(max(1, 2))
print(max(2, 3, 1, -5))
```

输出：

```text
2
3
```

也可以传入一个可迭代对象：

```python
print(max([2, 3, 1, -5]))
```


## 6、数据类型转换函数

Python内置了一些常用的数据类型转换函数。

| 函数        | 作用     |
| --------- | ------ |
| `int()`   | 转换为整数  |
| `float()` | 转换为浮点数 |
| `str()`   | 转换为字符串 |
| `bool()`  | 转换为布尔值 |
示例：

```python
print(int("123"))
print(int(12.34))

print(float("12.34"))

print(str(1.23))
print(str(100))

print(bool(1))
print(bool(""))
```

输出：

```text
123
12
12.34
1.23
100
True
False
```

## 7、函数名也是变量

在 Python 中，函数本身也是对象。**函数名可以理解为指向函数对象的变量**。

例如：

```python
a = abs
```

这里不是调用 `abs()`，而是把函数 `abs` 赋值给变量 `a`。

之后可以通过 `a` 调用这个函数：

```python
a = abs

print(a(-1))
```


# 二、定义函数

## 1、函数定义的基本语法

在 Python 中，使用`def`定义函数。

基本结构如下：

```python
def 函数名(参数):
	函数体
	return 返回值
```

例如，定义一个求绝对值的函数：

```python
def my_abs(x):
	if x >= 0:
		return x
	else:
		return -x
		
print(my_abs(-99))
```

输出：

```text
99
```

其中：

|部分|含义|
|---|---|
|`def`|定义函数的关键字|
|`my_abs`|函数名|
|`x`|参数|
|`:`|表示函数体开始|
|缩进代码块|函数体|
|`return`|返回函数结果|
## 2、return返回结果

`return`用于结束函数，并把结果返回给调用方。

```python
def my_abs(x):
    if x >= 0:
        return x
    else:
        return -x
```

函数执行到 `return` 后，就会立即结束。后面的代码不会继续执行。

如果函数没有写 `return`，执行结束后默认返回 `None`。

```python
def hello():
    print("hello")

result = hello()

print(result)
```

输出：

```text
hello
None
```

`return None` 可以简写为`return`。

## 4、从文件中导入函数

如果把函数定义保存到`abstest.py`文件中：

```python
def my_abs(x):
    if x >= 0:
        return x
    else:
        return -x
```

可以在同目录下启动Python解释器，然后导入这个函数：

```python
from abstest import my_abs  

print(my_abs(-10))
```

输出：

```text
10
```

这里的 `abstest` 是文件名，不包含 `.py` 扩展名。

`import` 的完整用法后续在模块部分再展开。

## 5、空函数和pass

如果暂时还没写好函数体，可以使用`pass`作为占位语句。

```python
def nop():
	pass
```

`pass` 什么也不做，只是为了让语法结构完整。

例如：

```python
if age >= 18:
    pass
```

如果代码块中什么都不写，会产生语法错误：

```python
if age >= 18:
```

所以，`pass` 常用于先搭好代码结构，后续再补充具体逻辑。

## 6、参数数量和类型检查

调用自定义函数时，如果参数数量不对，Python会自动报错。

```python
my_abs(1, 2)
```

会报错：

```text
TypeError: my_abs() takes 1 positional argument but 2 were given
```

参数数量错误时，Python 可以自动检查。但参数类型是否合理，需要函数内部自己处理。

```python
print(my_abs("A"))
```

报错：

```text
TypeError: '>=' not supported between instances of 'str' and 'int'
```

原因是 `"A" >= 0` 这个比较本身不合法。

可以使用 `isinstance()` 做参数类型检查，`isinstance()`判断一个对象是否属于某个类型。

基本写法：

```python
isinstance(对象, 类型)
```

例如：

```
print(isinstance(10, int))
print(isinstance(3.14, float))
print(isinstance("A", str))
```

输出：

```text
True
True
True
```

如果想同时允许多种类型，可以把类型写成一个元组：

```
isinstance(x, (int, float))
```

它表示：判断 `x` 是否是 `int` 或 `float` 类型。

因此，可以把 `my_abs()` 改成：

```python
def my_abs(x):
    if not isinstance(x, (int, float)):
        raise TypeError("bad operand type")

    if x >= 0:
        return x
    else:
        return -x
```

这里：

```python
if not isinstance(x, (int, float)):
```

表示如果 `x` 既不是 `int`，也不是 `float`，就进入这个分支。

再次传入错误类型：

```python
my_abs("A")
```

会报错：

```text
TypeError: bad operand type
```

这里的 `raise` 用于主动抛出错误。错误和异常处理后续再展开。

## 7、返回多个值

Python 函数可以看起来返回多个值。

例如，可以根据坐标，移动距离和角度计算新坐标：

```python
import math

def move(x, y, step, angle=0):
	nx = x + step * math.cos(angle)
	ny = y + step * math.sin(angle)
	return nx, ny
```

调用函数：

```python
x, y = move(100, 100, 60, math.pi / 6)

print(x, y)
```

输出：

```text
151.96152422706632 70.0
```

Python 函数返回多个值时，本质上返回的是一个 `tuple`。

示例：

```python
r = move(100, 100, 60, math.pi / 6)  
print(r)
```

输出：

```text
(151.96152422706632, 70.0)
```

下面两种写法是等价的：

```python
return nx, ny
```

```python
return (nx, ny)
```

只是在语法上，返回 `tuple` 时可以省略括号。

多个变量也可以同时接收一个 `tuple`：

```python
x, y = move(100, 100, 60, math.pi / 6)
```

相当于按位置解包：

```python
r = move(100, 100, 60, math.pi / 6)

x = r[0]
y = r[1]
```


# 三、函数参数

## 1、函数参数的作用

定义函数时，参数决定了函数可以接收哪些输入。

```python
def power(x):
	return x * x
```

这里的 `x` 就是参数。调用函数时，传入的值会赋给参数 `x`：

```python
print(power(5))  
print(power(15))
```

输出：

```text
25
225
```

函数参数相当于函数对外提供的接口。调用者只需要知道如何传参，以及函数返回什么结果，不需要关心函数内部的具体实现。

## 2、位置参数

位置参数是最常见的形式。

```python
def power(x, n):
    s = 1

    while n > 0:
        n = n - 1
        s = s * x

    return s
```

调用时，传入的值会按照位置顺序依次赋给参数：

```python
print(power(5, 2))  
print(power(5, 3))
```

输出：

```text
25
125
```

在 `power(5, 3)` 中，`5` 赋给 `x`，`3` 赋给 `n`。

如果缺少必选的位置参数，会报错：

```python
power(5)
```

```text
TypeError: power() missing 1 required positional argument: 'n'
```

## 3、默认参数

默认参数是在定义函数时给参数指定默认值。

```python
def power(x, n=2):
    s = 1

    while n > 0:
        n = n - 1
        s = s * x

    return s
```

这样调用 `power(5)` 时，相当于调用 `power(5, 2)`：

```python
print(power(5))  
print(power(5, 2))  
print(power(5, 3))
```

输出：

```text
25
25
125
```

默认参数可以降低函数调用的复杂度。常用、变化小的参数适合设置默认值。

例如：

```python
def enroll(name, gender, age=6, city="Beijing"):
    print("name:", name)
    print("gender:", gender)
    print("age:", age)
    print("city:", city)
```

调用时可以只传必选参数：

```python
enroll("Sarah", "F")
```

也可以覆盖部分默认参数：

```python
enroll("Bob", "M", 7)
enroll("Adam", "M", city="Tianjin")
```

有多个默认参数时，可以按位置传参，也可以用参数名传参。跳过前面的默认参数、只指定后面的默认参数时，必须写参数名。

必选参数必须放在默认参数前面。

正确写法：

```python
def enroll(name, gender, age=6, city="Beijing"):
    pass
```

错误写法：

```python
def enroll(name, age=6, gender, city="Beijing"):    
	pass
```

会报语法错误：

```text
SyntaxError: non-default argument follows default argument
```

原因是默认参数在前面时，位置传参会产生歧义。

**默认参数不要使用可变对象**。

**默认参数在函数定义时就会被计算出来，并在后续调用中复用**。

下面的写法有问题：

```python
def add_end(L=[]):  
    L.append("END")  
    return L  
```

调用结果：

```python
print(add_end())
print(add_end())
print(add_end())
```

输出：

```text
['END']
['END', 'END']
['END', 'END', 'END']
```

原因是默认参数 `L` 指向同一个列表对象，每次调用都会修改这个列表。

推荐写法是使用 `None` 作为默认值：

```python
def add_end(L=None):
	if L is None:
		L = []
	
	L.append("END")
```

再次调用：

```python
print(add_end())
print(add_end())
```

输出：

```text
['END']  
['END']
```

定义默认参数时，应避免使用 `list`、`dict`、`set` 这类可变对象。

## 4、可变参数

可变参数用于接收任意数量的位置参数。

例如，计算多个数的平方和：

```python
def calc(*numbers):
    total = 0

    for n in numbers:
        total = total + n * n

    return total
```

调用时可以传入任意个参数：

```python
print(calc(1, 2))
print(calc(1, 2, 3))
print(calc())
```

输出：

```text
5
14
0
```

**在函数内部，`numbers` 是一个 `tuple`**。

```python
def calc(*numbers):
    print(numbers)
```

## 5、使用\*展开成可变参数

如果已经有一个`list`或`tuple`，可以使用`*`把它展开为可变参数。

```python
nums = [1, 2, 3]  
  
print(calc(*nums))
```

`*nums` 的作用是把 `nums` 中的元素按位置展开后传入函数。

## 6、关键字参数

关键字参数用于接收任意的命名参数。

```python
def person(name, age, **kw):
	print("name:", name, "age:", age, "other:", kw)
```

调用时，可以只传必选参数：

```python
person("Michael", 30)
```

输出：

```text
name: Michael age: 30 other: {}
```

也可以传入额外的关键字参数：

```python
person("Bob", 35, city="Beijing")
person("Adam", 45, gender="M", job="Engineer")
```

输出：

```text
name: Bob age: 35 other: {'city': 'Beijing'}
name: Adam age: 45 other: {'gender': 'M', 'job': 'Engineer'}
```

在函数内部，`kw` 是一个 `dict`。

关键字参数适合接收可选信息。例如用户注册时，`name` 和 `age` 是固定字段，`city`、`job`、`gender` 等信息可以按需传入。

## 7、使用\*\*展开为关键字参数

如果已经有一个`dict`，可以使用`**`把它展开为关键字参数。

```python
extra = {
    "city": "Beijing",
    "job": "Engineer",
}

person("Jack", 24, **extra)
```

输出：

```text
name: Jack age: 24 other: {'city': 'Beijing', 'job': 'Engineer'}
```

这相当于：

```python
person("Jack", 24, city="Beijing", job="Engineer")
```

`**extra` 的作用是把字典中的 `key-value` 展开为关键字参数。

## 8、命名关键字参数

如果想限制关键字参数的名字，可以使用命名关键字参数。

```python
def person(name, age, *, city, job):
	print(name, age, city, job)
```

`*` 后面的参数只能通过参数名传入：

```python
person("Jack", 24, city="Beijing", job="Engineer")
```

输出：

```text
Jack 24 Beijing Engineer
```

不能省略参数名：

```python
person("Jack", 24, "Beijing", "Engineer")
```

会报错：

```text
TypeError: person() takes 2 positional arguments but 4 were given
```

命名关键字参数也可以设置默认值：

```python
def person(name, age, *, city="Beijing", job):
	print(name, age, city, job)
```

调用时可以省略有默认值的 `city`：

```text
person("Jack", 24, job="Engineer")
```

输出：

```
Jack 24 Beijing Engineer
```

如果函数已经有可变参数，后面的命名关键字参数不需要再写单独的 `*`：

```python
def person(name, age, *args, city, job):    
	print(name, age, args, city, job)
```

## 9、参数组合

Python 函数可以组合使用多种参数。

参数定义顺序通常是：

```text
必选参数、默认参数、可变参数、命名关键字参数、关键字参数
```

示例：

```python
def f1(a, b, c=0, *args, **kw):
	print("a =", a, "b =", b, "c =", c, "args =", args, "kw =", kw)
	
def f2(a, b, c=0, *, d, **kw):
	print("a =", a, "b =", b, "c =", c, "d =", d, "kw =", kw)
```

调用示例：

```text
f1(1, 2)
f1(1, 2, c=3)
f1(1, 2, 3, "a", "b")
f1(1, 2, 3, "a", "b", x=99)
```

输出：

```text
a = 1 b = 2 c = 0 args = () kw = {}
a = 1 b = 2 c = 3 args = () kw = {}
a = 1 b = 2 c = 3 args = ('a', 'b') kw = {}
a = 1 b = 2 c = 3 args = ('a', 'b') kw = {'x': 99}
```

调用 `f2()`：

```python
f2(1, 2, d=99, ext=None)
```

输出：

```text
a = 1 b = 2 c = 0 d = 99 kw = {'ext': None}
```

也可以使用 `*args` 和 `**kw` 调用函数：

```python
args = (1, 2, 3, 4)
kw = { 
	"d": 99,
	"x": "#",
}
f1(*args, **kw)
```

输出：

```text
a = 1 b = 2 c = 3 args = (4,) kw = {'d': 99, 'x': '#'}
```

```python
args = (1, 2, 3)
kw = {
	"d": 88,
	"x": "#",
}

f2(*args, **kw)
```

输出：

```text
a = 1 b = 2 c = 3 d = 88 kw = {'x': '#'}
```

虽然 Python 支持复杂的参数组合，但实际写函数时应尽量保持接口清晰，不要为了灵活而过度组合。
