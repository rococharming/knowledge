# 一、函数的定义和调用

## 1、函数的基本含义

函数是一段可重复使用的代码。当调用函数时，函数体中的代码才会运行。

Python 内置了很多常用函数，前面已经使用过一些：

|函数|作用|
|---|---|
|`print()`|把内容输出到终端|
|`input()`|接收用户输入|
|`int()`|转换为整数|
|`float()`|转换为浮点数|
|`str()`|转换为字符串|
|`bool()`|转换为布尔值|

## 2、调用内置函数

调用函数时，需要写函数名和一对括号。如果函数需要参数，就把参数写在括号中。

示例：

```python
print('Hello Python')
```

`input()`可以提示用户输入内容：

```python
name = input('What is your name?')

print('Hello', name)
```

如果用户输入：

```text
Tom
```

输出：

```text
Hello Tom
```

`input()`接收的值类型总是`str`。如果要参与数字运算，需要先用`int()`或`float()`转换。

```python
age = int(input('How old are you?'))

print(age + 1)
```

如果不清楚一个函数怎么使用，可以通过`help()`查看帮助信息。

```python
help(abs)
```

也可以查阅[Python函数文档](https://docs.python.org/3/library/functions.html)。

## 3、定义函数

Python 使用`def`关键字定义函数。

基本语法：

```python
def 函数名():
    函数体
```

示例：

```python
def hello():
    print('Hello World')
```

定义函数并不会立刻执行函数体，只有调用函数时，函数体才会运行。

```python
hello()
```

输出：

```text
Hello World
```

Python 使用**缩进**表示代码块，函数体也必须缩进。

错误写法：

```python
def hello():
print('Hello World')
```

报错：

```text
IndentationError: expected an indented block after function definition
```

## 4、函数名

在 Python 中，函数本身也是对象。函数名可以理解为指向函数对象的变量。

```python
a = abs

print(a(-1))
```

输出：

```text
1
```

## 5、空函数和pass
如果暂时还没写好函数体，可以使用`pass`作为占位语句。

```python
def nop():
    pass
```

`pass`什么也不做，只是让语法结构保持完整。


# 二、函数参数

## 1、形参和实参

函数可以接收外部传入的数据。

定义函数时，括号中的名字称为**形参**。调用函数时，传入的具体值称为**实参**。

示例：

```python
def calculate_sum(a, b):
    print(a + b)

calculate_sum(3, 1)
```

输出：

```text
4
```

这里`a`和`b`是形参，`3`和`1`是实参。

调用函数时，实参数量必须符合函数定义。

错误示例：

```python
calculate_sum()
```

报错：

```text
TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

## 2、位置参数

位置参数是最常见的参数形式。调用函数时，实参会按照位置顺序依次传给形参。

```python
def power(x, n):
    result = 1

    while n > 0:
        n = n - 1
        result = result * x

    return result
```

调用：

```python
print(power(5, 3))
```

在`power(5, 3)`中，`5`传给`x`，`3`传给`n`。

## 3、默认参数

默认参数是在定义函数时给参数指定默认值。

```python
def power(x, n=2):
    result = 1

    while n > 0:
        n = n - 1
        result = result * x

    return result
```

调用：

```python
print(power(5))
print(power(5, 3))
```

输出：

```text
25
125
```

注意：必选参数必须放在默认参数前面。

正确写法：

```python
def enroll(name, gender, age=6, city='Beijing'):
    pass
```

错误写法：

```python
def enroll(name, age=6, gender, city='Beijing'):
    pass
```

报错：

```text
SyntaxError: non-default argument follows default argument
```

默认参数不要使用`list`、`dict`、`set`这类可变对象。

错误示例：

```python
def add_end(items=[]):
    items.append('END')
    return items

print(add_end())
print(add_end())
```

输出：

```text
['END']
['END', 'END']
```

原因是默认参数在函数定义时就会被创建，并在后续调用中复用。

推荐写法：

```python
def add_end(items=None):
    if items is None:
        items = []

    items.append('END')
    return items
```

## 4、可变参数

可变参数用于接收任意数量的位置参数，写法是在参数名前加`*`。

```python
def calc(*numbers):
    total = 0

    for n in numbers:
        total = total + n * n

    return total
```

调用：

```python
print(calc(1, 2))
print(calc(1, 2, 3))
print(calc())
```

输出：

```text
5
14
0
```

**在函数内部，`numbers`是一个`tuple`**。

如果已经有一个`list`或`tuple`，可以使用`*`展开成位置参数。

```python
nums = [1, 2, 3]

print(calc(*nums))
```

## 5、关键字参数

关键字参数用于接收任意数量的命名参数，写法是在参数名前加`**`。

```python
def person(name, age, **kw):
    print('name:', name, 'age:', age, 'other:', kw)
```

调用：

```python
person('Bob', 35, city='Beijing')
person('Adam', 45, gender='M', job='Engineer')
```

输出：

```text
name: Bob age: 35 other: {'city': 'Beijing'}
name: Adam age: 45 other: {'gender': 'M', 'job': 'Engineer'}
```

**在函数内部，`kw`是一个`dict`**。

如果已经有一个`dict`，可以使用`**`展开为关键字参数。

```python
extra = {
    'city': 'Beijing',
    'job': 'Engineer',
}

person('Jack', 24, **extra)
```

这相当于：

```python
person('Jack', 24, city='Beijing', job='Engineer')
```

## 6、命名关键字参数

如果想限制关键字参数的名字，可以使用命名关键字参数。

```python
def person(name, age, *, city, job):
    print(name, age, city, job)
```

`*`后面的参数只能通过参数名传入。

正确写法：

```python
person('Jack', 24, city='Beijing', job='Engineer')
```

错误写法：

```python
person('Jack', 24, 'Beijing', 'Engineer')
```

报错：

```text
TypeError: person() takes 2 positional arguments but 4 were given
```

命名关键字参数也可以设置默认值：

```python
def person(name, age, *, city='Beijing', job):
    print(name, age, city, job)
```

对于仅限关键字参数，带默认值的参数可以放在不带默认值参数前面。

## 7、参数组合

Python 函数可以组合使用多种参数。

参数定义顺序通常是：

```text
必选参数、默认参数、可变参数、命名关键字参数、关键字参数
```

示例：

```python
def f1(a, b, c=0, *args, **kw):
    print('a =', a, 'b =', b, 'c =', c, 'args =', args, 'kw =', kw)

def f2(a, b, c=0, *, d, **kw):
    print('a =', a, 'b =', b, 'c =', c, 'd =', d, 'kw =', kw)
```

调用：

```python
f1(1, 2, 3, 'a', 'b', x=99)
f2(1, 2, d=99, ext=None)
```

输出：

```text
a = 1 b = 2 c = 3 args = ('a', 'b') kw = {'x': 99}
a = 1 b = 2 c = 0 d = 99 kw = {'ext': None}
```

虽然 Python 支持复杂的参数组合，但实际写函数时应尽量保持接口清晰。


# 三、函数返回值

## 1、return返回结果

`print()`只是把内容输出到终端，并不代表函数把结果返回给了调用方。

示例：

```python
def calculate_sum(a, b):
    print(a + b)

my_sum = calculate_sum(3, 1)

print(my_sum)
```

输出：

```text
4
None
```

函数内部的`print(a + b)`会输出`4`，但函数没有使用`return`返回结果，所以`my_sum`得到的是`None`。

如果要把结果返回给调用方，需要使用`return`。

```python
def calculate_sum(a, b):
    return a + b

my_sum = calculate_sum(3, 1)

print(my_sum)
```

输出：

```text
4
```

`return`会结束函数，并把结果返回给调用方。

## 2、默认返回None

如果函数没有显式使用`return`，Python 默认返回`None`。

```python
def hello():
    print('Hello World')

result = hello()

print(result)
```

输出：

```text
Hello World
None
```

## 3、返回多个值

Python 函数可以看起来返回多个值。

```python
import math

def move(x, y, step, angle=0):
    nx = x + step * math.cos(angle)
    ny = y + step * math.sin(angle)
    return nx, ny
```

调用：

```python
x, y = move(100, 100, 60, math.pi / 6)

print(x, y)
```

输出：

```text
151.96152422706632 130.0
```

Python 函数返回多个值时，本质上返回的是一个`tuple`。

```python
r = move(100, 100, 60, math.pi / 6)

print(r)
```

输出：

```text
(151.96152422706632, 130.0)
```

下面两种写法是等价的：

```python
return nx, ny
```

```python
return (nx, ny)
```

多个变量同时接收一个`tuple`，本质上是按位置解包。


# 四、变量作用域

## 1、作用域的基本含义

作用域决定了变量可以在哪些位置被访问。

Python 按照`LEGB`规则查找变量名：

|缩写|名称|含义|
|---|---|---|
|`L`|Local|局部作用域，函数内部定义的变量|
|`E`|Enclosing|封闭作用域，外层嵌套函数中的变量|
|`G`|Global|全局作用域，文件顶层定义的变量|
|`B`|Built-in|内置作用域，Python 内置名称|

## 2、局部作用域

在函数内部定义的变量，默认只能在函数内部访问。

示例：

```python
def my_func():
    my_var = 10
    print(my_var)

my_func()
```

输出：

```text
10
```

如果在函数外部访问`my_var`，会抛出`NameError`：

```python
def my_func():
    my_var = 10
    print(my_var)

my_func()

print(my_var)
```

报错：

```text
NameError: name 'my_var' is not defined
```

## 3、封闭作用域

封闭作用域出现在嵌套函数中。内部函数可以访问外部函数中的变量。

示例：

```python
def outer_func():
    msg = 'Hello there!'

    def inner_func():
        print(msg)

    inner_func()

outer_func()
```

输出：

```text
Hello there!
```

外层函数不能直接访问内层函数中定义的局部变量。

错误示例：

```python
def outer_func():
    msg = 'Hello there!'
    print(res)

    def inner_func():
        res = 'How are you?'
        print(msg)

    inner_func()

outer_func()
```

报错：

```text
NameError: name 'res' is not defined
```

如果内层函数需要修改外层函数中的变量，可以使用`nonlocal`。

```python
def outer_func():
    msg = 'Hello there!'
    res = ''

    def inner_func():
        nonlocal res
        res = 'How are you?'
        print(msg)

    inner_func()
    print(res)

outer_func()
```

输出：

```text
Hello there!
How are you?
```

## 4、全局作用域

在函数外部定义的变量属于全局作用域。全局变量可以在函数内部读取。

示例：

```python
my_var = 100

def show_var():
    print(my_var)

show_var()
print(my_var)
```

输出：

```text
100
100
```

如果需要在函数内部修改全局变量，可以使用`global`。

```python
my_var = 10

def change_var():
    global my_var
    my_var = 20

change_var()

print(my_var)
```

输出：

```text
20
```

`global my_var`表示函数内部使用的是全局变量`my_var`，而不是创建一个新的局部变量。

不过，实际写代码时应谨慎使用`global`。如果大量函数都直接修改全局变量，程序状态会变得难以追踪。

## 5、内置作用域

内置作用域中保存了 Python 预先提供的名称，例如`print`、`str`、`type`、`isinstance`等。

示例：

```python
print(str(45))
print(type(3.14))
print(isinstance(3, str))
```

输出：

```text
45
<class 'float'>
False
```

这些名称不需要自己定义，就可以直接使用。
