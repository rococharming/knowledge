**问题汇总**：

1、使用`mac-intel` runner 跑 CI build 失败，

原因是  Skia 依赖：

```
NO LOCAL PREBUILT FOUND
GitHub prebuilt download → 404
```

随后退回本地编译 Skia，但 CI Runner 的 ICU 依赖不完整：

```
ninja: error:
icu/scripts/make_data_assembly.py
missing and no known rule to make it
```

> mac-intel 环境没有匹配当前 Skia 版本和 x64 架构的预编译包；回退源码构建时，Skia 的 ICU 依赖缺失。

建议下一步让 CI/Runner 维护者确认：

1. mac-intel Runner 是否完整执行了 Skia 依赖同步。
2. 构建前是否存在：

```
crates/skia-safe/skia-bindings/skia/third_party/externals/icu/scripts/make_data_assembly.py
```

3. 是否需要为当前 Skia 版本补充 x64 prebuilt artifact。
4. 修复后重新运行 `build-bundle-x64`。


 2、bdb --version 的版本问题

bdb --version 输出版本是否和 bdb npm 的版本保持一致


3、 @blueos/bdb@1.0.18-alpha.2

@blueos/bdb@1.0.18-alpha.2 的 UI预览 只支持 mac arm64，其他平台暂时只带了一个 bdb二进制。
