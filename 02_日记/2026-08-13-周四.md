1、ui 仓 main 合入的 1fecf4dd — "add native app framework (dlopen-based lifecycle +shared/macro NDK)"，在 shared/lib.rs 写了使用 libc 的代码，但漏了shared/Cargo.toml 声明 libc 依赖；GN 构建靠 rustflags 注入 libc 所以没暴露，cargo 构建（ui-previewer 路径）缺这个声明而失败。

分支：ui 仓库的  fix/ui-previewer-compile-error

2、feature 仓 main 合入的 3546a04 — "bluetooth# rewrite bluetooth features in rust"，在 features/bluetooth_feature.rs / bluetooth_ble_feature.rs 写了使用 bluetooth_framework / bluetooth_interface_bidl crate 的代码，但漏了 features/mod.rs 里这两个模块声明的 std_local cfg 保护；GN 构建靠 rustflags --extern 注入这两个预编译 rlib 所以没暴露，cargo 构建（ui-previewer 路径，std_local 模式）没有注入、且这两个 crate 在 monorepo 无 Cargo.toml 无法声明依赖而失败。
修复：给 bluetooth_feature / bluetooth_ble_feature 的 mod 声明加 #[cfg(not(feature = "std_local"))]
分支：feature 仓库的 fix/ui-previewer-compile-error
