# 跟踪日志

一、分析 Windows 上的 app.dll jax 编译问题

当前 Windows 上为解决 MSVC Link 导出表符号超限问题，对 `system_framework.dll`进行了分层串联。

当前 jax 能识别 `system_framework` facade，但 jax 的 Windows `local` ABI 实现不完整。

具体来说，jax 在 Rust app 编译失败，卡在 jax 的 Windows 路径处理。当前`blueos-pack@1.0.12-ndk.12`虽然接受 Windows `local` ABI，文件命名，wrapper 启动和链接参数仍然按 macOS/Linux 处理。

因此，现在使用裸 rustc 临时绕过编译 app.dll。

要恢复 jax，需要补齐 JAX Windows local-ABI：.exe/.dll/.lib命令，MVSC链接参数、Node wrapper 启动和自动初始化 VS 环境。
