
# 一、亚马逊平台概况

亚马逊公司（Amazon），创立于 1994 年，1995 年网站正式上线，最初以在线图书销售起家，之后发展成为全球大型综合电商及科技公司。

2012 年，Amazon Global Selling（亚马逊全球开店）进入中国，为中国卖家开展跨境出口业务提供支持。

Amazon 电商业务既面向 C 端消费者（Consumer，个人消费者），也面向 B 端消费者（Business，企业及机构买家）。

类似于国内京东，亚马逊也有自己的自营产品，即 **1P（First Party，第一方零售）**，亚马逊自己就是卖家。在商品界面看到类似 Sold by Amazon，就是典型的亚马逊自营。

国内做跨境电商运营，是指** 3P（Third Party，第三方卖家）**。

亚马逊全球开店已向中国卖家开放 20 大海外站点，覆盖北美、拉美、欧洲、亚太和中东。其中欧洲共有 10 大站点

# 二、亚马逊主流运营模式

## 按发货方式分

**FBA模式**：批量配货并发货至亚马逊官方仓库，出单后由亚马逊官方进行发货。

**FBM模式**：根据库存所在地分为**国内直发**和**第三方海外仓发货**两种

- 国内直发模式：无需囤货，批量上传大量产品链接，出单后到供应商处采购，再发往国外。
- 第三方海外仓发货模式：
	- 囤货至第三方海外仓，出单后由第三方海外仓发货（常见**FBA库容限制**和**易融产品**【每年5月1号-10月中旬亚马逊仓库不接收】）
	- 和供销平台合作（赛赢分销、大健云仓），销售供销平台的产品，作为中间商赚差价，不需要囤货（选品限制）

## 按经营方式分

- **精品**：自行开发一款产品（私模），市面没有同款，规避同质化竞争。以 FBA 模式为主，资金投入风险较高。（少量产品，重点打造爆款）
- **精铺**：细致分析市场数据，只做现货。FBA、FBM两种模式都行，FBA收益最大，但投入较高（先铺一批，再看哪些有销量，然后重点优化）
- **泛铺**：利用ERP软件或者纯手工创建大量产品，没有选品没有运营。有手就行，对于小卖家只适合 FBM 模式，侵权挂账号风险较大。（一次性上架几百上千个产品，什么热卖就铺什么，出单了再重点看，没出单就放着或下架）。

# 四、准备工作

## 账户准备信息

- 公司营业执照彩色扫描件
- 法人身份证彩色扫描件货彩色照片（文件清晰且完整）
- 外币信用卡（Visa或Mastercard），用于支付 39.9 美金（月服务费）
- 联系信息（手机号码/电子邮箱/联系地址）
- 收款信息（任选其一）
	- 亚马逊官方收款中国银行账户
	- 美国/香港银行账户
	- 第三方收款（推荐）

## 产品准备信息

了解亚马逊产品合规政策，哪些产品不能在亚马逊销售，哪些产品需要提供认证审核。

- FDA认证：食品、餐具、化妆品、药物、生物制剂、医疗设备或放射产品等
- CPC认证：所有12岁及以下儿童为主要目标使用对象的产品，如玩具、摇篮、儿童服饰等。
- FCC认证：无线电应用产品通讯产品和数字产品，遥控射频类产品。

亚马逊的**SPN服务商**去做认证。

## 品牌信息

亚马逊允许你卖货，但如果你想以“品牌方”的身份完整运营，就要证明这个品牌是你的，或者你有权使用这个品牌，证明材料的核心就是商标。

在亚马逊里，品牌信息主要包括：

| 内容        | 解释                      |
| --------- | ----------------------- |
| 品牌名称      | 例如：ABC HOME、KAMEN LIFE  |
| 商标类型      | 文字商标、图形商标，或带文字的 Logo 商标 |
| 商标注册国家/地区 | 美国、英国、日本、欧盟等            |
| 商标状态      | 已申请、待审中，或已注册成功          |
| 商标编号      | 商标局给你的申请号或注册号           |
| 品牌实物证明    | 产品或包装上真实印有该品牌名 / Logo   |

提供**目标站点国家商标局**注册的商标后，才能使用完整的运营功能。

例如做美国站，需要提前准备好美国的商标。因为商标的注册周期较长，需要提前准备好。

| 类型   | 含义                   | 状态         | 你可以怎么理解         |
| ---- | -------------------- | ---------- | --------------- |
| TM 标 | Trademark，商标已申请或正在使用 | 通常还没正式注册成功 | “我已经在申请/使用这个品牌” |
| R 标  | Registered，注册商标      | 已经被商标局核准注册 | “这个商标正式注册成功了”   |

以美国为例，TM 标注册回执 15 天左右，R 标下证 8—10 个月。

如果只做 FBM，可以不用注册商标，但做 FBA 一定要提前准备好。

**常见问题**：

1、商标的注册类目怎么选择？

根据自己选择做的类目来注册，因为商标也有保护范围。注册商标前，确定好自己要做什么类目。

2、如何注册国外商标？

如果拥有国外的身份信息，可以委托当地律师注册。如果没有，则通过服务商注册。推荐通过**亚马逊SPN服务商网络**中的官方认真服务商进行注册。
