# 一、什么是飞书 CLI ？

日常工作中，AI 和 飞书没有沟通渠道。当你让 AI 帮你写一份总结报告或者会议纪要，自己还需要把 AI 生成的内容复制粘贴到飞书文档里。

飞书 CLI （lark-cli）是飞书官方开源的命令行工具，它做的事情就是把飞书接入 AI 的工作流中。

安装好飞书 CLI 和对应的 Skill 之后，AI Agent （例如 Codex）就能直接：

- 创建和编辑云文档
- 读写多维表格数据
- 查询和创建日历事件
- 发送消息、回复群聊
- 处理邮件、管理任务
- 操作幻灯片、画板、知识库

# 三、场景实战

# 1、云文档

写文档需要反复和 AI 对话、复制粘贴、格式排版，效率比较低，有了飞书 CLI 后，就可以有三种方式：

- AI 起草，你来把关：AI 在飞书文档里直接创建初稿，你在文档里直接用**评论**提修改意见。AI 读取评论、修改正文，持续迭代，最终生成一篇符合要求的文档。
- 你起草，AI 把关：你写好初稿后，让 AI 阅读全文，以**评论**的方式指出逻辑漏洞、数据缺失、表述不清的地方，和你在评论区讨论。
- Markdown 无缝转飞书文档：如果你在 AI 工具或者自己用 Markdown 写了一篇技术文档，想发给同事看。那么直接说：把这个 Markdown 创建成飞书文档。Agent 会自动转换格式，高亮、表格、代码块、分栏全部保留。

## （1）AI 起草，你来把关

例如，根据团队讨论的会议纪要整理项目复盘：

```text
{{飞书文档链接}}
如上是团队讨论的会议纪要，根据我们讨论的内容，帮我在飞书创建一篇云文档，题目是“项目复盘”。
文档结构包括：项目背景、核心成果、遇到的问题、下阶段计划。
内容先写一个框架，每个部分 2-3 个要点。
```
## （2）你起草，AI把关

有时候自己写初稿，但初稿不知道哪里有问题，这时候可以将文档链接给 Agent，让它以**自身难保挑剔同事**的身份帮你 review，不直接改，只在有问题的地方留修改建议。

```text
{{飞书文档链接}}
阅读这篇文档，以**资深挑剔同事**的身份帮我 review。
不要直接修改，只把有问题的地方用划词评论标注出来，并给出具体的修改建议。
```
