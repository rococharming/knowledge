
# 一、飞书多维表格

飞书多维表格（ Base）是一款**表格形态**的在线数据库，用来存储和管理数据。区别于常规的电子表格，多维表格不仅能实现数据的存储、分析和可视化，还具有以下优势：

- **易协作**：实现多人编辑实时同步、批注讨论、历史记录一键溯源，协作更便捷
- **个性化**：提供丰富的字段、视图、仪表盘、插件能力，根据业务需求灵活搭建定制化的业务系统，用一张表轻松实现个性化业务管理
- **自动化**：通过自动化能力，无需代码即可快速同步项目进展、自动发送消息通知，解放人力，提升工作效率
- **安全性**：通过高级权限，可根据需要对行、列进行精细化的权限设置，保障数据安全。

与 Excel 的区别：

| 产品     | 定位       | 特点                 |
| ------ | -------- | ------------------ |
| Excel  | 电子表格     | 功能强大但门槛高，协作弱       |
| 飞书多维表格 | 数据库型协作工具 | AI 能力集成深，智能体是差异化优势 |

# 三、核心概念

### 字段

字段（列）规定一条数据应该包含哪些信息。比如客户管理表的字段可能是客户名称、联系方式、跟进状态、负责人。

![[assets/Pasted image 20261021002448.png|800]]

### 字段类型

每个字段必须设置类型，决定了这个字段能填什么内容。字段类型种类丰富，可以支持单选、多选、日期、地址等，根据需求选择合适的字段类型。

![[assets/Pasted image 20261021002540.png|800]]

| 类别   | 字段类型                                | 说明         | 示例                     |
| ---- | ----------------------------------- | ---------- | ---------------------- |
| 信息录入 | 文本、数字、日期、附件、<br>附件、单选、多选、超链接、<br>货币 | 基本数据录入     | 客户名称、联系电话等             |
| 组织协同 | 人员、群组                               | 可以 @ 对应的人  | @张三、项目群                |
| 数据关联 | 单项关联、双向关联、查找引用                      | 跨表格数据同步    | 关联客户表、引用订单金额           |
| 自动追踪 | 创建人、修改人、创建时间、最后更新时间                 | 自动记录变更     | 自动显示创建人和时间             |
| 计算   | 公式                                  | 支持 AI 辅助生成 | IF(状态="已完成", "✅", "⏳") |
| 自动化  | 自动编号、按钮                             | 触发工作       | 自动生成订单号、一键审批           |

### AI写公式

这是多维表格相比 Excel 最大的体验提升。

操作步骤：

1、字段类型选公式
2、选择编辑公式
3、切换到 AI 生成公式，在输入框用自然语言描述需求（例如判断当前行的「项目进展」是否等于“已完成”）
4、点击生成，等待AI自动写出公式
5、点击采纳再点击确认

公式生成后，新数据录入时会自动触发计算，不需要手动调整范围。

### 字段捷径

字段类型下方有「探索字段捷径入口」，封装了大量 AI 能力：

- AI文字生成（接入 DeepSeek、豆包等大模型）
- AI生图（接入即梦等模型）
- 图片文字提取（OCR）
- 网页链接读取和总结
- AI 翻译
- 发票信息提取
- 图片理解（多模态）
### 视图

视图是数据的展示方式，同一个底表可以创建多个视图，各自独立设置筛选和排序。

![[assets/Pasted image 20261021012310.png|800]]

共有六种基础视图类型：

| 视图类型 | 适用场景           |
| ---- | -------------- |
| 表格视图 | 默认视图，查看和编辑原始数据 |
| 看板视图 | 按状态分组，适合任务管理   |
| 画册视图 | 卡片形式展示，适合内容浏览  |
| 日历视图 | 按日期排列，适合排期管理   |
| 甘特图  | 项目时间线，适合进度跟踪   |
| 表单视图 | 收集数据，适合问卷和信息录入 |
### 仪表盘

仪表盘把底表数据用图表直观呈现，支持折线图、柱状图、饼图、数字卡片、进度条等组件。

![[assets/Pasted image 20261021012729.png|800]]

可以手动搭建，也可以让 AI 一键生成后微调。布局拖拉拽即可，支持多种主题风格。仪表盘跟随底表数据实时变化，不需要手动刷新。

### 自动化

表格右上角的机器人图标，点开编辑自动化规则。逻辑就两部分："当以下情况发生时"，"就执行以下操作"。

![[assets/Pasted image 20261021013225.png|800]]

触发条件：新增/修改记录、定时任务、按钮点击、字段值变更等
执行动作：发飞书消息、更新字段、新增记录、发 HTTP 请求、调用 AI

### 工作流

工作流支持多步骤节点式流程编排，比自动化更复杂。

可在节点中选择 AI 能力和外部接口，实现自动分类、内容填充、通知推送等。
