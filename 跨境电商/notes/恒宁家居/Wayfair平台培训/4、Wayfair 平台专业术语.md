
Wayfair 的供应商后台为 Partner Home，它是供应商在 Wayfair 平台上管理商品、订单、库存、价格、物流和资金的工作台。

模块名称：

| 模块名称                       | 功能说明                      | 举例                             |
| -------------------------- | ------------------------- | ------------------------------ |
| Orders（订单）                 | 查看所有订单、下载订单报告、上传跟踪号       | 客户买了2把餐椅，需要查看订单，安排发货，填写物流单号    |
| Products（产品）               | 上传新产品、编辑产品信息、管理产品列表       | 上传一款新吧椅，上传 主题、填写尺寸、颜色、材质等信息    |
| Inventory（库存）              | 更新库存数量、查看库存状态、管理仓库信息      | 某款办公椅原来有100件，卖掉20件后，更新可售库存     |
| Advertising（广告）            | 查看/调整 WSP 广告              | 给一款餐椅投放 WSP 广告，吸引更多客户点击购买      |
| Prcing（定价）                 | 查看/调整供货价、了解定价策略和成本结构、促销提报 | 一套餐椅供货价为80美元，想调整为85美元，或参加促销    |
| CastleCate Forwarding（CGF） | Wayfair 官方头程物流服务/箱标创建等    | 从中国工厂发一批椅子到美国，使用 CGF 安排国际运输    |
| Finance（账单）                | 查看付款、发票等                  | 查看某批订单的货款是否结算、实际收到了多少钱         |
| Insights（洞察）               | 查看洞察报告、各种销售报表、店铺数据报表      | 查看本月哪款吧椅销量最高，哪些商品表现不好          |
| Integrations（集成）           | 管理 API 对接                 | 把公司 ERP 和 Wayfair 对接，自动同步订单和库存 |

# 核心术语

## 订单与发货类

### Dropship Orders（供应商直发订单）

消费者在 Wayfair 前台下单后，Wayfair 向供应商发送采购订单（Purchase Order，PO），由供应商从自己的仓库或合作仓库直接向消费者发货。

核心特点： 商品不需要提前存放在 Wayfair 的 CastleGate 仓库，而是由供应商负责安排发货。

### CastleGate Orders（CG 仓库订单）

消费者在 Wayfair 前台下单后，由 Wayfair 的 CastleGate 仓库使用提前存放的库存完成订单发货。

核心特点： 供应商提前备货到 CastleGate 仓库，消费者下单后由 CastleGate 负责仓储出库和配送履约。

### Tracking Number（物流跟踪号）

物流公司为包裹生成的唯一跟踪编号，用于查询包裹的运输状态和配送进度。

例如 供应商收到 Wayfair 的采购订单（PO），供应商将办公椅交给 FedEx 运输，FedEx 为包裹生成 Tracking Number，供应商将物流跟踪号上传到 Wayfair。Wayfair 和消费者可以通过该单号查询包裹的运输进度。

核心作用：让平台和消费者知道商品是否发货、运输到哪里以及是否送达。

### Multichannel Fulfillment（MC，多渠道履约）

供应商将商品存放在 Wayfair 的 CastleGate（CG）仓库，除了履行 Wayfair 平台的订单，还可以使用这些库存为其他销售渠道的订单发货。

例如，你同时在 Wayfair 和自己的独立站销售餐椅，并且已经在 CastleGate 仓库储存了100把餐椅。消费者 A 在 Wayfair 购买了2把餐椅，由 CastleGate 仓库发货。消费者 B 在你的独立站购买了4把餐椅，你通过 MC 服务提交消费者 B 的履约订单。CastleGate 仓库从库存中取出4把餐椅，发给消费者 B。

核心作用：一个 CastleGate 仓库的库存可以服务多个销售渠道，减少供应商自行管理多个仓库的需求。

### Order Alerts（订单异常提醒）

Wayfair 系统针对需要关注或处理的订单发出提醒，帮助供应商及时发现订单异常。例如订单超时未发提醒。

核心作用： 帮助供应商及时发现订单问题，避免因处理不及时影响订单履约。

## 产品管理相关类

### SKU

Wayfair 产品编号，Wayfair 用来识别和管理商品的编号，同一商品页面可能包含多个颜色或规格变体。例如 CHKR1116。

### Part Number

供应商产品编号，供应商为具体商品型号（每个变体）设置的编号，用于识别、备货、发货。例如 WF-6870-Beige-F。

## Listing 

商品详情页，复用亚马逊的专有概念。

## Product Name

商品标题，让消费者知道卖什么。

## Description

产品描述，详细介绍产品的特点、材质、用途。
