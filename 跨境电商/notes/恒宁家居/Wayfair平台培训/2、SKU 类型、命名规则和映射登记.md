
# 一、SKU 映射是什么？

SKU 映射，就是建立“平台销售商品”与“仓库实际发货内容”之间的对应关系。

买家下单一个售卖 SKU 后，系统需要知道：

- 发哪一种或哪几种货
- 每种货发多少
- 从哪个仓库发
- 使用哪一种配货方案

因此，售卖 SKU 负责识别销售方案，映射登记负责说明具体怎么发货。


# 二、四种编码区别

| 编码类型    | 核心含义                                            | 主要使用人员     | 是否具备唯一性 | 示例             | 说明                                  |
| ------- | ----------------------------------------------- | ---------- | ------- | -------------- | ----------------------------------- |
| 统一型号    | 产品的型号，不区分颜色，材质等具体规格，用于同型号产品的汇总统计                | 全司人员       | 唯一      | 3008           | 3008 是公司的某款餐椅                       |
| 统一 SKU  | 公司内部用于标识具体产品规格的编码，可区分颜色、材质、规格、箱规等               | 全司人员       | 唯一      | 3008-BE-FB     | 3008-BE-FB 表示 3008 下的颜色为米色，材质为布艺的餐椅 |
| ERP SKU | ERP 系统中的货品识别编号，同一产品可能因工厂等不同而对应不同编码              | 物仓、仓库、下单人员 | 不唯一     | CQH-3008-BE-FB | CQH的C是国家，这里是China，QH是工厂识别代码         |
| 售卖SKU   | 各售卖平台用于识别商品销售方案的编码，同一产品可对应多个售卖 SKU，例如一个产品可能上架多次 | 渠道运营人员     | 不唯一     | WF-3008-BE-FB  | WF是 Wayfair 平台。                     |
一个假设的发货流程：

买家在 Wayfair 下单  ->   系统根据售卖 SKU 找到对应货品  ->  内部人员或系统创建发货单  ->  仓库按 ERP SKU 拣货发出。


# 三、统一 SKU 的编码结构

统一 SKU 是公司内部识别产品的唯一编码（相当于身份证），基本规则为款号 + 变体属性，用于将不同的 Seller SKU 或 ERP SKU 归类到同一个产品下。

从书记生成器的编码来看，统一 SKU 的完整结构为：

产品款号 - 颜色编码 + 框架颜色编码 + 材质编码  - 包装编码

以`BSW24-BRN1B-2P为例`：

| 字段     | 示例值   | 含义                             |
| ------ | ----- | ------------------------------ |
| 产品款号   | BSW24 | 产品型号，如餐椅 DCW、金属餐椅 DCM、吧椅 BSW 等 |
| 颜色编码   | BR    | 颜色简写，BR是 Brown                 |
| 框架颜色编码 | N     | 框架颜色（N原木色、K黑色、L胡桃木色）           |
| 材质编码   | 1B    | 材质类型（1B为布料1，2B为布料2，1L人造皮革1）    |
| 包装方式   | 2P    | 包装方式（1P=1箱一件、2P=1箱两件）          |


# 四、售卖 SKU 创建前的准备

售卖 SKU（Seller SKU），在 Wayfair 平台也称**Part Number**。

参考：https://lxpsvydtpzv.feishu.cn/wiki/Usr6wGc1niOL94k2HQIcP3yMnEd?sheet=M8uqcW

## 1、先确认店铺，再查前缀

公司通过 **渠道 + 店铺主体 + 区域站点** 区分账号，并为对应店铺规定 SKU 前缀。

![[assets/Pasted image 20261020140945.png]]

例如，Wayfair-NJHN-US 账号对应的 SKU 前缀就是 WF- 。

## 2、明确销售内容

创建前需要确认：

- 买家下单一件，会收到什么
- 产品每箱装多少
- 是否涉及多个箱规、多个产品或多个部位
- 是否有替代配货方案
- 发货仓库及货品状态

## 3、数量符号

| 表达   | 含义                      |
| ---- | ----------------------- |
| `1P` | 每箱一把                    |
| `2P` | 每箱两把                    |
| `2B` | 常规整箱销售示例中，发两箱           |
| 把数   | 买家最终收到的椅子数量             |
| 套数   | 完整销售单元的数量；一套可能包含一个或多个箱子 |

# 五、五类售卖 SKU 编写与登记规则

## 1、常规：单一统一SKU，按整箱发货

一个售卖 SKU 的配货内容只涉及一种统一 SKU，可以发一箱或多箱，不拆分原包装。

假设 `W23T-BE` 每箱装两把椅子：

|售卖 SKU|实际发货|买家收到|
|---|---|---|
|`DE-VC-W23T-BE`|`W23T-BE` × 1箱|2把椅子|
|`DE-VC-W23T-BE-2B`|`W23T-BE` × 2箱|4把椅子|
|`DE-VC-W23T-BE-3B`|`W23T-BE` × 3箱|6把椅子|

编写结构：店铺前缀  +  统一 SKU  + 数量后缀

一箱默认不加后缀，多箱使用 `-2B`、`-3B`。

## 2、组合：同款不同箱规组合

产品本身相同，但是不同箱规对应不同 SKU，将这些货搭配成一个销售规格。

例如：

| 统一 SKU            | 箱规   |
| ----------------- | ---- |
| `BSW23A-BE-FB-1P` | 每箱1把 |
| `BSW23A-BE-FB-2P` | 每箱2把 |

若销售三把椅子，可采用：

1P × 1箱＋2P × 1箱＝3把

此时三把椅子的  售卖 SKU 写为`BSW23A-BE-FB-1P+2P`。

编写结构：店铺前缀  +  统一 SKU 相同部分 + 箱规

**同一售卖 SKU 可以有不同配货方案**

注意，以这里的3把椅子为例，如果 2P 库存不足，或者 1P 需要清仓，实际发货也可以直接发 3 箱 1P。因此，该三把装商品的配货方案可以有两种：

|配货方案|发货内容|总箱数|总把数|
|---|---|---|---|
|方案一|`1P × 1箱＋2P × 1箱`|2|3|
|方案二|`1P × 3箱`|3|3|
因此，售卖 SKU 名称不能代替完整的配货映射。

**与常规的区别**

常规只使用一种统一 SKU；不同箱规组合的某个方案会使用两种或以上统一 SKU。两种方式都保持整箱包装，组合不等于拆箱。

## 3、拆箱类：一件完整产品分多个部位包装

拆箱类是指一件完整产品由多个部位组成，并分成多个箱子包装。例如沙发，床等，必须把对应部位一起发出，才能构成完整产品。

假设一张床分成床头箱和床架箱：

|买家购买|必须发出的内容|
|---|---|
|1张完整的床|床头箱 × 1＋床架箱 × 1|

这里发两箱，只交付一件完整产品。

**它不是指打开一箱两把装椅子、只取出一把销售。**

编写结构：店铺前缀＋统一 SKU＋套数后缀

登记分老品和新品两种情况：

- 老品：统一 SKU 代表完整产品。登记时，拆成几个部位，就要登记几行，并在 ERP SKU 字段填写对应的部位和数量。


![[assets/Pasted image 20261020112502.png]]

- 新品：各部位已有独立统一SKU。系统为各个部位分配了统一 SKU，按部位分行，分别选择统一 SKU 并填写数量。

![[assets/Pasted image 20261020112625.png]]

## 4、组合类：不同款式组合销售

将不同产品组合成一个销售套装，例如餐桌＋餐椅。编写时使用 `#` 连接不同产品。

示例：GC-EDTO4A-BK-WD#DCW70A-BE-FB-2P-2B

|组成部分|含义|发货数量|
|---|---|---|
|`EDTO4A-BK-WD`|餐桌|1份|
|`DCW70A-BE-FB-2P`|每箱2把的餐椅|2箱，共4把|

EDTO4A-BK-WD 为餐桌，DCW70A-BE-FB-2P 为餐椅。

通常单台餐桌放在前面，餐椅放在后面。

登记要求：同一个 Seller SKU，不同产品的统一 SKU 各自登记一行，并在配货数量上填入单套发货量。如餐桌行填1，餐椅行填2。

## 翻新类：Like New 状态产品

适用于状态为 Like New 的翻新产品。

编写结构：店铺前缀＋仓库翻新 SKU

适用于状态为 Like New 的上架产品，编写规则为：店铺代码  + 仓库翻新 SKU。

多套售卖同样可以增加 2B 和 3B。

登记要求：翻新产品有专属通道，在登记表里的壹禾仓-FX产品上架登记视图中填写。

# 六、常见问题

1. 二次上架链接标注规则

次重复上架的次数在统一SKU中的标注位置：  

- ✅ 老版SKU变体属性带「-」分隔：WF-W188-DGY2-2B（推荐在颜色上标注）
- ✅ 新版SKU变体属性无分隔：WF-DCW103A-DNL1L2-2P（推荐直接在属性上标注）
- ❌ WF-DCW45A-BE-FB2 -1P-3B（影响不大，但不推荐）

2. 统一 SKU 的规格问题

统一SKU的规格属性为公司固定规定，无需自行编写。餐椅吧椅无规格标识的统一 SKU，默认一箱 2 把。个别特殊情况除外（例如吧椅4840BS和B6269的1P规格的统一SKU，并没有标记规格）。新品统一SKU均会标明规格，无法判断规格的情况会未来逐渐减少甚至杜绝，后续无需自行判断。

可参考 ERPSKU 底表：https://lxpsvydtpzv.feishu.cn/wiki/NoTTwq8fPi7kuIkqVsXcMsS5n3b?table=tbl64mtzxtMzAyqv&view=vewrf9CEPt。

3. 3P规格平台SKU写法

- ✅ WF-6225-BE-FB- 1P+2P （推荐1箱+1箱组合，易识别组合发货且字符短）
- ❗️ WF-6225-BE-FB- 3P （可用但不推荐，易与普通SKU混淆）
- ❌ WF-6225-1P-BE-FB#6225-2P-BE-FB（字符过多，不推荐1箱+1箱组合用这样编写）
- 另外补充：✅ WF-6225-1P-BE-FB#6225-2P-BE-FB-2B（5P组合情况下的推荐写法）

4、 组合产品多次上架规则

套装组合产品多次上架时，上架次数标记统一加在#符号后的统一SKU。

举例：  

- 初次上架：WF-EDT04A-BK-WD-1P#DCW87A-BE-FB-2P-2B
- 二次上架：WF-EDT04A-BK-WD-1P#DCW87A-BE2-FB-2P-2B
- 三次上架：WF-EDT04A-BK-WD-1P#DCW87A-BE3-FB-2P-2B
