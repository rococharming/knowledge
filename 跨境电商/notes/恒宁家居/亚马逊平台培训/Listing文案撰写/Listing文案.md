# 一、Listing 框架

## 标题（Title）

亚马逊自 2026 年 7 月 27 日起实施新的 Listing 标题规则：

| 维度              | 官方规定                                      |
| --------------- | ----------------------------------------- |
| 适用站点            | 所有站点，**但不包括埃及、沙特阿拉伯、土耳其、阿联酋**             |
| 适用商品            | 所有商品类型，**但不包括媒体类商品（media product types）** |
| 主标题             | 最多 **75字符，包含空格**                          |
| Item Highlights | 最多 **125字符，包含空格**                         |

>两个字段分别受字符限制，不能相互调剂额度。

- Product Title（主标题）

参考结构：品牌词  +  核心产品词  +  最关键属性/最强差一点 + 颜色（适用时）

主标题优先让卖家快速识别产品是什么，以及与其他商品的重要区别。

关键区分信息可以是型号、尺寸、套装数量或核心功能，应根据商品特点和类目要求取舍，不必机械填满上述各项。优先将最重要的变体属性保留在主标题，其他属性可放入 Item Highlights。

对于颜色比较突出的产品例如家具，颜色词放在主标题末尾。

- Item Highlights（商品亮点）

可选信息：补充功能、材质 、结构、风格、适用场景

适合放置需要进一步说明、帮助买家比较商品，但不必全部放入主标题的信息。根据实际产品选择，不必逐项填写。

>主标题和商品亮点都参与搜索，两者没有搜索优先级差异；合理分配关键词，避免为收录反复堆词。

写作规范：

- **英文大小写**：实义词首字母大写，介词、冠词、连词通常小写；品牌、型号及常用缩写保留正确大小写，不使用整段全大写。
- **必要标点**：允许用于正常表达的 `&`、逗号、连字符等标点，避免装饰性符号。
- **禁用字符**：主标题不得使用 `! $ ? _ { } ^ ¬ ¦。~ # < > *` 等符号仅可在产品标识、尺寸或测量等必要语境中使用，不得用于装饰。
- **品牌特殊字符**：品牌名称含禁用字符时，应按官方指引填写在 **Brand name 字段**；该字段中的特殊字符享有豁免，不应直接理解为主标题也享有相同豁免。
- **重复用词**：主标题中同一单词不超过 **2 次**，单复数合并检查；介词、冠词、连词除外。品牌词也受此限制，但同一词用于明显不同语境时可区别处理，例如品牌 **Old Navy** 与颜色 **Navy Blue**。

## 五点描述（Bullet Points）

五点描述用于说明产品的重要功能、特点及其对买家的实际价值，帮助买家判断产品是否符合需求。

写作方式：

利益点小标题 + 具体功能说明 + 用户场景 / 痛点连接

按 FAB：事实 -> 作用 -> 买家好处展开，不只列参数或空泛形容词。

| 层次           | 要回答的问题     | 示例                  |
| ------------ | ---------- | ------------------- |
| Feature：特性   | 产品有什么？     | 椅子可以折叠              |
| Advantage：作用 | 这个特性有什么作用？ | 闲置时可以收起，减少占地        |
| Benefit：好处   | 对买家有什么意义？  | 小房间需要活动空间时，可以把椅子收起来 |

五条默认分工：

① 最核心卖点：讲清产品定位，以及卖家购买它的首要理由
② 技术/材质/功能差异化：用具体事实说明产品特点及实际好处，即为什么比别人好
③ 其他功能/参数/规格等次功能卖点等介绍：产品除了与别人的差异化意外的功能卖点能介绍
④ 产品材质等详细描述：使用优质面料/海绵等
⑤ **适用范围、安装或保障**：说明适用条件、安装方式或允许展示的真实保障，减少购买疑问；不写退款、无条件保证等受限承诺。

写作要求：
- **长度**：默认5条，英文每条以 200 ~ 250 为写作参考。实际服从站点／商品类型上限，不凑字数。每条字数尽量接近。
- **小标题**：说清“具体利益＋对应特性”，英文通常 **4–8 词**。
- **重点前置**：尽量在每条前 **80 字符**讲清核心好处，各条主题独立、句式自然有变化。
- **关键词**：每条至少自然融入 **1 个适用的词库候选词**，优先保留完整词序和连续性，不拆词冒充完整覆盖，不为埋词重复内容。
- **场景**：适用空间／场所主要集中在最合适的一条，一般在安装部分；其他条可自然说明打字、后仰、收纳等功能动作。
- **句式变化**：
	- **开头变化**：The／This 可以使用，但避免五条反复同样开头；可自然使用品牌名、品牌所有格（Brand’s）、部件名、a/an、your、it/its，避免反复重复品牌。
	- **结构变化**：不只使用主谓宾、主系表，也可搭配祈使句、介词短语、条件从句，以及“配件／功能 of 关键词”等后置定语结构。
	- **自然优先**：保持指代清楚、所属关系准确、关键词完整；不机械替换开头，不硬套复杂语法，不设固定句型配额。
- **兼顾客观事实与主观体验**：家居类产品应结合材质、填充、支撑、包覆及表面特点，描述具体的触感、坐感、柔软度或姿态感受，让买家能够想象使用体验，避免反复使用“舒适”“优质”等空泛形容词。

## 描述（Description）

产品详情描述（Product Description），也叫长描述，用于进一步介绍产品、补充五点未展开的细节，帮助买家理解使用价值。

产品详情描述是亚马逊卖家进一步展示产品细节，或再次强调产品重点的位置，更可以作为标题和五点描述的关键词补充，提高Listing的关键词或长尾关键词权重。

**Basic／Premium A+ 上线后，原纯文本描述会被隐藏，但仍应维护该字段，使信息与 A+ 保持一致。

亚马逊规定，详情描述的字数限制不能超过**2000字符**。具体站点／商品类型另有限制时，以实际要求为准。

参考内容结构：


一般包含：

- 开头标题＋产品介绍段
- Why Choose［品牌 + 产品］?
- 5组利益点小标题＋独立说明段
- Specifications：逐行列出参数
- 结尾核心价值收束句

应用 A+ 后描述不会显示。

亚马逊规定，详情描述的字数限制不能超过**2000字符**。

一般包含：

- 开头标题＋产品介绍段
- **Why Choose［品牌＋核心产品名］?**：同时包含品牌和产品类型，不只写品牌名（无则不写）。
- 5组利益点小标题＋独立说明段：每段提供不同信息，补充细节，不逐段复制五点。
- Specifications：按“参数名：数值与单位”逐行列出购买判断所需的核心规格。
- **结尾核心价值收束句**：简洁重申产品价值，不加折扣、催单或绝对承诺。

写作要求：

- **参数择要**：优先保留尺寸、适配、承重／容量等关键规格，不必列全；区分整体尺寸、座面尺寸及调节范围，不推算缺失数据。
- **兼顾事实与体验**：例如家居类结合材质、填充、支撑、包覆及表面特点，描述具体触感、坐感或姿态感受，避免重复“舒适”“优质”。
- **清晰易读**：保留小标题、空行及逐行参数，句式自然有变化；使用纯文本，不添加 HTML、表情或装饰符号。
- **事实不足先确认**：不为凑满五组补造功能、参数、安装或保障信息，不写竞品品牌、无依据的比较优势或绝对化保证。

## 后台搜索词（Search Terms）

Search Terms（后台搜索词）简称 ST，是卖家在后台填写的词，用于补充前台未覆盖的相关搜索词，不展示给卖家。

选词要求：

- 从适用的词库候选中，补充前台未覆盖的同义词、相关称呼、缩写及正确拼写变体，如 colour／color。
- 以产品相关性为前提，不因流量大而加入不适用的词，不刻意添加错拼
- 不含任何品牌（包括自有品牌和竞品品牌）、ASIN、促销或时效词、主观夸大及冒犯性内容

格式要求：

- **美国站少于 250 字节**，不是 250 字符；其他站点核实实际限制。
- 全部小写，单词间用单空格分隔，不加逗号或其他标点。
- 候选短语可拆成有效单词，无需组成句子或符合阅读语序。
- 删除最终主标题、商品亮点、五点和长描述已覆盖的单词；ST 内每个词只保留一次
- 明确的单复数通常保留一种，去掉无必要的冠词、介词和连词。


# 二、埋词

## 1、什么是埋词

“埋词”是在 Listing 的标题、商品亮点、五点、长描述、后台搜索词及 A+ 等内容中，合理使用潜在买家可能搜索的关键词，帮助平台理解产品，也让买家快速判断是否符合需求。

埋词的整个过程不是为了堆砌那些关键词，而是为了让亚马逊的算法更准确地理解你的产品是什么，从而在顾客搜索查询中更好地展示出你的产品。

## 2、埋词位置的权重

亚马逊算法对 listing 各部分的权重从高到低布局：

- **标题（权重最高）**：前60个字符必须包含核心词，移动端前60个字符很重要，PC端80个字符。
- **五点描述（次于标题）**：每条嵌入1~3个核心词以及其他的属性词，必须保证语速通顺。
- **产品描述 & A+页面（权重中等）**：A+页面所有大小标题都可以埋词。详细描述产品时，可自然埋入关键词。
- **Search Term（不会在前台显示，权重较低）**：所有未嵌入的关键词都可以放在这个位置，关键词可以拆分成单词灵活搭配。

## 3、词库在Listing文案中的埋词策略

在 [[跨境电商/notes/恒宁家居/亚马逊平台培训/词库搭建/词库搭建方法|词库搭建方法]] 中对 P0、P1、P2 优先级的词进行过埋词整理，

| 优先级      | 允许用途 | 筛选策略                                   |
| -------- | ---- | -------------------------------------- |
| P0       | 标题   | 选 **5–8 个候选词**，覆盖产品类型、关键属性和可证实差异；不足不凑数 |
| P1       | 五点   | 能解释卖点、功能、规格、材质、适用或安装信息；不设固定数量          |
| P1       | 描述   | 能展开介绍、选择理由、细节或场景；不设固定数量                |
| P0／P1／P2 | ST   | 从剩余代表词中选择，并能增加前台未覆盖的有效单词               |
| P3       | 留空   | 储备观察                                   |

要求：

- **数量目标**：主标题＋亮点＋五点＋长描述，合计 **20–25 个不同原始关键词**；重复只计一次。
- **完整命中**：保持原词顺序和连续性，不插词、跨句拆词或用共享单词冒充完整覆盖；必要变形单独记录。
- **自然度优先**：事实、适用性、可读性和字段上限优先，不为凑数量堆词。
