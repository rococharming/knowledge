# 搜索词、自然结果与广告结果

Customer Search Term（买家搜索词），或称关键词，是指指买家提交搜索时使用的文字，可以是一个词，也可以是一整串短语。

想找餐椅，可以在输入框搜索：`dining chairs`。

结果有两种展示方式：

- Sponsored Result（广告结果）：通过付费广告展示的结果，页面会用 **Sponsored** 等标记，告诉你这是一处广告展示。它可能是一张商品卡片，也可能是一组商品组成的广告模块。
- Organic Result（自然搜索结果）：搜索页正常排列的非广告结果，它不是购买广告位得到的。

# 广告关键词和买家搜索词

Advertising Keyword（广告关键词）是广告主在广告中选择的词或短语，用来匹配相关的买家搜索。广告主就是投放广告的一方，即卖家。

例如，卖家选择 **beige dining chairs**（米色餐椅）作为广告关键词，目的是让餐椅广告有机会展示给正在搜索这类商品的人。

Match Type（匹配类型）是控制广告关键词怎样与买家搜索文字对应的规则。这里先看一种：**Phrase Match（词组匹配）**，可以匹配保留关键词个部分及其顺序，并在前后增加其他文字的搜索。

例如，卖家推广一款米色餐椅：

1. 在广告里设置关键字 **beige dining chairs**，选择词组匹配
2. 买家搜索 **beige dining chairs set of 4**
3. 这串搜索保留了 beige dining chairs 的顺序，又加上 set of 4，因此可以符合这个关键词的匹配规则。
4. 广告由此获得参与展示的机会；是否实际展示，还取决于预算、竞争等因素。

所以，一个广告关键词可以关联多种符合规则的买家搜索词，两边不需要每次完全相同。

# 广泛、词组、精确匹配

Match Type（匹配类型）是广告关键词与买家搜索词之间的对应规则。关键字文字相同，选的匹配类型不同，可以关联的搜索范围也不同。

以 dining chairs （餐椅）作为关键词，假设卖家在 Sponsored Products（商品推广广告）中手动选择关键词。

## Exact  Match（精准匹配）

精准匹配范围最收敛，搜索词与关键词保持相同词语及顺序，也包括单复数等允许的变化。因此“精准”不表示每个字符都必须完全相同。

关键词：dining chairs

搜索：

- dining chairs 可匹配
- dining chair   可匹配（单复数变化）
- wooden dining chairs  不匹配（增加了 wooden 属性词，不符合精准匹配）

## Phrase Match（词组匹配）

词组匹配保留关键词这组词及其顺序，允许在前后增加其他词，也包括单复数变化。

关键词：dining chairs

搜索：

- wooden dining chairs  可匹配（增加了 wooden 属性词）
- dining chairs set of 4  可匹配
- chairs for dining room  词组被序，不能被本例词组匹配

## Broad  Match（广泛匹配）

广泛匹配允许更大的变化范围。买家搜索可以增加词、改变关键词词语的顺序，还可能根据词义与所推广商品上下文匹配同义表达与相关搜索，不要求每次都完整出现关键词。

关键词：dining chairs 

搜索：
- wooden dining chairs     符合广义匹配
- chairs  for  dining room   词语顺序改变并增加 for、room，也符合广泛匹配

广泛匹配不是“出现一个相同的词就都能匹配”。对于其他相关表达，是否匹配还取决于系统对词义和商品的判断，不能只用字面包含关系做绝对推断。

选择：

- 想让同一个词覆盖更多相关搜索，可以使用广泛匹配
- 想保留某个词组，同时接受前后加词，可以使用词组匹配
- 想更集中在所选词及其允许变化，可以使用精准匹配

# 自动投放与手动投放

Targeting（投放定向，简称投放）是确定广告希望匹配哪些搜索或商品的方式。以 Sponsored Products （商品推广广告）为例，卖家可以选择自动投放，也可以选择手动投放。

两者的核心区别是：亚马逊帮你寻找匹配目标，还是你选择目标。

Automatic Targeting（自动投放）：自动投放由亚马逊依据所推广商品的信息、历史购物查询等，寻找相关搜索和商品，决定广告可以参与哪些展示机会。卖家不需要先把每个要匹配的关键词逐条填进去。

例如，你选择推广米色四把装餐椅，并使用自动投放。系统可能为它寻找与餐椅相关的查询，例如 beige dining chairs set of 4（米色四把装餐椅），也可能匹配相关商品。这些是系统可能找到的目标，不是你事先逐条设置的关键词。

Manual Targeting（手动投放）：手动投放由广告主选择希望匹配的目标。这里的广告主就是投放餐椅广告的卖家，可选的目标包括关键词，也包括商品或类目。

你在手动关键词投放中添加 dining chairs（餐椅），选择词组匹配。买家搜索 beige dining chairs set of 4 时，可以按这个词组规则匹配。

这里的关键词和匹配类型都是你选择的；系统再按设置寻找符合条件的展示机会。

Product Targeting（商品投放）是手动投放的另一种选择：你可以挑选相关的具体商品或类目作为目标。例如挑选一款相似餐椅，争取在相关商品页面等位置展示广告。此时是在选商品目标，不是在填一个搜索关键词。

**Campaign（广告活动）**是可以独立设置、管理的一组广告安排。一个商品可以分别放进自动活动和手动活动，两种方式配合使用。

1. 先为米色餐椅建立一个自动活动，让系统探索相关搜索。
2. 查看**Search Term Report（搜索词报告）**，即帮助了解广告关联了哪些买家搜索及其表现的报告。假设其中出现 beige dining chairs set of 4，并且你判断值得继续测试。
3. 另外建立手动关键词活动，把这串词加为关键词，选择合适的匹配类型，单独观察。

这样，自动活动负责继续探索，手动活动让你对选中的词作更明确的控制。发现一个搜索词，不等于它必然值得长期投放；还要看后续表现。

# 否定关键词

Negative Keyword（否定关键词）是你在广告中设置的排除条件，用于阻止广告匹配不希望参与的买家搜索。普通广告关键词帮助寻找展示机会，否定关键词则帮助排除其中不想要的机会。

例如，你在美国站推广的是整把餐椅，不卖椅套。搜索词报告中出现 chair covers（椅套）和 dining chair covers（餐椅套）。这些人找的是套在椅子上的罩子，与这份餐椅广告的目标不符。

你可以添加与椅套相关的否定关键词，减少广告参与这类搜索。

在 Sponsored Products（商品推广广告）**中，自动投放和手动投放都能使用否定关键词。

Negative Exact（否定精准）排除与所填词完整对应的卖家搜索，也覆盖单复数等近似变体。它不会仅因更长的搜索包含这串词，就将其一并排除。

例如填 chair covers，选择否定精准：chair covers 和单数 chair cover 会被排除；加了 dining 的 dining chair covers 不会仅因这一项否定精准被排除。

Negative Phrase（否定词组）排除包含完整词组及其近似变体的卖家搜索，词组前后可以有其他词。因此，同样填 chair covers，选择否定词组，dining chair covers 也会被排除。
