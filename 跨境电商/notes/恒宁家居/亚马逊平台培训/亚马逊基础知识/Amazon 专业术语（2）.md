# Title

Title（商品标题）是商品页上的名称，用一段简明文字告诉买家这是哪款商品。标题中通常能读到品牌、商品类型、颜色等识别信息。

美国站从 **2026 年 7 月 27 日**起，除媒体类目外，标题最多 **75 个字符，包含空格**。这里计的是字符数，英文字母、数字、标点和空格都要计入，不是按单词数计算。

因此，标题应优先保留认出商品所需的核心信息。材质、使用场景等额外细节，可以放在 **Item Highlights（补充亮点）**：这是标题之外的简短补充字段，最多 **125 个字符**。

补充亮点可以与标题一起出现在搜索结果和商品详情页，也能被搜索。标题与补充亮点各有自己的上限，填写时分别安排信息。

# Bullet Points

Bullet Points（商品要点）是分条列出的重要商品信息，常用于说明特点、功能和使用细节。运营上也称为“卖点”或“五点描述”。

继续在同一餐椅页面向下看，找到 **About this item**，其下分条列出的短段落，就是商品要点：

# 主图和附图

**Main Image（主图）** 是商品图片组的首张图片，承担商品的主要视觉展示，也用于搜索和浏览结果，让买家先看清卖的是什么。

美国站通用图片指南要求主图准确呈现所售商品，通常使用纯白背景。只有有限商品类型允许生活场景作为主图，需看对应分类要求。

**Additional Images（附图）** 是主图之外的补充商品图片，用于展示其他角度、局部细节、尺寸或使用场景等。它们帮助买家进一步了解同一商品。

# 商品描述和A+

**Product Description （商品描述）** 用来进一步说明商品的特点、用途、规格或使用事项，承接标题、五点和图片没有展开的细节。普通商品描述可以用文字填写，前台也常以 Product Description 为区域标题。

**A+ Content（A+ 内容，常称 A+ 商品描述）** 是亚马逊提供的增强内容工具与展示形式，可以把图片、文字、对比表等组合起来介绍商品。一个模块就是一块按模板组织的内容，例如一张横图配说明，或一张商品对比表。

商品描述区域可以展示 A+ 内容。添加 A+ 后，该区域会展示这套增强内容，**原来的纯文本描述不再显示**。**原描述字段仍然保留**，其中的重要信息也要写进 A+。

基本 A+ 主要使用图文与对比表，Premium A+（高级A+）还可以使用视频、轮播等更丰富的形式。轮播是指同一个内容位置可以使用箭头、原点切换多页。

**A+ 的创建有资格与审核要求**。

# Rating 和 Review 

**Rating（星级评分）** 是用 1 到 5 星表达评价。某条条评论里的 5 星，是某个评论者的打分；页面汇总的 4.3 分，是亚马逊计算的整体星级。整体星级并不是简单的算术平均，还会考虑反馈的新旧、购买验证等因素。

**Rating count（评分数量）** 是页面显示的评论总数。买家可以只打星、不写完整文字评论，因此评分总数不等于文字评论篇数。

**Review（买家评论）** 指可逐条阅读的具体评价，通常包含星级、标题、正文和日期，也可能有图片或视频。星级表达评价高低，正文解释为什么。

继续进入 [VASAGLE 餐椅 B0GVYDW4YV](https://www.amazon.com/dp/B0GVYDW4YV)，下拉到页面的 Customer reviews，里面可以同时展示整体评分、评分数量和具体评论。

| 内容                 | 说明               |
| ------------------ | ---------------- |
| 4.3 out of 5       | 整体星级为 4.3，满分 5 分 |

| 一条带正文的 5 星评论       | 某位评论者的打分与体验      |
对于评论，还区分 VP 和 非 VP。

 VP 是指 **Verified Purchase（已验证购买）**，表示该评论者实际购买了该产品，提供亚马逊对平台购买来源的验证。

# 购买区域和销售报价

Offer（销售报价）是某个销售方针对具体商品提供的销售条件，它把“卖的是什么状况、多少钱、谁销售、谁发货”等信息放在一起，供买家选择。

打开 https://www.amazon.com/dp/B0GVYDW4YV 餐椅 Listing 页面，找到 Add to cart（加入购物车）、Buy Now（立即购买）按钮所在的购买区域：

![[assets/Pasted image 20261021114112.png]]

Buy New：购买全新商品
$299.98：一套四把装的商品价格
Shipper / Seller - Amazon.com：Amazon.com 同时负责销售和发货

因此，这份报价可以读为：向 Amazon.com 购买一套全新米色四把装餐椅，商品价格 $299.98，由 Amazon.com 发货。

Quantity（购买数量）按当前套装计算。选中四把装时，Quantity 1 就是一套，共四把；Quantity 2 则是两套，共八把。页面另显示的 $75.00 per count 是分摊到每把后的单位价，经过四舍五入；$299.98 才是这一套的商品价格。

此外，该 Listing 页面还提供二手报价，也就是 Used - Like New，表示二手，状况接近全新。

页面优先展示的是推荐报价（Featured Offer），它是商品详情页的重点展示、配有购买按钮的报价，也就是常说的**Buy Box**（购买框）。

如果要查看其他报价，可以找 Other sellers on Amazon（亚马逊上的其他卖家）等入口。这是因为亚马逊有跟卖的概念，也就是同一个 Listing 页面允许有多个卖家。
