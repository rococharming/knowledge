
>目标：围绕自己的产品，找到值得对标的竞品，说明为什么选择他们，并建立可用于后续分析的竞品表。
# 一、为什么需要竞品分析

市场分析帮助我们认识整个类目：市场有多大、主要有哪些产品、哪些类型卖的好，以及消费者有哪些需求。

明确自己的产品方向后，就需要进一步做竞品分析：在消费者可能拿来比较的商品中，哪些是我们的竞争对手？它们有什么优势和不足？我们可以据此优化什么？

例如，自己的产品日销量为 2，而相似竞品的日销量为 30+。面对这样的差距，可以从价格、图片、评论、卖点和关键词等方面逐步寻找原因。

## 1、确定定价基准

了解同类竞品的主流价格带和优惠后价格，为新品目标售价、可接受成本及供应链成本谈判提供参考，同时判断自己的产品是否具有价格优势或溢价空间。

主要结合 **Amazon 前台价格、Coupon / Deal 信息和卖家精灵历史价格曲线**，区分常规售价与短期促销价，避免用清仓价作为常规定价基准。

## 2、寻找流量机会

寻找搜索需求较高、与自己产品高度相关，但核心竞品覆盖较弱的关键词，用于标题、五点描述、A+ 页面和广告关键词布局。

例如，自己的床头柜具备充电功能，可以检查核心竞品对 `nightstand with charging station` 等词的覆盖情况，再结合搜索需求判断是否值得重点布局。

主要使用 **卖家精灵关键词挖掘、竞品 ASIN 关键词反查和多 ASIN 对比**。

## 3、挖掘消费者需求

通过竞品评论，识别消费者反复认可的优点和抱怨的问题。

- 好评中的高频认可点，可用于提炼产品卖点和改善 Listing 表达。
- 差评中的共性问题，可反馈给产品开发团队，用于优化结构、材质、尺寸和功能。

主要使用 **竞品评论区人工阅读和卖家精灵 AI 评论分析**，并结合具体评论理解问题发生的场景。

## 4、观察竞品运营节奏

持续跟踪竞品的价格、促销、销量和 BSR 排名变化，辅助调整自己的定价、广告、备货和上新节奏。

例如，竞品降价后销量和排名提升，需要结合降价持续时间及后续表现，判断它可能在冲排名、促销或清库存。单次变化只能提供线索，仍需持续观察。

主要使用 **卖家精灵历史价格曲线、BSR 趋势和 Amazon 前台持续监测**。



# 二、竞品分析怎么做

竞品分析可以按照以下顺序推进：

>明确自己的产品 → 建立候选池 → 筛选与分级 → 确定核心竞品 → 整理信息与评论 → 形成运营和优化方向

## 1、明确自己的产品

先整理自己的产品类型、款式、结构、材质、核心功能、卖点、规格、套装数量和目标售价。

如果产品已经上架，还需要记录当前所属细分类目及 BSR 排名，作为判断竞品排名位置的参照。

## 2、寻找候选竞品

通过 Amazon 核心关键词搜索、Best Sellers 榜单和 New Releases 新品榜，搜集值得进一步核对的商品。

这一阶段先建立候选池，再统一筛选。

## 3、筛选与分级

结合产品相似度、价格、目标消费者和销售表现，区分直接竞品、趋势竞品及间接竞品，并说明每个产品的选择原因。

## 4、确定核心竞品

从直接竞品中，进一步选出 **3个最直接的核心竞品**，作为后续重点运营对标对象。

## 5、对标分析并形成判断

建立完整竞品表，记录基础信息、变体结构、好评要点和差评要点，并说明每个产品的选择原因及分析用途。

最终围绕以下问题形成判断：

- 哪些商品是自己最直接的竞争对手？
- 哪些商品需要持续观察？
- 自己的价格、产品和 Listing 可以优化什么？
- 后续重点对照哪几个竞品推进运营？

# 三、先明确筛选范围

## 1、排除公司自有品牌

本轮竞品分析暂不纳入公司自有品牌 **MALOL、COLAMY** 的产品。

搜索或浏览榜单时，即使这些品牌的产品符合其他条件，也应从外部竞品名单中排除。

## 2、优先选择最近 2–3 年上架的产品

本轮重点分析 **最近 2–3 年上架**、具有现实对标价值的产品。

## 3、核对产品与需求是否相关

优先选择与自己的餐椅在款式、结构、材质、功能、卖点和使用场景上具有明确联系的产品。

配件、零部件及明显不属于餐椅研究范围的商品应排除。同一商品从多个渠道发现时，合并记录。

# 四、如何寻找候选竞品

寻找竞品的目标，是先建立一个相对完整的候选池。关键词搜索帮助发现争夺相似搜索流量的商品，榜单则补充类目内销售表现较好和近期值得关注的商品。

## 1、Amazon 前台核心关键词搜索

操作步骤：

1. 浏览器无痕浏览，打开 Amazon.com，确认是 **美国站**，并设置美国配送地址或邮编，例如 `10001`。
2. 输入与自己产品相关的核心关键词。例如床头柜可以搜索 `nightstand`、`bedroom nightstand`、`bedside table`；两件套产品还可以搜索 `nightstand set of 2`。
3. 优先浏览第一页，记录款式、功能、结构、规格和价格较接近的商品。
4. 如果第一页符合条件的商品较少，再扩展到第二页、第三页。通常检查前 1–3 页，重点关注前 2 页。
5. 记录候选商品的 ASIN、链接及发现它的关键词，便于后续核对。

**如何减少遗漏**

类目较大时，建议至少使用 **3 个核心关键词** 交叉搜索。

如果不确定该用哪个英文词，可以参照市场分析中的方法：先通过翻译工具或 AI 得到英文，再用卖家精灵关键词挖掘，结合相关商品图片和月搜索量选择更贴切的词。

优先选择与产品高度相关、能准确表达产品类型且具有稳定搜索需求的词。同一商品在多个关键词下出现时，合并记录，并保留对应关键词。

## 2、Best Sellers 榜单

关键词搜索更多反映搜索流量竞争关系，Best Sellers 榜单用于补充发现类目内销售表现较好的商品。

操作步骤：

1. 进入与自己产品对应的细分类目 **Best Sellers** 榜单。
2. 浏览 **Top 1–100** 商品，将相似度较高的产品加入候选池。
3. 重点关注排名靠前的产品、与自己产品结构及价格带接近的产品，以及关键词搜索中没有明显出现但类目销售表现较好的产品。

对于排名靠前的商品，还应通过历史趋势进一步确认其表现是否长期稳定。

## 3、New Releases 新品榜

进入对应类目的 **New Releases** 榜单，浏览 Top 1–100；做新品分析时，重点关注 **Top 20**。

1. 进入对应类目的 **New Releases** 榜单
2. 浏览 Top 1–100，新品分析时重点关注 **Top 20**
3. 记录其中与自身产品相似、且近期表现较好的新品。

记录与自己产品相似、近期表现较好的新品，主要寻找：

- 新进入市场的潜力产品。
- 新款式、新功能和新设计。
- 后续可能形成竞争的新兴产品。

新品榜的商品不能统一归为趋势竞品，需要根据竞争关系进一步区分。直接竞品和趋势竞品都可能存在。

# 五、竞品分级与交付

先核对候选商品是否与自己的产品或消费者需求有关，再按主要分析用途分为三个等级。

| 等级      | 主要关注什么                | 主要用途                        |
| ------- | --------------------- | --------------------------- |
| 一级：直接竞品 | 产品定位、功能、结构、价格和消费者高度接近 | 定价、卖点、关键词、评论、图片、A+ 和广告的全面对标 |
| 二级：趋势竞品 | 近期增长较快的新品或潜力产品        | 观察新品趋势、产品创新和潜在爆款特征          |
| 三级：间接竞品 | 满足相似需求，但产品形态或定位差异较大   | 参考替代需求、设计、材质及高低价格带机会        |
## 一级：直接竞品

直接竞品与自己的产品在 **产品定位、功能、结构、价格和目标消费者** 等方面高度接近，是上架后最直接争夺流量和订单的产品。

直接竞品可以来自核心关键词搜索、BSR 榜单，也可以来自新品榜。

筛选时优先考虑：

- 产品类型、款式和结构高度相似。
- 核心功能和主要属性高度重合。
- 目标消费者及使用场景基本一致。
- 核心关键词相同或高度重合。
- 价格接近，可先以自身目标售价 **±20%** 左右作为筛选参考。
- 有一定销量和市场代表性。

比较价格前，需要先核对套装数量和规格。多件套可按 **单件价＝套装售价÷套装内商品数量** 折算，同时保留套装售价，结合实际购买需求判断是否可比。

±20% 是筛选参考，最终仍要综合产品和需求判断，不能只凭价格接近就认定为直接竞品。**

## 二级：趋势竞品

趋势竞品当前体量可能还没有头部商品大，但属于 **近期增长较快、值得持续关注的新品或潜力产品**。

趋势竞品重点从新品榜寻找：产品与自己高度相似或仅有细微差异，价格相近，BSR 排名位于自己的产品附近。

筛选条件

可重点关注：

- 上架时间较短，例如不足 6 个月。
- 销量持续提升，或 BSR 排名持续改善。
- 评论增长速度明显高于普通新品。
- 评分表现较好。
- 功能、设计或款式具有明显创新和差异化。

例如：

> 上架约45天，已有30条评论，评分4.5分，同时销量和BSR持续提升。

这些信息可以作为进一步观察的线索。判断趋势时应结合历史变化，不能仅凭“上架时间短”或某一天的排名就认定为潜力产品。**

## 三级：间接竞品

间接竞品能够满足消费者相似的需求，但在 **价格、材质、结构、定位或产品形态** 上与自己的产品存在较明显差异。

常见情况包括：

- 功能相近，但价格差距较大。
- 用途相同，但材质档次不同。
- 产品形式不同，但能够互相替代。
- 消费场景相似，但产品定位不同。

例如，自己的产品是 **$70 的板式床头柜**，可以辅助参考 **$150 的实木床头柜** 或 **$35 的床边推车**。

价格高于自身产品约 2 倍，或低于自身产品约 50% 的商品，可作为寻找间接竞品的线索。但仍要确认它是否满足相似需求，价格差距本身不能证明竞争关系。**

这类产品主要用于参考功能创新、材质趋势、设计风格、替代需求和高低价格带机会，通常不作为主要定价与销量对标对象。


从候选池中确定 **10 个竞品产品**，优先保证直接竞品能够支撑主要对标，再按产品情况补充趋势竞品和间接竞品。

每个入选产品都需要写明：

- 它与自己的产品有哪些相似点或差异？
- 为什么选择它？
- 准备用它分析什么？
数量不足时，继续扩展相关关键词或榜单搜索；不要为了凑满 10 个而加入没有明确参考价值的商品。

## 最终名单与核心标记

最终整理 **10 个竞品产品**，优先保证直接竞品能够支撑主要分析，再补充具有明确价值的趋势竞品和间接竞品。

此外，从直接竞品中选择 3 个核心竞品，作为后续的 Listing 标题拆解、图片分析及卖点痛点分析。


## 建立完整竞品分析表

# 六、核心竞品深入分析

完成竞品筛选和基础信息整理后，对所选的 **3 个核心竞品** 分别进行标题拆解、图片分析和评论分析。

这一阶段需要从竞品信息进一步推导：它如何表达产品、如何帮助消费者理解产品、消费者实际认可什么，以及自己的产品和 Listing 可以怎样改进。

以下沿用床头柜作为方法示例。

## 模块一：标题

### 1、标题拆解

先保存竞品的标题原文，再按表达含义拆成词或短语，并标注每一部分的作用。

不需要把所有内容拆成单个英文单词。例如，`Fabric Drawer` 应作为一个短语理解，`Set of 2` 应完整保留，才能看出它表达的是材质、结构还是套装数量。

以 B0FD9TRBGG 标题为例：

> Huuger Night Stand Set of 2, Nightstand with 2 Drawers, Bedside Table | Open Shelf, Wooden Top, End Table, Fabric Drawer, for Bedroom, Living Room, Rustic Brown

| 词或短语                  | 作用分类               | 表达的信息                            |
| --------------------- | ------------------ | -------------------------------- |
| Huuger                | 品牌词                | 告诉消费者商品品牌；分析时记录，不作为自己的埋词候选       |
| Night Stand Set of 2  | 核心产品词 + 数量修饰       | 说明商品是床头柜                         |
| Nightstand            | 核心大词 + 同一产品词的另一种写法 | 与 Night Stand 表达同类产品，需检查是否存在重复表达 |
| with 2 Drawers        | 结构／收纳功能词           | 说明有两个抽屉                          |
| Bedside Table         | 产品同义词              | 床头柜的另一种常用称呼                      |
| Open Shelf            | 结构／功能词             | 说明具有开放式置物层                       |
| Wooden Top            | 材质                 | 描述桌面材质；不能仅凭该词认定为实木               |
| End Table             | 相关产品词              | 表达边桌用途，需要结合产品及关键词数据判断相关性         |
| Fabric Drawer         | 材质＋结构词             | 说明抽屉使用布艺材质                       |
| Bedroom / Living Room | 场景词                | 说明适用空间                           |
| Rustic Brown          | 风格／颜色词             | 表达外观风格及颜色                        |

分类时主要识别：

- **品牌词：** 商品属于哪个品牌。
- **核心大词：** 产品的核心大词，买家搜索最频繁的词。
- **功能／结构词：** 产品能做什么、采用什么结构。
- **材质词：** 产品或某个部位使用什么材质。
- **场景词：** 在哪里使用、适合什么用途。
- **风格词：** 产品呈现什么风格外观。
- **颜色词**：产品的颜色。
    
一个短语可能承担多个作用，不必强行只归入一类。

### 2、评估标题

| 检查项       | 评价                                                  |
| --------- | --------------------------------------------------- |
| 核心词是否齐全？  | 是否覆盖核心大词                                            |
| 品牌词位置     | 是否位于最前面                                             |
| 功能词是否突出？  | 主要功能是否都有                                            |
| 有没有堆砌无关词？ | 是否有无关词冗余                                            |
| 长度是否合适？   | Amazon允许200字符以内。<br>新规：主要标题（75字符内），Highlight（125字符） |

### 3、对比

对目标产品同样进行标题拆解，进行对比。

| 结果                | 后续处理                     |
| ----------------- | ------------------------ |
| 竞品表达了，自己也具备，但尚未表达 | 作为补充表达的候选，再核对关键词价值及放置位置  |
| 竞品表达了，自己不具备       | 不加入自己的 Listing           |
| 自己具备，竞品没有或表达较弱    | 判断是否属于消费者在意的差异化优势，安排重点表达 |
| 双方都有，属于基础属性       | 清楚说明即可，不必全部作为核心卖点        |

## 模块二：图片分析

### 1、先看主图

主图重点判断：消费者能否快速看清产品、套装数量和主要外观，以及图片是否真实、清晰。

| 检查项      | 说明                     |
| -------- | ---------------------- |
| 产品完整展示？  | 主体是否完整，是否容易辨认，套装数量数否明确 |
| 白底/纯色背景？ | 白底主图                   |
| 有无使用场景？  | 最好有场景感（但不是强制）          |
| 尺寸参照物？   | 建议放常见物品作大小对比           |
| 图片清晰度？   | 不能模糊/像素化               |
| 有无文字水印？  | 主图不能有非必要文字             |

### 2、附图和视频

附图主要帮助消费者理解产品、判断是否适合自己，并减少购买前的疑问

按信息任务检查，不必预设某类内容一定出现在第几张图。

| 类型    | 主要解决什么问题    |
| ----- | ----------- |
| 多角度展示 | 产品整体是什么样    |
| 尺寸与参照 | 能否放下、大小是否合适 |
| 材质与细节 | 用料和质感如何     |
| 功能与卖点 | 为什么值得购买     |
| 使用场景  | 放在家里是什么效果   |
| 套装与配件 | 到底会收到什么     |
| 安装说明  | 安装是否容易      |
| 视频    | 静态图片难以说明什么  |

### 3、形成自己的图片制作需求

每个核心竞品分析后，回答：

1. 哪些内容表达得清楚，值得借鉴？
2. 哪些购买疑问没有被解决？
3. 自己的产品有哪些特点需要重点展示？
4. 上架前需要制作哪些图片或视频？

# 七、汇总改进方向

三个核心竞品分别分析后，再横向比较，避免把某一个竞品的特点当作整个市场的需求。

|分析维度|核心竞品 1|核心竞品 2|核心竞品 3|对自己的启示|
|---|---|---|---|---|
|标题及 Item Highlights 的重点|||||
|图片表达的优点与缺口|||||
|好评中的主要认可点|||||
|差评中的主要问题|||||
|值得借鉴或改进的方向|||||

重点判断：

- 三个竞品反复表达、消费者也反复认可的特点是什么？
    
- 哪些问题在多个竞品中共同出现？
    
- 哪些只是单个商品或特定变体的问题？
    
- 自己的产品能解决哪些问题？
    
- 哪些改进需要调整产品，哪些可以通过 Listing 和图片表达完成？
    

最终输出三类具体行动：

1. **产品改进：**需要优化的结构、材质、规格、包装或配件。
    
2. **Listing 改进：**需要补充的关键词、产品信息和卖点表达。
    
3. **图片制作需求：**需要制作的主图、附图及视频内容。
