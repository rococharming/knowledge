>目标：掌握关键词采集、筛选、分类的方法，建立自己的产品词库，便于后续将关键词合理地应用到 Listing 文案中。

# 一、搭建关键词词库的作用

关键词是买家表达需求的方式，也是连接消费者与产品的重要桥梁。

买家在 Amazon 前台输入关键词寻找产品，平台结合商品信息、搜索相关性和广告投放等因素，向买家展示相应商品。因此，找到准确的关键词，并在产品信息和广告中合理使用，有助于产品被相关消费者发现。

例如，买家搜索 `office chair`，表达的是寻找办公椅的基本需求；搜索 `ergonomic office chair`，则进一步表达了对人体工学设计的关注。

搭建关键词词库，主要有以下作用：

- **了解消费者如何寻找产品**：通过关键词，了解消费者使用哪些产品称呼、关注哪些功能，以及有哪些具体使用需求。
- **找到值得关注的流量**：结合相关性、搜索量、点击和购买表现，判断哪些词值得重点覆盖，哪些词适合作为补充或后续观察。
- **为 Listing 编写提供依据**：将关键词用于标题、Item Highlights、五点描述、长描述和后台 Search Terms，使产品表达和选词更有依据。
- **为广告选词提供基础**：根据词库分层选择广告核心词、长尾词和拓展词，再结合实际投放表现持续调整。

# 二、准备工作

首先需要明显产品的细节，包括结构、材质、颜色、规格、场景、适用人群等，需要考虑该产品的所有变体主题。

明确产品特征后，通过[[跨境电商/notes/恒宁家居/亚马逊平台培训/竞品分析/竞品分析方法|竞品分析]]找到最符合目标产品的10个竞品（数量根据情况自行调整）。

找到的竞品有两个作用：
- 分析竞品标题、五点，确定其中的核心大词。这些核心大词将用于卖家精灵的关键词挖掘。
- 用于卖家精灵的关键词反查或拓展流量词。

## 3、注意事项

使用关键词挖掘和关键词反查（或拓展流量词），必须确保站点和日期一致，例如美国站、最近30天。

此外，还需要留意不同渠道得到的同一关键词数据是否基本一致，如果差异明显，尝试切换到其他月份。卖家精灵可能会有 Bug。

# 四、合并去重

得到各个渠道的关键词原表后，需要对所有关键词进行合并去重，生成一张词库表。

词库表的表头可设计为：

| 表头             | 说明                          |
| -------------- | --------------------------- |
| 埋词整理           | 后续判断                        |
| 优先级            | 后续判断                        |
| 关键词            | 原表关键词                       |
| 关键词翻译          | 原表关键词翻译                     |
| 相关性-需搭配具体的产品定义 | 后续判断                        |
| 流量词大小          | 后续判断                        |
| ABA月排名         | 原表ABA月排名，竞品导出的独有关键词无该数据，留空后 |
| 月搜索量           | 原表月搜素量                      |
| 月购买量           | 原表月购买量                      |
| 购买率            | 原表月购买率                      |
| 展示量            | 原表展示量                       |
| 点击量            | 原表点击量                       |
| 点击率            | 需要计算，计算公式为点击量 / 展示量         |
# 五、标灰处理

先需要合并去重后的词库表按照**月购买量降序**排序。

然后进行标灰处理，标灰是指对一些核心数据缺失，或者关键词与目标产品明显符合的词进行深灰色背景标灰。后续的流量词大小、相关性等不考虑这些标灰关键词。

判灰规则如下：

| 1   | 月购买量缺失或已确认不可用                                            |
| --- | -------------------------------------------------------- |
| 2   | 月搜索量、购买率、展示量、点击量、点击率任一缺失                                 |
| 3   | 月购买量＜30，包含0                                              |
| 4   | 完整关键词属于英文、西班牙语之外的语言                                      |
| 5   | 仅由形容词组成                                                  |
| 6   | 主要购买意图超出已确认的商品或用途范围，或要求不同组成的组合/系统；同类型商品仅变体属性或套装件数不同的情形除外 |
| 7   | 仅有宽泛类目、属性或场景，无有效目标类型指向；品牌/系列/型号＋商品名词按规则8判断               |
| 8   | 完全没有商品名词的孤立品牌、系列、型号及其组合；带完整商品名词时按下文核实购买对象                |
| 9   | 明确联名、影视/动漫/游戏IP或名人授权专属系列                                 |

# 六、流量大小判断

针对所有未标灰词，根据其 ABA 月排名数据判断流量大小，划定大词、次级词和长尾词。

|有效ABA月排名|流量词大小|
|---|---|
|≤10,000|大词|
|>10,000且≤100,000|次级词|
|>100,000且≤1,000,000|长尾词|
|缺失、不可用或>1,000,000|真实空白|

# 七、相关性划分

相关性划分主要看关键词与产品的匹配程度。针对所有未标灰词，浏览器无痕浏览模式下，确定美国邮编地址，在亚马逊前台搜索关键词，看前5页与目标产品的匹配程度，可划分为**完全精准词A**、**相关但不精确词B**、**比较广泛关键词C**。

# 七、优先级划分

结合关键词的相关、流量大小、月搜索量、月购买量、购买率和点击率指标，综合考虑判断未标灰词的优先级。

|优先级|类型|相关性|搜索量|应用场景|
|---|---|---|---|---|
|P0（必含）|高相关+高流量|极高|大|Title/广告核心词|
|P1（优选）|高相关+中低流量|高|中|Bullet Points/Description/广告长尾词|
|P2（补充）|中相关+中流量|中|中|Search Terms/广告拓词|
|P3（储备）|中低相关+趋势词|中低|趋势中|观察期/待测广告/直接否|
例如可以以**全部未标灰的 A/B/C 词**为统计范围，分别计算月搜素量、月购买量、购买率和点击量的 Q25、Q50、Q75（各指标从小到大排序后，前25%位置，前50%，前75%的数据）：

| 等级     | 通用条件                                                            |
| ------ | --------------------------------------------------------------- |
| P0     | 相关性为 **A**<br>流量标签为**大词、次级词或空白**<br>**月搜索量 ≥ Q75，并且月购买量 ≥ Q75** |
| **P1** | 未达到 P0 的 **A**<br>月购买量、购买率、点击率中**至少一项 ≥ 自己的 Q25**。              |
| **P2** | 未达到 P0 的 **A**<br>**月购买量＜Q25、购买率＜Q25、点击率＜Q25**三项同时成立。           |
| **P2** | 相关性为 **B**<br>**月购买量 ≥ Q50**。                                   |
| **P2** | 相关性为 **B**<br>**月购买量 ≥ Q25、购买率 ≥ Q50、点击率 ≥ Q25**三项同时满足。         |
| **P3** | **所有 C**，以及两条 P2 路径都不满足的 **B**。                                 |

# 八、埋词整理

埋词整理进一步根据优先级筛选适合放到 Listing文案各部分的词，如标题、五点、描述（或A+）、ST。
