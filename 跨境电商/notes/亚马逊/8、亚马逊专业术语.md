
# 跟卖

指卖家在亚马逊平台同一条 Listing 上销售与你完全相同的商品，与你共享同一个产品页面，从而争夺购物车（Buy Box）和订单的行为。

这是亚马逊平台允许的机制，但容易引发价格战和恶性竞争。

比如，A卖家创建了一条Listing，B卖家也想卖这款产品，B卖家为了节省创建 Listing 的时间，直接在 A 卖家创建的 Listing 中跟卖。

# Buy Box 黄金购物车

Buy Box 是亚马逊 Listing 的一个核心功能，位于页面右侧。买家可以直接点击“Add to cart”或“Buy now”完成下单。

如果没有Buy Box，会有如下影响：

1. 产品曝光减少：系统不会推荐无购物车的 Listing，无购物车也无法开启站内广告，无法使用站内促销工具
2. 买家购买流程复杂：多次点击页面才能完成下单，导致转化下降
3. 上述曝光减少、转化下降连锁反应，导致排名下降

此外，在被跟卖的情况下，被抢夺购物车，也会导致 Listing 失去控制权。

如何获得 Buy Box：

- 使用 FBA：FBA 模式下的 Listing 基本都有购物车
- 使用专业销售计划：每月 39.99 美元服务费
- 优化卖家绩效：减少订单取消、延迟发货和差评（FBA模式）
- 保持库存充足：避免因断货导致 Buy Box 丢失
- 避免提价过高，也会导致 Buy Box 丢失

此外，完成品牌备案，可以防止跟卖，被人抢夺购物车。

# Listing 变狗

Listing 变狗就是链接失效的意思，它是指 Listing 因各种原因被亚马逊强制下架或禁止显示，导致前台页面变成可爱狗狗提示页面。

Listing 变狗的常见原因：

- 侵权投诉（最常见）
	- 品牌侵权：被商品持有者投诉
	- 专利/版权侵权：如图片、文案抄袭
	- 假货投诉：被买家或品牌方举报卖假货
- 违反亚马逊政策
	- 操纵评论：刷单、违规索评
	- 滥用变体：违规合并变体
- 账户问题
	- 账号被封，所有 Listing 下架
	- 绩效不达标：ODR（订单缺陷率）过高、迟发率超标

>商品侵权（Trademark Infringement）：未经许可使用他人的品牌名称、Logo等商标标识，使得消费者对商品来源产生混淆
>专利侵权（Patent Infringement）：未经许可制造、销售等行为涉及他人有效专利保护范围内的产品或技术，即使使用自己的品牌也可能侵权

# 商品编码 GTIN

GTIN（Global  Trade Item Number，全球贸易项目代码），是全球通用的商品编码标准，用于唯一标识产品。

在亚马逊上，GTIN 通常指 UPC、EAN、ISBN 或 JAN 等条形码，是创建商品 Listing 必须提供的编码之一。

![[assets/Pasted image 20261023011630.png]]

商品编码类型：

- UPC：美国统一代码委员会指定的一种商品用条码，主要用于美国和加拿大地区
- EAN：国际物品编码协会指定的一种商品用条码，通用于全世界，主要用于欧洲
- JAN：日本工业标准（JIS）制定，主要用于亚马逊日本站
- ISBN：国际标准书号，专门为识别图书等文献而设计的国际编号
- GCID：全球目录编码，完成品牌备案后，系统进行分配

如何获取商品编码：

- FBA或FBM第三方海外仓：务必注册品牌，完成品牌备案，申请 GTIN 豁免
- FBM铺货且不囤货（不注册品牌的情况下）：

1. 国内某宝 or 店小秘购买（便宜，但有安全隐患）
2. 生成器生成（不正规，不推荐。没有证书或已被使用过）
3. BARCODESTALK（稍微）https://www.barcodestalk.com
4. Gs1官网购买（较贵，适合完成豁免后仍需要提供 UPC 的产品，完全合规）https://www.gs1us.org

# 品牌备案

品牌备案是指注册国外商品后，在亚马逊平台上进行的品牌信息登记操作。通过品牌备案，卖家不仅可以上传产品，还能使用后台的所有品牌功能。（品牌备案需提供目标站点国家的注册商标信息）

品牌备案的好处：

- 防止跟卖：备案后可以举报未经授权的卖家跟卖你的产品
- 增强 Listing 控制权：可锁定品牌名称、修改商品详情页（即使被跟卖）
- A+页面：可使用图文并茂的A+页面提升转化率
- 品牌分析工具：查看官方关键词报告、竞品数据等
- 透明计划：可申请产品防伪标识，完全杜绝跟卖

# 品牌白名单

品牌白名单：亚马逊允许未完成商标注册的卖家暂时使用特定品牌名上传商品的过渡方案，虽然目前没有注册目标站点商标，但亚马逊允许以自己的品牌上架 Listing。

白名单的作用：

上传产品时，品牌是必填项，如果填写 Generic、no branded、N/A等等，会影响产品在前台的展示效果，以至于对 Listing 的转化率产生影响。

所以品牌白名单的作用，大多数仅仅只是为了成功创建 Listing，解决 Listing 上传时的报错问题。
