
# 变体

点击某个竞品的 Listing 页面，首先看卖家精灵的变体对比：

![[assets/Pasted image 20261008102945.png]]

看哪个变体最畅销决定备货数。

![[assets/Pasted image 20261008103149.png]]

这里可以看到 B0F32L3C1R 标注是最畅销变体，且其上架时间也较早，因此畅销也有上架时间早的缘故。

但这并不意味着它一直都是畅销款，可能是这段时间畅销。此时可以切换到图形模式：

![[assets/Pasted image 20261008103407.png]]

看下不同变体按月的一个销量对比。

这里就看到在2026年6月之前，B0F32L3C1R 变体销量最高，但自从 B0GY7S5M2B 上架之后，B0GY7S5M2B 变成最畅销的了。

此外，还可以看不同 Color 销量占比和不同 Size 销量占比。

但注意，亚马逊并非所有的产品都会公布子体销量，此时就要看流量词和评分数，流量词高且评分数多一半就是畅销变体。

# Keepa 插件替代

Keepa 插件替代呈现的是该产品的价格走势，包括 Buybox 价格、价格、Prime 价格、Coupon（一次性）、Coupon（订阅）、Deal 价格、FBA价格、FBM价格、列表价格。

Keepa 插件替代也呈现了评分/卖家数走势。
