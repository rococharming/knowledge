
关键词反查：查询任意 ASIN 的流量词以及搜索流量来源，并提供了详细的关键词数据。

# 一、入口

卖家精灵官网  ->  产品  ->  关键词优化  ->   关键词反查。

# 二、功能介绍

## 关键词反查

在搜索页面选择站点、时间，填入目标 ASIN，点击立即查询：

![[assets/Pasted image 20260928172743.png]]

首先会展示该产品的标题、ASIN、卖家、大类BSR排名、价格、评分/评分数以及上架时间，还会列出所有变体的一个流量词数概况。

因为当前只是针对 B0GY7S5M2B 变体查询，可以看到流量词数是309，流量词越多一般表示该变体是销量最靠前的。

## 拓展流量词

当然，也可以点击查看下方绿色按钮：查看所有变体流量词。它会跳转到**拓展流量词**入口，支持一次最多查看20个ASIN的所有流量词。此时点立即查询，会进入选择拓词方式：

![[assets/Pasted image 20260929005053.png]]

- 使用全部变体：查询该ASIN对应父体下的所有变体关键词
- 使用畅销变体：查询该ASIN对应父体下最畅销的变体关键词
- 使用当前变体：即选择的变体

## 搜索流量词占比

继续回到关键词反查入口，接下来会给出搜索流量词数量以及占比的柱形图：

![[assets/Pasted image 20260928173746.png]]

搜索流量词是指该 ASIN 能通过什么搜索词，在 Amazon 搜索结果前 3 页被买家看到。而搜索流量词的数量表示能让该 ASIN 在搜索结果前 3 页获得曝光的关键词数量。

搜索流量又分为**自然搜索流量**和**广告搜索流量**。

- 自然搜索流量词：自然搜索词、AC推荐词、ER推荐词、4星推荐词
- 广告搜索流量词：HR推荐词、SP广告词、视频广告词、品牌广告词

>注意，如果某个词既属于自然搜索词也属于SP广告词，也分别算入在自然流量和广告流量中的占比，因此会导致自然流量和广告流量的总百分比大于100%。

**知识补充**

自然搜索词：卖家搜索该词时，该产品出现在亚马逊搜索结果前3页的自然流量位置。

![[assets/Pasted image 20260929011359.png]]

AC推荐词：卖家搜索该词时，该产品主图左上角会出现**Amazon's Choice**（简称AC），或者该产品出现在**Amazon's Choice**推荐专栏。亚马逊系统会根据 Listing 的表现在某个关键词优质、好价的产品上标注 Amazon's Choice。

ER推荐词：买家在搜索该词时，该产品出现在了Editorial recommendations （简称ER）
>Editorial recommendations：亚马逊官方或第三方博主测评的产品推荐

4星推荐词：卖家搜索该词时，该产品出现在 4+ star styles 专栏
> 4+ star styles：评价超过100条，且星级评分达到4分以上的店铺产品推荐。

HR推荐词：买家搜索该词时，该产品出现在 Highly Rated （简称HR）专栏。
> Highly Rated：PPC广告的一种，要求产品评分星级在4星以上

什么是 PPC 广告？

PPC广告（Pay Per Click）：按点击付费广告，即广告展示出来通常不收费，买家点击广告后，卖家才产生广告费用。

SP广告词：买家在搜索该词时，该产品出现在了Sponsored （简称SP）广告位。
> Sponsored：PPC广告的一种，一般出现在自然搜索结果或Listing详情页中，有Sponsored标识

视频广告词：买家在搜索该词时，搜索结果页出现了该产品的视频广告。
> 视频广告：在搜索结果列表中部出现的一种默认静音播放的广告

品牌广告词：买家在搜索该词时，搜索结果页出现了该产品的品牌广告  
> 品牌广告：PPC广告的一种，一般在搜索结果页顶部或底部出现

## 搜索结果过滤

可以把反查出来的一大堆流量词根据自己的侧重点逐层筛选，如下是筛选入口：

![[assets/Pasted image 20260930143506.png]]

对于流量 & 转化一栏，先把几个基础指标搞清楚：

- 周曝光量：表示该关键词本周内给这个产品带来的预估曝光量
- 曝光量占比：某个关键词贡献的曝光，占这个 ASIN 所有关键词曝光的比例
- ABA：Amazon  Brand Analytics，亚马逊品牌分析。它是亚马逊官方提供的一套品牌数据分析工具，用来分析买家在 Amazon 上搜了什么、点了什么、买了什么。
流量：

|类型|核心判断|实际含义|
|---|---|---|
|**主要流量词**|曝光占比 ≥5% + 排名前8|这个 ASIN **很依赖这个词**|
|**精准流量词**|周曝光 ≥2000 + 排名前8|这个词给 ASIN **带来的流量很多**|
|**精准长尾词**|周曝光 500～2000 + 排名前8|流量较小，但**排名好、比较精准**|

转化：
- 有效转化词：ABA数据中转化率 > 0，即买家通过这个关键词搜索后，最终确实产生过购买。
- 转化优质词：转化率 >= 5% + 周曝光 >= 2000 或者 转化率 >= 10% + 周曝光 >= 1000。
- 转化平稳词：最近 2 周转化率 >= 3%，同时周曝光量 >= 500。
- 转化流失词：上周有转化，本周无转化，同时周曝光量在 50～1000。
- 无效曝光词：ABA数据中有点击，但是没有转化

| 类型        | 最简单的理解           |
| --------- | ---------------- |
| **有效转化词** | 这个词**出过单**       |
| **转化优质词** | **流量不小，而且很会出单**  |
| **转化平稳词** | **最近持续稳定出单**     |
| **转化流失词** | **以前出单，现在不出了**   |
| **无效曝光词** | **有人看、有人点，就是不买** |
