# 公务员备考 领域规则

## 领域概述

公务员考试备考知识：覆盖行测、申论、面试、选岗、时政与公共基础知识，并沉淀可执行的复习方法。

## 分类体系

wiki 页面按以下子目录组织：

- `summaries/` — 单篇课程、政策文件、真题解析或备考资料的摘要。
- `entities/` — 考试机构、招录单位、职位类别与权威信息源的说明。
- `concepts/` — 行测模块、申论方法、面试题型、公基知识点与选岗术语。
- `comparisons/` — 国考与省考、不同地区公告或职位条件的对比。
- `overviews/` — 考试全流程、科目结构、年度备考框架与时政专题概览。
- `syntheses/` — 跨资料归纳的解题原则、复习策略与选岗判断框架。
- `recipes/` — 可直接执行的学习计划、刷题复盘、申论写作与面试练习流程。

## 标签体系

领域初始标签。标签是动态扩展的——以下只是种子标签，LLM 在 ingest 时会根据素材内容自动补充：

- `#行测` — 职业能力测验的模块、题型、技巧与真题复盘。
- `#申论` — 材料分析、归纳概括、贯彻执行与文章写作。
- `#面试` — 结构化面试、无领导小组等题型及练习方法。
- `#时政` — 与备考直接相关的时事政策与周年专题。
- `#公基` — 法律、政治、经济、人文与管理等公共基础知识。
- `#选岗` — 职位表解读、条件筛选、竞争评估与报名决策。
- `#学习计划` — 阶段目标、时间安排、刷题节奏与复盘机制。

**标签添加原则**：
- 初始标签作为 ingest 时的参考基准
- 当素材涉及新的子主题时，自动创建新标签
- 定期 review 标签使用情况，合并过于细分的标签

## qmd 配置

- collection 名称：`knowledge-公务员备考`
- collection root：`公务员备考/wiki`
- collection 注册：由 `qmd_sync.py` 根据 Git 根目录与 collection root 幂等同步；本机配置不写入仓库

## 特殊约定

- 招录公告、职位表、报考条件、考试时间与政策解读必须注明适用考试、地区、年份和来源发布日期；过期信息不得作为当期结论。
- 真题、题型和分数经验须标明考试类型、地区、年份及资料来源；对未经核实的回忆版内容明确标记。
- 选岗页面只提供基于公开条件的比较框架，不把个人经历、资格或偏好写入 wiki；这类信息仅可由用户保留在 `notes/`。
