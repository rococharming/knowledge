# 一、常见命题形式

## 1、一组式

已知四幅以上的图片，推导问号处的图形。

![[assets/Pasted image 20260824094625.png|400]]

>观察路径：顺序看、间隔看、分组看

图中的题目是典型的顺序看，从左到右每个图形的组成元素依次递增，第一幅图是1个，第二幅图是2个，...，第六幅图就是6个，因此选**A**。

## 2、两组式

已知一组图片，推导另一组图片问号处的图形。

![[assets/Pasted image 20260824095020.png|400]]

>观察路径：第一段找规律，第二段用规律。（规律是相同或者相似）

第一组图的每个图形是沿着纵轴方向轴对称，第二组则沿着对角线方向轴对称，因此选**A**。

## 1、位置类

位置类：考虑图形元素所在的位置。

- 动态位置
- 静态位置

### （1）动态位置

![[assets/Pasted image 20260824101821.png|400]]

动态位置题型特征：

1. 组成元素相同
2. 整体或局部位置变化明显

考察要点：

- 移动（平移）
- 转动
	- 旋转（围绕点）
	- 翻转（围绕轴）

#### 移动

- 组成元素相同
- 有框架或格子，内部元素发生移动

![[assets/Pasted image 20260824102222.png|400]]

方向：左右、上下、顺时针、逆时针
步数：常数数列、等差数列、周期数列
方式：
![[assets/Pasted image 20260824102600.png|400]]

例1：

![[assets/Pasted image 20260824102658.png|400]]

首先看黑圆，它在按每间隔两个点逆时针移动，因此排除B、D。

其次看空着的位置，它是按顺指针按步长为1移动，因此最终选**C**。

例2：

本题为一组式。每个图形组成元素相同（6个白圆 + 1个黑圆），有格子且每个图的元素发生移动，因此属于平移位置类题型。

先看三角形，它在逆时针按步长为1移动，因此排除A、B。

角度：常考察30°、45°、60°、90°、120° 等

左右翻：

上下翻：

例2：

本题为两组式，先看第一组找规律。第一组：第2幅图是第1幅图顺时针旋转90度得到，第3幅图整个上下翻转了一下，第4幅图则是第3幅图沿着纵轴方向的翻转。

因此，对应到第二组，答案选**D**。注意4的那个图形是竖形椭圆。

### （2）静态位置

![[assets/Pasted image 20260824105520.png|400]]

静态位置题型特征：

> 每个图形由两个及以上元素组成，图形元素间存在结构的特征。

静态位置考察要点：

- 相离
- 相连
- 相交

![[assets/Pasted image 20260824105821.png|400]]

#### 相离

- 2个元素（方位）
![[assets/Pasted image 20260824110054.png|400]]

- 3个及以上元素（排布）
