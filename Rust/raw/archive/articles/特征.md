# 一、Trait的基本概念

`Trait`是 Rust 中描述“类型具备某种能力”的机制。

一个类型实现了某个`Trait`，就表示这个类型提供了该`Trait`规定的一组行为。可以把`Trait`理解为一组方法约定：`Trait`负责声明能力，具体类型负责实现能力。

例如，`String`类型的值可以用`{}`打印，是因为`String`实现`std::fmt::Display`：

```rust
let s = String::from("Hello");

println!("{}", s);
```

再例如`std::io::Write`表示可以“写入字节数据”的能力。标准库的文件（`File`），网络流（`TcpStream`）、字节缓冲区（`Vec<u8>`）等类型都实现了该`Trait`。

`Write`的简化定义如下：

```rust
trait Write {
	fn write(&mut self, buf: &[u8]) -> Result<usize>;
	fn flush(&mut self) -> Result<()>;

	// 其他方法这里不展示，都是默认实现
}
```

`Trait`和泛型经常一起使用。泛型让代码适用于多种类型，`Trait`则进一步限制这些类型必须具备哪些能力。

例如：

```rust
fn show<T: std::fmt::Display>(value: T) {
	println!("{}", value);
}
```

这里的 `T` 可以是很多类型，但前提是它必须实现 `Display`。

此外，一些标准库中的内置类型承担着**语言级钩子**的作用。

# 二、Trait的定义、实现与使用

## 1、Trait定义

Rust使用 `trait` 关键字定义`Trait`。

基本形式：

```rust
trait Animal {
	fn eat(&self);
}
```

这里定义了一个 `Animal` Trait，表示实现它的类型必须提供 `eat` 方法。

`Trait`中可以包含：

- 只有签名的方法
- 带默认实现的方法
- 关联函数
- 关联类型
- 关联常量

## 2、Trait实现

### （1）为具体类型实现Trait

使用 `impl Trait for Type` 为具体类型实现`Trait`。

示例：

```rust
trait Animal {
    fn eat(&self);
}

struct Dog {
    name: String,
}

impl Animal for Dog {
    fn eat(&self) {
        println!("{} is eating", self.name);
    }
}

fn main() {
    let dog = Dog {
        name: String::from("Bob"),
    };

    dog.eat();
}
```

`impl Animal for Dog` 表示：`Dog` 实现了 `Animal` 这个 Trait。实现之后，`Dog` 的值就可以调用 `Animal` 中定义的方法。

Trait 方法和结构体方法一样，也可以使用不同形式的接收者：

- `&self` 表示共享借用，不会取得所有权
- `&mut self` 表示可变借用，可以修改当前值
- `self` 表示取得当前值的所有权，调用后原值通常不能继续使用。

### （2）默认方法实现

`Trait` 可以为方法提供默认实现。

示例：

```rust
trait Animal {
    fn name(&self) -> &str;

    fn sound(&self) {
        println!("{} makes sound", self.name());
    }
}
```

这里的 `sound` 有默认实现。实现 `Animal` 的类型只要提供 `name`，就可以直接复用 `sound`。

```rust
struct Cat {
    name: String,
}

impl Animal for Cat {
    fn name(&self) -> &str {
        &self.name
    }
}

fn main() {
    let cat = Cat {
        name: String::from("Tom"),
    };

    cat.sound();
}
```

默认方法也可以被具体类型重写：

```rust
struct Dog {
    name: String,
}

impl Animal for Dog {
    fn name(&self) -> &str {
        &self.name
    }

    fn sound(&self) {
        println!("{} says woof", self.name);
    }
}
```

标准库中的 `Write` 特征的方法除了 `write()` 和 `flush()` 方法，其他方法都是默认实现。

### （3）默认实现调用其他方法

默认实现可以调用同一个 `Trait` 中的其他方法。即使被调用的方法没有默认实现，也可以这样写，因为具体类型最终必须提供这些方法。

示例：

```rust
trait Animal {
	fn name(&self) -> String;
	fn eat(&self);
	fn sound(&self) {
		println!("{} makes sound", self.name());  // 默认实现调用其他方法
	}
}

struct Dog {
	name: String,
}

impl Animal for Dog {

	fn name(&self) -> String {
		self.name.clone()
	}

	fn eat(&self) {
		println!("Dog {} eats meat.", self.name());
	}

	fn sound(&self) {
		println!("Dog {} says woof", self.name());
	}

}
```

标准库中的 `Iterator` 就大量使用这种模式。实现迭代器时，通常只需要实现核心的 `next` 方法，很多其他方法都有默认实现。


## 3、孤儿规则

Rust 不允许随意为任何类型实现任意`Trait`。

规则：

> 实现`impl Trait for Type`时，`Trait`或`Type`至少有一个必须定义在当前crate中

例如，不能在自己的 crate 中为`String`实现标准库的`Display`。

孤儿规则的目的，是避免不同 crate 为同一组“外部 Trait + 外部类型”提供冲突实现。


## 4、Trait的作用域

调用 Trait 方法时，需要注意一个规则：**Trait 方法通常要求对应的 Trait 名称在作用域内**。

例如，`File`实现了`std::io::Write`，但如果没有引入`Write`，则`Write`特征的方法无法调用：

```rust
let mut file = File::create("hello.txt").unwrap();

file.write_all(b"hello world\n").unwrap();
```

报错：没有`write_all`方法。

必须将`Write`引入当前作用域：

```rust
use std::io::Write;

let mut file = File::create("hello.txt").unwrap();

file.write_all(b"hello world\n").unwrap();
```

如果不引入当前作用域，如果多个库定义了同名`Trait`，则会产生命名冲突。

**值得注意的是，有些`Trait`不需要手动导入也能使用，因为它们在标准库预导入模块中，例如 `Clone`、`Iterator`、`ToString` 等**。



# 三、Trait Bound

## 1、类型参数约束

泛型参数中的类型参数本身没有任何已知能力。例如下面的代码无法通过编译：

```rust
fn show<T>(value: T) {  
    println!("{}", value);  
}
```

![[Pasted image 20260526141426.png|500]]

原因是：不是所有类型都能用 `{}` 打印。要使用 `{}`，类型必须实现 `Display`。

因此需要使用`Trait Bound`限制类型参数：

```rust
use std::fmt::Display;  
  
fn show<T: Display>(value: T) {  
	println!("{}", value);  
}
```

`T: Display` 表示：`T` 必须是实现了 `Display` 的类型。

Trait Bound 的本质是给泛型参数增加能力约束。约束之后，函数体内部才能使用对应 Trait 提供的能力。


## 2、Trait Bound 的基本写法

`Trait Bound`可以写在泛型参数后：

```rust
use std::fmt::Display;

fn show<T: Display>(value: T) {
    println!("{}", value);
}
```

也可以写在`where`子句中：

```rust
use std::fmt::Display;

fn show<T>(value: T) 
where 
	T: Display
{
	println!("{}", value);	
}

```

约束简单时，直接写在泛型参数后即可。

约束复杂时，`where`子句更清晰。


## 3、多重Trait Bound

一个类型参数可以同时要求实现多个`Trait`。

示例：

```rust
use std::fmt::{Debug, Display};

fn show<T: Display + Debug>(value: T) {
    println!("{}", value);
    println!("{:?}", value);
}
```

也可以写成：

```rust
use std::fmt::{Debug, Display};

fn show<T>(value: T)
where
    T: Display + Debug,
{
    println!("{}", value);
    println!("{:?}", value);
}
```

`Display + Debug` 表示 `T` 必须同时实现这两个 Trait。


## 4、对关联类型增加约束

有时不只是类型参数本身需要满足约束，它的关联类型也需要满足约束。

以迭代器为例：

```rust
fn dump<I>(iter: I)  
where   
	I: Iterator,  
{  
    for (index, value) in iter.enumerate() {  
        println!("{index}: {value:?}");  
    }  
}
```

这段代码无法通过编译，因为`value` 使用了 `{:?}`，但编译器不知道迭代器产生的元素是否实现了 `Debug`。

因此需要进一步约束迭代器的关联类型`I::Item`：

```rust
use std::fmt::Debug;

fn dump<I>(iter: I)
where
    I: Iterator,
    I::Item: Debug,
{
    for (index, value) in iter.enumerate() {
        println!("{index}: {value:?}");
    }
}
```

`I::Item: Debug` 表示：迭代器产生的元素类型必须实现 `Debug`。

有关迭代器及其关联类型详见[[17、迭代器|迭代器]]。


# 四、impl Trait

## 1、基本语法

`Trait Bound`还有一种语法糖形式：`impl Trait`。`impl Trait`仍然表示任意实现了该`Trait`的类型。

示例：

```rust
use std::fmt::Display;

fn show(value: impl Display) {
	println!("{}", value);
}
```

`impl Trait`写法更短，但表达能力不如显式泛型参数细。

示例：

```rust
use std::fmt::Display;

fn show_pair(a: impl Display, b: impl Display) {
	println!("{a}, {b}");
}
```

这里的`a`和`b`可以是不同类型，只要都实现了`Display`。

如果希望两个参数都是同一种具体类型，需要写成显式泛型参数：

```rust
use std::fmt::Display;  
  
fn show_pair<T: Display>(a: T, b: T) {  
	println!("{a}, {b}");  
}
```

这里两个参数都使用同一个 `T`，因此它们必须是同一种具体类型。

## 2、函数参数位置的impl Trait

函数参数位置`impl Trait` 可以出现在函数参数位置，也可以出现在函数返回值位置。它的含义在两个位置上略有不同，但都表示“某个实现了指定Trait的具体类型”。

参数位置常见形式有三种：

```rust
fn take(value: impl Display) {
	// 获取所有权
}

fn borrow(value: &impl Display) {
	// 共享借用
}

fn borrow_mut(value: &mut impl Display) {
	// 可变借用
}
```

是否使用引用，取决于函数是否需要取得所有权、是否需要修改值。

## 3、返回位置的 impl Trait

函数返回值也可以使用`impl Trait`：

```rust
trait Animal {
    fn speak(&self);
}

struct Dog;

impl Animal for Dog {
    fn speak(&self) {
        println!("woof");
    }
}

fn create_animal() -> impl Animal {
    Dog
}
```

这表示：函数返回某个实现了 `Animal` 的具体类型，但调用方不需要知道具体类型是什么。

调用方只能按照 `Animal` 暴露的能力使用返回值：

```rust
fn main() {
    let animal = create_animal();

    animal.speak();
}
```

需要注意：返回位置的 `impl Trait` 在一个函数中必须对应单一具体类型。

下面这种写法是不允许的：

```rust
fn create_animal(flag: bool) -> impl Animal {
    if flag {
        Dog
    } else {
        Cat
    }
}
```

即使 `Dog` 和 `Cat` 都实现了 `Animal`，它们仍然是不同的具体类型。`impl Animal` 只是隐藏了具体类型，不是返回“任意实现了 Animal 的类型”。

如果需要在运行时返回不同具体类型，通常使用`Trait Object`。
