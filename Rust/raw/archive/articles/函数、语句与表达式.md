# 一、表达式和语句

在介绍函数之前，需要先理解 Rust 中的表达式和语句。

Rust 是一门偏表达式风格的语言。函数体通常由若干语句组成，并且可以用最后一个表达式作为返回值。

简单来说：

- 语句执行操作，但不产生可继续使用的值；
- 表达式会求值，并产生一个值

示例：

```rust
let x = 1 + 1; // 语句1，其中 1 + 1 是表达式
let y = 2 + 2; // 语句2，其中 2 + 2 是表达式
x + y          // 表达式（若作为块的最后一行，可作为块的返回值）
```

## 1、语句

语句用于完成一个具体操作，但不产生一个可被继续使用的值。

例如，`let`绑定就是语句：

```rust
let a = 8;
```

由于`let`是语句，因此不能将`let`语句赋值给其他变量。

错误示例：

```rust
let b = (let a = 8);
```

这段代码会编译失败，因为 `let a = 8` 不是表达式，不能作为一个值使用。

## 2、表达式

表达式会求值并返回一个值。

例如，`5 + 6`就是一个表达式，它会得到结果`11`。

表达式也可以成为语句的一部分，例如`let a = 6;`是一个语句，但其中的`6`是表达式。

在`Rust`中，函数调用也是表达式。即使函数没有显式返回值，它也会返回`()`，即单元类型的值。

示例：

```rust
println!("Hello");
```

这里的 `println!` 是宏调用，也可以作为表达式使用。它执行输出操作，并返回 `()`。

代码块 `{}` 也是表达式。代码块的值由最后一个不带分号的表达式决定；如果代码块最后没有表达式，或者最后一行以分号结尾，那么代码块的值就是 `()`。

示例（把语句块当作表达式赋值给变量）：

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };

    println!("The value of y is: {}", y);
}
```

上面赋值给 y 的语句块是：


```rust
{
    let x = 3;

    x + 1
}
```

其中，最后一行 `x + 1` 没有分号，因此它的值会作为整个代码块的值。所以 `y` 的值是 `4`。

如果给最后一行加上分号：

```rust
fn main() {
    let y = {
        let x = 3;

        x + 1;
    };

    println!("The value of y is: {:?}", y);
}
```

那么 `x + 1;` 就变成了语句，整个代码块的返回值变成 `()`。

`if` 也是表达式，因此可以用于赋值。

示例：

```rust
fn main() {
    let x = 11;

    let res = if x % 2 == 1 { "odd" } else { "even" };

    println!("{}", res);
}
```

需要注意：如果把 `if` 当作表达式使用，那么所有分支必须返回相同类型的值。

例如下面代码是错误的：

```rust
let res = if x % 2 == 1 { "odd" } else { 0 };
```

因为 `"odd"` 是 `&str` 类型，而 `0` 是整数类型，两个分支类型不一致。

`loop` 也是表达式，可以在 `break` 后面跟一个表达式，作为整个 `loop` 的返回值。

示例：

```rust
fn main() {
    let mut count = 0;

    let result = loop {
        count += 1;

        if count == 5 {
            break count * 2;
        }
    };

    println!("result: {}", result);
}
```

这里当 `count == 5` 时，执行：

```rust
break count * 2;
```

所以整个 `loop` 表达式的值是 `10`，最终 `result` 的值也是 `10`。

# 二、函数

## 1、函数定义和调用

在 Rust 中，使用 `fn` 关键字定义函数。

Rust 程序的入口函数是 `main`：

```rust
fn main() {
	println!("Hello, world!");
}
```

函数用于把可复用的逻辑封装起来，以便多次调用。

示例：

```rust
fn add(x: i32, y: i32) -> i32 {
    x + y
}
```

上面的函数实现了两个 `i32` 整数的加法。

其中：

- `fn` 表示定义函数；
- `add` 是函数名；
- `(x: i32, y: i32)` 是参数列表；
- `-> i32` 表示返回值类型是 `i32`；
- `x + y` 是函数体最后一个表达式，会作为函数返回值。

有了函数定义，就可以调用函数了：

```rust
fn main() {
    println!("1 + 2 = {}", add(1, 2));   // 函数调用
}

fn add(x: i32, y: i32) -> i32 {
    x + y
}
```

> Rust 不要求函数必须先声明再定义。函数可以写在调用位置之后，只要它在当前模块的可见范围内，编译器就能解析到。


## 2、函数参数

函数可以有参数。参数是一种特殊变量，属于函数签名的一部分。

函数签名通常包括：

- 函数名
- 参数列表
- 返回类型

例如：

```rust
fn add(x: i32, y: i32) -> i32
```

这里的 `x: i32` 和 `y: i32` 就是参数。

函数定义里的参数称为**形参**，调用函数时传入的具体值称为**实参**。

示例：

```rust
fn get(x: u32, y: u32) {
    println!("Got x: {x}, y: {y}");
}

fn main() {
	let a = 10;
	let b = 20;
    get(a, b);
}
```

在这个例子中：

- `x` 和 `y` 是形参；
- `a` 和 `b` 是实参。

注意：**函数参数必须写类型注解**，否则编译器无法确定参数类型，编译会失败。

Rust的实参传递给形参时不会自动做数值类型转换（例如`u32`不能自动转换成`i32`）：

```rust
fn get(x: i32) {
    println!("{}", x);
}

fn main() {
    let a: u32 = 10;

    get(a); // 错误：u32 不能自动转换为 i32
}
```

如果确实需要转换，需要显式使用 `as` 或其他安全转换方式：

```rust
fn get(x: i32) {
    println!("{}", x);
}

fn main() {
    let a: u32 = 10;

    get(a as i32);
}
```


## 3、函数返回值

函数可以有返回值。在参数列表后使用 `->` 指定返回类型。

示例：

```rust
fn add_one(x: i32) -> i32 {
	x + 1
}
```

这里的 `-> i32` 表示函数返回一个 `i32` 类型的值。

Rust 函数返回值有几种常见规则：

1. 如果函数体最后一行是表达式（不以;结尾），该表达式的值会作为返回值
2. 如果函数体最后一行是语句（以;结尾），函数体返回`()`
3. 如果函数返回类型是 `()`，可以省略 `-> ()`。
4. 可以使用`return`关键字提前返回值

示例：

```rust
fn add_one(x: i32) -> i32 {
    return x + 1;
}
```

不过在 Rust 中，如果不是提前返回，通常更推荐直接使用最后一个表达式作为返回值：

```rust
fn add_one(x: i32) -> i32 {
    x + 1
}
```
