# 一、控制流

控制流用于控制程序的执行顺序，例如根据条件选择不同分支，或者重复执行某段代码。

# 二、条件分支

## 1、if - else

Rust 使用 `if` 进行条件判断。

```rust
fn main() {
    let age: u8 = 10;

    if age < 18 {
        println!("You are young!");
    } else {
        println!("You are old!");
    }
}
```

注意事项：

- Rust 的 `if` 条件不需要写小括号
- 条件必须是`bool`类型，不能像 C / C++ 那样用整数、指针等直接作为条件。

错误示例：

```rust
let x = 1;

if x {
    println!("true");
}
```

正确写法：

```rust
let x = 1;

if x != 0 {
    println!("true");
}
```


## 2、if - else if - else

当条件较多时，可以使用 `else if` 链式分支。

示例：

```rust
fn main() {
    let score: u32 = 70;

    if score >= 90 {
        println!("Got A");
    } else if score >= 80 {
        println!("Got B");
    } else if score >= 70 {
        println!("Got C");
    } else {
        println!("Got D");
    }
}
```

# 三、循环

Rust 有三种常见循环结构：

- `loop`
- `while`
- `for`

## 1、loop

`loop`表示无限循环。循环体会不断执行，除非遇到`break`退出。

示例：

```rust
fn main() {
    let a = 10;

    loop {
        println!("{}", a);
    }
}
```

上面这段代码会一直打印 `10`，不会自动结束。

可以使用 `break` 退出循环：

```rust
fn main() {
    let mut count = 0;

    loop {
        count += 1;

        if count == 5 {
            break;
        }
    }

    println!("count = {}", count);
}

```

`continue` 用于跳过本次循环剩余部分，进入下一次循环。

## 2、while

`while`是条件循环。当条件为 `true` 时执行循环体；条件变为 `false` 后退出循环。

示例：

```rust
fn main() {
    let mut n = 10;

    while n > 0 {
        println!("{}", n);

        n -= 1;
    }
}
```

## 3、for

`for`循环常用于遍历集合或范围。

示例：

```rust
fn main() {

    // 遍历范围
    for i in 0..5 {
        println!("i = {}", i);
    }
	
	// 遍历数组
    let arr = [1, 2, 3, 4, 5];

    for val in arr {
        println!("val = {}", val);
    }

}
```

范围表达式`0..5`表示从`0`到`5`之前，也就是`0, 1, 2, 3, 4`。

范围表达式`0..=5`表示从`0`到`5`（包含`5`），也就是`0, 1, 2, 3, 4, 5`。

Rust 中还有非常重要的 `match` 控制流，它通常和枚举、模式匹配一起使用，详见[[Rust/notes/Rust基础/12、模式匹配|模式匹配]]。

## 4、循环标签

循环可以嵌套，`break` 和 `continue` 默认作用于当前最近的一层循环。

Rust 支持**循环标签**，用于指定跳出或继续哪一层循环。标签使用`'标签名`设置。


```rust
fn main() {
    'outer: for i in 0..3 {
        for j in 0..3 {
            if i == 1 && j == 1 {
                break 'outer;
            }

            println!("i = {}, j = {}", i, j);
        }
    }
}
```

这里的 `'outer` 是外层循环的标签。

当执行`break 'outer;`时，会直接跳出外层循环，而不是只跳出内层循环。
