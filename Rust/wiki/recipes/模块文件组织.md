# 模块文件组织

## 独立文件模块

在 `main.rs` 中声明模块：

```rust
mod shop;

fn main() {
    shop::run();
}
```

编译器会在对应文件中查找模块内容：

```
src/
├── main.rs
└── shop.rs
```

`src/shop.rs` 中**不需要**再写 `mod shop { ... }`，文件本身就是 `shop` 模块的内容：

```rust
pub fn run() {
    println!("shop is running");
}
```

## 目录模块（mod.rs 方式）

当模块需要拆分子模块时，使用目录结构：

```
src/
├── main.rs
└── shop/
    ├── mod.rs
    ├── product.rs
    ├── order.rs
    └── user.rs
```

`src/main.rs`：

```rust
mod shop;

fn main() {
    shop::product::list();
    shop::order::create();
    shop::user::login();
}
```

`src/shop/mod.rs`：

```rust
pub mod product;
pub mod order;
pub mod user;
```

子模块文件（如 `src/shop/product.rs`）：

```rust
pub fn list() {
    println!("product list");
}
```

## 现代模块文件组织

Rust 也支持更现代的组织方式，不使用 `mod.rs`：

```
src/
├── main.rs
├── shop.rs
└── shop/
    ├── product.rs
    └── order.rs
```

`src/main.rs`：

```rust
mod shop;

fn main() {
    shop::start();
}
```

`src/shop.rs`（模块入口，同时声明子模块）：

```rust
pub mod product;
pub mod order;

pub fn start() {
    println!("shop start");
    product::list_products();
    order::create_order();
}
```

`src/shop/product.rs`：

```rust
pub struct Product {
    pub name: String,
    price: u32,
}

pub fn list_products() {
    println!("product list: milk, chocolate, strawberry");
}

pub(crate) fn default_price() -> u32 {
    100
}
```

`src/shop/order.rs`：

```rust
pub fn create_order() {
    println!("create order");
    let price = super::product::default_price();
    println!("default price: {}", price);
}
```

`super::product::default_price()` 表示从 `order` 的父模块 `shop` 中访问 `product` 子模块。

## 选择建议

| 场景 | 推荐方式 |
|---|---|
| 模块内容简单，无子模块 | 单文件 `shop.rs` |
| 模块有子模块，团队习惯传统方式 | 目录 + `mod.rs` |
| 模块有子模块，偏好现代方式 | `shop.rs` + `shop/` 目录共存 |

现代方式的优势是：模块入口文件（`shop.rs`）与模块目录（`shop/`）并列，在文件树中更容易定位入口。
