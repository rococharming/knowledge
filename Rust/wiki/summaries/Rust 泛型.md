# Rust 泛型

本文是对 Rust 泛型机制的系统梳理，涵盖从基础概念到高级用法的完整内容。

## 核心内容

泛型允许函数、结构体、枚举和方法在不指定具体类型的情况下编写通用代码。Rust 编译器在编译期通过**单态化**为每种使用的具体类型生成专用代码，实现零成本抽象。

### 主要知识点

- **泛型函数与类型参数** — 使用 `<T>` 声明类型参数，编译器自动推导具体类型
- **显式指定泛型参数** — turbofish 语法 `::<>` 在类型推导不明确时使用
- **泛型结构体与枚举** — `Point<T>`、`Option<T>`、`Result<T, E>` 等
- **泛型方法** — impl 块中声明泛型、方法引入新泛型参数、为具体类型实现方法
- **const 泛型** — 编译期常量参与类型参数，如数组长度 `[T; N]`
- **单态化与性能** — 编译期展开无运行时开销，但可能增加编译时间和二进制体积

泛型与 trait 系统紧密配合：trait 声明能力，泛型参数通过[[trait bound]]约束类型必须具备的能力。
