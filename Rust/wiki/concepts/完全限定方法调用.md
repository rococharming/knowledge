# 完全限定方法调用

Rust 中的方法调用有时会出现歧义。当多个 trait 存在同名方法，或类型本身有固有方法与 trait 方法同名时，可以使用**完全限定方法调用**明确指定方法来源。

完全限定语法称为 **UFCS**（Universal Function Call Syntax）。

## 基本形式

最完整的形式：

```rust
<Type as Trait>::method(receiver, args...)
```

| 部分 | 含义 |
|---|---|
| `Type` | 接收者的具体类型 |
| `Trait` | 方法来源的 trait |
| `method` | 要调用的方法 |
| `receiver` | 显式传入的 `self` |

示例：

```rust
value.to_string()
// 等价于
ToString::to_string(&value);
// 更完整的形式
<String as ToString>::to_string(&value);
```

## 多个 Trait 存在同名方法

两个 trait 可以定义同名方法：

```rust
trait Render {
    fn draw(&self);
}

trait Shoot {
    fn draw(&self);
}

struct OutLaw;

impl Render for OutLaw {
    fn draw(&self) {
        println!("draw on screen");
    }
}

impl Shoot for OutLaw {
    fn draw(&self) {
        println!("draw a pistol");
    }
}
```

直接调用会报错：

```rust
let outlaw = OutLaw;
outlaw.draw(); // 歧义
```

消除歧义：

```rust
Render::draw(&outlaw);
Shoot::draw(&outlaw);

// 或完全限定形式
<OutLaw as Render>::draw(&outlaw);
<OutLaw as Shoot>::draw(&outlaw);
```

## 固有方法与 Trait 方法同名

如果类型本身有固有方法，同时某个 trait 也提供了同名方法，**普通方法调用会优先调用固有方法**。

```rust
trait Describe {
    fn describe(&self);
}

struct User;

impl User {
    fn describe(&self) {
        println!("inherent method");
    }
}

impl Describe for User {
    fn describe(&self) {
        println!("trait method");
    }
}

let user = User;
user.describe(); // 输出：inherent method
```

要调用 trait 中的方法：

```rust
Describe::describe(&user);
<User as Describe>::describe(&user);
```

## 关联函数的歧义

完全限定语法也能解决关联函数歧义。

```rust
trait Animal {
    fn baby_name() -> String;
}

struct Dog;

impl Dog {
    fn baby_name() -> String {
        String::from("Spot")
    }
}

impl Animal for Dog {
    fn baby_name() -> String {
        String::from("puppy")
    }
}
```

```rust
Dog::baby_name();                 // "Spot"（固有实现）
<Dog as Animal>::baby_name();     // "puppy"（trait 实现）
```

不能简单写成 `Animal::baby_name()`，因为没有 `self` 接收者，编译器无法推断具体实现类型。

## 泛型 Trait 实例的区分

对于带泛型参数的 trait，同一类型可实现不同的 trait 实例：

```rust
trait Convert<T> {
    fn convert(&self) -> T;
}

let nt = NumberText(String::from("123"));

// 完全限定语法明确指定实例
let value = <NumberText as Convert<i32>>::convert(&nt);
let text = <NumberText as Convert<String>>::convert(&nt);
```
