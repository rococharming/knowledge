# Rust 注释与 rustdoc 文档

Rust 注释可以分为普通代码注释和文档注释。普通注释用于帮助人类理解代码，编译时会被忽略；文档注释会被 `rustdoc` 解析，并可生成 API 文档。`Cargo` 的 `cargo doc` 命令会在底层调用 `rustdoc`。

## 注释分类

Rust 常见注释形式包括：

| 形式 | 写法 | 作用 |
|---|---|---|
| 行注释 | `// ...` | 简短说明或临时屏蔽单行代码 |
| 块注释 | `/* ... */` | 多行说明或临时屏蔽代码块 |
| 项文档注释 | `/// ...`、`/** ... */` | 为函数、结构体、枚举、trait 等 item 生成文档 |
| 内部文档注释 | `//! ...`、`/*! ... */` | 为当前模块或 crate 生成文档 |

行注释和块注释主要解释代码；文档注释主要服务于公开 API、模块说明、示例和文档测试。

## 行注释

行注释使用 `//` 开头，从 `//` 到行尾的内容都会被编译器忽略：

```rust
// 这是一个行注释

let x = 5; // 这是跟在代码后面的行注释
```

行注释适合写简短说明，也常用于临时屏蔽某一行代码：

```rust
let x = 5;

// println!("{x}");
```

## 块注释

块注释使用 `/* ... */` 包裹，可以跨多行，也可以写在同一行内：

```rust
/*
这是一个块注释。
它可以跨越多行。
*/

let y = 10;

/* 也可以这样写在同一行 */
```

和 C / C++ 不同，Rust 块注释支持嵌套：

```rust
/* 外层注释

    /* 内层注释 */

*/
```

这在临时注释一大段代码时很有用：即使那段代码内部已有块注释，Rust 也能正确识别注释边界。

## 项文档注释

`///` 是最常见的文档注释形式，用于为紧随其后的 item 添加说明。item 可以是函数、结构体、枚举、trait、常量、静态变量或模块。

````rust
/// `add_one` 会将指定值加 1。
///
/// # Examples
///
/// ```
/// # fn add_one(x: i32) -> i32 { x + 1 }
/// let arg = 5;
/// let answer = add_one(arg);
///
/// assert_eq!(6, answer);
/// ```
pub fn add_one(x: i32) -> i32 {
    x + 1
}
````

文档注释支持 Markdown 语法，例如标题、列表和代码块。上面的 `# Examples` 会在生成文档中显示为标题。

文档注释中的 Rust 代码块还可以作为文档测试，也就是 doctest。示例中的隐藏行 `# fn add_one(...)` 不会显示在生成文档中，但运行文档测试时会参与编译。真实项目中，也常用隐藏行导入被测试项，例如 `# use crate_name::add_one;`。

item 不一定必须是 `pub` 才能写文档注释。只是默认生成公开 API 文档时，非公开 item 通常不会显示；需要显示私有项时，要使用相关文档生成参数。

块式项文档注释 `/** ... */` 也可以为后面的 item 添加文档：

```rust
/**
`add_one` 会将指定值加 1。
*/
pub fn add_one(x: i32) -> i32 {
    x + 1
}
```

实际项目中更常用 `///`，因为它更直观，也更方便逐行维护。

## 内部文档注释

`//!` 是内部行文档注释，也叫 inner doc comment。它和 `///` 的区别在于：

- `///` 注释紧随其后的 item。
- `//!` 注释当前 crate 或当前模块本身。

`//!` 通常写在文件顶部，用于说明整个 crate 或模块：

```rust
//! 这是当前 crate 的说明文档。
//!
//! 这个 crate 提供了一些数学工具函数。

pub mod math {
    pub fn add(x: i32, y: i32) -> i32 {
        x + y
    }
}
```

也可以写在模块内部，用于说明该模块：

```rust
mod math {
    //! 数学工具模块。

    pub fn add(x: i32, y: i32) -> i32 {
        x + y
    }
}
```

块式内部文档注释 `/*! ... */` 的作用类似：

```rust
/*!
这是当前 crate 的说明文档。
可以写多行。
*/

pub fn add(x: i32, y: i32) -> i32 {
    x + y
}
```

实际项目中，`//!` 更常见。

## 生成与查看文档

在 Cargo 项目目录执行：

```shell
cargo doc
```

文档会生成到 `target/doc`。如果希望生成后自动打开浏览器，可以使用：

```shell
cargo doc --open
```

生成的文档中，`//!` 通常显示为 crate 或模块页面顶部的说明；`///` 显示为具体函数、结构体、枚举、trait 等 item 的说明。文档注释中的 Markdown 标题、代码块和列表会被渲染为 HTML 内容。

## 常见文档标题

Rust 社区常见文档标题包括：

- `# Examples`：示例用法，最常见。
- `# Panics`：说明哪些情况可能触发 `panic!`。
- `# Errors`：如果函数返回 `Result`，说明可能返回哪些错误。
- `# Safety`：如果函数涉及 `unsafe`，说明调用者必须满足哪些安全前提。

这些标题是社区惯例，不是语法强制要求。可以使用中文标题，但在实际项目中应遵循团队规范，并保持文档风格一致。
