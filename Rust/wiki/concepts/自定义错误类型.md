# 自定义错误类型

`Box<dyn Error>` 可以快速统一多种错误类型，但语义不够明确。当需要错误类型更清晰、更容易区分错误种类时，可以定义自己的错误类型。

## 适用场景

- 一个函数可能产生多种错误
- 调用者需要区分错误种类
- 错误需要携带业务上下文
- 当前 crate 是库，需要提供清晰稳定的错误 API
- 希望配合 `?` 自动转换底层错误

## 定义错误枚举

最常见的自定义错误形式是枚举，每个变体表示一种错误来源：

```rust
#[derive(Debug)]
enum ReadNumberError {
    Io(std::io::Error),
    Parse(std::num::ParseIntError),
}
```

| 变体 | 表示 |
|---|---|
| `ReadNumberError::Io` | 读取输入时发生错误 |
| `ReadNumberError::Parse` | 解析整数时发生错误 |

调用者可以用 `match` 精确处理不同错误：

```rust
match error {
    ReadNumberError::Io(error) => eprintln!("读取失败：{error}"),
    ReadNumberError::Parse(error) => eprintln!("数字格式失败：{error}"),
}
```

## 实现 Debug

错误类型通常需要实现 `Debug`，通过派生宏自动完成：

```rust
#[derive(Debug)]
enum ReadNumberError {
    Io(std::io::Error),
    Parse(std::num::ParseIntError),
}
```

`Debug` 面向开发者，用于调试输出：`println!("{:?}", error)`。

实现 `std::error::Error` 时，`Debug` 是前置要求。

## 实现 Display

`Display` 定义错误面向用户时的显示方式：

```rust
use std::fmt::{Display, Formatter};

impl Display for ReadNumberError {
    fn fmt(&self, f: &mut Formatter<'_>) -> std::fmt::Result {
        match self {
            ReadNumberError::Io(error) => write!(f, "读取输入失败：{}", error),
            ReadNumberError::Parse(error) => write!(f, "解析数字失败：{}", error),
        }
    }
}
```

`Display` 控制 `println!("{}", error)` 的输出格式。

## 实现 std::error::Error

接入 Rust 标准错误处理体系，需要实现 `std::error::Error`：

```rust
use std::error::Error;

impl Error for ReadNumberError {}
```

这是空实现，因为 `source()` 有默认实现。`Error` trait 的简化定义：

```rust
pub trait Error: Debug + Display {
    fn source(&self) -> Option<&dyn Error> {
        None
    }
}
```

- 实现 `Error` 需要先实现 `Debug` 和 `Display`
- `source()` 默认返回 `None`，表示没有更底层的错误来源

## 保留底层错误链（source）

如果希望上层代码继续访问底层错误，重写 `source()`：

```rust
impl Error for ReadNumberError {
    fn source(&self) -> Option<&(dyn Error + 'static)> {
        match self {
            ReadNumberError::Io(error) => Some(error),
            ReadNumberError::Parse(error) => Some(error),
        }
    }
}
```

有了 `source()`，可以逐层打印错误原因：

```rust
fn print_error(mut error: &dyn Error) {
    eprintln!("error: {error}");
    while let Some(source) = error.source() {
        eprintln!("caused by: {source}");
        error = source;
    }
}
```

> `Display` 负责当前错误怎么显示，`source()` 负责保留底层错误来源，两者作用不同。

## 实现 From 支持 ? 自动转换

配合 `?` 使用时，需要为自定义错误类型实现 `From`，让 `?` 知道如何把底层错误转换为当前类型：

```rust
impl From<std::io::Error> for ReadNumberError {
    fn from(error: std::io::Error) -> Self {
        Self::Io(error)
    }
}

impl From<std::num::ParseIntError> for ReadNumberError {
    fn from(error: std::num::ParseIntError) -> Self {
        Self::Parse(error)
    }
}
```

实现后，`?` 可以自动完成转换：

```rust
fn read_numbers(reader: &mut dyn BufRead) -> Result<Vec<i64>, ReadNumberError> {
    let mut numbers = Vec::new();
    for line_result in reader.lines() {
        let line = line_result?;      // io::Error → ReadNumberError::Io
        let number: i64 = line.parse()?;  // ParseIntError → ReadNumberError::Parse
        numbers.push(number);
    }
    Ok(numbers)
}
```

## 完整示例

```rust
use std::fmt::{Display, Formatter};
use std::error::Error;
use std::io::BufRead;

#[derive(Debug)]
enum ReadNumberError {
    Io(std::io::Error),
    Parse(std::num::ParseIntError),
}

impl Display for ReadNumberError {
    fn fmt(&self, f: &mut Formatter<'_>) -> std::fmt::Result {
        match self {
            ReadNumberError::Io(_) => write!(f, "读取输入失败"),
            ReadNumberError::Parse(_) => write!(f, "解析数字失败"),
        }
    }
}

impl Error for ReadNumberError {
    fn source(&self) -> Option<&(dyn Error + 'static)> {
        match self {
            ReadNumberError::Io(error) => Some(error),
            ReadNumberError::Parse(error) => Some(error),
        }
    }
}

impl From<std::io::Error> for ReadNumberError {
    fn from(value: std::io::Error) -> Self {
        Self::Io(value)
    }
}

impl From<std::num::ParseIntError> for ReadNumberError {
    fn from(value: std::num::ParseIntError) -> Self {
        Self::Parse(value)
    }
}

fn read_numbers(reader: &mut dyn BufRead) -> Result<Vec<i64>, ReadNumberError> {
    let mut numbers = Vec::new();
    for line_result in reader.lines() {
        let line = line_result?;
        let number: i64 = line.parse()?;
        numbers.push(number);
    }
    Ok(numbers)
}
```
