# 路径与导入

## 路径的基本概念

Rust 使用路径定位语法项，路径使用 `::` 分隔：

```rust
std::mem::swap
```

表示 `std` 模块中的 `mem` 子模块中的 `swap` 函数。

完整路径来源清楚，但较长时会使代码变得冗长。

## use 导入

`use` 将路径引入当前作用域，不复制代码，只是增加一个可用名字：

```rust
use std::mem;

fn main() {
    mem::swap(&mut a, &mut b);
}
```

也可直接导入具体函数：

```rust
use std::mem::swap;
```

常见风格：

- **类型、Trait、模块**通常导入到当前作用域
- **函数**常保留模块前缀，让来源更清楚

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();
```

## use 的作用范围

模块级别：当前模块后续代码都可用。

代码块级别：只在当前代码块内有效。

```rust
fn sort_pair(mut a: i32, mut b: i32) -> (i32, i32) {
    use std::mem;
    if a > b { mem::swap(&mut a, &mut b); }
    (a, b)
}
```

## 合并导入

同一路径下的多个名字一起导入：

```rust
use std::collections::{HashMap, HashSet};
```

同时导入模块本身和模块中的成员：

```rust
use std::fs::{self, File};
// 等价于：
// use std::fs;
// use std::fs::File;
```

通配导入：

```rust
use std::io::prelude::*;
```

> 通配导入容易让名字来源不清楚，建议只在常见 prelude 场景或小范围代码中使用。

## as 重命名

解决名字冲突或简化长名称：

```rust
use std::fmt::Result as FmtResult;
use std::io::Result as IoResult;
```

## 导入不会被子模块继承

每个模块有自己的名字作用域，父模块的 `use` 不会自动进入子模块：

```rust
mod parent {
    pub struct User { pub name: String; }
    use std::mem;

    pub mod child {
        pub fn func(a: &mut i32, b: &mut i32) {
            // User 和 mem 在这里都不可用
            let user = super::User { name: String::from("Tom") };
            // 需要在 child 内部重新 use std::mem;
        }
    }
}
```

## 特殊路径名

| 路径 | 含义 |
|---|---|
| `self` | 当前模块 |
| `super` | 父模块 |
| `crate` | 当前 crate 的根模块 |
| `::crate_name` | 外部 crate 根（用于与本地模块重名时消除歧义） |

`crate` 路径从 crate 根部开始，项目变复杂后通常更稳定：

```rust
use crate::account::User;
```

外部 crate 与本地模块重名时，以 `::` 开头表示外部 crate：

```rust
use crate::image::Sampler;    // 本地模块
use ::image::Sampler;          // 外部 crate
```

## 标准库预导入

每个模块默认自动导入 `std::prelude::v1::*`，因此常用类型和 Trait 无需手动导入：

```rust
let numbers: Vec<i32> = Vec::new();
let option: Option<i32> = Some(2);
let result: Result<i32, String> = Ok(1);
```

> 只有标准库的 prelude 会自动导入，其他库的 prelude 需要手动 `use`。

## pub use 重导出

`pub use` 将名字引入当前作用域，并作为当前模块的公开项重新导出：

```rust
pub mod leaves;
pub mod roots;

pub use self::leaves::Leaf;
pub use self::roots::Root;
```

外部既可以用原始路径 `plant_structures::leaves::Leaf`，也可以用更短的重导出路径 `plant_structures::Leaf`。

重导出常用于整理库的公共 API，让内部细分的模块结构对外提供更简洁的访问路径。
