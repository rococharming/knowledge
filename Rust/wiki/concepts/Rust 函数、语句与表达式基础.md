# Rust 函数、语句与表达式基础

Rust 是一门偏表达式风格的语言。函数体通常由若干语句组成，并且可以把最后一个表达式作为返回值。理解语句、表达式和代码块的取值规则，是读懂 Rust 函数、控制流和返回值语义的基础。

## 语句与表达式

语句用于执行操作，但不产生一个可继续使用的值；表达式会求值，并产生一个值。

```rust
let x = 1 + 1;
let y = 2 + 2;
x + y
```

上面前两行是 `let` 语句，其中 `1 + 1` 和 `2 + 2` 是表达式。最后一行 `x + y` 是表达式；如果它位于代码块的最后一行且没有分号，就可以作为该代码块的值。

## `let` 是语句

`let` 绑定是语句，不是表达式，因此不能把一个 `let` 语句当成值赋给另一个变量：

```rust
let a = 8;
// let b = (let a = 8); // 编译错误
```

这也是 [[Rust 变量绑定与常量基础]] 和表达式规则相交的地方：`let a = 8;` 整体是语句，右侧的 `8` 才是表达式。

## 代码块表达式

代码块 `{}` 本身也是表达式。代码块的值由最后一个不带分号的表达式决定；如果最后没有表达式，或者最后一行以分号结尾，代码块的值就是单元值 `()`。

```rust
let y = {
    let x = 3;
    x + 1
};

assert_eq!(y, 4);
```

如果给最后一行加上分号，`x + 1;` 就变成语句，整个代码块的值会变成 `()`：

```rust
let y = {
    let x = 3;
    x + 1;
};

assert_eq!(y, ());
```

单元类型 `()` 也见于 [[Rust 基本数据类型]]：它既是类型，也是值，常用来表示没有有意义的返回值。

## 控制流表达式

Rust 的一些控制流结构也可以作为表达式使用。

`if` 可以用于赋值，但所有分支必须返回相同类型：

```rust
let x = 11;

let res = if x % 2 == 1 { "odd" } else { "even" };
```

如果一个分支返回 `&str`，另一个分支返回整数，编译器会拒绝，因为两个分支类型不一致：

```rust
// let res = if x % 2 == 1 { "odd" } else { 0 };
```

`loop` 也可以作为表达式。`break` 后面可以跟一个表达式，作为整个 `loop` 的值：

```rust
let mut count = 0;

let result = loop {
    count += 1;

    if count == 5 {
        break count * 2;
    }
};

assert_eq!(result, 10);
```

这些规则和 [[Rust 控制流]] 直接相关：控制流不只是改变执行顺序，也可以参与求值。

## 函数定义

Rust 使用 `fn` 定义函数。程序入口函数是 `main`：

```rust
fn main() {
    println!("Hello, world!");
}
```

函数用于封装可复用逻辑。一个带参数和返回值的函数通常包含函数名、参数列表、返回类型和函数体：

```rust
fn add(x: i32, y: i32) -> i32 {
    x + y
}
```

其中：

- `fn` 表示定义函数。
- `add` 是函数名。
- `(x: i32, y: i32)` 是参数列表。
- `-> i32` 表示返回类型是 `i32`。
- `x + y` 是函数体最后一个表达式，会作为函数返回值。

Rust 不要求函数必须先声明再定义。函数可以写在调用位置之后，只要它在当前模块的可见范围内，编译器就能解析到。

```rust
fn main() {
    println!("1 + 2 = {}", add(1, 2));
}

fn add(x: i32, y: i32) -> i32 {
    x + y
}
```

## 函数参数

函数参数属于函数签名的一部分。定义中的参数称为形参，调用时传入的具体值称为实参：

```rust
fn get(x: u32, y: u32) {
    println!("Got x: {x}, y: {y}");
}

fn main() {
    let a = 10;
    let b = 20;
    get(a, b);
}
```

函数参数必须写类型注解。Rust 不会在实参与形参之间自动做数值类型转换：

```rust
fn get(x: i32) {
    println!("{x}");
}

fn main() {
    let a: u32 = 10;

    get(a as i32);
}
```

如果不希望简单地用 `as` 截断或重解释数值，应根据场景选择更明确的安全转换方式。

## 函数返回值

函数可以在参数列表后使用 `->` 指定返回类型：

```rust
fn add_one(x: i32) -> i32 {
    x + 1
}
```

Rust 函数返回值有几条常见规则：

- 如果函数体最后一行是表达式且不以分号结尾，该表达式的值会作为返回值。
- 如果函数体最后一行是语句，函数体返回 `()`。
- 如果返回类型是 `()`，可以省略 `-> ()`。
- 可以使用 `return` 提前返回值。

```rust
fn add_one(x: i32) -> i32 {
    return x + 1;
}
```

如果不是为了提前返回，Rust 通常更推荐直接使用最后一个表达式作为返回值：

```rust
fn add_one(x: i32) -> i32 {
    x + 1
}
```
