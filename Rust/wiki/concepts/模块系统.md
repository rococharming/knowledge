# 模块系统

## 基本概念

**模块（module）** 是 crate 内部组织代码的方式。可以理解为：给一组相关代码取一个名字，并管理这组代码的命名空间与可见性。

模块中可以包含：函数、结构体、枚举、Trait、常量、静态变量、类型别名、子模块、`use` 声明。

```rust
mod shop {
    pub struct Product {
        pub name: String,
        price: u32,
    }

    pub fn create_product(name: &str, price: u32) -> Product {
        Product { name: name.to_string(), price }
    }

    pub(crate) fn calc_discount_price(price: u32) -> u32 {
        price * 90 / 100
    }

    fn validate_price(price: u32) -> bool {
        price > 0
    }
}
```

## 核心作用

### 命名空间管理

不同模块中可以存在同名函数或类型，通过路径区分：

```rust
mod shop {
    pub fn create() { println!("create shop item"); }
}

mod user {
    pub fn create() { println!("create user"); }
}

fn main() {
    shop::create();
    user::create();
}
```

### 可见性管理

未标记 `pub` 的语法项**默认私有**。私有项可在定义它的模块内部使用，也可被其子模块访问。

```rust
mod shop {
    fn check_stock() { println!("check stock"); }

    pub mod admin {
        pub fn run() {
            super::check_stock();  // 子模块可访问父模块的私有项
        }
    }
}
```

## pub 与路径可见性

某个语法项能否被外部访问，**不仅取决于它自身是否标记 `pub`，还取决于所在路径是否可见**。

```rust
mod outer {
    mod inner {           // inner 不是 pub
        pub fn hello() {} // hello 是 pub，但路径不可达
    }
}

// outer::inner::hello(); // 错误：inner 是私有模块
```

## 受限制的公开可见性

| 修饰符 | 可见范围 |
|---|---|
| `pub` | 完全公开 |
| `pub(crate)` | 只在当前 crate 内可见 |
| `pub(super)` | 只对父模块可见 |
| `pub(in path)` | 只在指定模块路径内可见 |

`pub(crate)` 常用于内部共享代码：

```rust
mod pricing {
    pub(crate) fn calc_member_price(price: u32) -> u32 {
        price * 80 / 100
    }
}
```

`pub(super)` 适合表达"给父模块协调内部逻辑用"：

```rust
mod shop {
    pub mod order {
        pub(super) fn normalize_order_id(id: &str) -> String {
            id.trim().to_uppercase()
        }
    }

    pub fn test() {
        let id = order::normalize_order_id(" ab-123 "); // 父模块可见
    }
}
```

## 嵌套模块

模块可以嵌套，按领域划分代码层级：

```rust
mod shop {
    pub mod product { pub fn list() {} }
    pub mod order   { pub fn create() {} }
    pub mod user    { pub fn login() {} }
}
```
