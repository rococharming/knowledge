# Rust 基本数据类型

Rust 的基础数据类型可以分为两类：标量类型和复合类型。标量类型表示单个值，包括整型、浮点型、布尔型和字符型；复合类型把多个值组合成一个整体，Rust 原生支持的基础复合类型主要是数组和元组。

## 标量类型

标量类型适合表示单个不可再拆的值。Rust 的基础标量类型包括：

| 类型 | 说明 | 常见例子 |
|---|---|---|
| 整型 | 没有小数部分的数字 | `i32`、`u64`、`usize` |
| 浮点型 | 小数与 IEEE 754 特殊值 | `f32`、`f64` |
| 布尔型 | 条件真假值 | `true`、`false` |
| 字符型 | 单个 Unicode 标量值 | `'A'`、`'中'`、`'😊'` |

## 整型

Rust 内置有符号整数和无符号整数：

| 长度 | 有符号 | 无符号 |
|---|---|---|
| 8-bit | `i8` | `u8` |
| 16-bit | `i16` | `u16` |
| 32-bit | `i32` | `u32` |
| 64-bit | `i64` | `u64` |
| 128-bit | `i128` | `u128` |
| 架构相关 | `isize` | `usize` |

`i` 表示 signed integer，`u` 表示 unsigned integer。`isize` 和 `usize` 的大小随目标平台变化：32 位平台上是 32 位，64 位平台上是 64 位。集合索引通常使用 `usize`。

整数字面量默认推断为 `i32`，也可以通过类型注解或类型后缀显式指定：

```rust
let a = 1;
let b: u32 = 10;
let c = 10u32;
```

数字中可以使用 `_` 提高可读性，也可以使用不同进制：

```rust
let decimal = 1_000;
let hex = 0xffff_ffff;
let octal = 0o12;
let binary = 0b1110_0011;
let byte = b'A';
```

`b'A'` 是 `u8` 字节字符字面量，只能表示单个 ASCII 字符或字节转义；普通字符字面量 `'A'` 的类型是 `char`。

## 整数溢出

整数类型都有固定取值范围。例如 `u8` 是 `0..=255`，`i8` 是 `-128..=127`。编译期能确定越界时，编译器会直接报错；运行时计算发生溢出时，默认行为受构建模式影响：

- 调试构建会检查普通整数溢出，溢出时触发 `panic`。
- 发布构建默认不检查普通整数溢出，结果通常按二进制补码规则回绕。

为了让溢出语义更明确，Rust 提供了几类常用方法：

| 方法族 | 返回/行为 | 适用场景 |
|---|---|---|
| `checked_*` | 返回 `Option<T>`，溢出时为 `None` | 宁可显式失败，也不要错误结果 |
| `wrapping_*` | 按补码规则回绕 | 哈希、加密、循环计数、模运算 |
| `saturating_*` | 溢出时钳制到类型边界 | 音视频、图像处理、计数上限 |
| `overflowing_*` | 返回 `(result, overflowed)` | 既要结果，也要知道是否溢出 |

```rust
let a: u8 = 254;

assert_eq!(a.checked_add(2), None);
assert_eq!(a.wrapping_add(2), 0);
assert_eq!(a.saturating_add(2), 255);
assert_eq!(a.overflowing_add(2), (0, true));
```

## 浮点型

Rust 提供 `f32` 和 `f64` 两种浮点类型，分别对应 32 位单精度和 64 位双精度浮点数，并遵循 IEEE 754 标准。浮点数字面量默认推断为 `f64`：

```rust
let x = 2.0;
let y: f32 = 3.14;
let z = 5f32;
```

浮点数支持 `INFINITY`、`NEG_INFINITY` 和 `NAN` 等特殊值：

```rust
let positive_inf = f32::INFINITY;
let negative_inf = f64::NEG_INFINITY;
let not_a_number = f64::NAN;
```

`NaN` 不等于任何值，包括它自己，因此不能用 `==` 判断一个值是否为 `NaN`，应使用 `is_nan()`：

```rust
let x = f64::NAN;

assert!(x.is_nan());
assert!(!(x == x));
```

浮点类型还提供取值范围相关的关联常量。需要注意，`f64::MIN` 表示 `f64` 能表示的最小有限值，也就是一个很大的负数；最小正正规数应使用 `f64::MIN_POSITIVE`。数学常量位于 `std::f32::consts` 和 `std::f64::consts`，例如 `PI` 和 `E`。

## 布尔类型

`bool` 只有两个值：`true` 和 `false`。Rust 不会像 C 或 C++ 那样把整数、指针等隐式转换为布尔值：

```rust
let x = 1;

if x != 0 {
    println!("true");
}
```

`bool` 可以用 `as` 转换为整数，`true as i32` 是 `1`，`false as i32` 是 `0`；但整数不能直接转换为 `bool`。虽然布尔值理论上只需要 1 bit，Rust 中 `bool` 的大小是 1 字节。

在 [[Rust 控制流]] 中，`if` 和 `while` 的条件表达式必须是 `bool`。如果要根据整数是否为零决定分支，需要写成 `x != 0`，而不是直接把整数放进条件位置。

## 字符类型

`char` 占 4 字节，表示单个 Unicode 标量值。英文字母、汉字和单个 emoji 都可以写成 `char`：

```rust
let a = 'z';
let b: char = '中';
let c = '😊';
```

Unicode 标量值不完全等同于人类直觉中的“一个字符”。有些看起来像一个字符的内容，可能由多个 Unicode 标量值组合而成。

`String` 和 `&str` 使用 UTF-8 字节序列存储文本。由于 UTF-8 字符的字节长度不固定，Rust 不允许直接用整数下标访问字符串中的第 n 个字符：

```rust
let s = "hello";
// let c = s[0]; // 编译错误
```

## 数组

数组中的所有元素必须是同一种类型，并且长度固定。数组长度是类型的一部分，数组类型写作 `[元素类型; 长度]`：

```rust
let arr1 = [1, 2, 3, 4, 5];
let arr2: [f64; 3] = [1.0, 2.0, 3.0];
let arr3 = [10; 3];
```

打印数组通常使用 `{:?}`，因为数组实现了 `Debug`，但不适合用 `{}` 的 `Display` 形式直接打印：

```rust
println!("{:?}", arr1);
println!("{:#?}", arr1);
```

访问数组元素使用从 0 开始的索引。明显的常量越界可能在编译期报错；运行时才确定的越界访问会触发 `panic`。

## 元组

元组可以把多个不同类型的值组合在一起。元组长度固定，一旦定义后不能增减元素：

```rust
let tup1 = (10, 3.14);
let tup2: (bool, char) = (true, 'A');
```

访问元组元素使用 `.n`，其中 `n` 从 0 开始：

```rust
let tup = (10, 3.14);

println!("{}, {}", tup.0, tup.1);
```

元组也可以通过模式匹配解构：

```rust
let tup = (10, 3.14);
let (x, y) = tup;
```

空元组 `()` 称为单元类型。它既是类型，也是值，常用来表示“没有有意义的返回值”。

在 [[Rust 函数、语句与表达式基础]] 中，函数调用、代码块和函数体没有产生有意义的值时，通常也会返回 `()`。

## 与变量绑定的关系

类型推断、类型注解和字面量默认类型通常会和 [[Rust 变量绑定与常量基础]] 一起出现。`let a = 1` 同时涉及变量绑定和整数字面量默认类型；`let a: u32 = 10` 则同时展示了绑定语法和显式类型注解。
