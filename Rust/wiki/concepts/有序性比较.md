# 有序性比较

Rust 的大小比较由 `std::cmp::PartialOrd` 和 `std::cmp::Ord` 表示，分别对应部分有序和全序关系。它们与相等性比较的层级关系为：

| 相等关系 | 有序关系 |
|---------|---------|
| `PartialEq` | `PartialOrd` |
| `Eq` | `Ord` |

`PartialOrd` 扩展了 `PartialEq`，`Ord` 扩展了 `Eq` 和 `PartialOrd`。

## PartialOrd

`PartialOrd` 支持 `<`、`>`、`<=`、`>=` 运算符：

```rust
trait PartialOrd<Rhs = Self>: PartialEq<Rhs>
where
    Rhs: ?Sized,
{
    fn partial_cmp(&self, other: &Rhs) -> Option<Ordering>;

    fn lt(&self, other: &Rhs) -> bool { ... }
    fn le(&self, other: &Rhs) -> bool { ... }
    fn gt(&self, other: &Rhs) -> bool { ... }
    fn ge(&self, other: &Rhs) -> bool { ... }
}
```

### 必须实现的方法

唯一必须自行实现的方法是 `partial_cmp`：

```rust
fn partial_cmp(&self, other: &Rhs) -> Option<Ordering>;
```

返回类型是 `Option<Ordering>`，`Ordering` 枚举定义如下：

```rust
enum Ordering {
    Less,       // self < other
    Equal,      // self == other
    Greater,    // self > other
}
```

| 返回值 | 含义 |
|--------|------|
| `Some(Less)` | `self < other` |
| `Some(Equal)` | `self == other` |
| `Some(Greater)` | `self > other` |
| `None` | 两者无法比较顺序 |

之所以返回 `Option`，是因为并非所有值之间都能比较出顺序。典型例子是浮点数的 `NaN`：

```rust
let x = f64::NAN;
// x.partial_cmp(&x) == None
```

### 区间类型的部分有序示例

区间 `[lower, upper)` 是理解 `PartialOrd` 的典型例子：

```rust
#[derive(Debug, PartialEq)]
struct Interval<T> {
    lower: T,
    upper: T,
}

impl<T: PartialOrd> PartialOrd for Interval<T> {
    fn partial_cmp(&self, other: &Self) -> Option<Ordering> {
        if self == other {
            Some(Ordering::Equal)
        } else if self.upper <= other.lower {
            Some(Ordering::Less)
        } else if self.lower >= other.upper {
            Some(Ordering::Greater)
        } else {
            None  // 重叠，无法比较
        }
    }
}
```

- `[10, 20) < [20, 40)` ✓
- `[10, 30)` 与 `[20, 40)` 重叠 → `partial_cmp` 返回 `None`，`<` 返回 `false`

## Ord

`Ord` 表示**全序关系**：任意两个值之间都能比较出确定顺序。

```rust
trait Ord: Eq + PartialEq<Self> {
    fn cmp(&self, other: &Self) -> Ordering;
}
```

与 `partial_cmp` 的关键区别：

| | `partial_cmp` | `cmp` |
|--|---------------|-------|
| 返回类型 | `Option<Ordering>` | `Ordering`（非 Option） |
| 泛型参数 | 允许跨类型比较 | 通常只定义在同类型之间 |
| 前提 | `PartialEq` | `Eq` + `PartialOrd` |

### 排序接口

很多标准库排序方法依赖 `Ord`：

```rust
let mut v = vec![10, 30, 20];
v.sort();           // 要求 T: Ord，升序
println!("{:?}", v); // [10, 20, 30]
```

自定义排序规则：

```rust
v.sort_by(|a, b| b.cmp(a));  // 降序
```

比较器签名：`FnMut(&T, &T) -> Ordering`

| 返回值 | 含义 |
|--------|------|
| `Ordering::Less` | 第一个参数排在第二个前面 |
| `Ordering::Equal` | 顺序相同 |
| `Ordering::Greater` | 第一个参数排在第二个后面 |

## Reverse

`std::cmp::Reverse<T>` 是一个包装类型，用于**反转比较顺序**：

```rust
struct Reverse<T>(T);

impl<T: PartialOrd> PartialOrd for Reverse<T> {
    fn partial_cmp(&self, other: &Reverse<T>) -> Option<Ordering> {
        other.0.partial_cmp(&self.0)  // 交换比较方向
    }
}

impl<T: Ord> Ord for Reverse<T> {
    fn cmp(&self, other: &Reverse<T>) -> Ordering {
        other.0.cmp(&self.0)
    }
}
```

将默认升序变为降序的常见用法：

```rust
use std::cmp::Reverse;

let mut v = vec![40, 10, 30, 20, 50];
v.sort_by_key(|x| Reverse(*x));
println!("{:?}", v); // [50, 40, 30, 20, 10]
```
