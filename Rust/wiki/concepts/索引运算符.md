# 索引运算符

Rust 支持 `a[i]` 形式的索引语法。要让自定义类型支持索引，需要实现 `std::ops::Index`（只读）和 `std::ops::IndexMut`（可变）。

## Index

`Index` 的简化定义：

```rust
trait Index<Idx> {
    type Output: ?Sized;
    fn index(&self, index: Idx) -> &Self::Output;
}
```

| 组成 | 说明 |
|------|------|
| `Idx` | 索引参数类型，不限于 `usize` |
| `Output` | 索引结果类型 |
| `index` | 返回共享引用 `&Self::Output` |

表达式 `a[i]` 在只读上下文中等价于：

```rust
*a.index(i)
```

### 索引参数类型

索引参数可以是多种类型：

```rust
let v = vec![1, 2, 3, 4, 5];
let slice = &v[..];

let x = slice[0];        // Index<usize>
let y = &slice[1..4];    // Index<Range<usize>>
```

| 表达式 | 对应实现 |
|--------|---------|
| `slice[0]` | `Index<usize>` |
| `slice[1..4]` | `Index<Range<usize>>` |

### HashMap 索引

`HashMap` 支持以键为索引的只读访问：

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();
scores.insert("Tom", 90);

assert_eq!(scores["Tom"], 90);
```

> 索引访问要求键必须存在，不存在时会 `panic`。不确定时应使用 `get`：
>
> ```rust
> if let Some(score) = scores.get("Jack") {
>     println!("{}", score);
> }
> ```

## IndexMut

`IndexMut` 继承自 `Index`，表示可变索引：

```rust
trait IndexMut<Idx>: Index<Idx> {
    fn index_mut(&mut self, index: Idx) -> &mut Self::Output;
}
```

表达式 `a[i] = v` 等价于：

```rust
*a.index_mut(i) = v;
```

### 关键限制

`IndexMut` 必须返回**已存在的值**的可变引用。这带来一个重要限制：它不适合"索引不存在时自动创建"的场景。

```rust
let mut v = vec!["hello".to_string(), "hi".to_string()];
v[0].push_str(", world");  // 修改已有元素，OK
```

`HashMap` **没有实现 `IndexMut`**，因此不能这样写：

```rust
// 错误：HashMap 不支持可变索引赋值
// scores["Jack"] = 70;
```

原因：`index_mut` 必须返回已存在的值的 `&mut` 引用。如果键不存在，就没有现成的值可返回。

对于 `HashMap`，应使用 `insert` 或 `entry` API：

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();
scores.insert("Jack", 70);
*scores.entry("Tom").or_insert(0) += 10;
```
