# 生命周期

生命周期是 Rust 用来描述引用有效范围的概念。它与[[所有权系统]]、[[引用与借用]]共同保证：引用不会比被引用的数据活得更久，从而避免悬垂引用。

## 核心直觉

所有权决定一个值由谁负责释放；借用允许在不转移所有权的情况下访问值；生命周期则约束引用能使用到什么时候。

在安全 Rust 中，编译器会在编译期检查引用是否有效。如果引用可能指向已释放的数据，代码无法通过编译。

生命周期标注不会延长任何值的实际生命周期。它只是在函数、结构体或方法签名中描述多个引用之间的关系，让借用检查器知道返回引用依赖哪些输入引用。

## 悬垂引用

悬垂引用指引用仍然存在，但它指向的数据已经被释放。Rust 会在编译期阻止这类代码：

```rust
fn main() {
    let r;

    {
        let x = 5;
        r = &x;
    }

    println!("{r}");
}
```

`x` 在内部作用域结束时被释放，而 `r` 仍在外层作用域中使用。借用检查器会拒绝这段代码，因为被引用的数据比引用本身活得更短。

## 函数中的生命周期关系

当函数返回引用时，返回值的生命周期通常需要与某个输入引用建立关系。若函数只有一个输入引用，编译器通常可以通过[[生命周期省略规则]]推断关系：

```rust
fn first_word(s: &str) -> &str {
    match s.find(' ') {
        Some(index) => &s[..index],
        None => s,
    }
}
```

如果函数有多个输入引用并返回引用，编译器无法猜测返回值来自哪个参数，需要显式生命周期参数：

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}
```

这里的 `'a` 表示返回引用不能比 `x` 和 `y` 中较短的那个生命周期更长。

## 生命周期标注描述关系

生命周期参数以单引号开头，常见名称是 `'a`：

```rust
&i32
&'a i32
&'a mut i32
```

单独一个生命周期名称没有意义。它的作用是把多个引用放进同一个关系中：

```rust
fn first<'a>(x: &'a str, y: &str) -> &'a str {
    x
}
```

这个签名说明返回值只与 `x` 的生命周期相关，和 `y` 没有关联。

若函数返回局部变量的引用，无论如何标注生命周期都无法成立：

```rust
fn wrong<'a>() -> &'a str {
    let s = String::from("temporary");
    s.as_str()
}
```

`s` 在函数结束时释放，返回它的引用会产生悬垂引用。此时应返回拥有所有权的 `String`。

## 结构体中的引用字段

结构体如果保存引用字段，需要在结构体定义中声明生命周期参数：

```rust
struct Excerpt<'a> {
    text: &'a str,
}
```

这表示 `Excerpt` 实例不能比其 `text` 字段中的引用活得更久。只要结构体实例仍被使用，被引用的数据就必须保持有效。

如果结构体保存 `String` 这类拥有所有权的数据，则不需要生命周期参数。

## 非词法生命周期

Rust 使用非词法生命周期（NLL）分析引用的最后一次使用位置，而不是机械地把借用延长到整个词法作用域末尾：

```rust
let mut s = String::from("hello");
let r = &s;
println!("{}", r);

s.push_str(" world"); // r 最后一次使用后，共享借用已结束
```

这让借用规则更贴近真实使用范围。

## 临时值生命周期延长

引用可以指向临时值，但仅在 `let` 初始化语句中临时值生命周期会被延长：

```rust
let r = &String::from("hello");
println!("{}", r);
```

先声明再赋值则不适用：

```rust
let r;
r = &String::from("hello"); // 错误：临时值在此语句后释放
println!("{}", r);
```

## 静态生命周期

`'static` 是特殊生命周期，表示引用可在整个程序运行期间有效。字符串字面量天然具有 `'static` 生命周期：

```rust
let s: &'static str = "hello";
```

不要把 `'static` 当作普通生命周期错误的万能修复方式。多数情况下，编译器建议 `'static` 是因为代码存在悬垂引用、生命周期关系错误或数据活得不够久。
