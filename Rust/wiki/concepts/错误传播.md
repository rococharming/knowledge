# 错误传播

当当前函数不想处理错误，而是把错误交给调用者处理时，Rust 提供了手动传播和 `?` 运算符两种方式。

## 手动传播

使用 `match` 手动返回错误：

```rust
use std::fs::File;
use std::io::Read;

fn read_username_from_file() -> Result<String, std::io::Error> {
    let mut file = match File::open("username.txt") {
        Ok(f) => f,
        Err(e) => return Err(e),
    };

    let mut username = String::new();
    match file.read_to_string(&mut username) {
        Ok(_) => Ok(username),
        Err(e) => Err(e),
    }
}
```

逻辑清楚，但写起来比较啰嗦。

## ? 运算符

`?` 是错误传播的快捷写法：

- `Ok(value)` → 取出 `value`，程序继续执行
- `Err(error)` → 立即从当前函数返回 `Err(error)`

```rust
fn read_username_from_file() -> Result<String, std::io::Error> {
    let mut file = File::open("username.txt")?;
    let mut username = String::new();
    file.read_to_string(&mut username)?;
    Ok(username)
}
```

`File::open("username.txt")?` 等价于：

```rust
let mut file = match File::open("username.txt") {
    Ok(f) => f,
    Err(e) => return Err(e),
};
```

## 链式写法

`?` 可以连续使用：

```rust
fn read_username_from_file() -> Result<String, std::io::Error> {
    let mut username = String::new();
    File::open("username.txt")?.read_to_string(&mut username)?;
    Ok(username)
}
```

## ? 与错误类型转换

`?` 不只是提前返回错误。**如果满足条件，它还会把当前错误类型转换为当前函数返回的错误类型**。

这个转换依赖 [[From]] Trait。如果一个类型实现了 `From<其他错误类型>`，那么 `?` 就可以自动完成转换。

例如，函数返回 `Result<T, MyError>`，而表达式返回 `Result<T, std::io::Error>`，只要存在：

```rust
impl From<std::io::Error> for MyError
```

就可以使用 `?` 自动转换。这也是 [[自定义错误类型]] 中经常实现 `From` 的原因。

## ? 用于 Option

`?` 不只用于 `Result`，也可以用于 `Option`：

- `Some(v)` → 取出 `v`，继续执行
- `None` → 立即返回 `None`

```rust
fn first_elem(values: &[i32]) -> Option<&i32> {
    let value = values.get(0)?;
    Some(value)
}
```

链式用法：

```rust
fn last_char_of_first_line(text: &str) -> Option<char> {
    text.lines().next()?.chars().last()
}
```

逻辑：获取第一行 → 没有则返回 `None` → 有则取最后一个字符。
