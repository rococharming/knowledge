# 文档测试

Rust 的文档注释不仅可以生成 HTML 文档，还可以包含可测试的代码示例。

## 文档注释类型

| 注释 | 作用 |
| --- | --- |
| `///` | 为紧随其后的函数、结构体、枚举等项编写文档 |
| `//!` | 为当前模块或 crate 编写整体文档 |

## 基本示例

```rust
//! # My Test Adder
//!
//! `adder` 提供了简单的数学工具

/// Add one to the given number
///
/// # Examples
///
/// ```
/// let arg = 2;
/// let answer = adder::add_one(arg);
///
/// assert_eq!(3, answer)
/// ```
pub fn add_one(value: i32) -> i32 {
    value + 1
}
```

生成文档：

```shell
cargo doc
cargo doc --open
```

运行测试（包含文档测试）：

```shell
cargo test
```

只想运行文档测试：

```shell
cargo test --doc
```

## 文档测试的执行方式

普通文档测试满足两个条件时通过：

1. 代码可以编译
2. 运行时不发生 `panic`

如果代码块没有标注语言，文档测试默认会按 Rust 代码处理。

## 隐藏辅助代码

有时文档示例需要一些辅助代码才能编译，但不希望这些代码显示在最终文档中。可以使用 `#` 隐藏行：

```rust
/// # Examples
///
/// ```
/// # use adder::add_one;
/// let arg = 2;
/// let answer = add_one(arg);
///
/// assert_eq!(3, answer)
/// ```
pub fn add_one(value: i32) -> i32 {
    value + 1
}
```

以 `#` 开头的行会参与编译和测试，但不会显示在生成的文档中。这种写法适合隐藏 `use`、初始化代码或辅助定义，让文档展示更简洁。

## 文档测试代码块标记

| 标记 | 含义 |
| --- | --- |
| `no_run` | 只编译，不运行 |
| `should_panic` | 代码应当编译成功，但运行时应当 panic |
| `compile_fail` | 代码应当编译失败 |
| `ignore` | 忽略该代码块 |
| `edition2021` / `edition2024` | 指定代码块使用的 Rust Edition |

示例：只编译不运行

```rust
/// ```no_run
/// loop {
///     println!("running forever");
/// }
/// ```
pub fn example() {}
```

代码块会参与编译，但不会真正运行无限循环。
