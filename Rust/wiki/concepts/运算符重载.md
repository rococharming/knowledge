# 运算符重载

Rust 中大多数运算符并非独立语法，而是建立在 `std::ops` trait 之上的统一接口。为自定义类型实现对应 trait，即可让该类型支持自然运算符语法。

## 基本原理

运算符本质上是 trait 方法调用的语法糖：

| 表达式 | 对应 trait | 等效方法调用 |
|--------|-----------|-------------|
| `x + y` | `std::ops::Add` | `x.add(y)` |
| `-x` | `std::ops::Neg` | `x.neg()` |
| `x & y` | `std::ops::BitAnd` | `x.bitand(y)` |
| `x += y` | `std::ops::AddAssign` | `x.add_assign(y)` |

## 一元运算符

一元运算符只作用于单个操作数，trait 定义使用 `self` 按值接收：

```rust
trait Neg {
    type Output;
    fn neg(self) -> Self::Output;
}

trait Not {
    type Output;
    fn not(self) -> Self::Output;
}
```

| trait | 表达式 | 说明 |
|-------|--------|------|
| `std::ops::Neg` | `-x` | 一元负号 |
| `std::ops::Not` | `!x` | 逻辑取反（`bool`）或按位取反（整数）|

> Rust 不区分 `!` 和 `~`，统一用 `Not` trait 表达两类操作。

为泛型类型实现一元负号的示例：

```rust
use std::ops::Neg;

#[derive(Debug, Clone, Copy)]
struct Complex<T> {
    re: T,
    im: T,
}

impl<T> Neg for Complex<T>
where
    T: Neg<Output = T>,
{
    type Output = Self;

    fn neg(self) -> Self::Output {
        Self {
            re: -self.re,
            im: -self.im,
        }
    }
}
```

约束 `T: Neg<Output = T>` 表示字段类型本身必须支持一元负号，且结果仍为 `T`。

## 二元算术运算符

### Add 的核心结构

```rust
trait Add<Rhs = Self> {
    type Output;
    fn add(self, rhs: Rhs) -> Self::Output;
}
```

| 组成 | 说明 |
|------|------|
| `Rhs = Self` | 右操作数类型默认与左操作数相同 |
| `type Output` | 运算结果类型由关联类型指定 |
| `self` | 左操作数按值接收，可能消耗原值 |

### 同类型相加

```rust
impl<T> Add for Complex<T>
where
    T: Add<Output = T>,
{
    type Output = Self;

    fn add(self, rhs: Self) -> Self::Output {
        Self {
            re: self.re + rhs.re,
            im: self.im + rhs.im,
        }
    }
}
```

### 跨类型相加

`Rhs` 可自定义，左右操作数不必同类型：

```rust
impl<L, R> Add<Complex<R>> for Complex<L>
where
    L: Add<R>,
{
    type Output = Complex<L::Output>;

    fn add(self, rhs: Complex<R>) -> Self::Output {
        Complex {
            re: self.re + rhs.re,
            im: self.im + rhs.im,
        }
    }
}
```

> 跨类型运算类型系统上成立，但 API 设计中需谨慎使用，避免过度复杂化。

### 算术与按位运算符一览

| 类别 | Trait | 表达式 |
|------|-------|--------|
| 算术 | `Add`、`Sub`、`Mul`、`Div`、`Rem` | `+`、`-`、`*`、`/`、`%` |
| 按位 | `BitAnd`、`BitOr`、`BitXor`、`Shl`、`Shr` | `&`、`|`、`^`、`<<`、`>>` |

## 复合赋值运算符

复合赋值运算符（`+=`、`-=`、`*=` 等）对应 `std::ops::*Assign` trait：

```rust
trait AddAssign<Rhs = Self> {
    fn add_assign(&mut self, rhs: Rhs);
}
```

与 `Add` 不同，`AddAssign` **没有 `Output` 关联类型**，目标是直接修改左操作数。表达式结果类型为 `()`：

```rust
let mut x = 1;
let result = { x += 2; };  // result 的类型是 ()
```

| 类别 | Trait |
|------|-------|
| 算术复合赋值 | `AddAssign`、`SubAssign`、`MulAssign`、`DivAssign`、`RemAssign` |
| 按位复合赋值 | `BitAndAssign`、`BitOrAssign`、`BitXorAssign`、`ShlAssign`、`ShrAssign` |

## 不可重载的运算符

以下运算符属于语言核心语义，**不能由用户重载**：

| 运算符 | 原因 |
|--------|------|
| `&&`、`\|\|` | 短路求值语义不可自定义 |
| `?` | 错误传播是内建控制流机制 |
| `..`、`..=` | 直接构造范围结构体值 |
| `&` | 借用运算符，属于所有权系统 |
| `=` | 赋值运算符，涉及移动/复制语义 |
| `()` | 稳定 Rust 中普通类型不能实现函数调用运算符 |
