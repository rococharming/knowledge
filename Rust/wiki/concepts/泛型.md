# 泛型

泛型（Generics）是 Rust 中描述"代码适用于多种类型"的机制。通过在函数、结构体、枚举和方法中引入**类型参数**，可以编写不依赖具体类型的通用代码。Rust 的泛型在编译期通过**单态化**展开为具体代码，通常不带来运行时性能损耗。

## 类型参数

类型参数通常使用大写字母命名，如 `T`、`U`、`E`、`K`、`V`。

```rust
fn identity<T>(value: T) -> T {
    value
}
```

编译器根据调用时的实参自动推导 `T` 的具体类型。

## 泛型函数

在函数名后使用 `<T>` 声明类型参数：

```rust
fn swap<T>(a: &mut T, b: &mut T) {
    std::mem::swap(a, b);
}
```

同一调用中所有 `T` 必须是同一种类型。若需支持不同类型，声明多个参数：

```rust
fn pair<T, U>(a: T, b: U) {
    // ...
}
```

## 显式指定泛型参数

当编译器无法推导时，使用 turbofish 语法 `::<...>` 显式标注：

```rust
let numbers = (0..5).collect::<Vec<i32>>();
```

也可通过变量类型标注辅助推导：

```rust
let numbers: Vec<i32> = (0..5).collect();
```

## 泛型结构体

```rust
struct Point<T> {
    x: T,
    y: T,
}
```

`Point<i32>`、`Point<f64>` 是不同的具体类型。若字段类型不同，使用多个参数：

```rust
struct Point<T, U> {
    x: T,
    y: U,
}
```

## 泛型枚举

`Option<T>` 和 `Result<T, E>` 是标准库中最常用的泛型枚举，详见[[Option]]与[[Result]]。

## 泛型方法

### 在 impl 块中使用结构体的泛型参数

```rust
impl<T> Point<T> {
    fn new(x: T, y: T) -> Self {
        Self { x, y }
    }

    fn x(&self) -> &T {
        &self.x
    }
}
```

`impl<T> Point<T>` 表示该实现块适用于任意 `Point<T>`。方法中的 `Self` 指代当前实现对应的类型。

### 方法引入新的泛型参数

```rust
impl<T, U> Point<T, U> {
    fn mixup<V, W>(self, other: Point<V, W>) -> Point<T, W> {
        Point {
            x: self.x,
            y: other.y,
        }
    }
}
```

`V`、`W` 仅在该方法内有效，与结构体的 `T`、`U` 无必然关系。

### 为具体类型实现方法

```rust
impl Point<f64> {
    fn distance_from_origin(&self) -> f64 {
        (self.x.powi(2) + self.y.powi(2)).sqrt()
    }
}
```

此类方法只属于 `Point<f64>`，不属于 `Point<i32>` 或其他实例。

## const 泛型

`const` 泛型让编译期常量参与类型参数，常用于数组长度等场景：

```rust
fn first<T, const N: usize>(array: [T; N]) -> T {
    array[0]
}
```

`N` 是编译期已知的 `usize` 常量，可以出现在类型中。与普通函数参数不同，`const` 泛型必须是编译期可确定的常量表达式。

结构体也可以使用 `const` 泛型：

```rust
struct Buffer<T, const N: usize> {
    data: [T; N],
}

impl<T, const N: usize> Buffer<T, N> {
    fn len(&self) -> usize {
        N
    }
}
```

## 单态化与性能

Rust 编译器在编译期为每种实际使用的具体类型生成专用代码，这个过程称为**单态化**（Monomorphization）。

```rust
let a = Some(5);       // 生成 Option<i32> 专用代码
let b = Some(3.14);    // 生成 Option<f64> 专用代码
```

由于泛型在编译期展开，运行时没有额外的抽象开销，这是 Rust 零成本抽象的体现。但单态化也会增加编译时间和二进制体积。
