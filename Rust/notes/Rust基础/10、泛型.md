# 一、泛型的基本概念

泛型（Generics）是 Rust 中非常重要的抽象能力。它允许函数、结构体、枚举和方法在**不指定具体类型的情况下**编写通用代码。

例如，一个交换两个值的函数不应该只适用于`i32`，也应该适用于`f64`、`String`或其他类型。

泛型可以理解为一种类型层面的模板。**模板使用类型参数占位，等真正调用时，编译器再根据实际类型生成对应的具体代码**。

常见的泛型参数名是`T`、`U`、`E`、`K`、`V` 等。它们通常使用大写字母或大驼峰命名。

例如：

```rust
fn identity<T>(value: T) -> T {
	value
}
```

这里的`T`是类型参数，表示这个函数可以接受任意类型的值，并返回同类型的值。

调用时：

```rust
fn main() {
    let n = identity(10);
    let s = identity(String::from("hello"));

    println!("{n}");
    println!("{s}");
}
```

第一次调用时，`T` 被推导为 `i32`；第二次调用时，`T` 被推导为 `String`。

Rust 的泛型主要在编译期完成处理。编译器会根据实际使用到的具体类型生成专用版本，这个过程叫 **单态化**。

# 二、泛型函数

在函数中使用泛型，需要在函数名后面使用 `<T>` 声明类型参数。

示例：

```rust
fn add<T>(a: T, b: T) -> T {
	a + b
}
```

`add`实现两个值相加，两个值可以是任意的同一种类型。

再看交换两个同类型变量的值：

```rust
fn swap<T>(a: &mut T, b: &mut T) {
    std::mem::swap(a, b);
}

fn main() {
    let mut n1 = 1;
    let mut n2 = 2;

    swap(&mut n1, &mut n2);
    println!("n1 = {n1}, n2 = {n2}");

    let mut s1 = String::from("hello");
    let mut s2 = String::from("world");

    swap(&mut s1, &mut s2);
    println!("s1 = {s1}, s2 = {s2}");
}
```

`swap<T>` 中的 `T` 表示两个参数指向的值必须是同一种类型。

调用 `swap(&mut n1, &mut n2)` 时，编译器推导出 `T = i32`。

调用 `swap(&mut s1, &mut s2)` 时，编译器推导出 `T = String`。

如果两个参数不是同一种类型，代码无法通过编译。例如`swap(&mut n1, &mut s1)`就是错误的。

如果希望两个参数是不同类型，需要定义两个类型参数：

```rust
fn pair<T, U>(a: T, b: U) {
	// ...
}
```

# 三、显式指定泛型参数

多数情况下，Rust可以根据实参自动推导泛型参数，不需要手动指定。

但在某些场景中，编译器无法推断具体类型，需要显式标注。

显式标注的常见语法为`::<...>`，也叫 turbofish 语法。

示例：

```rust
let numbers = (0..5).collect::<Vec<i32>>();
```

如果不写具体类型：

```rust
let numbers = (0..5).collect();
```

编译器会报错，因为`collect()`可以收集成很多类型，例如`Vec<i32>`、`HashSet<i32>`等，单靠右侧表达式无法确定目标类型。

也可以通过变量类型标注帮助编译器推导：

```rust
let numbers: Vec<i32> = (0..5).collect();
```

显式泛型参数不是日常代码里必须频繁使用的东西，但在类型推导不够明确时很有用。


# 四、泛型结构体

结构体也可以使用泛型。泛型参数通常用于字段类型。

示例：

```rust
struct Point<T> {
    x: T,
    y: T,
}
```

这里的`Point<T>`是一个二维点，`x`和`y`的类型相同。

```rust
fn main() {
	
	let p1 = Point { x: 1, y: 2 };
	let p2 = Point { x: 1.0, y: 2.0 };

}
```

`p1` 的类型是 `Point<i32>`，`p2` 的类型是 `Point<f64>`。

如果希望两个字段可以是不同类型，可以使用多个泛型参数：

```rust
struct Point<T, U> {
    x: T,
    y: U,
}

fn main() {
    let p = Point { x: 10, y: 3.14 };
}
```

此时 `p` 的类型是 `Point<i32, f64>`。

需要注意：`Point<T>` 不是一个完整的具体类型（它只是一个模板），`Point<i32>`、`Point<f64>` 才是具体类型。


# 五、泛型枚举

枚举也可以使用泛型。泛型参数常用于变体携带的数据类型。

示例：

```rust
enum Maybe<T> {
	Some(T),
	None
}
```

Rust 标准库中最常见的泛型枚举是 `Option<T>` 和 `Result<T, E>`。

## 1、Option\<T\>

`Option<T>` 用来表示一个值可能存在，也可能不存在。

它的简化定义如下：

```rust
enum Option<T> {
    Some(T),
    None,
}
```

`Some(T)` 表示有值，`None` 表示无值。

例如：

```rust
if find_number(flag: bool) -> Option<i32> {
	if flag {
		Some(10)
	} else {
		None
	}
}
```

`Option<T>` 常用于替代其他语言中的 `null`。Rust 中没有普通意义上的空指针值，可能缺失的值通常用 `Option<T>` 表示。


## 2、Result<T, E>

`Result<T, E>` 用来表示一个操作可能成功，也可能失败。

它的简化定义如下：

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

`Ok(T)` 表示成功，并携带成功结果；`Err(E)` 表示失败，并携带错误信息。

例如：

```rust
fn divide(a: i32, b: i32) -> Result<i32, String> {
    if b == 0 {
        Err(String::from("cannot divide by zero"))
    } else {
        Ok(a / b)
    }
}
```

`Option<T>` 和 `Result<T, E>` 广泛用于模式匹配和错误处理。

# 六、泛型方法

泛型不仅能用于函数、结构体和枚举，也可以用于方法。

## 1、在impl块中声明结构体已有的泛型参数

如果结构体本身带有泛型参数，那么为它实现方法时，通常也需要在 `impl` 后声明对应的泛型参数。

示例：

```rust
struct Point<T> {
    x: T,
    y: T,
}

impl<T> Point<T> {
    fn new(x: T, y: T) -> Self {
        Self { x, y }
    }

    fn x(&self) -> &T {
        &self.x
    }

    fn y(&self) -> &T {
        &self.y
    }
}

fn main() {
    let p = Point::new(1, 2);

    println!("x = {}", p.x());
    println!("y = {}", p.y());
}
```

`impl<T> Point<T>` 中：

`impl<T>` 表示声明泛型参数 `T`。

`Point<T>` 表示这个实现块适用于任意 `Point<T>`。

在`new()`方法中，`Self`表示当前`impl`对应的类型，在这里就是`Point<T>`。

`new()`方法也可以写成：

```rust
fn new(x: T, y: T) -> Point<T> {
	Point { x, y }
}
```

函数体内的`Point`可以省略`<T>`，编译器会帮助我们自动推断。


## 2、方法引入新的泛型参数

方法也可以单独引入新的泛型参数：

```rust
#[derive(Debug)]
struct Point<T, U> {
    x: T,
    y: U,
}

impl<T, U> Point<T, U> {
    fn mixup<V, W>(self, other: Point<V, W>) -> Point<T, W> {
        Point {
            x: self.x,
            y: other.y,
        }
    }
}

fn main() {
    let p1 = Point { x: 10, y: 3.14 };
    let p2 = Point { x: "hello", y: 'A' };

    let p3 = p1.mixup(p2);

    println!("{p3:?}");
}
```

## 3、为具体类型实现方法

也可以只为某个具体的泛型实例实现方法。

示例：

```rust
struct Point<T> {
    x: T,
    y: T,
}

impl Point<f64> {
    fn distance_from_origin(&self) -> f64 {
        (self.x.powi(2) + self.y.powi(2)).sqrt()
    }
}

fn main() {
    let p = Point { x: 3.0, y: 4.0 };

    println!("{}", p.distance_from_origin());
}
```

注意：

这里的 `impl Point<f64>` 表示这些方法只属于 `Point<f64>`，不属于 `Point<i32>` 或其他 `Point<T>`。


# 七、泛型代码的性能

Rust泛型代码通常不会带来运行时性能损耗。原因是 Rust 编译器在编译期进行**单态化**：编译器在编译时根据泛型模板，为每一种实际使用到的类型生成专用版本代码。

例如：

```rust
let a = Some(5);
let b = Some(3.14);
```

这里分别使用了 `Option<i32>` 和 `Option<f64>`。

所以编译器在编译时，根据`Option<T>`模板，生成了类似这样的版本：

```rust

enum OptionI32 {
	Some(i32),
	None,
}

enum OptionF64 {
	Some(f64),
	None,
}

```

所以实际调用时也变成：

```rust
let a = OptionI32::Some(5);
let b = OptionF64::Some(3.14);
```

由于泛型在编译期被展开成具体类型代码，所以运行时通常没有额外的抽象开销。这也是 Rust 常说的零成本抽象之一。

不过，单态化也有代价：如果泛型代码被大量不同类型实例化，编译时间和最终二进制体积可能增加。

# 八、const泛型

前面介绍的都是类型泛型（如`T`、`U`）。Rust还支持`const`泛型，也就是让编译期常量参与类型参数。

`const`泛型常见于数组长度这类场景：数组`[T; N]`的长度是类型的一部分，所以`[i32, 5]`和`[i32; 3]`是不同类型。

使用`const`泛型可以写出适用于不同数组长度的代码：

```rust
fn first<T, const N: usize>(array: [T; N]) -> T {
	array[0]
}
```

这里的 `N` 是一个编译期常量参数，类型是 `usize`。

示例：

```rust
fn dot_product<const N: usize>(a: [f64; N], b: [f64; N]) -> f64 {
    let mut sum = 0.0;

    for i in 0..N {
        sum += a[i] * b[i];
    }

    sum
}

fn main() {
    let r1 = dot_product([1.0, 2.0], [3.0, 4.0]);
    let r2 = dot_product::<3>([1.0, 1.0, 1.0], [2.0, 2.0, 2.0]);

    println!("{r1}");
    println!("{r2}");
}
```

`dot_product` 要求两个数组的长度相同，因为它们都使用 `[f64; N]`。

`N` 和普通函数参数不同。普通参数是运行时值，而 `const N: usize` 是编译期已知的常量，可以出现在类型中。

与类型参数一样，既可以显式提供常量参数，也可以让Rust推断它们。

```rust
let r1 = dot_product([1.0, 2.0], [3.0, 4.0]);
let r2 = dot_product::<3>([1.0, 1.0, 1.0], [2.0, 2.0, 2.0]);
```

结构体也可以使用 `const` 泛型：

```rust
struct Buffer<T, const N: usize> {
    data: [T; N],
}

impl<T, const N: usize> Buffer<T, N> {
    fn new(data: [T; N]) -> Self {
        Self { data }
    }

    fn len(&self) -> usize {
        N
    }
}

fn main() {
    let buffer = Buffer::new([1, 2, 3]);

    println!("{}", buffer.len());
}
```

`const` 泛型不等于任意运行时参数。它必须是编译期能够确定的常量表达式。
