# 一、简介

Rust 标准库提供了多种集合类型，用于在内存中存储和管理多个值。集合和数组、元组不同，它们通常可以动态增长，适合处理数量不固定的数据。遍历和转换集合时通常会用到 [[Rust/notes/Rust基础/22、迭代器|迭代器]]。

集合类型大多是泛型类型，例如`Vec<T>`、`HashMap<K,V>`、`HashSet<T>`。其中，`T`表示元素类型，`K`表示键类型，`V`表示值类型。

Rust集合在使用方式上与其他语言有一些重要差异：

| 特点        | 说明                            |
| --------- | ----------------------------- |
| 所有权明确     | 向集合中插入值时，通常会把值的所有权移动进集合       |
| 避免隐式深拷贝   | Rust 不会自动复制复杂数据，是否克隆由程序员显式决定  |
| 借用检查严格    | 不能在持有集合内部元素引用时随意修改集合结构，避免悬空引用 |
| 没有 `null` | 需要表示“可能没有值”时，使用 `Option<T>`   |
| 类型约束清晰    | 哈希集合要求元素可哈希和可比较，有序集合要求元素可排序   |

例如，将 `String` 放入 `Vec<String>` 时，字符串本身不会被复制，而是移动到集合中：

```rust
fn main() {
	let text = String::from("hello");
	
	let mut values = Vec::new();
	values.push(text);
	
	// println!("{text}"); // 错误：text 的所有权已经移动到 values 中
}
```

Rust 常用集合包括 `Vec<T>`、`HashMap<K, V>`、`HashSet<T>`、`VecDeque<T>`、`BinaryHeap<T>`、`BTreeMap<K, V>`、`BTreeSet<T>` 等。其中 `Vec<T>`、`HashMap<K, V>` 和 `HashSet<T>` 最常用，分别对应动态数组、键值映射和不重复集合。


# 二、Vec\<T>

## 1、概述

`Vec<T>`是Rust中最常用的集合类型，表示**可增长的动态数组**。

它适合存储一组类型相同，数量可能变化的数据。`Vec<T>`的元素连续存储在堆上，按索引访问效率高，尾部追加效率也高，因此很多列表场景都会优先使用`Vec<T>`。

## 2、创建向量

创建`Vec<T>`最常用的方式是使用`vec!`宏。

```rust
fn main() {  
      
    // 创建空向量  
    let mut numbers: Vec<i32> = vec![];  
      
    // 使用指定元素创建向量  
    let words = vec!["step", "on", "no", "pets"];  
      
    // 创建长度为 1024 的向量，每个元素都是 0u8    let buffer = vec![0u8; 1024];  
  
}
```

常见创建方式如下：

|写法|含义|
|---|---|
|`Vec::new()`|创建空向量|
|`vec![]`|创建空向量|
|`vec![a, b, c]`|使用指定元素创建向量|
|`vec![value; n]`|创建长度为 `n` 的向量，每个元素都是 `value` 的克隆|
|`Vec::with_capacity(n)`|创建空向量，并预留至少容纳 `n` 个元素的空间|
如果创建空向量时暂时没有插入元素，编译器无法推断元素类型，通常需要显式标注：

```rust
let numbers: Vec<i32> = Vec::new();
```

`Vec<T>`内部可以简单理解为三个核心信息：

|信息|含义|
|---|---|
|指针|指向堆上的元素缓冲区|
|长度 `len`|当前已经存储的元素数量|
|容量 `capacity`|当前缓冲区最多能容纳的元素数量|
空向量的长度和容量都是 `0`。只有插入元素或主动预留容量后，才会分配堆内存。

```rust
fn main() {
    let numbers: Vec<i32> = Vec::new();

    println!("len = {}", numbers.len());
    println!("capacity = {}", numbers.capacity());
}
```

可以把 `Vec<T>` 的内存关系简化理解为：

```text
栈上的 Vec<T>                         堆上的缓冲区

numbers
┌──────────────┐
│ ptr ─────────┼──────────────▶  [10, 20, 30, _, _]
│ len = 3      │
│ cap = 5      │
└──────────────┘
```

其中 `len` 表示当前有效元素数量，`cap` 表示已经分配的总空间。

## 3、向量与所有权

向 `Vec<T>` 中插入非`Copy`类型值时，会把值的所有权移动进向量。

```rust
fn main() {
    let text = String::from("hello");

    let mut values = Vec::new();
    values.push(text);

    // println!("{text}"); // 错误：text 的所有权已经移动到 values 中
}
```

如果元素类型实现了 `Copy`，读取或传递时发生复制；如果是 `String`、`Vec<T>` 这类拥有堆内存的类型，则发生所有权移动。

这体现了 Rust 集合的重要特点：Rust 不会隐式深拷贝集合元素，是否克隆需要由代码明确表达。

## 4、从迭代器创建向量

`Vec<T>`可以通过迭代器收集元素创建，常见写法是`.collect::<Vec<_>>()`。

```rust
fn main() {
    let numbers = (1..=5).collect::<Vec<i32>>();

    println!("{numbers:?}");
}
```

常见写法是把一个迭代过程的结果收集成向量：

```rust
fn main() {
	let squares = (1..=5)
		.map(|x| x * x)
		.collect::<Vec<_>>();
	
	println!("{squares:?}");
}
```

## 5、访问元素

访问 `Vec<T>` 元素最常见的方式有两种：索引访问和 `get` 方法。

```rust
fn main() {
    let numbers = vec![10, 20, 30];

    let first = numbers[0];
    let second = numbers.get(1);

    println!("{first}");
    println!("{second:?}");
}
```

| 写法                   | 返回值                      | 越界行为         |
| -------------------- | ------------------------ | ------------ |
| `vec[index]`         | 元素引用，或在 `Copy` 类型场景下复制出值 | 越界时 panic    |
| `vec.get(index)`     | `Option<&T>`             | 越界时返回 `None` |
| `vec.get_mut(index)` | `Option<&mut T>`         | 越界时返回 `None` |

`get` 更适合索引不确定的场景：

```rust
fn main() {
    let numbers = vec![10, 20, 30];

    match numbers.get(5) {
        Some(value) => println!("value = {value}"),
        None => println!("index out of range"),
    }
}
```

如果需要修改某个元素，可以使用 `get_mut`：

```rust
fn main() {
    let mut numbers = vec![10, 20, 30];

    if let Some(value) = numbers.get_mut(1) {
        *value = 200;
    }

    println!("{numbers:?}");
}
```

索引类型必须是 `usize`。如果手里是 `i32`、`u32`、`isize` 等整数，需要显式转换：

```rust
fn main() {
    let numbers = vec![10, 20, 30];

    let index: u32 = 1;
    let value = numbers[index as usize];

    println!("{value}");
}
```


## 6、切片访问

`Vec<T>`可以通过范围语法取得切片。

```rust
fn main() {
    let numbers = vec![10, 20, 30, 40, 50];

    let part = &numbers[1..4];

    println!("{part:?}");
}
```

切片不会复制元素，它只是对原数据中一段连续区域的引用。

| 写法                 | 含义                    |
| ------------------ | --------------------- |
| `&vec[..]`         | 整个向量的切片               |
| `&vec[start..end]` | 从 `start` 到 `end - 1` |
| `&vec[start..]`    | 从 `start` 到末尾         |
| `&vec[..end]`      | 从开头到 `end - 1`        |
如果范围越界，会发生 panic。

```rust
fn main() {
    let numbers = vec![10, 20, 30];

    // let part = &numbers[1..10]; // panic
}
```

如果需要把切片复制成新的 `Vec<T>`，可以使用 `.to_vec()`：

```rust
fn main() {
    let numbers = vec![10, 20, 30, 40, 50];

    let part = numbers[1..4].to_vec();

    println!("{part:?}");
}
```

`.to_vec()` 会克隆切片中的元素，因此元素类型需要满足 `Clone`。


## 7、常用切片访问方法

`Vec<T>`可以自动借用为切片，因此很多切片方法也能直接用于向量。

| 方法               | 作用            | 返回值              |
| ---------------- | ------------- | ---------------- |
| `first()`        | 获取第一个元素       | `Option<&T>`     |
| `last()`         | 获取最后一个元素      | `Option<&T>`     |
| `get(index)`     | 获取指定位置元素      | `Option<&T>`     |
| `first_mut()`    | 获取第一个元素的可变引用  | `Option<&mut T>` |
| `last_mut()`     | 获取最后一个元素的可变引用 | `Option<&mut T>` |
| `get_mut(index)` | 获取指定位置元素的可变引用 | `Option<&mut T>` |
示例：

```rust
fn main() {
    let numbers = vec![10, 20, 30];

    if let Some(first) = numbers.first() {
        println!("first = {first}");
    }

    if let Some(last) = numbers.last() {
        println!("last = {last}");
    }
}
```

修改最后一个元素：

```rust
fn main() {
    let mut numbers = vec![10, 20, 30];

    if let Some(last) = numbers.last_mut() {
        *last = 300;
    }

    println!("{numbers:?}");
}
```

这些方法比直接索引更安全，因为它们使用 `Option<T>` 表达“元素可能不存在”。
