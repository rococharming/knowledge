
Git Submodule 用于在一个 Git 仓库中引用另一个独立的 Git 仓库，并把这个外部仓库锁定到一个确定提交。

主仓库记录的信息：

1. `.gitmodules`记录路径和远程地址（必须提交到主仓库）
2. `gitlink`记录子模块提交哈希（初始化或同步子模块，子模块工作区检出到主仓库记录的那个提交）
3. 子模块的 Git 数据

## 一、添加和克隆子模块

> 项目维护者如何把子模块加入主仓库，团队成员如何完整拉下带子模块的项目。

### 1、添加子模块

```shell
git submodule add <仓库地址> <本地目录>
```

执行后，Git 完成三件事：

1. 克隆子模块仓库
2. 创建或更新`.gitmodules`
3. 在主仓库索引中记录子仓库当前指向的提交

### 2、克隆带子模块的仓库

```shell
git clone --recurse-submodules https://github.com/example/my-project.git
```


# 二、查看和同步子模块状态

- 查看子模块状态

```shell
git submodule status
```

- 同步到主仓库记录的版本

```shell
git pull
git submodule update --init --recursive
```
