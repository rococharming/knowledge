
teach skill 是 mattpocock skills  的 productivity 类 skill。

只需要安装并调用：

```
/teach Rust 生命周期
```

第一次运行时，`teach`会把当前目录当作教学工作区，并逐步创建自己的文件：

```
学习目录/
├── MISSION.md
├── RESOURCES.md
├── NOTES.md
├── lessons/
│   └── 0001-xxx.html
├── reference/
├── learning-records/
└── assets/
```

其中：

- `MISSION.md`：为什么学习这个主题
- `RESOURCES`：可信学习资料
- `lessons/`：每一节 HTML 课程
- `learning-records/`：已经掌握的知识
- `assets/`：课程共用的样式，测试组件等
