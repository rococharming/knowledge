## 蓝海产品调研工作流

1. 定范围    ->     类目
2. 找机会    ->    关键词、竞品、价格带
3. 挖痛点    ->    低星评论到产品要求
4. 看站外    ->    其他电商平台或社交媒体的信号
5. 出方案    ->    5个概念 + 方案图
