岗位职责归纳：

- 产品生命周期管理：管产品导入、推广、销售、停产、替代等
- 需求管理：收集区域和客户需求，并推动落地
- 销售数据分析：根据销量、区域、业务情况找销售问题
- 市场和竞品：看本地市场、竞品、价格和产品机会
- 推广与赋能：给销售/渠道做培训、宣讲、推广

产品售前工程师：把总部已有产品带到区域市场并帮助销售落地。

产品售前工程师的职责就处于这条链路的中间位置。

SMBG即中小企业事业群，是海康威视的三大事业群之一，与PBG（公告服务事业群）、EBG（企事业事业群）并列，是海康威视境内主页的三大核心板块之一。

SMBG面向中小企业市场，围绕广大安防从业者和中小企业市场，整合产品、渠道、服务和平台能力，帮助合作伙伴提高经营和服务效率。

**海康总部产品**  ->  **区域分公司**  -> **经销商/渠道伙伴** -> **中小企业客户**

SMBG 产品售前工程师，本质是区域产品经营岗位，核心任务不是单纯提供技术支持，而是围绕区域市场，把合适的产品卖给合适的客户，并通过需求分析、销售数据、竞品分析、产品策略和推广赋能，推动产品销售增长。

# 一、自我介绍

面试官您好，我叫宋鹏飞。本科就读于扬州大学通信工程专业，硕士就读于河海大学信号与信息处理专业。毕业后进入 vivo，目前主要从事 BlueOS 研发工具链相关的软件开发工作。

在目前的工作中，我主要参与 BDB 调试工具、UI 预览以及设备适配相关产品建设，过程中会涉及需求梳理、竞品研究、技术方案设计、功能落地、联调验证以及问题追踪，同时也需要和不同研发团队进行协作推进。

这一年的工作让我积累了比较扎实的技术积累和问题分析能力，但在实际工作中我发现，相比进行单纯的代码实现，我对产品需求、使用场景和如何通过产品解决实际问题更加感兴趣。所以这次希望寻找一个能够结合技术背景、同时更多参与产品和业务侧工作的岗位。

我了解到贵司 SMBG 产品售前工程师这个岗位，一方面需要理解产品和技术，另一方面也需要结合区域市场、销售情况和客户需求推动产品落地，我认为和我目前积累的能力比较契合，所以希望能够尝试这个方向，谢谢。

# 二、为什么从软件开发转产品售前

我觉得主要是两个方面。

第一，我在 vivo 的工作虽然是软件开发，但实际工作并不只是写代码。比如在 BDB 和 UI 预览项目中，我都会参与需求梳理、方案分析、功能验证、问题追踪以及跨团队合作。在这个过程中，我逐渐发现自己比较擅长，也比较感兴趣的是把一个模糊的问题梳理清楚，再去分析应该怎么解决，以及协调相关团队把事情推进下去。

第二，我希望自己的技术背景能够和产品、业务场景结合得更紧一些。软件开发更多关注功能怎么实现，而产品售前还需要进一步考虑客户需要什么，产品能不能解决这个问题、应该选择什么方案以及怎么向客户和销售把方案讲清楚。这种工作方式和我希望发展的发现比较一致。

# 三、为什么不继续做开发

我并不是认为开发不好，而是经过这一年多的工作，我对自己更适合什么类型的工作有了更明确的认识。

我能够完成研发工作，也积累了软件开发、问题定位和联调方面的经验。但相比长时间专注于代码实现，我更有兴趣的是理解需求、分析问题、梳理解决方案以及推动不同团队协作把问题解决掉。

所以我希望下一阶段能够把工作重心往产品和解决方案方向调整，而不是完全脱离技术。这样既可以保留之前积累的技术基础，也可以尝试更偏产品和业务的工作。


# 四、你没有售前经验，为什么觉得自己能做好？

确实，我之前没有传统意义上的售前岗位经验，这也是我和有相关经验候选人相比比较明显的差距。

但我认为该岗位有一部分核心能力和我之前的工作是相通的。

比如在目前的工作中，我经常需要先梳理需求，再进行方案分析，判断问题该从哪个模块解决，然后和不同团队进行联调和推进，最后完成验证和问题闭环。

而产品售前的工作虽然业务场景不同，但本质上同样需要先理解客户需求，再结合产品能力分析解决方案，并和销售、产品、研发等不同角色进行沟通推进。

所以我目前欠缺的主要是安防行业知识、产品知识以及实际客户沟通经验，但我认为这些属于可以通过学习和实践积累的部分。我认为自己原有的技术理解、分析和协作能力能够成为这个岗位的基础。
