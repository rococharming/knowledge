# Git 工作区域与文件状态

Git 的本地提交模型由工作区、暂存区和本地仓库组成。理解这三个区域后，`git add`、`git commit`、`git status` 和 `git diff` 的作用就能归位。Git 的整体定位见 [[Git 版本控制系统]]，仓库创建入口见 [[Git 仓库创建与验证]]，日常操作闭环见 [[Git 本地提交流程]]。

![[Pasted image 20260722011109.png|300]]

这条链路有一个关键结论：`git commit` 提交的是暂存区内容，不是工作区里的全部文件。

## 三个区域

| 区域 | 英文 | 作用 |
|---|---|---|
| 工作区 | Working Tree / Working Directory | 日常编辑的项目文件目录，普通文件的新建、修改、删除和移动都先发生在这里 |
| 暂存区 | Staging Area / Index | 保存下一次提交准备包含的内容快照 |
| 本地仓库 | Local Repository | 保存已经提交的历史记录，普通仓库的数据主要位于 `.git` 目录 |

`git add` 写入暂存区的是文件当前内容的快照，而不只是文件名。因此，同一个文件在暂存后继续修改时，后续修改仍留在工作区；只有再次执行 `git add`，这部分新内容才会进入下一次提交。

## 文件状态

Git 先把文件分为未跟踪与已跟踪两类。未跟踪文件尚未被 Git 纳入管理；已跟踪文件则已经出现在某次提交或暂存区中。

已跟踪文件还会在以下状态之间流转：

| 状态 | 含义 |
|---|---|
| `Unmodified` | 内容与最近一次提交一致 |
| `Modified` | 工作区内容发生变化，但还没有进入暂存区 |
| `Staged` | 修改已经加入暂存区，等待提交 |

![[Pasted image 20260722011900.png|300]]

同一个文件可以同时存在“已暂存的一版”和“工作区后来又修改的一版”。此时 `git status` 可能同时在 `Changes to be committed` 和 `Changes not staged for commit` 中列出它；若直接提交，进入历史的是暂存区那一版。

## 状态与差异检查

`git status` 用来回答两个问题：工作区有哪些变化，暂存区有哪些变化。常见输出区域包括：

| 输出区域 | 含义 |
|---|---|
| `Untracked files` | 文件还没有被 Git 跟踪 |
| `Changes not staged for commit` | 工作区有修改，但还没暂存 |
| `Changes to be committed` | 暂存区有内容，等待提交 |
| `working tree clean` | 工作区和暂存区都没有待处理内容 |

差异检查通常分成两个方向：

```shell
git diff
```

查看工作区相对于暂存区的差异，也就是尚未暂存的修改。

```shell
git diff --staged
```

查看暂存区相对于最近一次提交的差异，也就是下一次提交准备包含的内容。`git diff --cached` 是等价写法。

### 简洁状态码

`git status -s` 用 `XY path` 展示状态，其中 `X` 表示暂存区相对最近一次提交的状态，`Y` 表示工作区相对暂存区的状态。

| 输出 | 含义 |
|---|---|
| `?? b.txt` | 未跟踪文件 |
| `A  b.txt` | 新文件已暂存 |
| ` M b.txt` | 工作区有未暂存修改 |
| `M  b.txt` | 修改已暂存 |
| `MM b.txt` | 同一文件既有已暂存修改，又有新的未暂存修改 |

`MM` 是理解暂存区快照最直观的状态之一：下一次提交只会包含已经暂存的那一版，工作区后来追加的修改仍需再次 `git add`。

## 索引中的已跟踪文件

`git ls-files` 查看 Git 索引中记录的路径，通常包括已经提交过或已经加入暂存区的文件。它不同于 `ls`：`ls` 查看工作区目录，`git ls-files` 查看 Git 当前管理的路径。

需要查看索引的底层条目时，可以使用：

```shell
git ls-files --stage
```

常见文件模式包括 `100644`（普通不可执行文件）、`100755`（普通可执行文件）、`120000`（符号链接）和 `160000`（Git 子模块）。

需要列出未跟踪且未被忽略的文件时，可以使用：

```shell
git ls-files --others --exclude-standard
```

## 常见操作定位

| 命令 | 区域变化 |
|---|---|
| `git add <file>` | 将工作区当前内容快照写入暂存区 |
| `git commit -m "message"` | 将暂存区内容保存为一次提交 |
| `git status` | 查看工作区和暂存区相对提交历史的状态 |
| `git diff` | 查看工作区中尚未暂存的差异 |
| `git diff --staged` | 查看暂存区即将提交的差异 |
