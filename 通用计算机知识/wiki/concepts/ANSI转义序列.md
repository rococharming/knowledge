# ANSI 转义序列

ANSI 转义序列（ANSI Escape Sequence）是一组嵌入在文本流中的特殊控制指令，用于指挥终端改变显示效果或行为。它解决的核心问题是：**如何在普通文本输出中夹带控制命令**。

终端接收到普通可显示字符时会直接将其渲染到屏幕；但遇到特定控制序列时，会将其解释为指令而非文本，从而改变颜色、移动光标、清屏等。

## ESC 控制字符

ANSI 转义序列以 **ESC**（Escape）控制字符开头。ESC 的编号为十进制 `27`、十六进制 `0x1B`、八进制 `033`。在代码中通常写作 `\x1B` 或 `\033`。

> ESC 不是普通字符 `E`、`S`、`C` 的组合，而是一个不可见的控制字符。它的作用是提示终端：后续字符应作为控制序列解析，而非普通文本。

## CSI 控制序列

大多数常见的 ANSI 转义序列属于 **CSI**（Control Sequence Introducer，控制序列引入符）类型。其通用结构为：

```text
ESC [ 参数 命令字符
```

| 部分 | 含义 |
|------|------|
| `ESC` | 转义序列开始 |
| `[` | 进入 CSI 控制序列 |
| `参数` | 控制命令的具体数值参数 |
| `命令字符` | 标识要执行的操作类型 |

例如 `ESC[36m` 中，`36` 是参数（青色前景色），`m` 是命令字符（设置显示属性）。

## SGR 显示属性序列

**SGR**（Select Graphic Rendition）是 ANSI 转义序列中最常用的子集，专门用于控制终端文本的显示属性。

### 基本格式

```text
ESC[参数m
```

### 显示属性的持续性

SGR 设置的是终端的**当前显示状态**，从该指令位置开始持续生效，直到遇到新的 SGR 指令或重置序列 `ESC[0m`。

```text
ESC[31merrorESC[0m
```

上述序列将 `error` 渲染为红色，随后 `ESC[0m` 恢复默认样式。

### 常见参数

#### 文本样式

| 参数 | 效果 |
|:--:|------|
| `0` | 重置所有属性 |
| `1` | 加粗 / 高亮 |
| `3` | 斜体 |
| `4` | 下划线 |
| `7` | 反色（交换前景/背景） |
| `9` | 删除线 |

> 不同终端对样式的支持存在差异。部分终端不支持斜体，部分终端将加粗渲染为更亮的颜色。

#### 基础前景色（30–37）

| 参数 | 颜色 |
|:--:|------|
| `30` | 黑色 |
| `31` | 红色 |
| `32` | 绿色 |
| `33` | 黄色 |
| `34` | 蓝色 |
| `35` | 洋红色 |
| `36` | 青色 |
| `37` | 白色 / 浅灰色 |

#### 基础背景色（40–47）

| 参数 | 颜色 |
|:--:|------|
| `40` | 黑色背景 |
| `41` | 红色背景 |
| `42` | 绿色背景 |
| `43` | 黄色背景 |
| `44` | 蓝色背景 |
| `45` | 洋红色背景 |
| `46` | 青色背景 |
| `47` | 白色 / 浅灰色背景 |

#### 高亮颜色（90–97 与 100–107）

| 参数范围 | 效果 |
|----------|------|
| `90` ~ `97` | 高亮前景色 |
| `100` ~ `107` | 高亮背景色 |

实际显示效果受终端主题影响，同一颜色编号在不同终端下可能存在视觉差异。

### 多参数组合

多个显示属性可通过分号 `;` 在同一序列中组合设置：

```text
ESC[1;33;44m
```

表示：**加粗 + 黄色前景色 + 蓝色背景**。

参数顺序不影响最终效果，`ESC[1;31m` 与 `ESC[31;1m` 等效。为便于阅读，通常按 **样式 → 前景色 → 背景色** 的顺序排列。

## 与其他概念的关系

- ANSI 转义序列中的 **ANSI** 指美国国家标准协会（American National Standards Institute），与 [[字符编码基础|ANSI 编码]]（Windows 代码页）是完全不同的概念，不应混淆
- 控制字符（如 ESC）与可打印字符共同构成字符集，但功能上属于不同类别
