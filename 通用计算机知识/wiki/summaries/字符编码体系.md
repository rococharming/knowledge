# 字符编码体系

本文系统梳理了字符编码的核心概念体系，从 ASCII 到 Unicode 再到 UTF-8/UTF-16 的演进脉络，以及各编码方式的特点与适用场景。

## 核心脉络

1. **ASCII** — 7 位英文编码，128 个字符，现代计算机字节处理时最高位补 0
2. **本地编码（ANSI）** — 各地区扩展方案，如 GBK、Big5，但跨地区互通性差，易产生乱码
3. **Unicode** — 统一字符集，为每个字符分配唯一码点，但不规定具体存储格式
4. **UTF-8 / UTF-16** — Unicode 的两种主流编码实现，各有优劣

## 关键概念区分

字符编码涉及三层含义：

- **字符**：人类看到的符号（如 `A`、`中`、`🙂`）
- **字符集**：规定有哪些字符及对应编号（如 ASCII、Unicode）
- **编码方式**：规定编号如何转成字节（如 UTF-8、UTF-16、GBK）

> 字符集回答"有哪些字符、编号是多少"，编码方式回答"编号如何变成字节"。
