# 创建 Git 仓库

本文介绍 Git 仓库的创建方式、核心目录结构、状态检查与忽略规则。

## 核心内容

### 仓库创建方式

| 方式 | 命令 | 场景 |
|------|------|------|
| 本地初始化 | `git init` | 从本地目录开始新项目 |
| 克隆远程 | `git clone <URL>` | 复制已有远程仓库 |

详见 [[Git 仓库]]。

### .git 目录

执行 `git init` 后生成的 `.git` 目录是仓库的核心，保存提交对象、分支引用、HEAD、暂存区索引和本地配置。

删除 `.git` 目录会让当前目录退化为普通文件夹，版本历史丢失但文件保留。

### 仓库状态检查

`git status` 用于查看当前目录是否是 Git 仓库、当前分支、是否有未跟踪文件等。Git 会向上级目录递归查找 `.git`，因此子目录中也能正常使用 Git 命令。

### .gitignore

用于指定不应纳入版本控制的文件或目录（如编译产物、依赖目录、日志、本地配置等）。

`.gitignore` **只影响尚未被 Git 跟踪的文件**。已被跟踪的文件即使加入 `.gitignore`，Git 仍会继续追踪其变更。需要先用 `git rm --cached <file>` 从索引中移除。

### 远程仓库克隆

`git clone` 不只是下载代码，还会：
- 获取完整的提交历史
- 初始化 `.git` 目录
- 保存远程分支与标签
- 添加默认远程别名 `origin`
