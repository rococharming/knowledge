# Git

Git 是一个**分布式版本控制系统**（Distributed Version Control System），用于追踪文件的变更历史，协调多人协作开发。

## 核心特性

| 特性 | 说明 |
|------|------|
| 分布式 | 每个开发者本地拥有完整的仓库副本和完整历史 |
| 快照式存储 | 每次提交保存项目完整状态的快照，而非差异 |
| 分支轻量 | 分支本质是指向提交的指针，创建与切换极快 |
| 离线工作 | 大部分操作在本地完成，无需持续连接服务器 |

## 主要功能

- **版本记录**：保存文件在不同时间点的状态
- **版本回退**：将代码恢复到任意历史提交
- **差异对比**：查看文件、提交、分支之间的变更
- **分支管理**：在不同分支上并行开发功能
- **协同开发**：通过远程仓库实现多人协作
- **问题追踪**：根据提交历史定位代码变化来源

## 历史

Git 由 Linus Torvalds 于 2005 年为管理 Linux 内核源码而开发。设计目标包括：速度、简单的设计、对非线性开发的强力支持、完全分布式、高效处理大型项目。

如今 Git 已成为软件开发的事实标准，也广泛用于文档管理、配置文件管理等场景。
