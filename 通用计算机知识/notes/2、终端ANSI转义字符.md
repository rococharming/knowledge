# 一、概述

终端ANSI转义字符解决的核心问题是：**如何在文本输出中夹带控制指令，让终端改变显示效果**。

终端接收到普通字符时，会把它们显示在屏幕上；但终端接收到某些特殊控制序列时，不会把它们当作普通文本显示，而是把它们解释成控制命令。

例如：

```text
\033[36mhello\033[0m
```

`\033[36m`和`\033[0m`就是控制序列。

终端实际处理过程是：

- `\033[36m`：设置后续文本为青色
- `hello`：显示普通文本
- `\033[0m`：恢复默认显示样式

例如，Python打印：

```python
print("\033[36mhello\033[0m")
```

![[assets/Pasted image 20260602222010.png]]

ANSI转义序列可以控制很多终端行为：

|控制类型|作用|示例|
|---|---|---|
|文本颜色|设置前景色、背景色|红色文字、蓝色背景|
|文本样式|设置加粗、下划线、反色|加粗提示、下划线标题|
|光标位置|移动光标、隐藏光标|进度条刷新|
|屏幕内容|清屏、清除当前行|命令行界面刷新|
本篇主要介绍最常见的一类：**SGR显示属性序列**。它用于控制文本颜色和文本样式。

# 二、普通文本和控制字符

## 1、普通文本

普通文本就是终端会直接显示出来的内容。

例如：

```text
hello
```

终端接收到这几个字符后，会在屏幕上显示：

```text
hello
```

这里的 `h`、`e`、`l`、`l`、`o` 都是普通可显示字符。

## 2、控制字符

控制字符不是用来直接显示的字符，而是用来控制设备行为的字符。

`ESC`就是一个典型控制字符。它的作用是告诉终端：

> 表示后面可能跟着一段控制序列，不要把它们当作普通文本处理

`ESC` 的编号如下：

|表示方式|值|
|---|---|
|十进制|`27`|
|十六进制|`0x1B`|
|八进制|`033`|

通常使用下面几种写法表示`ESC`：

| 写法     | 含义      |
| ------ | ------- |
| `ESC`  | 便于阅读的写法 |
| `\x1B` | 十六进制写法  |
| `\033` | 八进制写法   |
这些写法指向的是同一个控制字符。

需要注意：

> `ESC` 不是普通字符 `E`、`S`、`C`，而是一个不可见的控制字符。


# 三、ANSI转义序列的基本结构

## 1、转义序列

ANSI转义序列通常以`ESC`开头，后面跟随若干字符，用来表示某个终端控制命令。

可以理解为：ESC + 控制命令

例如：

```text
ESC[31m
```

表示设置后续文字为红色。

```text
ESC[0m
```

表示恢复默认显示样式。

ANSI转义序列本身属于文本流的一部分，但终端会把它解释为控制命令，而不是直接显示出来。

## 2、CSI控制序列

很多常见ANSI转义序列都属于`CSI`控制序列。

`CSI`是 Control Sequence Introducer 的缩写，即控制序列引入符。

常见格式为：

```text
ESC [ 参数 命令字符
```

也可以写成：

```
ESC[参数命令字符
```

各部分含义如下：

| 部分     | 含义            |
| ------ | ------------- |
| `ESC`  | 转义序列开始        |
| `[`    | 表示进入 CSI 控制序列 |
| `参数`   | 控制命令的具体参数     |
| `命令字符` | 表示要执行哪一类控制操作  |
例如：

```text
ESC[36m
```

可以拆成：

|部分|含义|
|---|---|
|`ESC`|转义序列开始|
|`[`|CSI 控制序列开始|
|`36`|参数，表示青色前景色|
|`m`|命令字符，表示设置显示属性|
因此`ESC[36m`表示把后续文本设置为青色。

`ESC [` 是 CSI 控制序列的常见开头形式，后面可以跟参数和命令字符。SGR 序列则使用 `m` 作为命令字符，用于设置显示属性。




# 四、SGR显示属性序列

## 1、SGR 的基本定位

`SGR` 是 `Select Graphic Rendition` 的缩写，用来设置终端中文字的显示属性。

SGR 主要控制：

- 前景色
- 背景色
- 加粗
- 下划线
- 反色
- 重置样式

SGR 的格式为：

```text
ESC[参数m
```

| 部分     | 含义         |
| ------ | ---------- |
| `ESC[` | CSI 控制序列开始 |
| `参数`   | 显示属性参数     |
| `m`    | SGR 命令字符   |
例如：

```text
ESC[31m
```

表示设置前景色为红色。

```text
ESC[36m
```

表示设置前景色为青色。

```text
ESC[0m
```

表示重置所有显示属性。

ECMA-48 标准中，SGR 序列的形式为 `ESC [ parameters m`，用于设置显示属性；多个属性可以在同一个序列中设置，并使用分号分隔。

## 2、显示属性的持续性

SGR 设置的是终端当前的显示状态。

也就是说`ESC[31m`不止是让下一个字符变红，而是从这里开始，后续输出都按红色显示，直到后面出现新的 SGR 序列修改它，或者使用重置序列恢复默认样式。

例如：

```
ESC[31merrorESC[0m
```

表示将`error`这段文本使用红色显示，`ESC[0m`会恢复默认样式。其中 `0` 表示重置所有显示属性。

## 3、常见显示属性参数

### （1）重置与文本样式

|  参数 | 含义      |
| --: | ------- |
| `0` | 重置所有样式  |
| `1` | 加粗 / 高亮 |
| `3` | 斜体      |
| `4` | 下划线     |
| `7` | 反色      |
| `9` | 删除线     |
示例：

```text
ESC[1m
```

表示加粗。

```text
ESC[4m
```

表示下划线。

```text
ESC[7m
```

表示反色，也就是交换前景色和背景色。

> 不同终端对样式的支持并不完全一致。例如，有些终端不支持斜体，有些终端会把加粗显示成更亮的颜色。


### （2）基础前景色

前景色指文字本身的颜色。

基础前景色参数如下：

|参数|颜色|
|--:|---|
|`30`|黑色|
|`31`|红色|
|`32`|绿色|
|`33`|黄色|
|`34`|蓝色|
|`35`|洋红色|
|`36`|青色|
|`37`|白色 / 浅灰色|

### （3）基础背景色

背景色指文字背后的颜色。

基础背景色参数如下：

|参数|颜色|
|--:|---|
|`40`|黑色背景|
|`41`|红色背景|
|`42`|绿色背景|
|`43`|黄色背景|
|`44`|蓝色背景|
|`45`|洋红色背景|
|`46`|青色背景|
|`47`|白色 / 浅灰色背景|

### （4）高亮颜色

很多终端还支持高亮颜色。

| 参数范围          | 含义    |
| ------------- | ----- |
| `90` ~ `97`   | 高亮前景色 |
| `100` ~ `107` | 高亮背景色 |
例如：

```text
ESC[91m
```

表示高亮红色文字。

```text
ESC[96m
```

表示高亮青色文字。

这些颜色的实际显示效果会受到终端主题影响。同一个颜色编号，在不同终端或不同主题下可能看起来不完全一样。

## 4、多个参数的组合

### （1）分号分隔参数

SGR可以一次设置多个显示属性。多个参数使用分号`;`分隔。

格式为：

```text
ESC[参数1;参数2;参数3m
```

例如：

```text
ESC[1;31m
```

表示加粗 + 红色前景色。

再例如：

```text
ESC[1;33;44m
```

表示加粗 + 黄色文字 + 蓝色背景。


### （2）组合参数的理解顺序

下面两种写法效果相同：

```text
ESC[1;31m
ESC[31;1m
```

它们都表示红色加粗。

为了阅读清楚，通常可以按照下面顺序理解：

```text
样式参数 ; 前景色参数 ; 背景色参数
```

例如：

```text
ESC[1;33;44m
```
