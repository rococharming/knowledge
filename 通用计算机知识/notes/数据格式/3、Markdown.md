# 一、概述

Markdown 是一种使用纯文本编写结构化文档的轻量级标记语言。它用少量符号表达标题、列表、链接、代码等结构，让作者能够专注于内容，而不必直接编写 HTML。

> [!abstract] 本文内容
> 本文先介绍通用 Markdown 语法，再介绍 Obsidian 提供的维基链接、嵌入、标注和属性等扩展。

# 二、文档结构

## 1. 标题

在行首使用 `#` 创建标题。`#` 的数量表示标题级别，最多支持六级：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

一级和二级标题也可以使用 Setext 语法：

```markdown
一级标题
========

二级标题
--------
```

推荐使用 `#` 形式，因为层级更直观，也更便于统一维护。

## 2. 段落与换行

使用空白行分隔段落：

```markdown
这是第一个段落。

这是第二个段落。
```

单次回车通常不会创建新段落。如果需要在同一段落内强制换行，可以在行尾添加两个空格，或使用 `<br>`：

```markdown
第一行<br>
第二行
```

> [!tip]
> 行尾空格不易察觉，也可能被格式化工具删除。需要明确换行时，`<br>` 通常更容易维护。

普通段落不应使用空格或制表符缩进；行首四个空格通常会被解析为代码块。

## 3. 分隔线

单独一行输入三个或更多 `-`、`*` 或 `_` 可以创建分隔线：

```markdown
---
***
___
```

使用 `---` 时，前后应保留空行，以免它被误判为 Setext 二级标题或 YAML frontmatter。

# 三、文字格式

## 1. 粗体、斜体与删除线

| 效果 | 语法 | 示例 |
| --- | --- | --- |
| 粗体 | `**文本**` | **粗体文本** |
| 斜体 | `*文本*` | *斜体文本* |
| 粗斜体 | `***文本***` | ***粗斜体文本*** |
| 删除线 | `~~文本~~` | ~~删除文本~~ |

在 Obsidian 中，粗体快捷键通常为 <kbd>Ctrl</kbd> + <kbd>B</kbd>（Windows）或 <kbd>Command</kbd> + <kbd>B</kbd>（macOS），斜体快捷键通常为 <kbd>Ctrl</kbd> + <kbd>I</kbd> 或 <kbd>Command</kbd> + <kbd>I</kbd>。

> [!warning] Obsidian 中文排版
> 中文正文中的粗体标记两侧应留空格，例如：`这是 **重点内容** 示例`，以避免解析异常。

## 2. 转义字符

在 Markdown 中，反斜杠 `\` 可以取消部分符号的语法含义：

```markdown
\*这不是斜体\*
\# 这不是标题
```

也可以使用 HTML 字符实体表示特殊字符：

| 字符 | 实体 |
| --- | --- |
| `<` | `&lt;` |
| `>` | `&gt;` |
| `"` | `&quot;` |
| `'` | `&apos;` |
| `&` | `&amp;` |
| `©` | `&copy;` |
| `™` | `&trade;` |
| 空格 | `&nbsp;` |

# 四、引用与列表

## 1. 块引用

在段落前添加 `>` 创建块引用：

```markdown
> 这是块引用。
>
> 这是同一块引用中的第二个段落。
```

增加 `>` 可以创建嵌套引用：

```markdown
> 外层引用
>
> > 内层引用
```

## 2. 有序列表

数字后紧跟英文句点和空格：

```markdown
1. 第一项
2. 第二项
   1. 嵌套项
3. 第三项
```

## 3. 无序列表

使用 `-`、`*` 或 `+` 创建无序列表。为保持风格统一，通常推荐使用 `-`：

```markdown
- 第一项
- 第二项
  - 嵌套项
- 第三项
```

## 4. 任务列表

任务列表是在无序列表标记后添加 `[ ]` 或 `[x]`：

```markdown
- [x] 学习 Markdown 基础语法
- [ ] 学习 Obsidian 扩展语法
```

| 写法 | 状态 |
| --- | --- |
| `- [ ]` | 未完成 |
| `- [x]` | 已完成 |

在 Obsidian 中，通常可以使用 <kbd>Ctrl</kbd> + <kbd>L</kbd>（Windows）或 <kbd>Command</kbd> + <kbd>L</kbd>（macOS）切换任务状态。

# 五、代码

## 1. 行内代码

使用一对反引号包裹短代码：

```markdown
在 Rust 中，可以使用 `let` 声明变量。
```

如果内容本身包含反引号，可以使用两个反引号作为边界：

`````markdown
``使用 `code` 表示行内代码。``
`````

## 2. 围栏代码块

使用三个反引号包裹多行代码，并在开头注明语言以启用语法高亮：

````markdown
```rust
fn main() {
    println!("Hello, Markdown!");
}
```
````

# 六、链接与图片

## 1. 普通链接

外部链接使用标准 Markdown 语法：

```markdown
[Markdown Guide](https://www.markdownguide.org)
```

链接还可以添加可选标题：

```markdown
[Markdown 中文教程](https://markdown.com.cn "Markdown 教程")
```

## 2. 自动链接

使用尖括号可以把 URL 或邮箱地址转换为链接：

```markdown
<https://markdown.com.cn>
<fake@example.com>
```

## 3. 引用式链接

引用式链接把正文与地址定义分开，适合需要重复引用或链接较多的文档：

```markdown
阅读 [Markdown Guide][guide] 了解更多语法。

[guide]: https://www.markdownguide.org
```

## 4. 图片

标准 Markdown 图片语法是在链接前添加 <kbd>!</kbd>：

```markdown
![图片替代文本](https://example.com/image.jpg "可选标题")
```

也可以为图片添加链接：

```markdown
[![图片替代文本](./assets/image.jpg)](https://example.com)
```

> [!note]
> 在本知识库中，仓库内附件统一存放于顶层 `assets/`，并优先使用 Obsidian 嵌入语法，参见 [[#3. 嵌入内容]]。

# 七、表格与脚注

## 1. 表格

表格由表头、分隔行和数据行组成：

```markdown
| 姓名 | 角色 | 状态 |
| --- | --- | --- |
| 小明 | 开发者 | 进行中 |
| 小红 | 设计师 | 已完成 |
```

在分隔行中使用冒号控制对齐：

| 写法 | 对齐方式 |
| --- | --- |
| `:---` | 左对齐 |
| `:---:` | 居中 |
| `---:` | 右对齐 |
| `---` | 默认对齐 |

## 2. 脚注

脚注由正文中的引用和文末的定义组成：

```markdown
这是一个普通脚注[^1]，这是一个命名脚注[^note]。

[^1]: 这是第一个脚注。
[^note]: 这是命名脚注的内容。
```
