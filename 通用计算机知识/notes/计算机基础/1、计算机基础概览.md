# 一、整体视角

计算机基础关注的是一台计算机如何执行任务、保存数据、连接网络、保护访问权限，以及如何作为开发工作的运行环境。

对日常使用和编程入门来说，最先需要建立几个心智模型：计算在哪里发生，数据如何临时使用和长期保存，网络如何接入，账号如何保护，开发者通常用哪些工具完成工作。

# 二、硬件组成

计算机是一台执行指令、处理数据、保存结果的通用机器。常见个人电脑（PC）可以先理解为几类核心部件的协作。

| 部件 | 主要职责 | 直观类比 |
|---|---|---|
| CPU | 执行指令和计算 | 大脑 |
| RAM | 临时存放正在使用的数据 | 工作台 |
| SSD / HDD | 长期保存文件和软件 | 仓库 |
| 主板 | 连接所有部件并提供通信通道 | 城市道路和接口 |
| PSU | 把外部电力转换成电脑可用电力 | 供电系统 |

CPU（Central Processing Unit，中央处理器）负责执行程序指令。主频常用 GHz 表示，但电脑是否流畅不只取决于 CPU，还会受内存、硬盘、散热和软件负载影响。

RAM（Random Access Memory，随机访问存储器）是电脑的短期记忆。正在运行的程序、打开的文件、浏览器标签页等都会占用 RAM。RAM 速度快，但断电后内容会消失，所以重要文件必须保存到磁盘。

SSD（Solid State Drive，固态硬盘）和 HDD（Hard Disk Drive，机械硬盘）用于长期保存文件和软件。SSD 使用闪存芯片，速度快、体积小；HDD 使用旋转盘片，容量大、价格低，但速度和抗震性较弱。现代电脑通常优先用 SSD 做系统盘。

主板负责连接 CPU、内存、硬盘、显卡、网卡等部件。

PSU（Power Supply Unit，电源供应器）负责把外部电力转换成电脑可用电力。

GPU（Graphics Processing Unit，图形处理器）主要负责图形渲染，也可用于视频处理、机器学习等并行计算任务。

> 判断电脑卡顿时要有“瓶颈”意识：开机和打开软件慢，常见瓶颈是硬盘；浏览器标签页多就卡，常见瓶颈是 RAM；编译、压缩慢，常见瓶颈是 CPU；游戏或图形软件卡顿，常见瓶颈是 GPU。

# 三、输入设备

键盘、鼠标、触控板、轨迹球等都属于输入设备。它们不仅影响操作效率，也影响长期使用电脑时的手腕、肩颈和背部负担。

使用鼠标时，应尽量保持轻握，不要长期用力抓住鼠标。键盘和鼠标高度应尽量接近，鼠标放在键盘旁边，避免手腕过度上翘、下压或向外扭。

坐姿也不应理解成“坐直不动”。更可持续的方式是动态坐姿：定期变换姿势、起身走动、伸展肩颈和手腕。人体工学键盘和鼠标可以降低部分负担，但不一定一开始就需要购买；如果长期手腕酸痛、肩膀紧张，再考虑更换设备更有针对性。

快捷键的价值不只是更快，也能减少高频重复的鼠标动作。入门时可以先掌握复制、粘贴、撤销、搜索、保存、窗口切换、浏览器标签页切换等高频操作。

# 四、网络接入

ISP（Internet Service Provider，互联网服务提供商）是向个人、家庭或企业提供互联网接入服务的公司。用户通过 ISP 接入更大的互联网，再访问网站、云服务、邮件、视频平台等资源。

在中国，ISP的典型例子就是中国电信、中国移动、中国联通、中国广电。

ISP 可以粗略分为三层：Tier 1 通常拥有大型骨干网络；Tier 2 覆盖国家或较大区域，可能向更大网络购买部分传输能力；Tier 3 更接近本地市场，直接服务家庭、社区或城市用户。

常见接入方式如下：

| 类型 | 基础设施 | 特点 |
|---|---|---|
| 光纤 | 玻璃或塑料光纤 | 速度高、延迟低，现代宽带主流 |
| Cable | 有线电视同轴电缆 | 覆盖广，速度可能受共享线路影响 |
| DSL | 电话线 | 覆盖广，但速度通常较慢 |
| Dial-up | 电话线拨号 | 早期技术，基本淘汰 |
| 卫星网络 | 卫星链路 | 适合偏远地区，易受覆盖和天气影响 |
| 5G 家庭宽带 | 移动通信基站 | 部署灵活，受信号和拥塞影响 |

比如家里装宽带，师傅来拉光纤、装光猫、开通一个宽带账号，这个宽带服务通常就是由中国电信 / 联通 / 移动 / 广电这类 ISP 提供的。

手机上网也是类似的：你的手机插着中国移动的 SIM 卡，用 5G/4G 上网时，中国移动就是你的移动网络 ISP。

选择网络时，不只看下载速度。视频会议和云备份更关注上行带宽和稳定性；游戏和远程桌面更关注延迟和抖动；家庭多人同时使用还要考虑路由器、Wi-Fi 覆盖和设备数量。

# 五、安全登录

安全登录的目标，是让电脑和账号只被授权的人使用。个人电脑里通常保存着浏览器会话、聊天记录、照片、文档、代码、密钥和云服务登录状态，因此登录保护非常基础。

好密码的核心不是“看起来复杂”，而是足够长、难猜、不要复用。应避免 `123456`、`password`、姓名、生日、手机号、地址等常见或容易推断的信息。重要账号建议使用密码管理器生成和保存不同密码。

2FA（Two-Factor Authentication，双因素认证）要求登录时提供第二种证明，例如一次性验证码、验证器 App、硬件安全密钥或生物识别。它的意义是：即使密码泄露，攻击者仍然缺少第二个因素。

Windows Hello、Touch ID 等生物识别方式可以提升日常使用的安全性和便利性，但仍需要强密码作为后备。离开电脑时及时锁屏、保持系统和浏览器更新，也是登录安全的一部分。

# 六、开发工具

开发者工具链是一组配合使用的工具，用来完成“写代码、运行代码、管理依赖、追踪变更、测试、调试、发布”的循环。

常见工具可以先按职责理解：

| 工具类型      | 解决的问题             | 例子                                          |
| --------- | ----------------- | ------------------------------------------- |
| 编辑器 / IDE | 编写、阅读、调试代码        | VS Code、Visual Studio、IntelliJ IDEA、PyCharm |
| 版本控制      | 记录代码变化、协作、回退      | Git                                         |
| 远程仓库平台    | 托管代码、协作评审         | GitHub、GitLab、Bitbucket                     |
| 包管理器      | 安装和管理依赖           | npm、Yarn、pnpm、pip、Composer、Maven            |
| 测试框架      | 自动验证代码是否符合预期      | Jest、pytest、JUnit、Cypress、Playwright        |
| 浏览器开发者工具  | 调试网页结构、样式、脚本和网络请求 | Chrome DevTools、Firefox DevTools            |

编辑器通常轻量、灵活、依赖插件扩展（如 VS Code）；IDE（Integrated Development Environment，集成开发环境）通常更重（如 PyCharm），但内置项目管理、代码分析、调试、测试和构建能力。大型项目、强类型语言、复杂调试场景中，IDE 往往更省心。

Git 是目前最常用的版本控制系统，用于记录代码变化、比较差异、撤销错误和支持多人协作。Git 的安装和基础配置见 [[通用计算机知识/notes/Git/01_本地仓库与提交基础/1、Git 安装与配置|Git 安装与配置]]。
